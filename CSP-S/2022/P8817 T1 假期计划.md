# P8817 CSP-S 2022 T1 假期计划

## 题意

$n \le 2500$ 个点、$m \le 10^4$ 条边的无向图，1 号是家。选 4 个不同景点 $A, B, C, D$，使 家→A→B→C→D→家 每段都能在转车 $\le k$ 次（即距离 $\le k+1$）内到达，最大化四个景点分数和。

**标签**：BFS、枚举、贪心（前 3 大）　**难度**：6/10

## 解题思路

### 1. 底层逻辑

1. 求任意两点之间是否"可达"（距离 $\le k+1$）：边权都是 1，从每个点 BFS 一次。
2. 选 4 个点：直接枚举 $O(n^4)$ 不行。**枚举中间两个点 $B, C$**，$A$ 只和 $B$ 有关（要求 家–A、A–B 可达），$D$ 只和 $C$ 有关，各自贪心取分数最大的即可。

### 2. 隐藏条件

- 对固定的 $B$，最优的 $A$ 可能与 $C$ 或 $D$ 冲突（四个点要互不相同）。冲突的点最多 2 个（$C$ 和 $D$），所以为每个 $B$ 预处理**分数前 3 大**的合法 $A$ 就足够，$D$ 同理。
- 于是枚举 $(B, C)$ 后只需检查 $3 \times 3$ 种组合是否互不相同。

### 3. 注意事项

- "转车 $k$ 次"对应 $k+1$ 条边，BFS 距离上限是 $k+1$。
- 分数到 $10^{18}$，四个相加 $4 \times 10^{18}$ 仍在 `long long` 范围内。
- 预处理前 3 大时，$A \ne B$，且 $A$ 不能是家（$A$ 从 2 开始枚举）。
- 可达矩阵 $2500^2$ 的 `bool` 约 6MB。

### 4. 解决方案

1. 从每个点 BFS（距离 $\le k+1$ 时停止扩展），得到 `ok[x][y]`。
2. 对每个景点 $B$，在所有满足 `ok[1][A] && ok[A][B]`、$A \ne B$ 的 $A$ 中保留分数前 3 大，存入 `best[B]`。
3. 枚举 `ok[B][C]` 的 $(B, C)$，对 `best[B]` 中的 $A$ 和 `best[C]` 中的 $D$，若 $A \ne C$、$D \ne B$、$A \ne D$，更新答案。

复杂度 $O(n(n+m) + 9n^2)$。

## 部分分策略 / 错误思路

- $n \le 20$：直接枚举 4 个点。
- $n \le 300$：枚举 $A, B, C$ 再找最优 $D$，$O(n^3)$ 或更高。
- 只保留前 1 大或前 2 大：会因为与 $C$、$D$ 冲突而漏解。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2505;
int n, m, k, ans;
int s[N], d[N];
bool ok[N][N];
vector<int> g[N], best[N];

void bfs(int st) {
    For(i, 1, n) d[i] = -1;
    queue<int> q;
    d[st] = 0, q.push(st);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        if (u != st) ok[st][u] = true;
        if (d[u] == k + 1) continue;
        for (int v : g[u])
            if (d[v] == -1) d[v] = d[u] + 1, q.push(v);
    }
}

void solve() {
    cin >> n >> m >> k;
    For(i, 2, n) cin >> s[i];
    For(i, 1, m) {
        int x, y;
        cin >> x >> y;
        g[x].pb(y), g[y].pb(x);
    }
    For(i, 1, n) bfs(i);
    For(b, 2, n) For(a, 2, n) {
        if (a == b || !ok[1][a] || !ok[a][b]) continue;
        best[b].pb(a);
        for (int i = best[b].size() - 1; i > 0 && s[best[b][i]] > s[best[b][i - 1]]; i--) swap(best[b][i], best[b][i - 1]);
        if (best[b].size() > 3) best[b].pop_back();
    }
    For(b, 2, n) For(c, 2, n) {
        if (b == c || !ok[b][c]) continue;
        for (int a : best[b])
            for (int dd : best[c])
                if (a != c && dd != b && a != dd) ans = max(ans, s[a] + s[b] + s[c] + s[dd]);
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
