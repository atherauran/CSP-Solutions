# P8820 CSP-S 2022 T4 数据传输

## 题意

$n$ 个点的树，点权 $v_i$。树上距离 $\le k$ 的两点可以直接传输。$Q$ 次询问 $s \to t$ 的传输方案中，经过（含两端）的点权和最小值。$n, Q \le 2 \times 10^5$，$k \le 3$。

**标签**：树上倍增、动态 DP（min-plus 矩阵）、LCA　**难度**：9/10

## 解题思路

### 1. 底层逻辑

把 $s \to t$ 的树上路径看成一个序列，相当于在序列上选若干点（首尾必选），相邻选点"距离 $\le k$"，最小化点权和——这是一个线性 DP。多次询问、路径不同，就要把 DP 写成**矩阵乘法**的形式，用倍增预处理"往上跳 $2^i$ 步"的转移矩阵。

### 2. 隐藏条件

- **$k \le 2$ 时只会选路径上的点**：绕到路径外的点不会让跨度更大。
- **$k = 3$ 时可能选路径外的点**，但只会选与路径上某点**相邻**的点，而且选权值最小的邻居 $mn_u$ 即可。（例：路径 $a - u - b$ 中间若干点权很大，跳到 $u$ 的一个小权邻居再跳出去。）
- DP 状态：$f_j$ = 最后一个选中的点到"当前路径点"的距离为 $j$ 时的最小代价（$j < k$）。走到下一个路径点 $u$：
  - $f'_0 = \min(f_0, f_1, f_2) + v_u$（选 $u$）
  - $f'_1 = \min(f_0,\ f_1 + mn_u)$（$k = 3$ 时：上一个点离 $u$ 为 2 时，可以选 $u$ 的邻居）
  - $f'_2 = f_1$

  写成 $(\min, +)$ 矩阵 $M_u$：$f' = M_u \otimes f$。$k$ 较小时多余的状态置为 $+\infty$。
- 路径分成 $s \to lca$ 和 $t \to lca$ 两段，**都是往上走**，所以只需要"向上"方向的倍增矩阵；两段在 $lca$ 处合并。

### 3. 注意事项

- **合并**：$f$、$h$ 分别是两侧到达 $lca$ 时的状态。
  - 两侧最后选中的点距离 $i + j \le k$ 即可连通，代价 $f_i + h_j$；若 $i = j = 0$，$lca$ 被算了两次，要减去 $v_{lca}$。
  - $k = 3$ 时还可以在 $lca$ 的邻居处"搭桥"：代价 $f_i + h_j + mn_{lca}$。
- min-plus 矩阵乘法不满足交换律，倍增合并时注意顺序：先走的矩阵在右边。
- 询问时用"向量 × 矩阵"而不是"矩阵 × 矩阵"，单次 $O(k^2 \log n)$。
- 矩阵用 `long long` 存约 260MB，在 1GB 限制内。
- 建树用 BFS 序，避免递归太深。

### 4. 解决方案

1. BFS 求 `fa`、`dep`，每个点的最小邻居权 `mn`。
2. 倍增：`up[u][0]` = $M_{fa_u}$，`up[u][i]` = `up[mid][i-1]` $\otimes$ `up[u][i-1]`（$mid$ 为 $2^{i-1}$ 级祖先）。
3. 询问 $(s, t)$：求 $l = lca$；$f = (v_s, \infty, \infty)$，按二进制拆分把 $s$ 跳到 $l$，每跳一段 $f \gets up \otimes f$；$t$ 同理得到 $h$。
4. 按上面的合并规则取最小值输出。

复杂度 $O(nk^3\log n + Qk^2\log n)$。

## 部分分策略 / 错误思路

- $n, Q \le 2000$：每次询问把路径取出来做线性 DP，$O(nQ)$。
- $k = 1$：路径点权和，前缀和 + LCA。
- 特殊性质（随机树，深度 $O(\log n)$）：暴力取路径做 DP 即可。
- $k = 3$ 时只在路径上 DP：会漏掉"跳到路径外邻居"的情况，WA。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2e5 + 5, LG = 18;
int n, q, k;
int v[N], mn[N], dep[N], fa[N][LG];
vector<int> g[N];
struct mat { int a[3][3]; } up[N][LG];

mat mul(const mat &x, const mat &y) {
    mat r;
    Rep(i, 0, 3) Rep(j, 0, 3) {
        r.a[i][j] = LINF;
        Rep(t, 0, 3) r.a[i][j] = min(r.a[i][j], x.a[i][t] + y.a[t][j]);
    }
    return r;
}

mat trans(int u) {
    mat r;
    Rep(i, 0, 3) Rep(j, 0, 3) r.a[i][j] = LINF;
    Rep(j, 0, k) r.a[0][j] = v[u];
    if (k >= 2) r.a[1][0] = 0;
    if (k == 3) r.a[1][1] = mn[u], r.a[2][1] = 0;
    return r;
}

void lift(int &x, int steps, int f[]) {
    for (int i = 0; steps; i++, steps >>= 1)
        if (steps & 1) {
            int nf[3];
            Rep(r, 0, 3) {
                nf[r] = LINF;
                Rep(c, 0, 3) nf[r] = min(nf[r], up[x][i].a[r][c] + f[c]);
            }
            Rep(r, 0, 3) f[r] = nf[r];
            x = fa[x][i];
        }
}

int lca(int x, int y) {
    if (dep[x] < dep[y]) swap(x, y);
    for (int i = LG - 1; i >= 0; i--)
        if (dep[x] - (1 << i) >= dep[y]) x = fa[x][i];
    if (x == y) return x;
    for (int i = LG - 1; i >= 0; i--)
        if (fa[x][i] != fa[y][i]) x = fa[x][i], y = fa[y][i];
    return fa[x][0];
}

void solve() {
    cin >> n >> q >> k;
    For(i, 1, n) cin >> v[i], mn[i] = LINF;
    Rep(i, 1, n) {
        int a, b;
        cin >> a >> b;
        g[a].pb(b), g[b].pb(a);
        mn[a] = min(mn[a], v[b]), mn[b] = min(mn[b], v[a]);
    }
    vector<int> ord;
    ord.pb(1), dep[1] = 1;
    Rep(i, 0, n) {
        int u = ord[i];
        for (int w : g[u])
            if (w != fa[u][0]) fa[w][0] = u, dep[w] = dep[u] + 1, ord.pb(w);
    }
    for (int u : ord) {
        if (u == 1) continue;
        up[u][0] = trans(fa[u][0]);
        Rep(i, 1, LG) {
            int mid = fa[u][i - 1];
            fa[u][i] = fa[mid][i - 1];
            if (dep[u] > (1 << i)) up[u][i] = mul(up[mid][i - 1], up[u][i - 1]);
        }
    }
    while (q--) {
        int s, t;
        cin >> s >> t;
        int l = lca(s, t);
        int f[3] = {v[s], LINF, LINF}, h[3] = {v[t], LINF, LINF};
        lift(s, dep[s] - dep[l], f), lift(t, dep[t] - dep[l], h);
        int ans = LINF;
        Rep(i, 0, k) Rep(j, 0, k) {
            if (i + j <= k) ans = min(ans, f[i] + h[j] - (i == 0 && j == 0 ? v[l] : 0));
            if (k == 3) ans = min(ans, f[i] + h[j] + mn[l]);
        }
        cout << ans << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
