# P8818 CSP-S 2022 T2 策略游戏

## 题意

数组 $A$（长 $n$）和 $B$（长 $m$），$q$ 轮游戏：小 L 在 $A[l_1..r_1]$ 中选 $x$，然后小 Q 在 $B[l_2..r_2]$ 中选 $y$，得分 $A_x B_y$。L 要最大、Q 要最小，求每轮得分。$n, m, q \le 10^5$，值可负。

**标签**：博弈、分类讨论、ST 表（RMQ）　**难度**：5/10

## 解题思路

### 1. 底层逻辑

倒着想：L 选定 $a = A_x$ 后，Q 的最优回应只取决于 $a$ 的符号：
- $a \ge 0$：Q 选 $B$ 区间最小值 $mn$，得分 $a \cdot mn$；
- $a < 0$：Q 选 $B$ 区间最大值 $mx$，得分 $a \cdot mx$。

L 在区间里选 $a$ 使 $f(a)$ 最大。

### 2. 隐藏条件

$f(a)$ 在 $a \ge 0$ 时是关于 $a$ 的线性函数，在 $a < 0$ 时也是，所以最大值只可能在每一段的**端点**取到。候选只有 4 个：
- $A$ 区间最大值、最小值；
- 最小的非负数；
- 最大的负数（最接近 0 的负数）。

### 3. 注意事项

- 需要 6 个区间最值：$A$ 的最大、最小、最小非负、最大负数，$B$ 的最大、最小；用 ST 表 $O(1)$ 查询。
- 不存在非负数（或负数）时用 $\pm\infty$ 占位并跳过。
- 乘积可达 $10^{18}$，用 64 位。

### 4. 解决方案

1. 建 6 张 ST 表。$A$ 中负数在"最小非负"表里记为 $+\infty$，非负数在"最大负数"表里记为 $-\infty$。
2. 每次询问求出 $B$ 区间的 $mx, mn$ 和 4 个候选 $a$，对存在的候选算 $f(a)$ 取最大。

复杂度 $O((n+m)\log + q)$。

## 部分分策略 / 错误思路

- 暴力枚举 $x, y$：$O(q \cdot nm)$，只能过小数据。
- 全为正数：答案就是 $\max A \cdot \min B$。
- 只考虑 $A$ 的最大最小值：漏掉"选接近 0 的数让对方无处可去"的情况（如 $B$ 有正有负时，选 0 最优）。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5, LG = 17;
int n, m, q;
int lg[N];
int amx[N][LG], amn[N][LG], anz[N][LG], ang[N][LG], bmx[N][LG], bmn[N][LG];

inline int qmax(int st[][LG], int l, int r) {
    int k = lg[r - l + 1];
    return max(st[l][k], st[r - (1 << k) + 1][k]);
}

inline int qmin(int st[][LG], int l, int r) {
    int k = lg[r - l + 1];
    return min(st[l][k], st[r - (1 << k) + 1][k]);
}

void build(int st[][LG], int len, bool isMax) {
    Rep(k, 1, LG) For(i, 1, len - (1 << k) + 1) {
        int x = st[i][k - 1], y = st[i + (1 << (k - 1))][k - 1];
        st[i][k] = isMax ? max(x, y) : min(x, y);
    }
}

void solve() {
    cin >> n >> m >> q;
    For(i, 2, max(n, m)) lg[i] = lg[i / 2] + 1;
    For(i, 1, n) {
        int a;
        cin >> a;
        amx[i][0] = amn[i][0] = a;
        anz[i][0] = a >= 0 ? a : LINF;
        ang[i][0] = a < 0 ? a : -LINF;
    }
    For(i, 1, m) cin >> bmx[i][0], bmn[i][0] = bmx[i][0];
    build(amx, n, true), build(amn, n, false), build(anz, n, false), build(ang, n, true);
    build(bmx, m, true), build(bmn, m, false);
    while (q--) {
        int l1, r1, l2, r2;
        cin >> l1 >> r1 >> l2 >> r2;
        int mx = qmax(bmx, l2, r2), mn = qmin(bmn, l2, r2), ans = -LINF;
        int c[4] = {qmax(amx, l1, r1), qmin(amn, l1, r1), qmin(anz, l1, r1), qmax(ang, l1, r1)};
        for (int a : c) {
            if (a == LINF || a == -LINF) continue;
            ans = max(ans, a >= 0 ? a * mn : a * mx);
        }
        cout << ans << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
