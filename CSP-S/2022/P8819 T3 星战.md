# P8819 CSP-S 2022 T3 星战

## 题意

$n$ 点 $m$ 条有向边，四种操作：删一条边、删某点的所有入边、恢复一条边、恢复某点的所有入边。每次操作后判断：是否所有点的出度都恰好为 1（并且从任意点出发能无限走下去）。$n, m, q \le 5 \times 10^5$。

**标签**：哈希、随机化　**难度**：7/10

## 解题思路

### 1. 底层逻辑

"所有点都能实现连续穿梭" = 每个点出度恰好为 1。此时图是基环内向森林，从任何点出发都能一直走下去，"反击"条件自动满足。所以只需判断**每个点出度都是 1**。

难点：操作 2、4 是按**入边**批量修改的，维护出度需要遍历入边，会超时。

### 2. 隐藏条件

- 必要条件：总边数 $= n$。但不充分（可能一个点出度 2、另一个 0）。
- **哈希**：给每个点 $u$ 随机一个 64 位权值 $w_u$，令一条边 $u \to v$ 的权值为 $w_u$（起点的权值）。"每个点出度都为 1" ⇔ 当前所有边的权值和**恰好等于** $\sum_u w_u$（每个起点恰好出现一次）。不等价时相等的概率极小。
- 这个和可以**按终点分组**维护：$cur_v$ 为当前指向 $v$ 的边的权值和，$org_v$ 为所有指向 $v$ 的边的权值和。批量删/恢复 $v$ 的入边只需改 $cur_v$，$O(1)$。

### 3. 注意事项

- 用 `unsigned long long` 自然溢出，加减都在模 $2^{64}$ 下进行，不影响判断。
- 随机数用 `mt19937_64`，不要用 `rand()`（范围太小，容易冲突）。
- 题目保证操作 1、3 的边状态合法，操作 2、4 可能无效果，直接按公式算即可（无效果时改变量为 0）。

### 4. 解决方案

- 预处理：$target = \sum w_u$；$org_v = \sum_{u \to v} w_u$；$cur_v = org_v$，$sum = \sum cur_v$。
- 操作 1 $(u,v)$：$cur_v \mathrel{-}= w_u$，$sum \mathrel{-}= w_u$；
- 操作 2 $u$：$sum \mathrel{-}= cur_u$，$cur_u = 0$；
- 操作 3 $(u,v)$：$cur_v \mathrel{+}= w_u$，$sum \mathrel{+}= w_u$；
- 操作 4 $u$：$sum \mathrel{+}= org_u - cur_u$，$cur_u = org_u$；
- 每次输出 $sum = target$ ? `YES` : `NO`。

复杂度 $O(n + m + q)$。

## 部分分策略 / 错误思路

- 每次操作后 $O(n + m)$ 重新统计出度：40 分。
- 只有操作 1、3：直接维护出度和"出度为 1 的点数"。
- 只判断总边数 $= n$：错误，但能骗到不少分。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 5e5 + 5;
int n, m, q;
ull w[N], cur[N], org[N], sum, target;

void solve() {
    cin >> n >> m;
    mt19937_64 rng(20221029);
    For(i, 1, n) w[i] = rng(), target += w[i];
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        org[v] += w[u];
    }
    For(i, 1, n) cur[i] = org[i], sum += org[i];
    cin >> q;
    while (q--) {
        int t, u, v;
        cin >> t >> u;
        if (t == 1) cin >> v, cur[v] -= w[u], sum -= w[u];
        if (t == 2) sum -= cur[u], cur[u] = 0;
        if (t == 3) cin >> v, cur[v] += w[u], sum += w[u];
        if (t == 4) sum += org[u] - cur[u], cur[u] = org[u];
        cout << (sum == target ? "YES" : "NO") << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
