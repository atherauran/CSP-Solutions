# P9755 CSP-S 2023 T4 种树

## 题意

$n \le 10^5$ 个点的树，从 1 号点开始，每天在一个与已种点相邻的点上种一棵树（第 1 天种 1 号）。第 $x$ 天点 $i$ 的树长高 $\max(b_i + x c_i, 1)$。求所有点的树高都 $\ge a_i$ 的最少天数。$a_i \le 10^{18}$，答案 $\le 10^9$。

**标签**：二分答案、贪心、树　**难度**：8/10

## 解题思路

### 1. 底层逻辑

答案有单调性（$T$ 天能完成，$T+1$ 天也能）→ **二分答案** $T$。

固定 $T$ 后：每个点 $i$ 有一个**最晚种植日** $d_i$（在 $d_i$ 当天及以前种下，到第 $T$ 天才能长够）。问题变成：能否安排一个合法的种植顺序（父亲先于儿子），使每个点都在截止日前种下。

### 2. 隐藏条件

- **求 $d_i$**：种得越早长得越多，所以 $d_i$ 可以再二分：找最大的 $t$ 使第 $t$ 到 $T$ 天的生长量 $\ge a_i$。生长量是分段的等差数列求和：
  - $c \ge 0$：$b + xc \ge 1$ 恒成立，直接等差求和；
  - $c < 0$：$x \le \lfloor (b-1)/(-c) \rfloor$ 时为 $b + xc$，之后每天为 1，分两段求和。
- **树形约束**：儿子必须晚于父亲种，所以父亲的截止日要收紧：$d_{fa} \le d_u - 1$。从叶子往上传递一遍后，截止日严格满足"父亲 < 儿子"。
- **调度**：每天种一棵，按截止日从小到大种（经典的"截止日期排序贪心"）。收紧后父亲的截止日更小，所以这个顺序自动满足"父亲先种"；而且按截止日排序后父亲已种、该点就能种（连通性满足）。可行 ⇔ 排序后第 $i$ 个截止日 $\ge i$。

### 3. 注意事项

- 生长量最大约 $10^9 \times 10^9 \times 10^9$，必须用 `__int128`。
- $c < 0$ 时注意"每天至少长 1"那一段。
- 二分下界为 $n$（至少要 $n$ 天才能种完）。
- 复杂度 $O(n \log^2 V + n \log n \log V)$，$V = 10^9$。
- 用 BFS 序代替 DFS，倒序扫即可完成"从叶到根"的收紧。

### 4. 解决方案

1. BFS 求父亲和 BFS 序。
2. 二分 $T \in [n, 10^9]$，`check(T)`：
   - 对每个点，若 $[1, T]$ 的生长量都不够，返回 false；否则二分出 $d_i$；
   - 按 BFS 序倒序，$d_{fa_u} = \min(d_{fa_u}, d_u - 1)$；
   - 把 $d$ 排序，若存在 $s_i < i$ 返回 false，否则 true。
3. 输出最小可行的 $T$。

## 部分分策略 / 错误思路

- 性质 A（$c = 0$）：每天生长量固定，$d_i$ 可以直接算。
- 性质 B（链）：顺序固定，直接逐个算完成时间取最大。
- 性质 D（菊花）：除根以外任意顺序，按截止日排序即可。
- 不收紧父亲的截止日而直接排序：可能先安排儿子再安排父亲，判断错误。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5;
int n;
int a[N], b[N], c[N], fa[N], d[N], ord[N], s[N];
vector<int> g[N];

__int128 grow(int i, int l, int r) {
    if (c[i] >= 0) return (__int128)(r - l + 1) * b[i] + (__int128)c[i] * (l + r) * (r - l + 1) / 2;
    int x = (b[i] - 1) / (-c[i]);
    if (x < l) return r - l + 1;
    int m = min(r, x);
    return (__int128)(m - l + 1) * b[i] + (__int128)c[i] * (l + m) * (m - l + 1) / 2 + (r - m);
}

bool check(int t) {
    For(i, 1, n) {
        if (grow(i, 1, t) < a[i]) return false;
        int l = 1, r = t;
        while (l < r) {
            int mid = (l + r + 1) / 2;
            if (grow(i, mid, t) >= a[i]) l = mid;
            else r = mid - 1;
        }
        d[i] = l;
    }
    for (int k = n; k > 1; k--) {
        int u = ord[k];
        d[fa[u]] = min(d[fa[u]], d[u] - 1);
    }
    For(i, 1, n) s[i] = d[i];
    sort(s + 1, s + 1 + n);
    For(i, 1, n) if (s[i] < i) return false;
    return true;
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i] >> b[i] >> c[i];
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    int tot = 0;
    ord[++tot] = 1;
    For(k, 1, n) {
        int u = ord[k];
        for (int v : g[u])
            if (v != fa[u]) fa[v] = u, ord[++tot] = v;
    }
    int l = n, r = 1e9;
    while (l < r) {
        int mid = (l + r) / 2;
        if (check(mid)) r = mid;
        else l = mid + 1;
    }
    cout << l;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
