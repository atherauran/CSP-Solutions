# P9752 CSP-S 2023 T1 密码锁

## 题意

5 位循环数字锁。从正确密码出发，转动一次：转一个拨圈，或把相邻两个拨圈转相同幅度。给出 $n \le 8$ 个锁车后的状态（都不是正确密码），问有多少个正确密码能产生所有这些状态。

**标签**：枚举　**难度**：2/10

## 解题思路

### 1. 底层逻辑

对每个状态，求出所有"能一步转成它"的密码集合，答案就是这 $n$ 个集合的交集大小。

### 2. 隐藏条件

- 转动是可逆的：密码 $P$ 一步转成状态 $S$ ⇔ $S$ 反向转一步得到 $P$。所以从每个状态出发反向转动，枚举出的就是它的候选密码。
- 每个状态的候选密码：单圈 $5 \times 9 = 45$ 个，相邻双圈 $4 \times 9 = 36$ 个，共 81 个，**互不重复**（单圈只改一位、双圈改两位），所以计数时不会重复累加。

### 3. 注意事项

- 幅度 $1 \sim 9$（转 0 等于没转，状态不是正确密码）。
- 拨圈循环，加完要 $\bmod 10$。
- 双圈转动时两个圈幅度相同。

### 4. 解决方案

开数组 `cnt[100000]`。对每个状态枚举 81 个候选密码，`cnt[密码]++`。最后统计 `cnt == n` 的个数。复杂度 $O(81n + 10^5)$。

## 部分分策略 / 错误思路

- $n = 1$：答案恒为 81。
- 也可以枚举全部 $10^5$ 个密码，逐个检查与每个状态的差是否符合"一位不同"或"相邻两位差相同"，同样能过。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

int n, ans;
int cnt[100000];

inline int code(int a[]) {
    int r = 0;
    Rep(i, 0, 5) r = r * 10 + a[i];
    return r;
}

void solve() {
    cin >> n;
    For(t, 1, n) {
        int a[5];
        Rep(i, 0, 5) cin >> a[i];
        Rep(i, 0, 5) For(d, 1, 9) {
            int b[5];
            Rep(j, 0, 5) b[j] = a[j];
            b[i] = (b[i] + d) % 10;
            cnt[code(b)]++;
            if (i < 4) b[i + 1] = (b[i + 1] + d) % 10, cnt[code(b)]++;
        }
    }
    Rep(i, 0, 100000) ans += cnt[i] == n;
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
