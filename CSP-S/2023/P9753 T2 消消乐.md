# P9753 CSP-S 2023 T2 消消乐

## 题意

长度 $n \le 2 \times 10^6$ 的小写字母串，每次可以删除相邻两个相同字符。求有多少个非空子串可以被删空。

**标签**：DP、括号匹配、字符串　**难度**：6/10

## 解题思路

### 1. 底层逻辑

可消除串很像"括号序列"：每个字符和另一个相同字符配对，配对关系不交叉。设 $dp_i$ 为以 $i$ 结尾的可消除子串个数，答案 $= \sum dp_i$。

若 $s_i$ 在以 $i$ 结尾的**最短**可消除串中与位置 $j$ 配对（即 $s_j = s_i$ 且 $s[j+1..i-1]$ 可消除，$j$ 尽量大），那么以 $i$ 结尾的可消除串 = $[j, i]$ 前面再拼上一个以 $j-1$ 结尾的可消除串（或什么都不拼）：

$$dp_i = dp_{j-1} + 1$$

### 2. 隐藏条件

问题变成快速找 $j$：从 $i-1$ 开始往左，如果 $s_{i-1} = s_i$ 就是它；否则跳过以 $i-1$ 结尾的最短可消除块，继续看块前面的字符……这个"跳块"过程可能很慢。

**预处理跳转表**：$to_{i,c}$ 表示"在位置 $i$ 之后接一个字符 $c$，它会和哪个位置配对"（0 表示无）：
- 若 $s_i = c$：$to_{i,c} = i$；
- 否则若 $i$ 有配对位置 $j$：$to_{i,c} = to_{j-1,c}$（跳过整块 $[j, i]$）；
- 否则为 0。

即 $to_i$ 整体复制 $to_{j-1}$（$i$ 无配对时为全 0），再令 $to_{i,s_i} = i$。

### 3. 注意事项

- $to$ 数组 $2 \times 10^6 \times 26$，必须用 32 位整数（约 208MB），64 位会超内存。
- 答案可达 $n^2/4$ 量级，用 64 位。
- 复制 26 个整数用 `memcpy`，总共约 $5 \times 10^7$ 次操作。

### 4. 解决方案

对 $i = 1 \dots n$：$j = to_{i-1, s_i}$；若 $j \ne 0$，$dp_i = dp_{j-1} + 1$，累加答案，并把 $to_{j-1}$ 复制到 $to_i$；最后 $to_{i, s_i} = i$。复杂度 $O(26n)$。

## 部分分策略 / 错误思路

- 枚举左端点，向右用栈模拟：$O(n^2)$，$n \le 8000$ 可过。
- **哈希做法**（另一种正解）：用栈从左到右扫，若栈顶与当前字符相同就弹出，否则压入。子串 $[l+1, r]$ 可消除 ⇔ 处理完前缀 $l$ 和前缀 $r$ 时**栈完全相同**。对每个前缀的栈求哈希，统计相同哈希的对数即可。
- 直接暴力跳块找 $j$：最坏 $O(n^2)$。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2e6 + 5;
int n, ans;
int dp[N];
signed to[N][26];
string s;

void solve() {
    cin >> n >> s;
    s = " " + s;
    For(i, 1, n) {
        int c = s[i] - 'a', j = to[i - 1][c];
        if (j) {
            dp[i] = dp[j - 1] + 1, ans += dp[i];
            memcpy(to[i], to[j - 1], sizeof(to[i]));
        }
        to[i][c] = i;
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);

    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
