# P7078 CSP-S 2020 T4 贪吃蛇

## 题意

$n$ 条蛇有体力 $a_i$（输入已排序）。每轮最强的蛇可以选择吃掉最弱的蛇（体力减去对方体力）或结束游戏。每条蛇首先保证自己不被吃，其次尽量多吃。问最后剩几条。$n \le 10^6$，$T \le 10$ 组（后续组为修改）。

**标签**：博弈、贪心、双端队列（类似"合并果子"的双队列技巧）　**难度**：9/10

## 解题思路

### 1. 底层逻辑

每一轮的决策只有"吃"或"不吃"，关键是判断"最强的蛇吃了以后会不会在之后被吃掉"。需要两部分：
1. 推出"什么时候吃一定安全"；
2. 不安全的情况下判断最终能不能吃；
3. 用线性的数据结构模拟"取最大、取最小、插入"。

### 2. 隐藏条件

**结论 1**：若最强蛇 $X$ 吃完后**不是最弱的**，那么它一定会吃。
依据：下一轮最强的 $Y$ 比 $X$ 原来弱、吃的最弱蛇比 $X$ 吃的更强，所以 $Y$ 吃完后比 $X$ 吃完后还弱。如果之后有人要吃，也会先吃到 $Y$ 而不是 $X$；$Y$ 为了自保就不会让局面发展到那一步。因此 $X$ 是安全的。

**结论 2**：若 $X$ 吃完后变成最弱的，它是否安全取决于下一条最强蛇 $X_2$ 吃不吃它；而 $X_2$ 吃完如果又成为最弱，取决于 $X_3$……这是一条链。链终止于"某条蛇吃完不是最弱"或"只剩 2 条蛇"（这两种情况一定会吃）。设终止位置在第 $d$ 层，安全性逐层取反：**$d$ 为偶数时 $X$ 吃，否则不吃**。且一旦进入这条链，游戏会在 $X$ 吃或不吃之后立即结束（若 $X$ 吃了，$X_2$ 就不吃）。

**结论 3**（单调性）：在结论 1 的阶段中，每次产生的新蛇（$x - y$）一定是**单调不增**的。依据：最强的在变弱、最弱的在变强。于是新蛇可以按产生顺序放入第二个队列，它自然有序——不需要堆。

### 3. 注意事项

- $n = 10^6$、$T = 10$，用堆 $O(n \log n)$ 只能 70 分左右，需要 $O(n)$ 的双队列。
- 比较实力时体力相同按编号比，直接用 `pair<体力, 编号>` 比较。
- 链的模拟阶段（结论 2）中当前最弱蛇就是刚吃完的蛇，单独记录，不放回队列。
- 每组数据重新建队列。

### 4. 解决方案

队列 `q1` 存原始蛇（升序），`q2` 存新产生的蛇（降序，队首最大）。最大值取两队中较大的一端，最小值同理。

1. **阶段一**：反复取最强 $x$ 和最弱 $y$，新蛇 $cur = (x - y, id_x)$：
   - 若当前只剩 2 条，答案为 1；
   - 若 $cur$ 比剩下的最弱蛇强，放入 `q2`，蛇数 $cnt - 1$，继续；
   - 否则进入阶段二。
2. **阶段二**：从 $c = cnt - 1$ 条蛇、当前最弱为 $cur$ 开始，令 $d = 0$，循环：$d{+}{+}$；若 $c = 2$ 则终止；否则取出最强 $z$，$cur = (z - cur, id_z)$，若 $cur$ 比剩下的最弱者强则终止，否则 $c{-}{-}$ 继续。
3. $d$ 为奇数：$X$ 不吃，答案 $cnt$；否则 $X$ 吃，答案 $cnt - 1$。

复杂度 $O(Tn)$。

## 部分分策略 / 错误思路

- $n = 3$：手工分类讨论。
- $n \le 2000$：按定义递归模拟（吃了之后自己是否存活），每层排序。
- 用 `set` 模拟阶段一、阶段二：$O(n \log n)$，约 70 分。
- 错误想法："吃完不是最弱就吃，是最弱就不吃"——忽略了链式博弈的奇偶性。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e6 + 5;
int t, n;
int a[N];
deque<pii> q1, q2;

inline pii getMax() {
    pii x;
    if (q2.empty() || (!q1.empty() && q1.back() > q2.front())) x = q1.back(), q1.pop_back();
    else x = q2.front(), q2.pop_front();
    return x;
}

inline pii getMin() {
    pii x;
    if (q2.empty() || (!q1.empty() && q1.front() < q2.back())) x = q1.front(), q1.pop_front();
    else x = q2.back(), q2.pop_back();
    return x;
}

inline pii peekMin() {
    if (q2.empty() || (!q1.empty() && q1.front() < q2.back())) return q1.front();
    return q2.back();
}

int calc() {
    q1.clear(), q2.clear();
    For(i, 1, n) q1.pb({a[i], i});
    int cnt = n;
    while (true) {
        pii x = getMax(), y = getMin();
        pii cur = {x.F - y.F, x.S};
        if (cnt == 2) return 1;
        if (cur > peekMin()) {
            q2.pb(cur), cnt--;
            continue;
        }
        int c = cnt - 1, d = 0;
        while (true) {
            d++;
            if (c == 2) break;
            pii z = getMax();
            cur = {z.F - cur.F, z.S};
            if (cur > peekMin()) break;
            c--;
        }
        return d % 2 ? cnt : cnt - 1;
    }
}

void solve() {
    cin >> t >> n;
    For(i, 1, n) cin >> a[i];
    cout << calc() << endl;
    while (--t) {
        int k;
        cin >> k;
        For(i, 1, k) {
            int x, y;
            cin >> x >> y;
            a[x] = y;
        }
        cout << calc() << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
