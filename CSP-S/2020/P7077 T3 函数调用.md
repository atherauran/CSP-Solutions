# P7077 CSP-S 2020 T3 函数调用

## 题意

长度 $n$ 的数组和 $m$ 个函数：类型 1 给 $a_P$ 加 $V$；类型 2 全体乘 $V$；类型 3 依次调用若干函数（调用关系无环）。按顺序执行 $Q$ 个函数，输出最终数组 mod 998244353。$n, m, Q \le 10^5$，$\sum C \le 10^6$。

**标签**：拓扑排序、DAG 上 DP、贡献法　**难度**：7/10

## 解题思路

### 1. 底层逻辑

最终每个元素 = 初值 × (所有乘法之积) + Σ(每次加法的 $V$ × 这次加法**之后**发生的所有乘法之积)。

所以问题变成：对每个类型 1 的函数，求它被执行的所有"实例"的后缀乘积之和——即它的**有效执行次数** $cnt$（每次加法相当于被执行了"后缀乘积"次）。

### 2. 隐藏条件

- 先求每个函数自身的乘积 $mul_f$（执行一次 $f$ 会让全体乘多少）：类型 2 为 $V$，类型 3 为所有子调用 $mul$ 之积。调用关系是 DAG，按拓扑序逆序求。
- **倒序处理**：对一个调用序列 $g_1, g_2, \dots, g_c$，$g_i$ 之后的乘积是 $mul_{g_{i+1}} \cdots mul_{g_c}$。从后往前扫，维护后缀乘积 $s$，就能得到每个 $g_i$ 该被"放大"的倍数。
- 一个函数的 $cnt$ 会按同样的方式下传给它调用的函数：$cnt_{g_i} \mathrel{+}= cnt_f \cdot s_i$。只要按拓扑序（调用者在前）下传，每个函数在下传前已经收集完了所有调用者的贡献。

### 3. 注意事项

- 不能真的模拟调用：一个函数可能被指数级次数间接调用。
- 主序列的处理和类型 3 函数相同（可以看作一个调用 $f_1 \dots f_Q$ 的虚拟函数），主序列的全部乘积就是初值要乘的倍数。
- $V$ 可以为 0，所以不能用"除以乘积"的方式求后缀积，只能倒序累乘。
- 所有运算取模。

### 4. 解决方案

1. 读入，建 DAG（$f \to$ 它调用的函数），Kahn 算法求拓扑序 `ord`。
2. 按 `ord` 逆序求 $mul$。
3. 主序列从后往前：$cnt_{f_i} \mathrel{+}= cur$，$cur \gets cur \cdot mul_{f_i}$。最后 $a_i \gets a_i \cdot cur$。
4. 按 `ord` 正序处理每个函数 $u$：
   - 若是类型 1：$a_{P_u} \mathrel{+}= V_u \cdot cnt_u$；
   - 把 $cnt_u$ 下传：对子调用从后往前，$cnt_x \mathrel{+}= s$，$s \gets s \cdot mul_x$（$s$ 初值为 $cnt_u$）。
5. 输出 $a$。

复杂度 $O(n + m + Q + \sum C)$。

## 部分分策略 / 错误思路

- 直接递归模拟：只能过调用次数小的点。
- 只有加法或只有乘法：只有乘法时答案是初值乘总积；只有加法时 $cnt$ 就是调用次数，DAG 上计数。
- 正序处理并"先乘后加"地维护 $(k, b)$ 线性变换：对每个元素都要单独维护，$O(nQ)$。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5, P = 998244353;
int n, m, q;
int a[N], tp[N], pos[N], v[N], mul[N], cnt[N], deg[N], f[N];
vector<int> g[N];
vector<int> ord;

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    cin >> m;
    For(j, 1, m) {
        cin >> tp[j];
        if (tp[j] == 1) cin >> pos[j] >> v[j];
        if (tp[j] == 2) cin >> v[j];
        if (tp[j] == 3) {
            int c;
            cin >> c;
            g[j].resize(c);
            for (int &x : g[j]) cin >> x, deg[x]++;
        }
    }
    queue<int> qu;
    For(j, 1, m) if (!deg[j]) qu.push(j);
    while (!qu.empty()) {
        int u = qu.front();
        qu.pop(), ord.pb(u);
        for (int x : g[u])
            if (!--deg[x]) qu.push(x);
    }
    for (int i = m - 1; i >= 0; i--) {
        int u = ord[i];
        mul[u] = tp[u] == 2 ? v[u] : 1;
        for (int x : g[u]) mul[u] = mul[u] * mul[x] % P;
    }
    cin >> q;
    For(i, 1, q) cin >> f[i];
    int cur = 1;
    for (int i = q; i >= 1; i--) cnt[f[i]] = (cnt[f[i]] + cur) % P, cur = cur * mul[f[i]] % P;
    For(i, 1, n) a[i] = a[i] * cur % P;
    for (int u : ord) {
        if (tp[u] == 1) a[pos[u]] = (a[pos[u]] + v[u] * cnt[u]) % P;
        int s = cnt[u];
        for (int i = (int)g[u].size() - 1; i >= 0; i--) {
            int x = g[u][i];
            cnt[x] = (cnt[x] + s) % P, s = s * mul[x] % P;
        }
    }
    For(i, 1, n) cout << a[i] << " ";
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
