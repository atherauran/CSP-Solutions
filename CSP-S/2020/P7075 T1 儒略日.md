# P7075 CSP-S 2020 T1 儒略日

## 题意

儒略日 0 是公元前 4713 年 1 月 1 日。1582 年 10 月 4 日（含）之前用儒略历（4 年一闰），之后从 10 月 15 日开始用格里高利历，中间 10 天不存在；没有公元 0 年。$Q \le 10^5$ 次询问，把儒略日 $r$ 转成日期。答案年份不超过 $10^9$。

**标签**：模拟、日期计算　**难度**：5/10

## 解题思路

### 1. 底层逻辑

分成两段处理：
1. $r$ 落在儒略历范围内：从公元前 4713 年开始，按 4 年一周期跳；
2. $r$ 落在格里高利历范围内：从 1582 年开始，按 400 年一周期跳。

周期跳完后剩余天数不多，逐年、逐月减即可。

### 2. 隐藏条件

- **公元前年份换算**：把公元前 $x$ 年记为第 $1-x$ 年（公元前 1 年 = 第 0 年），这样年份连续，"公元前 1、5、9…年是闰年"恰好变成"年份是 4 的倍数"。公元前 4713 年就是第 $-4712$ 年。
- 儒略历 4 年恰好 $1461$ 天；格里高利历**任意连续 400 年**都恰好有 97 个闰年，共 $146097$ 天，与起点是否对齐无关。
- 1582 年 10 月 15 日对应儒略日 $2299161$（可以由 1461 周期推出，也是常用常数）。1582 年在两种历法下都不是闰年，可以把格里高利历的起点视为"1582 年 1 月 1 日"：它距 10 月 15 日 $287$ 天，这样周期跳和逐月处理都与普通年份一样。

### 3. 注意事项

- $r$ 可到年份 $10^9$ 级别，不能逐年模拟，必须先按周期跳。
- 周期跳完后最多逐年 400 次 + 逐月 12 次，$Q = 10^5$ 时约 $4 \times 10^7$，可以接受。
- 输出公元前年份时要换回 $1 - y$ 并加 ` BC`。

### 4. 解决方案

对每个 $r$：
1. 若 $r < 2299161$（儒略历）：$y = -4712 + 4\lfloor r / 1461 \rfloor$，$r \gets r \bmod 1461$；
2. 否则（格里高利历）：$r \gets r - 2299161 + 287$（转为距 1582 年 1 月 1 日的天数），$y = 1582 + 400\lfloor r / 146097 \rfloor$，$r \gets r \bmod 146097$；
3. 当 $r \ge$ 当年天数时减去并 $y{+}{+}$；再逐月减，得到月份和日（$r + 1$）；
4. $y \le 0$ 输出 `d m (1-y) BC`，否则输出 `d m y`。

## 部分分策略 / 错误思路

- 逐日模拟：$r \le 10^5$ 左右可以过。
- 逐年模拟：$r \le 10^7$ 可以过，约 60~80 分。
- 常见错误：忘记 10 月 5~14 日被删除、把公元前闰年写成"年份数值是 4 的倍数"（应为公元前 1、5、9…年）、格里高利历闰年规则写错。

void solve() {
    cin >> q;
    while (q--) {
        int r, y;
        cin >> r;
        bool greg = r >= 2299161;

        int m = 1;
        while (r >= md[m] + (m == 2 && leap(y, greg))) r -= md[m] + (m == 2 && leap(y, greg)), m++;
        cout << r + 1 << " " << m << " ";
        if (y <= 0) cout << 1 - y << " BC" << endl;
        else cout << y << endl;
    }
}
