# P7076 CSP-S 2020 T2 动物园

## 题意

动物编号是 $k$ 位二进制数。若养了某个第 $p$ 位为 1 的动物，就必须买饲料 $q$（$q$ 互不相同）。已养 $n$ 种，问还能养多少种（加入后饲料清单不变）。$k \le 64$，$n, m \le 10^6$。

**标签**：位运算　**难度**：3/10

## 解题思路

### 1. 底层逻辑

一种新动物 $x$ 可以养 ⇔ 它的每个为 1 的位 $p$ 所要求的饲料都已经在清单里。所以只需判断每一位"能不能为 1"，能为 1 的位数为 $free$，答案就是 $2^{free} - n$。

### 2. 隐藏条件

- 由于每条要求的 $q$ 互不相同，饲料 $q$ 只由这一条要求引入。所以"第 $p$ 位的所有要求都已满足"⇔ 已有动物中**存在第 $p$ 位为 1 的**（这样第 $p$ 位的所有饲料都已买）。
- 于是：把所有 $a_i$ 求或得到 `all`；若某条要求的位 $p$ 在 `all` 中为 0，这一位就被禁止。**饲料编号 $q$ 和 $c$ 完全没用。**

### 3. 注意事项

- $k = 64$ 时编号要用 `unsigned long long` 读入。
- $2^{64} - n$：当 $free = 64$ 且 $n = 0$ 时答案是 $2^{64} = 18446744073709551616$，超出 `ull`，需要特判输出；$n > 0$ 时用 `ull` 的自然溢出 $0 - n$ 恰好得到 $2^{64} - n$。
- `1ULL << 64` 是未定义行为，不能直接写。

### 4. 解决方案

1. `all` = 所有 $a_i$ 的按位或；
2. 对每条要求 $(p, q)$，若 `all` 第 $p$ 位为 0，把第 $p$ 位加入 `ban`；
3. $free = k - \text{popcount}(ban)$；
4. 特判 $free = 64, n = 0$；否则输出 $2^{free} - n$（`ull`）。

复杂度 $O(n + m)$。

## 部分分策略 / 错误思路

- 枚举所有 $2^k$ 个编号检查：只能过 $k \le 20$。
- 用 `long long`：$k = 64$ 时溢出，丢掉若干点。这道题的分数基本都丢在 $2^{64}$ 的边界上。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

int n, m, c, k;
ull all, ban;

void solve() {
    cin >> n >> m >> c >> k;
    For(i, 1, n) {
        ull a;
        cin >> a;
        all |= a;
    }
    For(i, 1, m) {
        int p, q;
        cin >> p >> q;
        if (!(all >> p & 1)) ban |= 1ULL << p;
    }
    int free = k - __builtin_popcountll(ban);
    if (free == 64 && n == 0) {
        cout << "18446744073709551616";
        return;
    }
    ull ans = (free == 64 ? 0 : 1ULL << free) - n;
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);

    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
