# P7916 CSP-S 2021 T4 交通规划

## 题意

$n \times m$ 网格图，边有权。每次询问在网格外围的 $2(n+m)$ 条射线中的若干条上放附加点（带颜色和连边权值），要求给所有格点染黑白，使两端异色的边权和最小。$n, m \le 500$，$\sum k \le 50$。

**标签**：平面图最小割、对偶图最短路、区间 DP　**难度**：9/10

## 解题思路

### 1. 底层逻辑

"两端异色的边权和最小"就是把黑点和白点分开的**最小割**。网格是平面图，附加点都在外面一圈上，平面图的最小割可以转成**对偶图上的最短路**。

### 2. 隐藏条件

- **对偶图**：每个网格内的小方格是一个对偶点；网格外部被 $2(n+m)$ 条射线分成 $2(n+m)$ 个外部区域，各是一个对偶点（区域 $r$ 在射线 $r$ 和 $r+1$ 之间）。每条原图边连接它两侧的对偶点，权值不变；射线 $p$ 上若有附加点，射线边连接区域 $p-1$ 和 $p$，权值为附加边权，否则权值为 0（没有边，两区域连通）。
- 把附加点按射线编号排成一圈，相邻两点颜色不同的地方称为一个"**分界**"（对应一个外部区域）。分界一定是偶数个。
- 割在对偶图中表现为若干条**路径**，每条路径把两个分界连起来；最优解中这些路径**互不交叉**（交叉的两条路径可以交换端点而不变差）。
- 所以答案 = 分界点之间的**不交叉完美匹配**的最小代价，代价是对偶图最短路。环上不交叉匹配可以直接在序列上做区间 DP（像括号匹配）。

### 3. 注意事项

- 对偶图约 $25$ 万个点，$\sum k \le 50$，所以最多 50 次 Dijkstra，可以接受。
- 射线编号顺序：上边从左到右 $1 \sim m$，右边从上到下 $m+1 \sim m+n$，下边从右到左，左边从下到上。由此推出网格边界边连接的外部区域编号（见代码）。
- 射线边的权值随询问变化，不要每次重建图：Dijkstra 中对外部区域单独处理两侧射线边，询问结束后把权值清零。
- 所有附加点同色时答案为 0。

### 4. 解决方案

1. 建对偶图的静态部分：
   - 竖边 $(i,j)-(i+1,j)$：连左面方格（$j = 1$ 时为左侧外部区域 $2m+2n-i$）和右面方格（$j = m$ 时为右侧区域 $m+i$）；
   - 横边 $(i,j)-(i,j+1)$：连上面方格（$i = 1$ 时为区域 $j$）和下面方格（$i = n$ 时为区域 $2m+n-j$）。
2. 每次询问：记录射线权值，附加点按射线编号排序；对每个 $i$，若点 $i$ 与下一个点（环形）颜色不同，把区域 $p_i$ 作为一个分界。
3. 从每个分界跑 Dijkstra，得到两两距离 $d$。
4. 区间 DP：$f[l][r] = \min\big(f[l+1][r-1] + d[l][r],\ \min_{mid} f[l][mid] + f[mid+1][r]\big)$（只考虑偶数长度）。输出 $f[1][c]$。

复杂度 $O(\sum k \cdot nm \log(nm) + k^3)$。

## 部分分策略 / 错误思路

- $n, m$ 很小：枚举染色或直接网络流。
- $k = 2$：两个点异色时就是一次最小割 / 一条对偶最短路，可用网络流（小数据）或对偶最短路拿到较多分。
- 一般 $k$ 用网络流（超级源连黑点、超级汇连白点）：$O(T \cdot \text{flow})$，$n, m = 500$ 时太慢。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2.6e5 + 5, K = 105;
int n, m, t, F, R, c;
int rw[2005], d[K][K], f[K][K], dist[N], src[K];
vector<pii> g[N];
struct node { int w, p, t; } a[K];

inline int id(int i, int j) { return (i - 1) * (m - 1) + j; }

inline void add(int u, int v, int w) { g[u].pb({v, w}), g[v].pb({u, w}); }

inline bool cmp(const node &x, const node &y) { return x.p < y.p; }

void dijkstra(int s) {
    For(i, 1, F + R) dist[i] = LINF;
    priority_queue<pii, vector<pii>, greater<pii>> q;
    dist[s] = 0;
    q.push({0, s});
    while (!q.empty()) {
        auto cur = q.top();
        int du = cur.F, u = cur.S;
        q.pop();
        if (du != dist[u]) continue;
        for (auto e : g[u]) {
            int v = e.F, w = e.S;
            if (dist[v] > du + w) dist[v] = du + w, q.push({dist[v], v});
        }
        if (u > F) {
            int r = u - F, pr = r == 1 ? R : r - 1, nx = r == R ? 1 : r + 1;
            if (dist[F + pr] > du + rw[r]) dist[F + pr] = du + rw[r], q.push({dist[F + pr], F + pr});
            if (dist[F + nx] > du + rw[nx]) dist[F + nx] = du + rw[nx], q.push({dist[F + nx], F + nx});
        }
    }
}

void solve() {
    cin >> n >> m >> t;
    F = (n - 1) * (m - 1), R = 2 * (n + m);
    For(i, 1, n - 1) For(j, 1, m) {
        int w;
        cin >> w;
        add(j > 1 ? id(i, j - 1) : F + 2 * m + 2 * n - i, j < m ? id(i, j) : F + m + i, w);
    }
    For(i, 1, n) For(j, 1, m - 1) {
        int w;
        cin >> w;
        add(i > 1 ? id(i - 1, j) : F + j, i < n ? id(i, j) : F + 2 * m + n - j, w);
    }
    while (t--) {
        int k;
        cin >> k;
        For(i, 1, k) cin >> a[i].w >> a[i].p >> a[i].t, rw[a[i].p] = a[i].w;
        sort(a + 1, a + 1 + k, cmp);
        c = 0;
        For(i, 1, k) if (a[i].t != a[i % k + 1].t) src[++c] = F + a[i].p;
        For(i, 1, c) {
            dijkstra(src[i]);
            For(j, 1, c) d[i][j] = dist[src[j]];
        }
        for (int len = 2; len <= c; len += 2)
            For(l, 1, c - len + 1) {
                int r = l + len - 1;
                f[l][r] = (len == 2 ? 0 : f[l + 1][r - 1]) + d[l][r];
                for (int mid = l + 1; mid < r; mid += 2) f[l][r] = min(f[l][r], f[l][mid] + f[mid + 1][r]);
            }
        cout << (c ? f[1][c] : 0) << endl;
        For(i, 1, k) rw[a[i].p] = 0;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
