# P7914 CSP-S 2021 T2 括号序列

## 题意

"超级括号序列"由 `(`、`)`、`*` 组成：`()`、`(S)` 合法（$S$ 为 $1 \sim k$ 个 `*`）；$A, B$ 合法则 `AB`、`ASB` 合法；$A$ 合法则 `(A)`、`(SA)`、`(AS)` 合法。给定含 `?` 的长度为 $n$ 的串，求填法使其合法的方案数 mod $10^9+7$。$n \le 500$。

**标签**：区间 DP、计数　**难度**：7/10

## 解题思路

### 1. 底层逻辑

区间 DP，但难点在于**不重不漏**：同一个串可能有多种按文法拆分的方式（如 `()()()` 可以拆成 `A·B` 的多种组合），必须给每个串规定**唯一**的拆分方式。

### 2. 隐藏条件

把合法串看成"顶层的若干括号块，块之间夹着 0 或 $1 \sim k$ 个 `*`"：`(...)***(...)(...)**(...)`。按"首字符、尾字符"分类定义 6 种状态（区间 $[l, r]$ 的方案数）：

| 状态 | 形态 | 含义 |
|:-:|:-:|:-|
| 0 | `***` | 全是 `*`，长度 $\le k$ |
| 1 | `(...)` | 首尾是一对匹配括号 |
| 2 | `(...)**` | 合法串 + 末尾一段 `*` |
| 3 | `(...)**(...)` | **合法串**（答案） |
| 4 | `**(...)` | 开头一段 `*` + 合法串 |
| 5 | `**(...)**` | 开头 `*` + 合法串 + 末尾 `*`，也包含全 `*` |

唯一拆分方式：**以最后一个顶层括号块为分界**。最后一个块 `(...)` 的左括号就是与 $r$ 匹配的那个，位置唯一；末尾的星号段是"最长后缀 `*`"，也唯一。

### 3. 注意事项

- 状态 1 的括号内部只能是：空、$S$、$A$、$SA$、$AS$，即状态 0、3、4、2（**不能是 5**，`(SAS)` 不合法）。
- 状态 3 中块与块之间的 `*` 段由状态 0 保证长度 $\le k$。
- $O(n^3)$，$n = 500$ 时约 $2 \times 10^7$ 次枚举，每次几个乘法取模，可以通过。

### 4. 解决方案

按区间长度从小到大，对 $[l, r]$：
- $f_0$：长度 $\le k$ 且每位都能是 `*`；
- $f_1$：$s_l$ 能是 `(`、$s_r$ 能是 `)` 时，长度为 2 取 1，否则取 $f_{0,2,3,4}[l+1][r-1]$ 之和；
- 枚举分界点 $i \in [l, r)$：
  - $f_2 \mathrel{+}= f_3[l][i] \cdot f_0[i+1][r]$
  - $f_3 \mathrel{+}= (f_2[l][i] + f_3[l][i]) \cdot f_1[i+1][r]$
  - $f_4 \mathrel{+}= (f_4[l][i] + f_5[l][i]) \cdot f_1[i+1][r]$
  - $f_5 \mathrel{+}= f_4[l][i] \cdot f_0[i+1][r]$
- 最后 $f_3 \mathrel{+}= f_1$（单个块），$f_5 \mathrel{+}= f_0$（全星）。

答案 $f_3[1][n]$。

## 部分分策略 / 错误思路

- $n \le 15$：枚举 $3^n$ 种填法，再用区间 DP 判断合法性。
- 直接按文法写 $g[l][r] = \sum g[l][i] \cdot g[i+1][r] + \dots$：同一个串被 `AB` 规则以不同分界点重复计数，样例就过不了。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 505, P = 1e9 + 7;
int n, k;
int f[N][N][6];
string s;

inline bool can(int i, char c) { return s[i] == c || s[i] == '?'; }

void solve() {
    cin >> n >> k >> s;
    s = " " + s;
    For(len, 1, n) For(l, 1, n - len + 1) {
        int r = l + len - 1;
        int *g = f[l][r];
        if (len <= k && can(r, '*') && (len == 1 || f[l][r - 1][0])) g[0] = 1;
        if (len >= 2 && can(l, '(') && can(r, ')')) {
            if (len == 2) g[1] = 1;
            else g[1] = (f[l + 1][r - 1][0] + f[l + 1][r - 1][2] + f[l + 1][r - 1][3] + f[l + 1][r - 1][4]) % P;
        }
        Rep(i, l, r) {
            int *x = f[l][i], *y = f[i + 1][r];
            g[2] = (g[2] + x[3] * y[0]) % P;
            g[3] = (g[3] + (x[2] + x[3]) * y[1]) % P;
            g[4] = (g[4] + (x[4] + x[5]) * y[1]) % P;
            g[5] = (g[5] + x[4] * y[0]) % P;
        }
        g[3] = (g[3] + g[1]) % P;
        g[5] = (g[5] + g[0]) % P;
    }
    cout << f[1][n][3];
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
