# P7915 CSP-S 2021 T3 回文

## 题意

序列 $a$ 长 $2n$，$1 \sim n$ 各出现两次。每次从 $a$ 的开头（L）或末尾（R）取出一个数放到 $b$ 末尾，要求 $b$ 是回文。输出字典序最小的操作串，无解输出 `-1`。$\sum n \le 5 \times 10^5$。

**标签**：贪心、双指针、构造　**难度**：6/10

## 解题思路

### 1. 底层逻辑

第一步只有两种选择：取 $a_1$ 或取 $a_{2n}$。选定后，$b_{2n}$ 必须是它的另一个出现位置 $p$，于是整个过程的结构被确定。按字典序先尝试 L，失败再尝试 R。

### 2. 隐藏条件

以第一步取 $a_1$ 为例。位置 $p$ 把剩余序列分成两段：$[2, p-1]$ 和 $[p+1, 2n]$。

- 前 $n$ 次操作从**外侧**取：段 1 的左端或段 2 的右端；
- 后 $n$ 次操作（倒着看）是从 $p$ 往外"扩张"，取的是**内侧**：段 1 的右端或段 2 的左端。

所以每一步 $b_i$ 和对应的 $b_{2n+1-i}$ 必须是：一个外端点和一个内端点，值相等。四种可能：

| 外端 | 内端 | 前半操作 | 后半操作 |
|:-:|:-:|:-:|:-:|
| 段 1 左 | 段 1 右 | L | L |
| 段 1 左 | 段 2 左 | L | R |
| 段 2 右 | 段 1 右 | R | L |
| 段 2 右 | 段 2 左 | R | R |

由于每个值只出现两次，前两种最多一种成立，后两种也最多一种成立。贪心：能用 L 开头就用 L。

**贪心正确性**：每次匹配掉的是一对相同的数，对剩余结构的影响只是两个端点向内收缩；可以证明若当前存在合法方案，选 L 开头的那一种之后仍存在合法方案（两段都像栈一样被消耗，不同选择之间不会互相阻塞）。前半操作串字典序最小，后半由前半唯一确定。

### 3. 注意事项

- 第一步无论 L 还是 R，最后一步（取 $a_p$，只剩一个数）写 `L` 字典序更小。
- 后半部分的操作要**倒序**输出（第 $i$ 步配对的内端点是倒数第 $i$ 个被取出的）。
- 判断时注意两段可能为空（`l1 <= r1`、`l2 <= r2`），且同一段内匹配要求 `l < r`。
- 多组数据，$\sum n \le 5 \times 10^5$，每组 $O(n)$。

### 4. 解决方案

`calc(first)`：$st$ 为第一步取出的位置，$pr$ 为其值的另一位置；段 1 为 $[l_1, r_1]$，段 2 为 $[l_2, r_2]$。前半串 `fr = first`，后半串 `bk = "L"`。重复 $n-1$ 次，按表格顺序尝试四种匹配，成功则把对应字符追加到 `fr`、`bk` 并移动指针；都不行返回失败。最后输出 `fr + reverse(bk)`。

先 `calc('L')`，失败再 `calc('R')`，都失败输出 `-1`。

## 部分分策略 / 错误思路

- $n \le 10$：枚举 $2^{2n}$ 种操作串，按字典序找第一个合法的。
- $n \le 1000$：可以在每一步尝试 L 后 $O(n)$ 检查剩余能否完成，$O(n^2)$。
- 错误思路：只看前半部分贪心而不考虑配对的内端点，无法保证回文。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e6 + 5;
int n;
int a[N];

string calc(char first) {
    int st = first == 'L' ? 1 : 2 * n, pr = 0;
    For(i, 1, 2 * n) if (i != st && a[i] == a[st]) pr = i;
    int l1 = first == 'L' ? 2 : 1, r1 = pr - 1, l2 = pr + 1, r2 = first == 'L' ? 2 * n : 2 * n - 1;
    string fr(1, first), bk = "L";
    Rep(i, 1, n) {
        if (l1 < r1 && a[l1] == a[r1]) fr += 'L', bk += 'L', l1++, r1--;
        else if (l1 <= r1 && l2 <= r2 && a[l1] == a[l2]) fr += 'L', bk += 'R', l1++, l2++;
        else if (l1 <= r1 && l2 <= r2 && a[r2] == a[r1]) fr += 'R', bk += 'L', r2--, r1--;
        else if (l2 < r2 && a[r2] == a[l2]) fr += 'R', bk += 'R', r2--, l2++;
        else return "";
    }
    reverse(bk.begin(), bk.end());
    return fr + bk;
}

void solve() {
    cin >> n;
    For(i, 1, 2 * n) cin >> a[i];
    string ans = calc('L');
    if (ans.empty()) ans = calc('R');
    if (ans.empty()) cout << -1 << endl;
    else cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
```
