# P7913 CSP-S 2021 T1 廊桥分配

## 题意

$n$ 个廊桥分给国内区和国际区。两类航班各自按"先到先得"停靠本区的空闲廊桥，没有就去远机位。求停靠廊桥的飞机数最大值。$n, m_1 + m_2 \le 10^5$。

**标签**：贪心、模拟、优先队列、前缀和　**难度**：5/10

## 解题思路

### 1. 底层逻辑

两个区互不影响。设 $f_1(i)$ 为国内区有 $i$ 个廊桥时能停靠的飞机数，$f_2(i)$ 同理，答案就是 $\max_i f_1(i) + f_2(n - i)$。问题变成如何对所有 $i$ 快速求 $f(i)$。

### 2. 隐藏条件

**关键性质**：假设廊桥无限多并编号，每架飞机到达时停到**编号最小**的空闲廊桥。那么廊桥数为 $i$ 时能停靠的飞机，恰好就是停在编号 $1 \sim i$ 上的那些飞机。

依据：增加第 $i+1$ 个廊桥时，原来停在 $1 \sim i$ 的飞机分配不变（它们总是优先选小编号），新增的只是原来去远机位、现在停到 $i+1$ 号的飞机。

所以只需模拟一次"无限廊桥 + 选最小编号"，统计每个编号停了多少架，前缀和就是 $f(i)$。

### 3. 注意事项

- 时间互不相同，离开时刻 $<$ 当前到达时刻的飞机才能释放廊桥。
- 对每个 $i$ 都重新模拟是 $O(n \cdot m \log m)$，只有 40 分。
- 廊桥编号最多用到 $n$（超过 $n$ 的编号对答案无意义），初始把 $1 \sim n$ 放进空闲堆，堆空就视为去远机位。

### 4. 解决方案

对每一类航班：
1. 按到达时间排序；
2. 小根堆 `busy` 存 $(离开时间, 廊桥编号)$，小根堆 `idle` 存空闲编号；
3. 每架飞机到达时，先把 `busy` 中离开时间早于到达时间的廊桥移回 `idle`；若 `idle` 非空，取最小编号 $id$，`f[id]++`，放入 `busy`；
4. 对 `f` 求前缀和。

最后枚举 $i \in [0, n]$，答案取 $\max f_1(i) + f_2(n-i)$。复杂度 $O((m_1 + m_2)\log + n)$。

## 部分分策略 / 错误思路

- 枚举分配方案后分别模拟：$O(n \cdot m \log m)$，40 分。
- 以为 $f(i)$ 是凸函数而三分：$f$ 不一定是凸的，错误。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5;
int n, m1, m2;
int f1[N], f2[N];
pii a[N];

void calc(int m, int f[]) {
    For(i, 1, m) cin >> a[i].F >> a[i].S;
    sort(a + 1, a + 1 + m);
    priority_queue<pii, vector<pii>, greater<pii>> busy;
    priority_queue<int, vector<int>, greater<int>> idle;
    For(i, 1, n) idle.push(i);
    For(i, 1, m) {
        while (!busy.empty() && busy.top().F < a[i].F) idle.push(busy.top().S), busy.pop();
        if (idle.empty()) continue;
        int id = idle.top();
        idle.pop();
        f[id]++, busy.push({a[i].S, id});
    }
    For(i, 1, n) f[i] += f[i - 1];
}

void solve() {
    cin >> n >> m1 >> m2;
    calc(m1, f1), calc(m2, f2);
    int ans = 0;
    For(i, 0, n) ans = max(ans, f1[i] + f2[n - i]);
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
