# P11234 CSP-S 2024 T4 擂台游戏

## 题意

$2^k$ 人的淘汰赛，第 $R$ 轮每场比赛由抽签 $d_{R,G}$ 指定擂主，擂主能力值 $\ge R$ 则擂主胜，否则另一人胜。已知前 $c$ 人的能力值，补足到 $2^k$ 人（补充者能力任意），求所有可能夺冠者的编号和。$m$ 个询问 $c_i$，$T \le 256$ 组数据（只改变能力值）。$n, m \le 10^5$。

**标签**：树形 DP、单调性、差分、贪心　**难度**：10/10

## 解题思路

### 1. 底层逻辑

比赛是一棵满二叉树。选手 $x$ 夺冠 ⇔ 在路径上每一轮都赢：
- 若 $x$ 这一侧是擂主（第 $R$ 轮）：需要 $a_x \ge R$；
- 若对面是擂主：需要对面子树的胜者**能力 $< R$**。

记 $thr(x)$ 为路径上 $x$ 作擂主的最大轮数。由于不同子树的补充选手互不影响，$x$ 能夺冠 ⇔
1. $x$ 是补充选手（能力任选），或 $a_x \ge thr(x)$；
2. 路径上每个"作擂主的兄弟子树" $S$ 都满足 $good(S)$："$S$ 的胜者可以能力 $\le$ $S$ 的层数"。

### 2. 隐藏条件

**关键：单调性。** $c$ 增大时，更多选手的能力被固定，所有可能的局面集合只会**缩小**。因此：
- $good(S, c)$ 关于 $c$ 单调：存在阈值 $t(S)$，$good \Leftrightarrow c < t(S)$；
- 对固定的 $k$，"$x$ 能夺冠"也有阈值：$x$ 能夺冠 ⇔ $c < T_k(x)$，其中

$$T_k(x) = \min\Big(\ [a_x < thr(x)]\ ?\ x : \infty,\ \min_{\text{路径上作擂主的兄弟 } S} t(S)\Big)$$

  （$c \ge x$ 时 $x$ 才是已知选手。）

有了 $T_k(x)$，对 $c \in (2^{k-1}, 2^k]$ 的答案用**差分**一次性加好，$O(2^k)$。

**求 $t(Y)$**（与 $k$ 无关，每组数据对整棵 $2^K$ 树算一次）：$Y$ 在第 $h$ 层，擂主孩子 $H$、另一孩子 $O$。$good(Y)$ ⇔ 某个 $w$ 能以能力 $\le h$ 赢下 $Y$：
- $w \in H$：第 $h$ 轮 $w$ 是擂主，需要能力 $\ge h$，结合 $\le h$ 得**恰好为 $h$**；
- $w \in O$：需要 $good(H)$（阈值 $t(H)$），且 $w$ 以能力 $\le h - 1$（即 $good(O)$）或**恰好 $h$** 赢下 $O$。

于是引入 $E(Y, v)$：$Y$ 的胜者"能力恰好为 $v$"的阈值（$v >$ $Y$ 的层数），有

$$t(Y) = \max\Big(E(H,h),\ \min\big(t(H),\ \max(t(O), E(O,h))\big)\Big)$$
$$E(Y,v) = \max\Big(E(H,v),\ \min\big(t(H), E(O,v)\big)\Big)$$

叶子：$t(w) = [a_w = 0]\ ?\ \infty : w$，$E(w, v) = [a_w = v]\ ?\ \infty : w$。

**$E$ 的存储**：$E(Y, \cdot)$ 只在 $v$ 等于子树内某个 $a_w$ 时才与"默认值" $E_{def}(Y)$ 不同，所以每个结点只存一个默认值加一个按 $v$ 有序的**例外表**，大小不超过 $\min(2^{层数}, K)$。合并两个孩子时有序归并，与默认值相同的项直接丢掉。

### 3. 注意事项

- $T = 256$ 组、$n = 10^5$，必须每组 $O(n)$ 级别；如果每个询问沿树走 $O(\log n)$ 层，总量约 $4 \times 10^8$ 次带分支的操作，会超时。
- 只有 $1 \le a_w \le K$ 的能力值需要记例外（$v$ 只取 $1 \sim K$），能力大于 $K$ 等价于"永远赢"。
- 编号大于 $n$ 的位置永远是补充选手，阈值自然取其编号（$> n$，永不触发）。
- 对不同的 $k$，子树 $Y$ 内部的比赛完全相同（第 $R$ 轮第 $G$ 场的抽签不随 $k$ 改变），所以 $t$、$E$ 只算一次；只有 $thr$ 与路径条件依赖 $k$，对每个 $k$ 自顶向下扫一遍，总共 $\sum 2^k = O(2^K)$。
- 阈值、例外表用 32 位整数存，常数小一半。

### 4. 解决方案

每组数据：
1. 算出 $a_i$。叶子层初始化 $t$、默认值、例外表。
2. 自底向上逐层用上面的公式算 $t(Y)$、默认值 $E_{def}(Y) = \max(E_{def}(H), \min(t(H), E_{def}(O)))$ 和例外表（只保留 $v >$ 当前层的项）。
3. 对每个 $k = 0 \dots K$，在 $2^k$ 树上自顶向下：擂主孩子的 $thr$ 与当前轮取 max，另一孩子的路径条件与 $t(\text{擂主孩子})$ 取 min；到叶子得到 $T_k(x)$，在 $c \in [\max(2^{k-1}+1, 1),\ \min(2^k, n, T_k(x) - 1)]$ 上差分加 $x$。
4. 前缀和得到每个 $c$ 的答案，按要求异或输出。

每组复杂度约 $O(2^K \log K)$。

## 部分分策略 / 错误思路

- $n \le 8$：枚举补充选手的能力（只需取 $0 \sim k$），模拟比赛。
- 性质 B（$d$ 全为 0，左边永远是擂主）：结构固定，可以直接推出谁能赢。
- 每个询问 $O(k)$ 地沿"已知/未知分界"那条链计算：思路正确，$T$ 较小时能过，$T = 256$ 的点会超时。
- 只记录子树胜者能力的最小值来判断 $good$：不够，能力"恰好为 $h$"的情况需要单独处理（擂主一方需要能力 $\ge h$ 才能晋级）。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = (1 << 17) + 5, LG = 18;
int n, m, K, T;
int a0[N], a[N], q[N], df[N];
signed cd[LG][N], tr[LG][N];
int dv[2][N], ec[2][N];
signed ek[2][N][LG], ev[2][N][LG];
vector<int> t[LG];
string d[LG];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a0[i];
    For(i, 1, m) cin >> q[i];
    while ((1 << K) < n) K++;
    For(j, 1, K) cin >> d[j];
    For(j, 0, K) t[j].assign((1 << (K - j)) + 1, 0);
    cin >> T;
    while (T--) {
        int X[4];
        Rep(i, 0, 4) cin >> X[i];
        For(i, 1, n) a[i] = a0[i] ^ X[i % 4];
        For(w, 1, 1 << K) {
            t[0][w] = (w <= n && a[w] == 0) ? INF : w, dv[0][w] = w, ec[0][w] = 0;
            if (w <= n && a[w] >= 1 && a[w] <= K) ek[0][w][0] = a[w], ev[0][w][0] = INF, ec[0][w] = 1;
        }
        For(j, 1, K) {
            int cu = j & 1, pr = cu ^ 1;
            For(g, 1, 1 << (K - j)) {
                int h = d[j][g - 1] == '0' ? 2 * g - 1 : 2 * g, o = 4 * g - 1 - h;
                int th = t[j - 1][h], to = t[j - 1][o], dh = dv[pr][h], dw = dv[pr][o];
                signed *kh = ek[pr][h], *vh = ev[pr][h], *ko = ek[pr][o], *vo = ev[pr][o];
                int ch = ec[pr][h], co = ec[pr][o];
                int ih = 0, io = 0;
                int eh = dh, eo = dw;
                if (ih < ch && kh[ih] == j) eh = vh[ih++];
                if (io < co && ko[io] == j) eo = vo[io++];
                t[j][g] = max(eh, min(th, max(to, eo)));
                dv[cu][g] = max(dh, min(th, dw));
                int &c = ec[cu][g];
                c = 0;
                while (ih < ch || io < co) {
                    int v = min(ih < ch ? kh[ih] : LINF, io < co ? ko[io] : LINF);
                    int x = dh, y = dw;
                    if (ih < ch && kh[ih] == v) x = vh[ih++];
                    if (io < co && ko[io] == v) y = vo[io++];
                    int e = max(x, min(th, y));
                    if (e != dv[cu][g]) ek[cu][g][c] = v, ev[cu][g][c++] = e;
                }
            }
        }
        For(i, 1, n + 1) df[i] = 0;
        For(k, 0, K) {
            int lo = k ? (1 << (k - 1)) + 1 : 1, hi = min(1LL << k, n);
            if (lo > hi) continue;
            cd[k][1] = INF, tr[k][1] = 0;
            for (int j = k; j >= 1; j--)
                For(g, 1, 1 << (k - j)) {
                    int h = d[j][g - 1] == '0' ? 2 * g - 1 : 2 * g, o = 4 * g - 1 - h;
                    cd[j - 1][h] = cd[j][g], tr[j - 1][h] = max((int)tr[j][g], j);
                    cd[j - 1][o] = min((int)cd[j][g], t[j - 1][h]), tr[j - 1][o] = tr[j][g];
                }
            For(w, 1, 1 << k) {
                int lim = min((int)cd[0][w], (w <= n && a[w] < tr[0][w]) ? w : INF);
                int r = min(hi, lim - 1);
                if (r >= lo) df[lo] += w, df[r + 1] -= w;
            }
        }
        int ans = 0;
        For(i, 1, n) df[i] += df[i - 1];
        For(i, 1, m) ans ^= i * df[q[i]];
        cout << ans << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
