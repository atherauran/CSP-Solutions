# P11233 CSP-S 2024 T3 染色

## 题意

把数组每个数染红或蓝。若 $A_i$ 左边最近的同色数 $A_j$ 满足 $A_j = A_i$，得分 $A_i$。求最大总得分。$n \le 2 \times 10^5$，$T \le 10$。

**标签**：动态规划、前缀和　**难度**：6/10

## 解题思路

### 1. 底层逻辑

把序列按颜色切成若干**连续同色段**。段内相邻两个数互为"最近同色"；而一段的第一个数 $i$，它的最近同色数是**上一段之前的那个数**，即位置 $j - 1$ 的数，其中 $[j, i-1]$ 是上一段（颜色交替，$i$ 和 $j - 1$ 同色）。

所以设 $dp_i$ = 位置 $i$ 是一段的开头（$i$ 与 $i-1$ 异色）时，前面所有数的最大得分（不含 $i$ 所在段内部），则：

$$dp_i = \max_{j < i}\Big(dp_j + \underbrace{s_{i-1} - s_j}_{段 [j,i-1] 内部得分} + [A_{j-1} = A_i] \cdot A_i\Big)$$

其中 $s_k = \sum_{t \le k} [A_t = A_{t-1}] A_t$ 是"相邻相等"得分的前缀和。

### 2. 隐藏条件

- 去掉最后一项后，转移是 $\max_j (dp_j - s_j) + s_{i-1}$，维护前缀最大值即可 $O(1)$。
- 最后一项只在 $A_{j-1} = A_i$ 时非零。对固定的 $i$，**只需考虑 $j - 1 = pre_i$**（$A_i$ 上一次出现的位置）。交换论证：设 $i$ 与更早的 $p$ 配对（同为 X 色），$q = pre_i$ 在中间，那么 $(p, i)$ 之间全是 Y 色。把 $(q, i)$ 之间改成 X、$i$ 改成 Y、$i$ 之后所有颜色互换：$(q, i)$ 内部的配对不变；$q+1$ 原来与 $q$ 比较、现在与 $p$ 比较，而 $A_p = A_q$，得分不变；$i$ 改为与 $q$ 配对，仍得 $A_i$；$i$ 之后只是整体换色，得分不变。所以总能让 $i$ 与 $pre_i$ 配对。
- 第一段的开头是 1：$dp_1 = 0$。

### 3. 注意事项

- 要求 $j < i$，即 $pre_i + 1 < i$；若 $pre_i = i - 1$，它们相邻同色的情况已在 $s$ 中计算。
- 答案 $= \max_j (dp_j - s_j) + s_n$（最后一段为 $[j, n]$）。
- $A_i \le 10^6$，用数组记录上次出现位置，多组数据记得清空。
- 得分和可达 $2 \times 10^{11}$，用 64 位。

### 4. 解决方案

1. 求 $pre_i$ 与前缀和 $s$。
2. $mx = dp_1 - s_1 = 0$。对 $i = 2 \dots n$：
   - $dp_i = mx + s_{i-1}$；
   - 若 $pre_i \ne 0$ 且 $pre_i + 1 < i$：$dp_i = \max(dp_i,\ dp_{pre_i + 1} - s_{pre_i + 1} + s_{i-1} + A_i)$；
   - $mx = \max(mx, dp_i - s_i)$。
3. 输出 $mx + s_n$。

复杂度 $O(n)$。

## 部分分策略 / 错误思路

- $n \le 15$：枚举 $2^n$ 种染色。
- $O(n^2)$ DP：$dp$ 记录"另一种颜色最后一个数的位置"，每步转移 $O(n)$，$n \le 2000$ 可过。
- 值域小（$A_i \le 10$）：状态记"另一种颜色最后一个数的值"，$O(n \cdot V)$。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2e5 + 5, M = 1e6 + 5;
int n;
int a[N], s[N], dp[N], lst[M], pre[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i], pre[i] = lst[a[i]], lst[a[i]] = i;
    For(i, 1, n) lst[a[i]] = 0;
    s[1] = 0;
    For(i, 2, n) s[i] = s[i - 1] + (a[i] == a[i - 1] ? a[i] : 0);
    dp[1] = 0;
    int mx = dp[1] - s[1];
    For(i, 2, n) {
        dp[i] = mx + s[i - 1];
        int j = pre[i] + 1;
        if (pre[i] && j < i) dp[i] = max(dp[i], dp[j] - s[j] + s[i - 1] + a[i]);
        mx = max(mx, dp[i] - s[i]);
    }
    cout << mx + s[n] << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
