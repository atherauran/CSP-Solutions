# P11232 CSP-S 2024 T2 超速检测

## 题意

$n$ 辆车在长 $L$ 的路上从 $d_i$ 以初速度 $v_i$、加速度 $a_i$ 匀加速行驶（到终点或速度降为 0 时离开），$m$ 个测速仪在 $p_j$。问：(1) 全部开启时有多少车超速（速度 $> V$）；(2) 保证这些车仍被判超速的前提下，最多能关多少测速仪。$n, m \le 10^5$，$T \le 20$。

**标签**：物理公式、二分、区间选点贪心　**难度**：5/10

## 解题思路

### 1. 底层逻辑

1. 对每辆车，求出它**超速的位置区间**，再转成"区间内的测速仪下标区间" $[l, r]$；区间非空的车就是会被判超速的车。
2. 第二问：选最少的测速仪，使每个区间至少含一个被选中的测速仪——经典**区间选点**问题。

### 2. 隐藏条件

由 $v^2 = v_0^2 + 2a s$，位置 $x$ 处速度超速 ⇔ $v_0^2 + 2a(x - d) > V^2$。由于速度单调，超速位置是一个区间，且测速仪位置是整数，可以用**整数运算**求出整数端点：
- $a = 0$：$v_0 > V$ 时为 $[d, L]$，否则不超速；
- $a > 0$：速度递增。$v_0 > V$ 时从 $d$ 开始；否则从 $d + \lfloor \frac{V^2 - v_0^2}{2a} \rfloor + 1$ 开始，到 $L$；
- $a < 0$：速度递减，必须 $v_0 > V$。超速到 $x - d < \frac{v_0^2 - V^2}{2|a|}$，即最大整数 $x = d + \lceil \frac{v_0^2 - V^2}{2|a|} \rceil - 1$，再与 $L$ 取较小值。（车停下的位置速度为 0，必然在这个区间之外。）

区间选点贪心：按右端点排序，若当前区间不包含已选的最后一个点，就选它的右端点。

### 3. 注意事项

- 用浮点数算端点容易出现边界误差（"超过"是严格大于），全部用整数。
- 用 `lower_bound` / `upper_bound` 把位置区间转成测速仪下标区间。
- 多组数据。

### 4. 解决方案

1. 对每辆车按上面公式求位置区间 $[lo, hi]$，二分得下标区间 $[l, r]$，非空则计入第一问并保存。
2. 区间按 $r$ 排序，贪心选点得最少点数 $cnt$。
3. 输出第一问答案和 $m - cnt$。

复杂度 $O((n + m)\log)$。

## 部分分策略 / 错误思路

- 对每辆车枚举所有测速仪判断：$O(nm)$，第一问可拿部分分。
- 性质 A（$a = 0$）：超速区间都是 $[d, L]$，只需选最右边的一个测速仪就能覆盖所有超速车（第二问答案为 $m - 1$ 或 $m$）。
- 用 `double` 的 `sqrt` 判断：边界数据容易错。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5;
int n, m, L, V;
int d[N], v[N], a[N], p[N];
pii seg[N];

void solve() {
    cin >> n >> m >> L >> V;
    int tot = 0;
    For(i, 1, n) cin >> d[i] >> v[i] >> a[i];
    For(i, 1, m) cin >> p[i];
    For(i, 1, n) {
        int lo, hi;
        if (a[i] == 0) {
            if (v[i] <= V) continue;
            lo = d[i], hi = L;
        } else if (a[i] > 0) {
            lo = v[i] > V ? d[i] : d[i] + (V * V - v[i] * v[i]) / (2 * a[i]) + 1, hi = L;
        } else {
            if (v[i] <= V) continue;
            lo = d[i], hi = min(L, d[i] + (v[i] * v[i] - V * V - 2 * a[i] - 1) / (-2 * a[i]) - 1);
        }
        if (lo > hi) continue;
        int l = lower_bound(p + 1, p + 1 + m, lo) - p, r = upper_bound(p + 1, p + 1 + m, hi) - p - 1;
        if (l <= r) seg[++tot] = {r, l};
    }
    sort(seg + 1, seg + 1 + tot);
    int last = 0, used = 0;
    For(i, 1, tot) if (seg[i].S > last) last = seg[i].F, used++;
    cout << tot << " " << m - used << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
```
