# P17831 CSP-S 2026 T1 能量水晶

## 题意

$n$ 颗水晶能量为 $a_i$，至多 $m$ 次操作，每次把某颗水晶能量 $+1$。求最多能让多少颗水晶能量相同。$n \le 5 \times 10^5$，$|a_i| \le 10^{12}$，$m \le 10^{18}$。

**标签**：贪心、排序、双指针、前缀和　**难度**：3/10

## 解题思路

### 1. 底层逻辑

只能加不能减，所以选定的一组水晶最终都要变成**组内最大值**（再往上加只会更费）。

排序后，若最大值是 $a_r$，要选 $len$ 颗，代价是 $\sum (a_r - a_i)$，显然应选 $a_r$ 左边**最近的** $len$ 颗，即一段连续区间 $[l, r]$，代价
$$cost(l, r) = (r - l + 1) \cdot a_r - (pre_r - pre_{l-1}).$$

### 2. 隐藏条件

固定 $l$ 时 $cost$ 随 $r$ 增大而增大，固定 $r$ 时随 $l$ 增大而减小，所以对每个 $r$ 满足 $cost \le m$ 的最小 $l$ 单调不降，可以**双指针**。

### 3. 注意事项

- 数值范围：$(a_r - a_i) \le 2 \times 10^{12}$，乘上 $n$ 不超过 $10^{18}$，`long long` 够用。前缀和与 $(r-l+1) \cdot a_r$ 绝对值都不超过 $5 \times 10^{17}$，作差不会溢出。
- $a_i$ 可以为负，公式不受影响。

### 4. 解决方案

排序、求前缀和；$r$ 从 1 到 $n$，当 $cost(l, r) > m$ 时 $l$ 右移，用 $r - l + 1$ 更新答案。复杂度 $O(n \log n)$。

## 部分分策略 / 错误思路

- $n \le 5000$：对每个 $r$ 向左暴力扩展，$O(n^2)$。
- 也可以对每个 $r$ 二分 $l$，$O(n \log n)$。
- 值域小（$|a_i| \le 100$）时可以枚举目标值。
- 性质 A / B（等差数列）：代价是 $d \cdot len(len-1)/2$，可以直接解不等式。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'

#define F first

#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;

const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 5e5 + 5;
int n, m, ans;
int a[N], pre[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i];
    sort(a + 1, a + 1 + n);
    For(i, 1, n) pre[i] = pre[i - 1] + a[i];
    int l = 1;
    For(r, 1, n) {
        while ((r - l + 1) * a[r] - (pre[r] - pre[l - 1]) > m) l++;
        ans = max(ans, r - l + 1);
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);

    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
