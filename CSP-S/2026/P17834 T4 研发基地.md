# P17834 CSP-S 2026 T4 研发基地

## 题意

给一棵 $n$ 个点的树，选**恰好** $k$ 个点组成集合 $S$，要求 $S$ 的导出子图至多 $2$ 个连通块。每个点到 $S$ 的最近距离的最大值称为通勤半径，求其最小值。多组数据，$n \le 10^6$，$\sum n \le 2 \times 10^6$。

**标签**：二分答案、树形 DP、换根、贡献拆分　**难度**：9/10

## 解题思路

### 1. 底层逻辑

**单调性。** 若合理的 $S$ 满足 $|S| < n$，往里加一个与 $S$ 相邻的点，连通块数不增、半径不增。所以设 $m(r)$ 为"半径 $\le r$ 的合理集合的最小大小"，答案就是最小的 $r$ 使 $m(r) \le k$，**二分 $r$** 即可。$r = 0$ 只在 $k = n$ 时可行，下面都设 $r \ge 1$。

**一个连通块的最小代价。** 对树 $T'$，把每条边 $(a, b)$ 两侧"从端点出发能走多远"记为 $d_a, d_b$。若 $\min(d_a, d_b) \ge r$，连通的 $S$ 必须同时碰到两侧（否则另一侧最远点距离 $\ge r + 1$），这条边必选；反之这些边的并恰好就能覆盖全树。所以

$$m_1(T', r) = 1 + \#\{\text{两侧深度都} \ge r \text{ 的边}\}.$$

**两个连通块 ⇔ 切一条边。** 设 $S = S_1 \cup S_2$，在 $S_1$ 到 $S_2$ 的路径中点处切开一条边 $(x, y)$，每个点都离自己这一侧的块更近；反过来，切开后两侧各放一个连通块也一定合理（两块相邻也没关系）。单块的情况也不用单独算：大小 $\ge 2$ 时切开 $S$ 内部的一条边即可，大小为 $1$ 时切分代价为 $2 \le k$，不影响判定。于是

$$m(r) = \min_{(x,y)} \big(m_1(X, r) + m_1(Y, r)\big).$$

难点是对**每条边**快速算出两侧的 $m_1$。

### 2. 隐藏条件

记 $H(u \to w)$ 为"从 $u$ 出发经过 $w$ 能走的最远距离"，即 $1 +$ 删掉边后 $w$ 那一侧从 $w$ 出发的深度。所有 $2(n-1)$ 个有向边的 $H$ 与 $r$ 无关，换根一次求出。

考虑删掉边 $(x, y)$ 后 $y$ 所在的连通块 $Y$，把 $Y$ 里的边都定向为**远离 $y$**。边 $a \to b$ 被计入 $m_1(Y)$ 当且仅当：
- 远侧够深：$H(a \to b) \ge r + 1$（远侧完全在 $Y$ 内，不受切边影响）；
- 近侧够深：$a$ 那一侧在 $Y$ 内的深度 $\ge r$。

于是 $m_1(Y) = 1 + \text{full}(x \to y) - \text{lost}(x \to y)$，其中 full 只看第一个条件（换根求和即可），lost 是"远侧够深但近侧不够"的边数。lost 有很强的结构：

- **损失的边是从 $y$ 出发的一条链。** 两条不在同一条祖先链上的损失边，一条的近侧会包含另一条的远侧，深度 $\ge r + 1$，矛盾；且若某条边损失，它上方的边近侧更小、也损失。所以损失边是 $y = v_0, v_1, \dots, v_L$ 这条链。
- **链往哪走是固定的。** 在 $v_j$ 处（回头方向不算），下一步必须是唯一一个 $H \ge r + 1$ 的方向，其余方向 $H \le r - 1$。对有向边 $s = (p \to v)$，预处理 $v$ 除 $p$ 外 $H$ 最大的方向 $nx(s)$、最大值 $v_1(s)$、次大值 $v_2(s)$，这一步可走 ⇔ $v_2(s) < r < v_1(s)$。指针与 $r$ 无关，只是激活条件随 $r$ 变化。
- **近侧深度的约束。** 第 $j$ 条边损失还要求近侧深度 $\max_{i \le j}(v_2(s_i) + j - i) \le r - 1$。

记 $\delta(s)$ 为从 $s$ 沿激活指针还能走几步，化简后得到

$$\text{lost}(s_0) = \delta(s_0) - \max\Big(0,\ \max_{i < \delta(s_0)} \big(\delta(s_i) + v_2(s_i)\big) - r\Big),$$

只需沿指针递推 $\delta(s) = \delta(nx(s)) + 1$、$mx(s) = \max(\delta(s) + v_2(s), mx(nx(s)))$，每条有向边 $O(1)$。

### 3. 注意事项

- **处理顺序。** 指针总是往"更外面"走：以 $1$ 为根，向下的有向边指向更深的向下边；向上的有向边指向父亲的向上边或兄弟的向下边。所以先按 BFS 逆序处理所有向下边，再按 BFS 序处理所有向上边，$nx$ 一定先算好。full 的换根恰好也是这两遍，可以合并。
- 预处理每个点所有出边 $H$ 的前三大，就能 $O(1)$ 得到"去掉回头方向后"的最大、次大值。
- 二分上界取半径 $\lceil D/2 \rceil$（$D$ 为直径）：此时把中心和其余部分切开，两侧各 $1$ 个点就够，$k \ge 2$ 一定可行。
- 深度可达 $10^6$，全程用 BFS 序，不递归；输入量大，用快读；按边开的数组较多，用 `signed` 省内存。
- 复杂度 $O(n \log n)$。

### 4. 解决方案

1. 建图（边编号从 $2$ 开始，反向边为 `e ^ 1`），从 $1$ 做 BFS 得到父亲和 BFS 序。
2. 逆序求向下的 $H$，正序用前两大换根求向上的 $H$；同时对每条有向边记下 $nx, v_1, v_2$，并求直径 $D$。
3. 若 $k = n$ 输出 $0$；否则在 $[1, \lceil D/2 \rceil]$ 上二分 $r$，`check(r)`：
   - BFS 逆序处理向下边：递推 $\delta, mx$，并累加 full；
   - BFS 正序处理向上边：同样递推，full 用"父亲的总和减去自己这一支"得到；
   - 对每条边 $(x, y)$ 计算 $2 + \text{full}(x \to y) - \text{lost}(x \to y) + \text{full}(y \to x) - \text{lost}(y \to x)$，取最小值与 $k$ 比较。

## 部分分策略 / 错误思路

- $n \le 15$：枚举子集，检查连通块数并 BFS 求半径。
- $n \le 4000$：二分 $r$ 后枚举切边，两侧分别"剥 $r$ 层叶子"求 $m_1$，$O(n^2 \log n)$。
- $k = 2$：两个点任意放都合理，就是树的 2-中心：枚举切边，取 $\max(\text{rad}(X), \text{rad}(Y))$ 的最小值，两侧直径用换根求。
- 错误思路一：**只在直径上切**。看起来深的部分都在直径附近，但一条挂在直径中部、深度接近一半直径的支链，把它末端单独切出来能省下整条损失链，比任何直径上的切法都优。
- 错误思路二：直接设 $f(u \to w) = \sum_c \big(f(w \to c) + [\text{边} (w, c) \text{ 计入}]\big)$。深处的边是否计入取决于整个连通块的形状（近侧可能经过 $w$ 拐到别的分支），不能按子树独立拆开，必须拆成 full 与 lost 两部分。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e6 + 5;
int n, k, tot;
signed head[N], nxt[N * 2], to[N * 2], q[N], pe[N], fa[N], dn[N], cs[N];
signed h[N * 2], nx[N * 2], v1[N * 2], v2[N * 2], dl[N * 2], mx[N * 2], fu[N * 2];

inline int read() {
    int x = 0;
    char c = getchar();
    while (c < '0') c = getchar();
    while (c >= '0') x = x * 10 + c - '0', c = getchar();
    return x;
}

inline void add(int u, int v) { to[++tot] = v, nxt[tot] = head[u], head[u] = tot; }

inline void calc(int s, int r) {
    if (v2[s] < r && v1[s] > r) dl[s] = dl[nx[s]] + 1, mx[s] = max(dl[s] + v2[s], mx[nx[s]]);
    else dl[s] = mx[s] = 0;
}

inline int lost(int s, int r) { return dl[s] - max(0LL, mx[s] - r); }

bool check(int r) {
    For(i, 1, n) cs[i] = 0;
    for (int i = n; i > 1; i--) {
        int v = q[i], s = pe[v];
        calc(s, r), fu[s] = cs[v], cs[fa[v]] += (h[s] > r) + fu[s];
    }
    int best = LINF;
    For(i, 2, n) {
        int v = q[i], p = fa[v], s = pe[v] ^ 1, up = pe[p] ^ 1;
        calc(s, r), fu[s] = cs[p] - (h[s ^ 1] > r) - fu[s ^ 1];
        if (p != 1) fu[s] += (h[up] > r) + fu[up];
        best = min(best, 2 + fu[s] - lost(s, r) + fu[s ^ 1] - lost(s ^ 1, r));
    }
    return best <= k;
}

void solve() {
    n = read(), k = read();
    tot = 1;
    For(i, 1, n) head[i] = 0;
    Rep(i, 1, n) {
        int u = read(), v = read();
        add(u, v), add(v, u);
    }
    int l = 1, r = 1;
    q[1] = 1, pe[1] = 0, fa[1] = 0;
    while (l <= r) {
        int u = q[l++];
        for (int e = head[u]; e; e = nxt[e])
            if (to[e] != fa[u]) pe[to[e]] = e, fa[to[e]] = u, q[++r] = to[e];
    }
    For(i, 1, n) dn[i] = 0;
    for (int i = n; i > 1; i--) {
        int v = q[i];
        h[pe[v]] = dn[v] + 1, dn[fa[v]] = max(dn[fa[v]], h[pe[v]]);
    }
    int d = 0;
    For(i, 1, n) {
        int v = q[i], a1 = 0, a2 = 0, a3 = 0, i1 = 0, i2 = 0;
        for (int e = head[v]; e; e = nxt[e]) {
            if (h[e] > a1) a3 = a2, a2 = a1, i2 = i1, a1 = h[e], i1 = e;
            else if (h[e] > a2) a3 = a2, a2 = h[e], i2 = e;
            else a3 = max(a3, (int)h[e]);
        }
        d = max(d, a1 + a2);
        for (int e = head[v]; e; e = nxt[e]) {
            int s = e ^ 1;
            if (e != (pe[v] ^ 1)) h[s] = 1 + (e == i1 ? a2 : a1);
            if (e == i1) nx[s] = i2, v1[s] = a2, v2[s] = a3;
            else if (e == i2) nx[s] = i1, v1[s] = a1, v2[s] = a3;
            else nx[s] = i1, v1[s] = a1, v2[s] = a2;
        }
    }
    if (k == n) {
        cout << 0 << endl;
        return;
    }
    int lo = 1, hi = (d + 1) / 2;
    while (lo < hi) {
        int mid = (lo + hi) / 2;
        if (check(mid)) hi = mid;
        else lo = mid + 1;
    }
    cout << lo << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int c = read(), tests = read();
    while (tests--) solve();
    return 0;
}
