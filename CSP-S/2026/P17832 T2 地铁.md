# P17832 CSP-S 2026 T2 地铁

## 题意

$m$ 个地铁站、$n$ 条线路。地铁口到站 $v$ 站厅步行 $w_v$；线路 $i$ 在站 $v$ 的站台到站厅步行 $t_{i,v}$。乘车不计时间，换乘要先从站台走到站厅、再走到另一条线路的站台。$q$ 次询问从 $x$ 的地铁口到 $y$ 的地铁口的最小总步行时间。$n \le 500$，$\sum k_i \le 5 \times 10^5$，每站至多 $d \le 20$ 条线路，$q \le 10^5$。

**标签**：图论建模、最短路、Floyd　**难度**：5/10

## 解题思路

### 1. 底层逻辑

乘车不花时间，所以上了线路 $i$ 之后，$i$ 经过的所有站都"免费可达"。真正花时间的只有三类动作：

- 进站：$w_x + t_{i,x}$（在 $x$ 登上线路 $i$）；
- 换乘：在站 $v$ 从线路 $i$ 换到线路 $j$，代价 $t_{i,v} + t_{j,v}$；
- 出站：$t_{j,y} + w_y$。

于是把**线路当作点**：线路 $i, j$ 之间连边，边权为 $\min_{v} (t_{i,v} + t_{j,v})$（$v$ 取两线共同经过的站）。设 $D_{i,j}$ 为这张图上的最短路，则
$$ans = w_x + w_y + \min_{i \ni x,\ j \ni y} \left( t_{i,x} + D_{i,j} + t_{j,y} \right)$$

### 2. 隐藏条件

- 站点多达 $5 \times 10^5$，但**线路只有 $500$ 条**，所以对线路图跑 Floyd 求全源最短路只要 $n^3 = 1.25 \times 10^8$ 次简单运算。
- 建边时枚举每个站上的线路对，总量 $\sum_v \deg(v)^2 \le d \cdot \sum k_i = 10^7$。
- 每站最多 $d$ 条线路，所以每个询问只需枚举 $d^2 = 400$ 对 $(i, j)$，总共 $4 \times 10^7$。

### 3. 注意事项

- $D_{i,i} = 0$：$x, y$ 在同一条线路上时不用换乘，公式自然包含这种情况。
- 线路上各站的先后顺序没有用：乘车不计时，只需知道哪些站在这条线上。
- 答案可达 $10^{12}$ 级，要用 64 位。`memset` 成 `0x3f` 后两个"无穷大"相加约 $9 \times 10^{18}$，不会溢出 `long long`。
- 读入约 $10^6$ 个数，关闭同步。

### 4. 解决方案

1. 读入时对每个站记录经过它的 $(线路, t)$ 列表。
2. 枚举每个站上的线路对 $(i, j)$，用 $t_{i,v} + t_{j,v}$ 更新 $D_{i,j}$。
3. Floyd 求线路间最短路。
4. 每个询问枚举 $x$ 上的线路 $i$、$y$ 上的线路 $j$，取 $t_{i,x} + D_{i,j} + t_{j,y}$ 的最小值，再加 $w_x + w_y$。

复杂度 $O(d \sum k_i + n^3 + q d^2)$。

## 部分分策略 / 错误思路

- 暴力：每站建一个"站厅"点，每个 $(线路, 站)$ 建一个"站台"点，站台与站厅连权 $t$ 的边，同线相邻站台连权 $0$ 的边，每个询问跑一次 Dijkstra。$O(q \sum k \log)$，能过前几档。
- 性质 B（$t$ 全为 $T$）：每次乘车贡献 $2T$，答案是 $w_x + w_y + 2T \cdot (\text{乘车次数})$，线路图上 BFS 即可。
- 把站点当作点、换乘代价挂在站点上：换乘代价取决于**换出和换入的两条线路**，站点图无法表达，必须以线路为点。
- 每个询问在线路图上单独跑 Dijkstra：$q \cdot n^2 = 2.5 \times 10^{10}$，超时；而全源最短路只需算一次。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 505, M = 5e5 + 5;
int c, n, m, d, q;
int w[M], dis[N][N];
vector<pii> g[M];

void solve() {
    cin >> c >> n >> m >> d >> q;
    For(i, 1, m) cin >> w[i];
    For(i, 1, n) {
        int k;
        cin >> k;
        while (k--) {
            int a, t;
            cin >> a >> t;
            g[a].pb({i, t});
        }
    }
    mset(dis, 0x3f);
    For(i, 1, n) dis[i][i] = 0;
    For(v, 1, m) for (auto x : g[v]) for (auto y : g[v])
        if (x.F != y.F) dis[x.F][y.F] = min(dis[x.F][y.F], x.S + y.S);
    For(k, 1, n) For(i, 1, n) {
        int dik = dis[i][k];
        For(j, 1, n) dis[i][j] = min(dis[i][j], dik + dis[k][j]);
    }
    while (q--) {
        int x, y, ans = LINF;
        cin >> x >> y;
        for (auto a : g[x]) for (auto b : g[y])
            ans = min(ans, a.S + dis[a.F][b.F] + b.S);
        cout << ans + w[x] + w[y] << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
