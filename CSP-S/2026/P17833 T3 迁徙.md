# P17833 CSP-S 2026 T3 迁徙

## 题意

$n$ 座岛在数轴上，坐标 $x_1 < x_2 < \dots < x_n$，距离不超过 $d$ 的两岛之间有一条长度为 1 的无向边。对 $u < v$，若 $u$ 到 $v$ 的最短路**恰好两条**，称为双径岛屿对，求其数量。多组数据，$\sum n \le 2 \times 10^6$，坐标绝对值 $\le 10^{18}$，$d \le 2 \times 10^{18}$。

**标签**：最短路计数、贪心、双指针、计数　**难度**：8/10

## 解题思路

### 1. 底层逻辑

记 $f_i$ 为 $i$ 一步能跳到的**最右**岛，$g_i$ 为一步能跳到的**最左**岛（双指针 $O(n)$ 求出）。

- **最短路一定从左往右单调走。** 若某一步往回走，要么可以直接跳过中间点，要么起点本身就能一步到达，都与"最短"矛盾。
- 设 $D = \operatorname{dist}(u, v)$。对 $w \in [u, v]$：$\operatorname{dist}(u, w) \le i \iff w \le f^i(u)$，$\operatorname{dist}(w, v) \le j \iff w \ge g^j(v)$（贪心跳最远）。所以最短路上"第 $i$ 步所在的点"恰好构成一个区间，称为**第 $i$ 层**：
$$\text{第 } i \text{ 层} = [\,g^{D-i}(v),\ f^i(u)\,],\quad 1 \le i \le D-1$$
  层内每个点都在某条最短路上。
- **最短路恰好两条 $\iff$ 恰有一层大小为 2，其余各层大小为 1。**
  - 某层大小 $\ge 3$，显然至少 3 条。
  - 相邻两层都是 2 个点 $\{a_1 < a_2\}$、$\{b_1 < b_2\}$：区间图的边满足"包含"性质，可推出 $a_1b_1$、$a_2b_1$、$a_2b_2$ 三条边都存在，至少 3 条。
  - 两个大小为 2 的层不相邻，若中间某层只有一个点，两段可以自由组合，至少 4 条；否则中间层大小也 $\ge 2$，归结为上一种情况。

### 2. 隐藏条件

只考虑层大小，问题就变成了纯粹的"结构计数"，不用再管路径条数。

- 称 $p \to q$ 为**紧边**，如果 $f_p = q$ 且 $g_q = p$。每个点至多一条紧出边、一条紧入边，所以紧边连成若干条**链**。
- 若相邻两层都只有一个点 $p, q$，则 $q = f_p$ 且 $p = g_q$，即 $p \to q$ 是紧边。所以连续的单点层就是紧链上连续的一段。
- 设大小为 2 的层是 $\{a, a+1\}$，在第 $k$ 层。把它左右两半拆开看：
  - **左半**（决定 $u$）：
    - $k = 1$：只需 $f_u = a + 1$，且 $u < a$。
    - $k \ge 2$：第 $k-1$ 层的点 $p$ 必须满足 $p = g_a$（第 $k$ 层左端往左跳一步）且 $f_p = a + 1$（往右跳一步到第 $k$ 层右端）；第 $1 \sim k-1$ 层是一段以 $p$ 结尾的紧链，开头 $c_1 = f_u$。
  - **右半**（决定 $v$）对称：$k = D-1$ 时 $g_v = a$ 且 $v > a + 1$；否则 $q = f_{a+1}$ 满足 $g_q = a$，第 $k+1 \sim D-1$ 层是从 $q$ 开始的紧链，末尾 $c_{D-1} = g_v$。
- 左右两半互不影响，任意拼起来都恰好得到一个双径岛屿对，而每个双径岛屿对的 $a$ 唯一。所以
$$ans = \sum_{a=1}^{n-1} L(a) \cdot R(a)$$

### 3. 注意事项

- 令 $cf_c = \#\{u < c : f_u = c\}$，$cg_c = \#\{v > c : g_v = c\}$。沿紧链求前缀/后缀和：
  - $tl_p = cf_p + tl_{g_p}$（若 $g_p \to p$ 是紧边），从左往右算；
  - $tr_q = cg_q + tr_{f_q}$（若 $q \to f_q$ 是紧边），从右往左算。
- $L(a) = \#\{u < a : f_u = a + 1\} + [\,g_a < a \text{ 且 } f_{g_a} = a + 1\,] \cdot tl_{g_a}$，其中第一项是 $cf_{a+1}$ 去掉 $u = a$ 的情况。$R(a)$ 对称。
- 坐标差最大 $2 \times 10^{18}$，判断相邻只用 $x_j - x_i \le d$，不会溢出；不要写 $x_i + d$ 之类再参与别的加法。
- 答案可达 $n^2$ 级，用 64 位。
- 输入有 $2 \times 10^6$ 个 64 位整数，用 `fread` 快读。

### 4. 解决方案

1. 双指针求 $f_i, g_i$。
2. 统计 $cf, cg$，沿紧链求 $tl, tr$。
3. 枚举 $a$，按上面的公式累加 $L(a) \cdot R(a)$。

复杂度 $O(n)$。

## 部分分策略 / 错误思路

- $N \le 300$：对每个 $u$ BFS，同时记录最短路条数（与 3 取 min）。
- $N \le 5000$：最短路单调向右，对每个 $u$ 从左往右 DP，$cnt_v = \sum cnt_w$（$w \in [g_v, v)$ 且距离少 1），前缀和优化到 $O(n^2)$。
- 性质 A（等差，公差 $s$）：令 $k = \lfloor d / s \rfloor$，所有中间层大小都是 $Dk - (v - u) + 1$，只有 $D = 2$、$v - u = 2k - 1$ 满足，答案为 $\max(0, n - 2k + 1)$（$k \ge 2$ 时）。
- 性质 B（存在中心岛）：所有距离 $\le 2$，只需统计 $D = 2$ 且 $f_u - g_v = 1$ 的对数。
- 性质 C：$D$ 不超过约 20，可以对每层分别处理，是从暴力走向正解的过渡。
- 以为"存在一层大小为 2"就是两条：其他层也大于 1 时路径数会成倍增加。
- 直接计路径条数会爆 long long，必须封顶或改成看层大小。
- 倍增求 $f^D(u)$ 再枚举：$O(n \log n)$ 时间和空间都很紧，且仍是 $O(n^2)$ 对数的枚举，没有抓住"左右独立拼接"的结构。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2e6 + 5;
int n, d, ans;
int x[N], f[N], g[N], cf[N], cg[N], tl[N], tr[N];
char buf[1 << 20], *p1 = buf, *p2 = buf;

inline char gc() { return p1 == p2 && (p2 = (p1 = buf) + fread(buf, 1, 1 << 20, stdin), p1 == p2) ? EOF : *p1++; }

inline int read() {
    int r = 0, s = 1;
    char c = gc();
    while (c < '0' || c > '9') {
        if (c == '-') s = -1;
        c = gc();
    }
    while (c >= '0' && c <= '9') r = r * 10 + c - '0', c = gc();
    return r * s;
}

void solve() {
    n = read(), d = read(), ans = 0;
    For(i, 1, n) x[i] = read(), cf[i] = cg[i] = 0;
    for (int i = 1, j = 1; i <= n; i++) {
        while (j < n && x[j + 1] - x[i] <= d) j++;
        f[i] = j;
    }
    for (int i = n, j = n; i >= 1; i--) {
        while (j > 1 && x[i] - x[j - 1] <= d) j--;
        g[i] = j;
    }
    For(i, 1, n) {
        if (f[i] > i) cf[f[i]]++;
        if (g[i] < i) cg[g[i]]++;
    }
    For(i, 1, n) tl[i] = cf[i] + (g[i] < i && f[g[i]] == i ? tl[g[i]] : 0);
    for (int i = n; i >= 1; i--) tr[i] = cg[i] + (f[i] > i && g[f[i]] == i ? tr[f[i]] : 0);
    Rep(a, 1, n) {
        int l = cf[a + 1] - (f[a] == a + 1), r = cg[a] - (g[a + 1] == a);
        int p = g[a], q = f[a + 1];
        if (p < a && f[p] == a + 1) l += tl[p];
        if (q > a + 1 && g[q] == a) r += tr[q];
        ans += l * r;
    }
    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    read(), tests = read();
    while (tests--) solve();
    return 0;
}
```
