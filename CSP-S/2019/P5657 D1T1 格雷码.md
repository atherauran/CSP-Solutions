# P5657 CSP-S 2019 D1T1 格雷码

## 题意

按"前半加前缀 0、后半逆序加前缀 1"的递归方式生成 $n$ 位格雷码，求编号为 $k$ 的串。$n \le 64$，$0 \le k < 2^n$。

**标签**：位运算、递归、格雷码　**难度**：3/10

## 解题思路

### 1. 底层逻辑

从最高位往低位逐位确定：$n$ 位格雷码分成前后两半，$k < 2^{n-1}$ 时这一位是 0，问题变成 $n-1$ 位、编号 $k$；否则这一位是 1，由于后半是**逆序**，问题变成 $n-1$ 位、编号 $2^n - 1 - k$。

### 2. 隐藏条件

把"逆序"代入二进制可以得到闭式：第 $i$ 位的格雷码 = $k$ 的第 $i$ 位 xor 第 $i+1$ 位，即

$$G(k) = k \oplus (k \gg 1)$$

依据：$2^n - 1 - k$ 就是把 $k$ 的低 $n$ 位全部取反。进入后半时，后面的位全部翻转一次；第 $i$ 位翻转的次数就是更高一位是否为 1，翻转结果正好是相邻两位的异或。

### 3. 注意事项

- $n = 64$ 时 $k$ 最大 $2^{64}-1$，超出 `long long`，必须用 `unsigned long long`（这正是 95 分和 100 分的分界）。
- 输出必须恰好 $n$ 位，包括前导 0。

### 4. 解决方案

用 `ull` 读入 $k$，计算 $k \oplus (k \gg 1)$，从第 $n-1$ 位到第 0 位逐位输出。$O(n)$。

## 部分分策略 / 错误思路

- 按定义递归生成整张表：只能过 $n \le 10$。
- 按第 1 步的递归逐位做也完全正确，只是要注意 `1ull << 63` 和 $2^n-1-k$ 的写法，用 `ull` 即可。
- 用 `long long` 读入：$k \ge 2^{63}$ 时溢出，丢 5 分。
