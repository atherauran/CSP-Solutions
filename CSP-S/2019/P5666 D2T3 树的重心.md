# P5666 CSP-S 2019 D2T3 树的重心

## 题意

给定一棵 $n$ 个点的树，对每条边，删掉后得到两棵树，把两棵树所有重心的编号加起来。求所有边的总和。$n \le 299995$，$T \le 5$。

**标签**：树的重心、换根 DP、倍增　**难度**：8/10

## 解题思路

### 1. 底层逻辑

对每条边 $(u, v)$（$v$ 是 $u$ 的儿子）要求两件事：
1. 子树 $v$ 的重心；
2. 整棵树去掉子树 $v$ 后（以 $u$ 为根）的重心。

所以核心子问题是：**以 $r$ 为根、大小为 $S$ 的树，快速求重心**。

### 2. 隐藏条件

- 以 $r$ 为根时，重心一定在从 $r$ 出发、一直走**重儿子**的那条链上（重心不在这条链上，则它所在的那一侧子树太大）。
- 沿重链往下走，"上方部分大小 $S - sz_x$"递增，"最大儿子 $sz_{son_x}$"递减。所以重心是重链上**最深的满足 $2 sz_x \ge S$ 的点 $x$**（再检查一下），若 $2sz_x = S$，$x$ 的父亲也是重心。
- 在重链上找"最深的满足条件的点"可以**倍增**：$f_{x,k}$ 表示从 $x$ 沿重儿子走 $2^k$ 步到达的点，条件单调，所以能二分跳。
- 第 2 类子问题需要"以 $u$ 为根"时的 $sz$ 和重儿子，用**换根**：DFS 从父亲走到儿子时，只有父亲 $u$ 这一个点的信息改变（大小变成 $n - sz_v$，重儿子在"除 $v$ 外所有邻居"中选），只需重建 $u$ 的倍增表 $O(\log n)$。

### 3. 注意事项

- 换根后 $u$ 的邻居包括原来的父亲，它此时的大小是 $n - sz_u^{原}$——这在递归进 $u$ 之前已经被父亲设好。所以要记录每个点的**最大和次大**邻居，排除 $v$ 后取重儿子。
- 判第二个重心要用当前根下的父亲 `fa`，换根时也要同步修改 `fa`，回溯时恢复 `sz`、`fa`、重儿子和倍增表（重儿子要用备份的 `oson`，因为循环中已被改写）。
- 递归深度可达 $3 \times 10^5$，评测栈空间需足够（洛谷/NOI Linux 环境均可）。
- 复杂度 $O(n \log n)$，时限 4s 足够。

### 4. 解决方案

1. `dfs1`：以 1 为根求 $sz$、`fa`、重儿子，并建倍增表 `f[u][k]`；备份原始的 `osz`、`ofa`、`oson`。
2. `calc(r)`：设 $S = sz_r$，从 $r$ 倍增跳到重链上最深的 $2sz_x \ge S$ 的点 $x$；若 $2\max(sz_{son_x}, S - sz_x) \le S$ 则 $x$ 是重心；若 $x \ne r$ 且 $2sz_x = S$，`fa[x]` 也是重心。
3. `dfs2(u)`：求 $u$ 所有邻居中 $sz$ 最大、次大的点 $b_1, b_2$。对每个原儿子 $v$：
   - 设 $sz_u = n - osz_v$，`fa[u] = 0`，重儿子取 $b_1$（若 $b_1 = v$ 则取 $b_2$），重建 `f[u]`；
   - 答案加上 `calc(u) + calc(v)`；
   - 令 `fa[u] = v`、`fa[v] = 0`，递归 `dfs2(v)`，回来后恢复 `fa[v] = u`。
   
   处理完所有儿子后，恢复 $u$ 的原始信息。

## 部分分策略 / 错误思路

- $n \le 1999$：枚举每条边，对两边各 $O(n)$ 求重心，$O(n^2)$，40 分。
- 链：重心就是中点，直接算。
- 完美二叉树：删边后的结构很规整，可以分类讨论。
- 直接对每条边从根往下暴力走重链：链状数据会退化到 $O(n^2)$。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 3e5 + 5, LG = 19;
int n, ans;
int sz[N], osz[N], son[N], oson[N], fa[N], ofa[N], f[N][LG];
vector<int> g[N];

inline void build(int u, int s) {
    son[u] = f[u][0] = s;
    Rep(k, 1, LG) f[u][k] = f[f[u][k - 1]][k - 1];
}

int calc(int r) {
    int tot = sz[r], x = r;
    for (int k = LG - 1; k >= 0; k--)
        if (f[x][k] && 2 * sz[f[x][k]] >= tot) x = f[x][k];
    int res = 0;
    if (2 * max(sz[son[x]], tot - sz[x]) <= tot) res += x;
    if (x != r && 2 * sz[x] == tot) res += fa[x];
    return res;
}

void dfs1(int u, int p) {
    sz[u] = 1, fa[u] = p;
    int s = 0;
    for (int v : g[u])
        if (v != p) {
            dfs1(v, u), sz[u] += sz[v];
            if (sz[v] > sz[s]) s = v;
        }
    build(u, s);
}

void dfs2(int u) {
    int b1 = 0, b2 = 0;
    for (int v : g[u]) {
        if (sz[v] > sz[b1]) b2 = b1, b1 = v;
        else if (sz[v] > sz[b2]) b2 = v;
    }
    for (int v : g[u]) {
        if (v == ofa[u]) continue;
        sz[u] = n - osz[v], fa[u] = 0;
        build(u, v == b1 ? b2 : b1);
        ans += calc(u) + calc(v);
        fa[u] = v, fa[v] = 0;
        dfs2(v);
        fa[v] = u;
    }
    sz[u] = osz[u], fa[u] = ofa[u];
    build(u, oson[u]);
}

void solve() {
    cin >> n;
    For(i, 1, n) g[i].clear();
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    ans = 0;
    dfs1(1, 0);
    For(i, 1, n) osz[i] = sz[i], ofa[i] = fa[i], oson[i] = son[i];
    dfs2(1);
    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
```
