# P5658 CSP-S 2019 D1T2 括号树

## 题意

以 1 为根的树，每个点上一个括号。$s_i$ 是根到 $i$ 路径上的括号串，$k_i$ 是 $s_i$ 中**位置不同**的合法括号子串个数。求 $\bigoplus (i \times k_i)$。$n \le 5 \times 10^5$。

**标签**：树、栈、递推（DP）　**难度**：5/10

## 解题思路

### 1. 底层逻辑

先看序列版本：$k_i = k_{i-1} + (\text{以 } i \text{ 结尾的合法子串数})$。记 $lst_i$ 为以 $i$ 结尾的合法子串数：

- 若 $i$ 是 `)` 且与位置 $m$ 的 `(` 匹配（用栈求），则以 $i$ 结尾的合法串 = "$[m,i]$ 这一段" 再在前面拼上若干个"以 $m-1$ 结尾的合法串"，所以 $lst_i = lst_{m-1} + 1$；
- 否则 $lst_i = 0$。

树上版本只是把"$i-1$"换成"父亲"：$lst_u = lst_{fa_m} + 1$，$k_u = k_{fa_u} + lst_u$。

### 2. 隐藏条件

- 题目保证 $f_u < u$，所以按编号从小到大处理时父亲一定已处理完，**不需要 DFS**。
- 每个点的"括号栈状态"只依赖父亲的栈状态。栈可以做成**可持久化**的：记 $top_u$ 为处理完 $u$ 后栈顶未匹配 `(` 的位置，那么栈顶下面一个元素就是 $top_{fa_{top_u}}$（压入它之前的栈顶）。

### 3. 注意事项

- $n = 5 \times 10^5$，链状数据递归 DFS 深度很大，用编号顺序递推更稳。
- $i \times k_i$ 会超过 int，要用 64 位。
- 题目说"互不相同的子串"实际是按位置区分（样例可验证），即统计所有合法子串的出现次数。

### 4. 解决方案

按 $u = 1 \dots n$ 递推（$fa_1 = 0$，下标 0 的各值为 0）：

- `(`：$top_u = u$，$lst_u = 0$；
- `)`：设 $m = top_{fa_u}$。若 $m \ne 0$，则匹配成功：$lst_u = lst_{fa_m} + 1$，弹栈后的栈顶 $top_u = top_{fa_m}$；若 $m = 0$，栈空，$top_u = 0$，$lst_u = 0$；
- $sum_u = sum_{fa_u} + lst_u$，答案异或上 $u \times sum_u$。

复杂度 $O(n)$。

## 部分分策略 / 错误思路

- 链的情况就是序列版本，直接用栈。
- 树上 DFS + 全局栈 + 回溯恢复栈也可以 AC，但要小心递归深度和回溯写法。
- 把 $lst_u$ 写成 $lst_{fa_u} + 1$（拼在父亲后面）是错的，应接在**匹配左括号的父亲**后面。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 5e5 + 5;
int n, ans;
int fa[N], top[N], lst[N], sum[N];
string s;

void solve() {
    cin >> n >> s;
    s = " " + s;
    For(i, 2, n) cin >> fa[i];
    For(u, 1, n) {
        int f = fa[u];
        if (s[u] == '(') top[u] = u;
        else if (top[f]) {
            int m = top[f];
            lst[u] = lst[fa[m]] + 1, top[u] = top[fa[m]];
        }
        sum[u] = sum[f] + lst[u];
        ans ^= u * sum[u];
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
