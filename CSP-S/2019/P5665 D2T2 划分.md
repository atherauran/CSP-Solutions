# P5665 CSP-S 2019 D2T2 划分

## 题意

把序列 $a$ 划分成若干连续段，要求段和单调不降，最小化各段和的平方和。$n \le 4 \times 10^7$（部分数据由生成器给出），答案可能超过 `long long`。

**标签**：贪心、单调队列、DP 优化、高精度（`__int128`）　**难度**：8/10

## 解题思路

### 1. 底层逻辑

朴素 DP：$f_i = \min_j f_j + (s_i - s_j)^2$，要求 $s_i - s_j \ge s_j - s_{g_j}$（$g_j$ 是 $j$ 的最优上一个分界点），$O(n^2)$。要优化需要更强的结构性质。

### 2. 隐藏条件

**关键结论**：对每个前缀 $i$，在合法前提下让**最后一段尽量短**（即最后一个分界点 $g_i$ 尽量靠右）就是最优的。

直观依据：平方和对"均匀"的划分更小——把一部分量从后段挪到前段（前段仍不超过后段）会让平方和变小；同时最后一段越短，后面能接的段限制越宽松。（这是考场上通过打表/小数据 DP 观察出来的结论，严格证明较长。）

于是 $g_i$ = 满足 $s_i \ge 2s_j - s_{g_j}$ 的最大 $j$。记 $val_j = 2s_j - s_{g_j}$：

- $s_i$ 单调递增 → 某个 $j$ 一旦对 $i$ 合法，对之后的 $i$ 也合法；
- 若 $j_1 < j_2$ 且 $val_{j_1} \ge val_{j_2}$，$j_1$ 永远不会比 $j_2$ 更优（更靠左、条件还更难满足），可以删掉。

所以用**单调队列**维护 $val$ 递增的候选：队首的下一个元素合法就弹出队首，最后队首就是最大的合法 $j$。

### 3. 注意事项

- $n = 4 \times 10^7$，只能 $O(n)$，而且内存要算清：前缀和 $s$ 用 64 位（320MB），$g$ 和队列只存下标，用 32 位（`signed`）各 160MB，总共约 640MB < 1GB。
- 答案可达 $(4 \times 10^7 \times 10^9)^2 \approx 1.6 \times 10^{33}$，要用 `__int128` 累加并手写输出。
- 生成方式里 $b_i$ 可以滚动计算，不必开数组；乘法 $x \cdot b$ 在 $2^{60}$ 以内，64 位不会溢出。

### 4. 解决方案

1. 读入/生成 $a$，求前缀和 $s$。
2. 队列初始为 $\{0\}$（$g_0 = 0$，$val_0 = 0$）。对 $i = 1 \dots n$：
   - 当队列至少两个元素且 $val_{q_{h+1}} \le s_i$ 时弹出队首；
   - $g_i = q_h$；
   - 当队尾 $val \ge val_i$ 时弹出队尾，然后把 $i$ 入队。
3. 从 $i = n$ 沿 $g$ 往回走，累加 $(s_i - s_{g_i})^2$（`__int128`），输出。

复杂度 $O(n)$。

## 部分分策略 / 错误思路

- $n \le 400$：$O(n^3)$ DP（记录最后一段的起点）。
- $n \le 5000$：$O(n^2)$ DP，配合"最后一段最短"的结论，可以从右往左找第一个合法 $j$。
- 不用 `__int128` 或高精度：最后 3 个点必错。
- $g$ 和队列开 64 位：内存约 960MB，加上其他开销有 MLE 风险。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'

#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 4e7 + 5, M = 1e5 + 5;
int n, type;
int s[N];
signed g[N], q[N];
int p[M], l[M], r[M];

inline int val(int j) { return 2 * s[j] - s[g[j]]; }

void solve() {
    cin >> n >> type;
    if (type == 0) {
        For(i, 1, n) cin >> s[i], s[i] += s[i - 1];
    } else {
        int x, y, z, b1, b2, m;
        cin >> x >> y >> z >> b1 >> b2 >> m;
        For(i, 1, m) cin >> p[i] >> l[i] >> r[i];
        int j = 1;
        For(i, 1, n) {
            int b;
            if (i == 1) b = b1;
            else if (i == 2) b = b2;
            else b = (x * b2 + y * b1 + z) % (1 << 30), b1 = b2, b2 = b;
            while (p[j] < i) j++;
            s[i] = s[i - 1] + b % (r[j] - l[j] + 1) + l[j];
        }
    }
    int h = 1, t = 1;
    q[1] = 0;
    For(i, 1, n) {
        while (h < t && val(q[h + 1]) <= s[i]) h++;
        g[i] = q[h];
        while (h <= t && val(q[t]) >= val(i)) t--;
        q[++t] = i;
    }
    __int128 ans = 0;
    for (int i = n; i; i = g[i]) ans += (__int128)(s[i] - s[g[i]]) * (s[i] - s[g[i]]);
    string out;
    while (ans) out += char('0' + ans % 10), ans /= 10;
    reverse(out.begin(), out.end());
    cout << out;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);

    // cin >> tests;
    while (tests--) solve();
    return 0;
}
