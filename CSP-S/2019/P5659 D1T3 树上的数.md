# P5659 CSP-S 2019 D1T3 树上的数

## 题意

树上每个点放着 $1 \sim n$ 的一个排列。按某种顺序删掉所有 $n-1$ 条边，每删一条边就交换其两端点上的数。最终把数字 $1 \sim n$ 所在的点编号依次写下得到排列 $P$，求字典序最小的 $P$。$n \le 2000$，$T \le 10$。

**标签**：贪心、构造、树、链表、并查集　**难度**：9/10

## 解题思路

### 1. 底层逻辑

字典序最小 → **贪心**：按数字 $1, 2, \dots, n$ 的顺序，每次给当前数字找一个能去的**编号最小**的终点，并把"走这条路"所需的约束固定下来，前提是不与之前的约束冲突。

于是问题拆成两部分：
1. 一个数字从 $s$ 走到 $t$，对删边顺序提出了什么约束？
2. 如何判断新约束与已有约束是否相容？

### 2. 隐藏条件

**数字的路径**：数字从 $s$ 出发，每次它所在的点有边被删，它就被换走，且来时的边已被删，无法回头，所以它沿树上**简单路径** $s \to t$ 走，且 $t \ne s$。

**约束全部是"每个点周围边的删除顺序"**，并且互相独立（不同点之间不影响）：
- 起点 $s$：出边必须是 $s$ 周围**第一条**被删的边（否则 $s$ 上的数早被换走）；
- 中间点 $v$（入边 $a$、出边 $b$）：在 $v$ 周围的边中，$b$ 必须**紧接在** $a$ 之后被删；
- 终点 $t$：入边必须是 $t$ 周围**最后一条**被删的边（否则数还会被换走）。

反过来，只要每个点周围边的顺序满足这些约束，就能拼出一个全局删边顺序（树上各点的局部顺序总能合并）。

所以对每个点维护：首边 `fst`、尾边 `lst`、以及若干条"紧邻"关系构成的**链**（`pre`/`nxt` + 并查集记录链的归属和长度）。

**相容条件**（都在同一个点 $u$、$\deg u$ 条边上考虑）：
- 设首边 $e$：$u$ 还没有首边；$e$ 没有前驱；若 $e$ 已是尾边则只能 $\deg u = 1$；若 $e$ 所在链已包含尾边，则这条链必须覆盖全部 $\deg u$ 条边。
- 设紧邻 $a \to b$：$a$ 没有后继，$b$ 没有前驱；$a$ 不是尾边，$b$ 不是首边；$a, b$ 不在同一条链（否则成环）；若 $a$ 的链含首边、$b$ 的链含尾边，合并后首尾连通，两链长度和必须等于 $\deg u$（否则剩下的边无处安放）。
- 设尾边 $a$：与首边对称。

### 3. 注意事项

- 约束存在"边的端点"上，同一条边在两端各有一个槽位，用有向边编号 $2i, 2i+1$ 表示，$e \oplus 1$ 是对面端点上的槽位。
- 每个数字做一次 DFS 枚举所有可达终点，$O(n)$；总共 $O(n^2 \alpha)$，$n = 2000$、$T = 10$ 可以通过。
- $n = 1$ 时直接输出 1。
- 每组数据要清空所有数组。

### 4. 解决方案

对数字 $i = 1 \dots n$，设它当前在点 $s$：

1. **搜索**：枚举 $s$ 的每条出边 $e$，若"$e$ 作为 $s$ 的首边"合法，沿它走到邻点。在点 $u$（入边槽位 $a$）：
   - 若"$a$ 作为 $u$ 的尾边"合法，用 $u$ 更新最小终点；
   - 枚举出边 $b \ne a$，若"$a \to b$ 在 $u$ 处紧邻"合法，继续往下走。
   同时记录每个点的入边 `in[u]`，便于回溯路径。
2. **提交**：取最小终点 $t$，设 `lst[t] = in[t]`；沿 `in` 往回走，每个中间点连上 $a \to b$（设 `nxt`、`pre`，并查集合并并累加链长）；回到 $s$ 时设 `fst[s]` 为出边。
3. 输出 $t$。

正确性：每一步的约束检查保证了"存在一个满足所有已固定约束的删边方案"，因此贪心选的终点一定可实现；字典序由逐位贪心保证。

## 部分分策略 / 错误思路

- $n \le 10$：枚举全部删边顺序 $(n-1)!$。
- 菊花图：中心点周围的边顺序就是一个排列，数字的移动形成一个环，可用并查集贪心。
- 链：每个点最多两条边，只需记录每个点"先删左边还是先删右边"，按数字贪心检查。
- 以上几个部分分思路正是正解的特例，正解把"每个点的边顺序约束"统一成链表 + 并查集。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2005;
int n, best;
int pos[N], deg[N], fst[N], lst[N], in[N];
int to[2 * N], f[2 * N], sz[2 * N], pre[2 * N], nxt[2 * N];
vector<int> g[N];

int find(int x) { return f[x] == x ? x : f[x] = find(f[x]); }

inline bool canFirst(int u, int e) {
    if (fst[u] || pre[e]) return false;
    if (lst[u] == e && deg[u] > 1) return false;
    if (lst[u] && find(lst[u]) == find(e) && sz[find(e)] < deg[u]) return false;
    return true;
}

inline bool canMid(int u, int a, int b) {
    if (nxt[a] || pre[b] || a == lst[u] || b == fst[u]) return false;
    if (find(a) == find(b)) return false;
    if (fst[u] && lst[u] && find(fst[u]) == find(a) && find(lst[u]) == find(b) && sz[find(a)] + sz[find(b)] < deg[u]) return false;
    return true;
}

inline bool canLast(int u, int a) {
    if (lst[u] || nxt[a]) return false;
    if (fst[u] == a && deg[u] > 1) return false;
    if (fst[u] && find(fst[u]) == find(a) && sz[find(a)] < deg[u]) return false;
    return true;
}

void dfs(int u, int a) {
    if (canLast(u, a)) best = min(best, u);
    for (int b : g[u])
        if (b != a && canMid(u, a, b)) in[to[b]] = b ^ 1, dfs(to[b], b ^ 1);
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> pos[i], g[i].clear(), deg[i] = fst[i] = lst[i] = 0;
    Rep(i, 1, n) {
        int x, y;
        cin >> x >> y;
        to[2 * i] = y, to[2 * i + 1] = x;
        g[x].pb(2 * i), g[y].pb(2 * i + 1);
        deg[x]++, deg[y]++;
    }
    For(e, 2, 2 * n - 1) f[e] = e, sz[e] = 1, pre[e] = nxt[e] = 0;
    if (n == 1) {
        cout << 1 << endl;
        return;
    }
    For(i, 1, n) {
        int s = pos[i];
        best = n + 1;
        for (int e : g[s])
            if (canFirst(s, e)) in[to[e]] = e ^ 1, dfs(to[e], e ^ 1);
        int t = best, a = in[t];
        lst[t] = a;
        int b = a ^ 1, u = to[a];
        while (u != s) {
            int c = in[u];
            nxt[c] = b, pre[b] = c;
            sz[find(b)] += sz[find(c)], f[find(c)] = find(b);
            b = c ^ 1, u = to[c];
        }
        fst[s] = b;
        cout << t << " ";
    }
    cout << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
