# P14362 CSP-S 2025 T2 道路修复

## 题意

$n$ 个城市、$m$ 条可修复道路（费用 $w_i$），另有 $k \le 10$ 个乡镇，改造乡镇 $j$ 费用 $c_j$，之后可以花 $a_{j,i}$ 在乡镇 $j$ 和城市 $i$ 间修路。求使原有 $n$ 个城市连通的最小总费用。$n \le 10^4$，$m \le 10^6$。

**标签**：最小生成树、Kruskal、状态枚举　**难度**：6/10

## 解题思路

### 1. 底层逻辑

$k \le 10$，**枚举改造哪些乡镇**（$2^k$ 种）。确定集合 $S$ 后，问题就是在"城市 + $S$ 中乡镇"的图上求最小生成树，再加上 $\sum_{j \in S} c_j$。

### 2. 隐藏条件

- 直接对每个 $S$ 跑 $10^6$ 条边的 Kruskal 太慢。关键：**原图中不在最小生成树上的边，加入新点后也永远不会被用到**（环性质：它是原图某个环上的最大边，这个环在新图中依然存在）。所以原图先求一次 MST，只保留 $n - 1$ 条边。
- 这样每次 Kruskal 只有 $n - 1 + |S| \cdot n \le 1.1 \times 10^5$ 条边。把"原 MST 边 + 所有乡镇边"**预先整体排序一次**，每次枚举时顺序扫描、跳过未选中乡镇的边即可，不必重新排序。

### 3. 注意事项

- 选中乡镇后，生成树需要连通 $n + |S|$ 个点，即 $n - 1 + |S|$ 条边，凑够就提前结束。
- 费用和可达 $10^{13}$ 级，用 64 位。
- 剪枝：当前费用已不小于最优答案时直接停止。
- 总复杂度 $O(m \log m + 2^k \cdot kn \cdot \alpha)$，约 $10^8$ 次并查集操作，并查集用路径压缩。
- 读入量约 $4 \times 10^6$ 个数，记得关闭同步。

### 4. 解决方案

1. 原图 Kruskal，得到 MST 边集。
2. 把 MST 边和所有 $k \times n$ 条乡镇边（乡镇 $j$ 编号为 $n + j$）合并排序。
3. 枚举 $S$：初始化并查集，费用为 $\sum_{j\in S} c_j$，按序扫描边（跳过不在 $S$ 中的乡镇的边），做 Kruskal；更新答案。

## 部分分策略 / 错误思路

- $k = 0$：普通最小生成树。
- 性质 A（$c_j = 0$ 且每个乡镇有一条 0 费用边）：改造所有乡镇一定不亏，只需一次 MST。
- 每次枚举都对全部 $m + kn$ 条边做 Kruskal：$2^k \cdot m \log m$，超时。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e4 + 20, M = 1e6 + 5, K = 12;
int n, m, k;
int c[K];
signed f[N];
struct edge { signed u, v; int w; } e[M], g[N * K];

inline bool cmp(const edge &x, const edge &y) { return x.w < y.w; }

int find(int x) {
    while (f[x] != x) x = f[x] = f[f[x]];
    return x;
}

void solve() {
    cin >> n >> m >> k;
    For(i, 1, m) cin >> e[i].u >> e[i].v >> e[i].w;
    sort(e + 1, e + 1 + m, cmp);
    For(i, 1, n) f[i] = i;
    int tot = 0;
    For(i, 1, m) {
        int x = find(e[i].u), y = find(e[i].v);
        if (x != y) f[x] = y, g[++tot] = e[i];
    }
    For(j, 1, k) {
        cin >> c[j];
        For(i, 1, n) {
            int w;
            cin >> w;
            g[++tot] = {(signed)(n + j), (signed)i, w};
        }
    }
    sort(g + 1, g + 1 + tot, cmp);
    int ans = LINF;
    Rep(s, 0, 1 << k) {
        int cost = 0, need = n - 1;
        For(j, 1, k) if (s >> (j - 1) & 1) cost += c[j], need++;
        For(i, 1, n + k) f[i] = i;
        For(i, 1, tot) {
            if (!need || cost >= ans) break;
            if (g[i].u > n && !(s >> (g[i].u - n - 1) & 1)) continue;
            int x = find(g[i].u), y = find(g[i].v);
            if (x != y) f[x] = y, cost += g[i].w, need--;
        }
        ans = min(ans, cost);
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
