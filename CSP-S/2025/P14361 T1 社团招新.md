# P14361 CSP-S 2025 T1 社团招新

## 题意

$n$（偶数）个新成员分到 3 个部门，成员 $i$ 去部门 $j$ 的满意度为 $a_{i,j}$。要求每个部门人数不超过 $n/2$，求满意度之和的最大值。$n \le 10^5$，$t \le 5$。

**标签**：贪心、排序　**难度**：3/10

## 解题思路

### 1. 底层逻辑

先不管人数限制，每人去自己最满意的部门；如果某个部门超员，再把其中一部分人调走，代价最小化。

### 2. 隐藏条件

- 总人数 $n$，上限 $n/2$，所以**最多只有一个部门会超员**（两个都超员人数就超过 $n$ 了）。
- 从超员部门调走一个人，最优是调到他的**第二满意**的部门，损失 = 最高满意度 − 第二满意度。调过去的部门不会因此超员：超员部门之外总共只有 $< n/2$ 人，调入 $cnt - n/2$ 人后其他两个部门合计恰好 $n/2$。
- 所以只需把超员部门里"损失"最小的 $cnt - n/2$ 个人调走。

### 3. 注意事项

- 第二满意度要从另外两个部门中取较大值。
- 多组数据清空计数与列表。

### 4. 解决方案

1. 每人选最大值，累加答案，记录所在部门与损失（最大值 − 次大值）。
2. 若某部门人数 $cnt > n/2$，把它的损失排序，减去最小的 $cnt - n/2$ 个。

复杂度 $O(n \log n)$。

## 部分分策略 / 错误思路

- $n \le 30$ 时可以 DP：$f[i][x][y]$ 记录前 $i$ 人中去部门 1、2 的人数。
- 性质 A（只有部门 1 有满意度）：取最大的 $n/2$ 个。
- 性质 B（部门 3 满意度为 0）：仍是同样的贪心。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5;
int n;
int a[N][3], cnt[3];
vector<int> loss[3];

void solve() {
    cin >> n;
    int ans = 0;
    Rep(j, 0, 3) cnt[j] = 0, loss[j].clear();
    For(i, 1, n) {
        Rep(j, 0, 3) cin >> a[i][j];
        int b = 0;
        Rep(j, 1, 3) if (a[i][j] > a[i][b]) b = j;
        int sec = -1;
        Rep(j, 0, 3) if (j != b) sec = max(sec, a[i][j]);
        ans += a[i][b], cnt[b]++, loss[b].pb(a[i][b] - sec);
    }
    Rep(j, 0, 3) if (cnt[j] > n / 2) {
        sort(loss[j].begin(), loss[j].end());
        Rep(t, 0, cnt[j] - n / 2) ans -= loss[j][t];
    }
    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
```
