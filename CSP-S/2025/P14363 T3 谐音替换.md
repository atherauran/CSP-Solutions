# P14363 CSP-S 2025 T3 谐音替换

## 题意

给定 $n$ 个等长字符串对 $(s_{i,1}, s_{i,2})$。一次替换：在 $t$ 中找到一个等于 $s_{i,1}$ 的子串，换成 $s_{i,2}$。$q$ 次询问：有多少种（位置, 二元组）的替换能把 $t_{j,1}$ 变成 $t_{j,2}$。$n, q \le 2 \times 10^5$，总长 $\le 5 \times 10^6$。

**标签**：字符串、Trie、DFS 序、扫描线 + 树状数组（二维数点）　**难度**：8/10

## 解题思路

### 1. 底层逻辑

设询问的 $t_1, t_2$ 等长，第一个和最后一个不同的位置为 $[L, R]$，把它们写成
$$t_1 = A + D_1 + B,\quad t_2 = A + D_2 + B$$

一次替换只改动一个窗口，所以窗口必须覆盖 $[L, R]$。同样把每个二元组写成 $s_1 = P + X + Q$，$s_2 = P + Y + Q$（$X, Y$ 是它们首个到末个不同位置之间的部分）。二元组 $i$ 能完成询问 ⇔
1. $X_i = D_1$ 且 $Y_i = D_2$；
2. $P_i$ 是 $A$ 的**后缀**；
3. $Q_i$ 是 $B$ 的**前缀**。

并且每个合法的二元组恰好对应一个替换位置（窗口位置由 $D$ 的位置唯一确定）。

### 2. 隐藏条件

- 条件 1：按 $(X, Y)$ 给二元组**分组**（用 `X + "#" + Y` 作为哈希表的键），询问只看同组。
- 条件 2、3 是前缀匹配，用 **Trie**：每组建两棵 Trie，一棵插入 $P_i$ 的**反串**，一棵插入 $Q_i$。询问时把 $A$ 的反串、$B$ 分别在 Trie 上走到最深处，得到结点 $u, v$。二元组 $i$ 合法 ⇔ $P_i$ 的结点是 $u$ 的祖先，且 $Q_i$ 的结点是 $v$ 的祖先。
- "$p$ 是 $u$ 的祖先" ⇔ $dfn_u \in [in_p, out_p]$。于是每个二元组是一个**矩形** $[in_1(p), out_1(p)] \times [in_2(q), out_2(q)]$，每个询问是一个**点** $(dfn_1(u), dfn_2(v))$，问题变成**数有多少矩形包含该点**——离线扫描线 + 树状数组。
- 各组的 Trie 根不同，DFS 序区间互不相交，所以可以把所有组放进同一片编号空间统一处理。

### 3. 注意事项

- $s_{i,1} = s_{i,2}$ 的二元组永远无用（询问保证 $t_1 \ne t_2$），直接跳过；$|t_1| \ne |t_2|$ 的询问答案为 0。
- Trie 结点总数 $\le$ 总长的一半（约 $2.5 \times 10^6$），子结点数组用 32 位整数，约 $2 \times 290$MB，内存限制 2GB 足够。
- Trie 深度可达 $10^6$ 级，求 DFS 序要用**手写栈**。孩子编号总比父亲大，所以按编号顺序扫描找根即可。
- 扫描线事件按横坐标排序，同一横坐标先处理加/删再处理询问；删除放在 $out + 1$ 处。

### 4. 解决方案

1. 对每个二元组求 $[l, r]$，得到键、$P$（$s_1[0..l-1]$）和 $Q$（$s_1[r+1..]$）；新键分配两棵 Trie 的新根；反向插入 $P$、正向插入 $Q$，记录结点对。
2. 对每个询问同样求键，查不到则答案为 0；否则从对应根出发，反向走 $A$、正向走 $B$，走不动就停，记录结点对。
3. 两棵 Trie 分别求 DFS 序（`in`、`out`）。
4. 二元组生成"在 $in_1$ 处对 $[in_2, out_2]$ 区间 +1、在 $out_1 + 1$ 处 −1"的事件，询问生成点查询事件。按横坐标排序，树状数组区间加、单点查。

复杂度 $O(L_1 + L_2 + (n + q)\log)$。

## 部分分策略 / 错误思路

- 暴力：枚举每个二元组、每个位置比较，$O(nq \cdot L)$，只能过很小的数据。
- 性质 A（$q = 1$）：只需对这一个询问检查所有二元组，用哈希比较前后缀，$O(L_1)$。
- 性质 B（只含 a 和一个 b）：字符串由"b 的位置"和长度描述，$D_1, D_2$ 对应 b 移动的方向和距离，可转化为简单的计数。
- 只对 $s_1$ 做匹配而忽略 $s_2$：会把"子串匹配但替换结果不同"的情况算进去。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2.8e6 + 5, Q = 2e5 + 5;
int n, q, tot1, tot2, cnt, gid;
signed ch1[N][26], ch2[N][26], in1[N], out1[N], in2[N], out2[N], bit[N];
int ans[Q];
unordered_map<string, int> root;
vector<pii> rt;
struct event { signed x, l, r, v, id; } ev[3 * Q];

inline bool cmp(const event &a, const event &b) { return a.x != b.x ? a.x < b.x : a.id < b.id; }

inline bool split(const string &s, const string &t, int &l, int &r) {
    l = 0, r = s.size() - 1;
    while (l <= r && s[l] == t[l]) l++;
    while (r >= l && s[r] == t[r]) r--;
    return l <= r;
}

void euler(signed ch[][26], signed in[], signed out[], int tot) {
    vector<bool> vis(tot + 1);
    int clk = 0;
    For(r, 1, tot) {
        if (vis[r]) continue;
        vector<pii> st;
        st.pb({r, 0}), vis[r] = true, in[r] = ++clk;
        while (!st.empty()) {
            int u = st.back().F, &c = st.back().S;
            while (c < 26 && !ch[u][c]) c++;
            if (c == 26) {
                out[u] = clk, st.pop_back();
                continue;
            }
            int v = ch[u][c++];
            vis[v] = true, in[v] = ++clk, st.pb({v, 0});
        }
    }
}

void solve() {
    cin >> n >> q;
    vector<pii> pr;
    For(i, 1, n) {
        string s, t;
        cin >> s >> t;
        int l, r;
        if (!split(s, t, l, r)) continue;
        string key = s.substr(l, r - l + 1) + "#" + t.substr(l, r - l + 1);
        if (!root.count(key)) root[key] = gid++, rt.pb({++tot1, ++tot2});
        int g = root[key], u = rt[g].F, v = rt[g].S;
        for (int p = l - 1; p >= 0; p--) {
            int c = s[p] - 'a';
            if (!ch1[u][c]) ch1[u][c] = ++tot1;
            u = ch1[u][c];
        }
        for (int p = r + 1; p < (int)s.size(); p++) {
            int c = s[p] - 'a';
            if (!ch2[v][c]) ch2[v][c] = ++tot2;
            v = ch2[v][c];
        }
        pr.pb({u, v});
    }
    vector<pair<pii, int>> qs;
    For(j, 1, q) {
        string s, t;
        cin >> s >> t;
        int l, r;
        if (s.size() != t.size()) continue;
        split(s, t, l, r);
        string key = s.substr(l, r - l + 1) + "#" + t.substr(l, r - l + 1);
        auto it = root.find(key);
        if (it == root.end()) continue;
        int u = rt[it->S].F, v = rt[it->S].S;
        for (int p = l - 1; p >= 0 && ch1[u][s[p] - 'a']; p--) u = ch1[u][s[p] - 'a'];
        for (int p = r + 1; p < (int)s.size() && ch2[v][s[p] - 'a']; p++) v = ch2[v][s[p] - 'a'];
        qs.pb({{u, v}, j});
    }
    euler(ch1, in1, out1, tot1), euler(ch2, in2, out2, tot2);
    for (auto x : pr) {
        int u = x.F, v = x.S;
        ev[++cnt] = {in1[u], in2[v], out2[v], 1, 0};
        ev[++cnt] = {out1[u] + 1, in2[v], out2[v], -1, 0};
    }
    for (auto x : qs) ev[++cnt] = {in1[x.F.F], in2[x.F.S], 0, 0, (signed)x.S};
    sort(ev + 1, ev + 1 + cnt, cmp);
    For(i, 1, cnt) {
        if (ev[i].id) {
            for (int p = ev[i].l; p; p -= p & -p) ans[ev[i].id] += bit[p];
            continue;
        }
        for (int p = ev[i].l; p <= tot2; p += p & -p) bit[p] += ev[i].v;
        for (int p = ev[i].r + 1; p <= tot2; p += p & -p) bit[p] -= ev[i].v;
    }
    For(j, 1, q) cout << ans[j] << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
