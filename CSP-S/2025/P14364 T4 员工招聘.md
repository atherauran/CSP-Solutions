# P14364 CSP-S 2025 T4 员工招聘

## 题意

$n$ 个人按排列 $p$ 依次面试。第 $i$ 天的题 $s_i = 1$ 时面试者通过，$s_i = 0$ 时不通过。若轮到某人时已有 $\ge c$ 人"被拒或放弃"，他直接放弃。求使录用人数 $\ge m$ 的排列数 mod 998244353。$n \le 500$。

**标签**：计数 DP、延迟决策（贡献提前/推迟计算）、组合数学　**难度**：9/10

## 解题思路

### 1. 底层逻辑

设第 $i$ 天开始时失败人数为 $j$。第 $i$ 天的面试者 $x$：
- $s_i = 0$：一定失败，$j{+}{+}$，对 $x$ 没有要求；
- $s_i = 1$：若 $c_x > j$ 则录用（$j$ 不变），否则放弃（$j{+}{+}$）。

所以排列合法 ⇔ 给每一天分配一个人，满足：**录用日**的人 $c > j$，**$s=1$ 的失败日**的人 $c \le j$，**$s=0$ 的日子**无要求。按天 DP 时，$j$ 由前面的天唯一确定，难点在于"每个人只能用一次"——直接记录用了哪些人不可能。

### 2. 隐藏条件

把人按 $c$ 分类：当 $j$ 增长到 $v$ 时，$c = v$ 的人"**死亡**"——之后再出场一定失败。

- **$s=1$ 的失败日**：需要一个已死亡（$c \le j$）且未使用的人，**当场选**。能选的人数可以算出来（见下）。
- **录用日**：需要 $c > j$ 的人，但此刻选会和以后冲突。于是**先留一个空位不填**（记待填空位数 $k$）。
- **死亡事件**：$j$ 变成 $v$ 时，$c = v$ 的 $cnt_v$ 个人里，选 $t$ 个去填之前的待填空位（这些空位要求 $c >$ 当时的 $j$，而 $v$ 一定更大，满足）；方案数 $\binom{cnt_v}{t} \cdot k^{\underline t}$。没被选的人以后只能当失败者。此后 $c = v$ 的人不能再进入录用空位。
- **$s=0$ 的日子**：无要求，**全部推迟到最后**统一分配剩下的人。

于是状态 $f_{j,k}$（处理完若干天、失败 $j$ 人、待填录用空位 $k$ 个）就够了，因为其它量都能推出：
- 已录用（含已填和待填）人数 $= (i - 1) - j$，已填录用空位 $= i - 1 - j - k$（都由死人填）；
- $s=1$ 失败日数 $= j - z$（$z$ 为前面 $s=0$ 的天数），都用了死人；
- 当前可用于 $s=1$ 失败日的死人数 $= pre_j - (i-1-j-k) - (j - z)$，$pre_j$ 为 $c \le j$ 的人数。

### 3. 注意事项

- $c = 0$ 的人一开始就是死的，直接计入 $pre_0$。
- 最后：活着的人（$c > j$）共 $alive = n - pre_j$ 个，必须填满剩下的 $k$ 个录用空位：$alive^{\underline k}$；剩下的人恰好填 $s=0$ 的 $z_n$ 个日子：$z_n!$。
- 答案只统计最终 $j \le n - m$ 的状态。
- 复杂度：每天状态 $O(n^2)$，死亡转移对 $t$ 求和，总共 $O(n^3)$；实际只遍历可达状态，很快。

### 4. 解决方案

$f_{0,0} = 1$。对第 $i$ 天：
1. 对每个状态 $(j, k)$：
   - $s_i = 0$：转到"失败暂存" $g_{j+1,k}$；
   - $s_i = 1$：录用 → $f'_{j,k+1}$；失败 → $g_{j+1,k} \mathrel{+}= f_{j,k} \times pool$（$pool$ 为上面算的可用死人数）。
2. 对每个 $g_{j,k}$ 结算死亡事件：$f'_{j,k-t} \mathrel{+}= g_{j,k}\binom{cnt_j}{t}k^{\underline t}$。
3. $f \gets f'$。

最后答案 $= \sum_{j \le n-m}\sum_k f_{j,k} \cdot (n - pre_j)^{\underline k} \cdot z_n!$。

## 部分分策略 / 错误思路

- $n \le 10$：枚举全排列模拟。
- $n \le 18$：状压 DP，状态为已使用的人的集合（失败人数可由集合和天数推出）。
- 性质 A（全为 1）：没有 $s=0$ 的日子，结构更简单。
- 性质 B（1 不超过 18 个）：可以枚举 $s=1$ 的日子里哪些被录用。
- 错误思路：在录用日当场选人——无法知道以后还剩多少 $c$ 大的人，会重复或漏算。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 505, P = 998244353;
int n, m;
int cnt[N], pre[N], C[N][N], A[N][N], dp[N][N], nd[N][N], fl[N][N];
string s;

void solve() {
    cin >> n >> m >> s;
    s = " " + s;
    For(i, 1, n) {
        int c;
        cin >> c;
        cnt[c]++;
    }
    pre[0] = cnt[0];
    For(j, 1, n) pre[j] = pre[j - 1] + cnt[j];
    For(i, 0, n) {
        C[i][0] = A[i][0] = 1;
        For(j, 1, i) C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % P, A[i][j] = A[i][j - 1] * (i - j + 1) % P;
    }
    dp[0][0] = 1;
    int z = 0;
    For(i, 1, n) {
        For(j, 0, i) For(k, 0, i) nd[j][k] = fl[j][k] = 0;
        Rep(j, 0, i) For(k, 0, i - 1 - j) {
            int v = dp[j][k];
            if (!v) continue;
            if (s[i] == '0') {
                fl[j + 1][k] = (fl[j + 1][k] + v) % P;
                continue;
            }
            nd[j][k + 1] = (nd[j][k + 1] + v) % P;
            int pool = pre[j] - (i - 1 - j - k) - (j - z);
            if (pool > 0) fl[j + 1][k] = (fl[j + 1][k] + v * pool) % P;
        }
        For(j, 1, i) For(k, 0, i - j) {
            int v = fl[j][k];
            if (!v) continue;
            For(t, 0, min(k, cnt[j])) nd[j][k - t] = (nd[j][k - t] + v * C[cnt[j]][t] % P * A[k][t]) % P;
        }
        For(j, 0, i) For(k, 0, i) dp[j][k] = nd[j][k];
        z += s[i] == '0';
    }
    int ans = 0, fz = 1;
    For(i, 1, z) fz = fz * i % P;
    For(j, 0, n - m) For(k, 0, n - j) {
        int alive = n - pre[j];
        if (dp[j][k] && alive >= k) ans = (ans + dp[j][k] * A[alive][k] % P * fz) % P;
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
