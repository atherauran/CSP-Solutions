# 概率与期望

**组别**：S　**关键词**：古典概型、条件概率、独立事件、数学期望、期望的线性性、指示变量、期望 DP、模意义下的概率

## 1. 是什么 / 解决什么问题

- **概率**：一个随机事件发生的可能性，取值在 $[0, 1]$。
- **期望**：随机变量的"平均值"——把每个可能的取值按概率加权求和。

在 CSP 中的形态：

- **初赛**：古典概型计算、条件概率、期望的简单计算，几乎每年都有。
- **复赛**：求某个随机过程的期望步数 / 期望得分（**期望 DP**），答案通常以小数或"模 $p$ 意义下的分数"输出；以及分析**随机化算法**（哈希）的出错概率。

最重要的一条工具是**期望的线性性**：和的期望等于期望的和，**不需要独立**。很多看似复杂的期望题，拆成若干个简单事件的概率之和就做完了。

## 2. 核心原理

### 2.1 古典概型

如果所有基本结果**等可能**，事件 $A$ 的概率

$$P(A) = \frac{A \text{ 包含的结果数}}{\text{总结果数}}$$

于是概率问题变成了两次计数（见"排列组合与计数"）。

例：掷两颗骰子，点数和为 7 的概率。总结果 $6 \times 6 = 36$，和为 7 的有 $(1,6),(2,5),\dots,(6,1)$ 共 6 种，$P = \frac16$。

注意"等可能"：把"两颗骰子的点数和"当成 $2 \sim 12$ 这 11 个等可能结果是错的。

### 2.2 加法公式与对立事件

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

$A, B$ **互斥**（不能同时发生）时 $P(A\cup B) = P(A) + P(B)$。

**对立事件**：$P(\bar A) = 1 - P(A)$。"至少一个"类问题用对立事件最方便。

例（生日问题）：$k$ 个人中至少两人同一天生日（一年 365 天）。对立事件"所有人生日互不相同"的概率是 $\frac{365}{365}\cdot\frac{364}{365}\cdots\frac{365-k+1}{365}$。$k = 23$ 时这个值已经小于 $\frac12$，所以至少两人同生日的概率超过一半。

### 2.3 条件概率、独立与全概率公式

**条件概率**：已知 $B$ 发生时 $A$ 发生的概率

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

直观理解：样本空间缩小到 $B$，再看其中属于 $A$ 的比例。变形得到**乘法公式** $P(A\cap B) = P(B)\,P(A\mid B)$。

**独立**：若 $P(A \cap B) = P(A)P(B)$（等价于 $P(A \mid B) = P(A)$），称 $A, B$ 独立——知道 $B$ 发生与否不影响 $A$ 的概率。多次掷骰子、独立的随机选择都是独立事件。

**全概率公式**：若 $B_1, \dots, B_k$ 两两互斥且必有一个发生，则

$$P(A) = \sum_i P(B_i)\,P(A \mid B_i)$$

例：甲盒有 2 红 1 白，乙盒有 1 红 3 白。随机选一个盒子再摸一个球，摸到红球的概率：$\frac12\cdot\frac23 + \frac12\cdot\frac14 = \frac{11}{24}$。

反过来问"已知摸到红球，它来自甲盒的概率"就是**贝叶斯公式**：$\dfrac{\frac12 \cdot \frac23}{\frac{11}{24}} = \dfrac{8}{11}$。

### 2.4 数学期望

随机变量 $X$ 取值 $x_1, x_2, \dots$ 的概率分别为 $p_1, p_2, \dots$，期望

$$E[X] = \sum_i x_i\, p_i$$

例：掷一颗骰子的点数期望 $= \frac{1+2+\cdots+6}{6} = 3.5$。期望不一定是能取到的值。

### 2.5 期望的线性性

$$E[X + Y] = E[X] + E[Y],\qquad E[aX + b] = aE[X] + b$$

**不要求 $X, Y$ 独立**。证明：设基本结果 $\omega$ 的概率为 $P(\omega)$，

$$E[X+Y] = \sum_\omega P(\omega)\big(X(\omega) + Y(\omega)\big) = \sum_\omega P(\omega)X(\omega) + \sum_\omega P(\omega)Y(\omega) = E[X] + E[Y]$$

只用到了乘法分配律。例：两颗骰子点数和的期望 $= 3.5 + 3.5 = 7$，不用列出 36 种情况。

**乘积没有这个性质**：$E[XY] = E[X]E[Y]$ 只在 $X, Y$ 独立时成立。反例：$X$ 是一枚硬币（正面 1、反面 0），$E[X \cdot X] = E[X] = \frac12$，但 $E[X]^2 = \frac14$。同理 $E[X^2] \ne E[X]^2$，这是期望题最常见的坑。

### 2.6 指示变量：把"个数的期望"拆成"概率之和"

要求"满足某性质的对象个数"的期望，对每个对象 $i$ 设**指示变量** $I_i$（满足为 1，否则为 0），则 $E[I_i] = P(\text{对象 } i \text{ 满足})$，

$$E[\text{个数}] = E\Big[\sum_i I_i\Big] = \sum_i P(\text{对象 } i \text{ 满足})$$

例 1：随机排列 $1 \sim n$，**不动点**（$p_i = i$）个数的期望。每个位置 $P(p_i = i) = \frac1n$，期望 $= n \cdot \frac1n = 1$，与 $n$ 无关。直接按不动点个数分布去算会非常麻烦。

例 2：随机排列的**逆序对**个数期望。每一对 $(i, j)$ 形成逆序的概率是 $\frac12$（交换这两个值就一一对应），期望 $= \binom n2 \cdot \frac12 = \frac{n(n-1)}{4}$。

例 3：$n$ 道单选题，第 $i$ 题有 $a_i$ 个选项，答案在随机生成，某人把第 $i$ 题的答案错位写到第 $i+1$ 题上。第 $i+1$ 题答对的概率是两题答案恰好相同：$\frac{1}{\max(a_i, a_{i+1})}$。期望答对数就是这些概率之和。

### 2.7 几何分布与收集问题

**几何分布**：每次尝试成功的概率为 $p$（相互独立），直到成功为止，期望尝试次数为 $E$。考虑第一次尝试：概率 $p$ 成功（共 1 次）；概率 $1-p$ 失败，之后的局面和开始时一模一样，还需要 $E$ 次：

$$E = 1 + (1 - p)\,E \quad\Longrightarrow\quad E = \frac 1p$$

例：掷骰子直到出现 6，期望掷 6 次。

**收集问题**（集齐 $n$ 种卡片，每次随机得到一种）：已有 $k$ 种时，下一张是新卡的概率为 $\frac{n-k}{n}$，期望等待 $\frac{n}{n-k}$ 次。由线性性，总期望

$$\sum_{k=0}^{n-1}\frac{n}{n-k} = n\left(1 + \frac12 + \cdots + \frac1n\right) \approx n\ln n$$

例：掷骰子直到 6 个面都出现过，期望 $6 \times 2.45 = 14.7$ 次。

### 2.8 期望 DP

当随机过程是"在若干状态之间按概率转移，每次转移有代价"时，设

$$f_s = \text{从状态 } s \text{ 出发，到结束为止的期望总代价}$$

终止状态 $f = 0$。按"第一步走到哪里"分类（全概率公式 + 线性性）：

$$f_s = \sum_t P(s \to t)\,\big(w(s \to t) + f_t\big)$$

**为什么通常倒着推**：$f_s$ 依赖的是"之后"的状态，终点的值是已知的 0。正着推也可以，但要同时维护"到达每个状态的概率"，再用 $\sum P(\text{到达 } u)\cdot P(u \to v)\cdot w$ 累加期望，更麻烦。

**例：DAG 上随机游走**。有向无环图从 1 出发，每次等概率随机选一条出边走，直到终点 $n$，求期望路径长度。设 $f_u$ 为从 $u$ 到 $n$ 的期望长度，$d_u$ 为 $u$ 的出度：

$$f_n = 0,\qquad f_u = \frac{1}{d_u}\sum_{u \to v} (w + f_v)$$

按拓扑序**倒序**计算即可。

**例：带自环的转移**。从 $0$ 走到 $n$，每次掷一个骰子（1~6 等概率），若不越过 $n$ 就前进那么多步，否则原地不动（但仍算一次）。求期望掷骰次数。设 $f_i$ 为从 $i$ 到 $n$ 的期望次数，$k = \min(6, n - i)$ 为能走的点数个数：

$$f_i = 1 + \frac16\sum_{d=1}^{k} f_{i+d} + \frac{6-k}{6} f_i$$

方程两边都有 $f_i$，**移项**解出来：

$$\frac k6 f_i = 1 + \frac16\sum_{d=1}^{k} f_{i+d} \quad\Longrightarrow\quad f_i = \frac{6 + \sum_{d=1}^{k} f_{i+d}}{k}$$

这和几何分布的推导是同一个技巧。如果状态之间有一般的环，就需要解线性方程组（高斯消元），超出 CSP 常见范围。

### 2.9 模意义下的概率与期望

概率和期望通常是有理数 $\frac ab$。题目会要求输出 $a \cdot b^{-1} \bmod p$（$p$ 为质数）。模质数的世界里加减乘除（除以非零数）都成立，所以**把所有分数直接换成"乘逆元"，照常计算即可**，最后的结果自动就是答案对应的模意义值。例如 $\frac16$ 换成 $6^{-1} \bmod p$。逆元求法见"模运算、快速幂与逆元"。

### 2.10 随机化算法的出错概率

哈希、随机权值等算法"可能出错"，需要估计概率：

- 两个不同对象的 $M$ 种可能的随机哈希值**恰好相等**的概率是 $\frac1M$。
- $k$ 个对象中**存在**两个哈希值相同的概率约为 $\frac{k^2}{2M}$（生日问题）。$M = 2^{64} \approx 1.8\times10^{19}$、$k = 10^6$ 时约 $2.7\times10^{-8}$，可以放心；但 $M = 10^9$、$k = 10^5$ 时约 $5$，几乎必然冲突（这时概率超过 1 说明近似失效，实际是"几乎一定冲突"）。所以**比较大量哈希值时要用 64 位或双模哈希**。

## 3. 代码模板

DAG 上随机游走的期望路径长度：$n$ 个点 $m$ 条有向边，从 1 出发、每次等概率选一条出边，到 $n$ 停止。

```cpp
const int N = 1e5 + 5;
int n, m;
int deg[N], out[N], ord[N];
double f[N];
vector<pii> g[N];

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].pb({v, w}), deg[v]++, out[u]++;
    }
    queue<int> q;
    int cnt = 0;
    For(i, 1, n) if (!deg[i]) q.push(i);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ord[++cnt] = u;
        for (auto e : g[u])
            if (!--deg[e.F]) q.push(e.F);
    }
    for (int i = cnt; i >= 1; i--) {
        int u = ord[i];
        for (auto e : g[u]) f[u] += (f[e.F] + e.S) / out[u];
    }
    cout << fixed << setprecision(2) << f[1];
}
```

掷骰子走到 $n$ 的期望次数（带自环，答案模 `MOD` 输出）：

```cpp
const int N = 1e6 + 5;
int n;
int f[N];

int qpow(int a, int b) {
    int r = 1;
    a %= MOD;
    while (b) {
        if (b & 1) r = r * a % MOD;
        a = a * a % MOD, b >>= 1;
    }
    return r;
}

void solve() {
    cin >> n;
    f[n] = 0;
    for (int i = n - 1; i >= 0; i--) {
        int k = min(6LL, n - i), s = 6;
        For(d, 1, k) s += f[i + d];
        f[i] = s % MOD * qpow(k, MOD - 2) % MOD;
    }
    cout << f[0];
}
```

这里 $k \le 6$，也可以预先求好 $1 \sim 6$ 的逆元，省掉每步的快速幂。

## 4. 复杂度

- 期望 DP 的复杂度等于对应的普通 DP：状态数 × 每个状态的转移数。DAG 上随机游走 $O(n + m)$，掷骰子例子 $O(6n)$。
- 模意义下若每步都求逆元，多一个 $O(\log p)$ 因子；分母种类少时预处理逆元。

## 5. 常见题型与技巧

1. **线性性拆分**：把要求的量拆成许多小量之和（每个位置、每一对、每一条边的贡献），分别求概率或期望再相加。这是期望题的第一反应。
2. **期望 DP 倒推**：状态定义为"从这里到结束的期望"，终点为 0，按拓扑序倒序计算。
3. **自环移项**：转移回到自身时，把含 $f_s$ 的项移到左边解出 $f_s$。
4. **平方的期望**：$E[x^2] \ne E[x]^2$。例如"连续成功长度 $x$ 的贡献是 $x^2$"，维护 $E[x]$，利用 $(x+1)^2 - x^2 = 2x + 1$，每一步的期望增量是 $p\,(2E[x] + 1)$。这里用线性性求的是"增量"的期望。
5. **对立事件**："至少一次"＝ $1 -$ "一次都没有"。
6. **概率 × 计数**：古典概型中，概率 = 合法方案数 / 总方案数，用组合计数完成。
7. **随机化**：给对象赋随机权值，把"是否完全相同"转化为"权值和是否相等"，用概率估计说明出错可能性极小。

## 6. 易错点

- 误以为 $E[XY] = E[X]E[Y]$、$E[X^2] = E[X]^2$；只有线性组合可以直接拆。
- 期望 DP 方向写反：$f$ 定义为"到结束还需要多少"时必须从终点往回推。
- 古典概型中把不等可能的结果当成等可能。
- 条件概率中分母弄错：$P(A\mid B)$ 的分母是 $P(B)$，不是 $P(A)$。
- 输出小数时精度：用 `double` 足够时注意输出位数（`fixed << setprecision(k)`）；模意义输出时不要混用浮点数。
- 模意义下的除法必须乘逆元，不能用整数除法；出度、骰子面数等分母都要求逆。
- 自环移项后要除以 $1 - P(\text{留在原地})$，这个值不能为 0（否则期望无穷大，题目一般会保证）。
