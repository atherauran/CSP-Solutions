# 离散化

**组别**：S　**关键词**：离散化、坐标压缩、排序去重、unique、lower_bound、区间离散化、离线

## 1. 是什么 / 解决什么问题

很多算法需要"以数值为下标"开数组：桶计数、树状数组按值统计、差分数组按坐标修改……但如果数值范围是 $10^9$，数组根本开不下。

注意到一个事实：$n$ 个数最多只有 $n$ 种不同的值。如果题目**只关心这些数的相对大小**（谁比谁大、是否相等），而不关心具体是多少，就可以把它们**按大小映射成 $1, 2, \dots, k$**：

```text
原数组:   1000000000   -5   300   -5   7
映射后:            4    1     3    1   2
```

映射保持大小关系和相等关系不变：原来 $a_i < a_j$，映射后仍然 $a_i < a_j$；原来相等的映射后仍相等。这样值域从 $10^9$ 压缩到了 $n$ 以内，数组就开得下了。这个操作叫**离散化**（也叫坐标压缩）。

典型场景：

- 值域很大的**逆序对**、**按值统计**（树状数组 / 线段树下标是值）；
- 坐标很大的**区间覆盖、差分**问题（数轴上的线段、平面上的矩形）；
- 值域很大的**桶计数**、判相等（也可以用 `map`，但离散化后用数组更快）。

## 2. 核心原理

### 2.1 排序 + 去重 + 二分

三步：

1. 把所有需要的值复制到数组 $b$；
2. 对 $b$ 排序，再去重，得到 $b_1 < b_2 < \dots < b_m$；
3. 每个值 $v$ 映射为它在 $b$ 中的位置，即满足 $b_p = v$ 的 $p$，用二分查找（`lower_bound`）求出。

以 $a = [100, -5, 300, -5, 7]$ 为例：

```text
复制:     b = [100, -5, 300, -5, 7]
排序:     b = [-5, -5, 7, 100, 300]
去重:     b = [-5, 7, 100, 300]，m = 4
映射:     100 → 3, -5 → 1, 300 → 4, -5 → 1, 7 → 2
```

`unique(b + 1, b + 1 + n)` 把**相邻**的重复元素移到后面，返回去重后末尾的下一个位置的指针，所以必须先排序；减去 `b + 1` 就是去重后的个数 $m$。`lower_bound(b + 1, b + 1 + m, v)` 返回第一个 $\ge v$ 的位置指针，减去 `b` 就是 1 开始的下标。

为什么映射保序：$b$ 严格递增，$v_1 < v_2$ 时它们在 $b$ 中的位置也是前者小。

映射后的值 $p$ 还能**还原**：原值就是 $b_p$。需要用到真实数值（比如算长度、算差值）时，就靠 $b$ 数组还原。

### 2.2 排序下标法

另一种写法：把下标按值排序，然后按顺序给排名，值变化时排名 +1。只需要一次排序，不用二分。适合需要"排名"的场合；如果想让相同的值得到**不同**的排名（比如按出现顺序区分），去掉"值相同则排名不变"的判断即可，并用稳定排序或在比较时加上下标作为第二关键字。

### 2.3 `map` 法

把所有值放进 `map<int, int>`，再按顺序遍历给编号。写起来直观，但常数比数组排序大不少。值需要**在线**加入（边读边编号、只需要判相等不需要保序）时，也可以用 `map` 或 `unordered_map` 直接给新值分配下一个编号。

### 2.4 离线：所有会用到的值都要放进去

离散化必须**事先知道所有会出现的值**。如果后面还有询问涉及新的数值（例如"询问 $[l, r]$ 内的和"，$l, r$ 是原坐标），就要先把所有询问读进来，把询问里的数值也加入 $b$ 一起离散化，再统一处理。这种"先读完所有输入再处理"的方式叫**离线**。

### 2.5 区间离散化：点与段

对数轴上的区间问题离散化时，要想清楚离散化后的下标代表**一个点**还是**一段**。

**连续区间（求长度）**：区间 $[l, r)$ 的端点排序去重得到 $x_1 < x_2 < \dots < x_m$，把"第 $i$ 段"定义为 $[x_i, x_{i+1})$。每个原区间恰好覆盖若干个完整的段，在段上做差分，最后被覆盖的段累加真实长度 $x_{i+1} - x_i$。

```text
区间: [1, 5)  [3, 9)  [12, 15)
端点: 1 3 5 9 12 15
段:   [1,3) [3,5) [5,9) [9,12) [12,15)
覆盖:   1     2     1     0      1
总长:   2  +  2  +  4  +  0  +   3  = 11
```

**离散的格子（求可见的颜色等）**：比如墙上贴海报，海报覆盖第 $l$ 到第 $r$ 个格子。这时直接把端点离散化会**丢失间隔**：

```text
海报 [1, 10]、[1, 4]、[6, 10]（后贴的盖住先贴的）
端点 1 4 6 10 → 映射成 1 2 3 4
离散化后 [1,4] 被 [1,2] 和 [3,4] 完全盖住，第一张看不见
但实际上第 5 格只被第一张覆盖，它是可见的
```

原因是 4 和 6 之间的格子 5 没有出现在离散化后的坐标里。解决办法：对相邻的两个端点，如果差大于 1，在中间额外插入一个点（如 $x_i + 1$）；或者简单地把每个 $r_i + 1$ 也加入离散化。

### 2.6 二维离散化

平面上的点或矩形，$x$ 坐标和 $y$ 坐标**分别**离散化，各自得到一个 $b$ 数组。矩形面积并、二维前缀和等问题常这样做。

## 3. 代码模板

### 3.1 标准离散化

把 $a$ 中的每个数替换成它的排名（相同值排名相同）。

```cpp
const int N = 1e5 + 5;
int n, m;
int a[N], b[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i], b[i] = a[i];
    sort(b + 1, b + 1 + n);
    m = unique(b + 1, b + 1 + n) - b - 1;
    For(i, 1, n) a[i] = lower_bound(b + 1, b + 1 + m, a[i]) - b;
    For(i, 1, n) cout << a[i] << ' ';
    cout << endl;
}
```

之后 $a_i \in [1, m]$，原值是 $b_{a_i}$。

### 3.2 排序下标法

```cpp
const int N = 1e5 + 5;
int n;
int a[N], id[N], rk[N];

bool cmp(const int &x, const int &y) {
    return a[x] < a[y];
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i], id[i] = i;
    sort(id + 1, id + 1 + n, cmp);
    int k = 0;
    For(i, 1, n) {
        if (i == 1 || a[id[i]] != a[id[i - 1]]) k++;
        rk[id[i]] = k;
    }
    For(i, 1, n) cout << rk[i] << ' ';
    cout << endl;
}
```

`id[i]` 是第 $i$ 小的元素的下标，`rk` 是每个位置的排名。

### 3.3 应用：逆序对

$n \le 5 \times 10^5$，$|a_i| \le 10^9$，求满足 $i < j$ 且 $a_i > a_j$ 的对数。离散化后用树状数组按值计数（树状数组见数据结构一篇，这里只用它"单点加 1、查前缀和"）。

```cpp
const int N = 5e5 + 5;
int n, m, ans;
int a[N], b[N], c[N];

void add(int x) {
    for (; x <= m; x += x & -x) c[x]++;
}

int ask(int x) {
    int s = 0;
    for (; x; x -= x & -x) s += c[x];
    return s;
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i], b[i] = a[i];
    sort(b + 1, b + 1 + n);
    m = unique(b + 1, b + 1 + n) - b - 1;
    For(i, 1, n) {
        a[i] = lower_bound(b + 1, b + 1 + m, a[i]) - b;
        ans += i - 1 - ask(a[i]);
        add(a[i]);
    }
    cout << ans << endl;
}
```

处理到 $i$ 时，树状数组里是前 $i - 1$ 个数；`ask(a[i])` 是其中 $\le a_i$ 的个数，剩下的就是比 $a_i$ 大的。不离散化的话，树状数组要开到 $10^9$。

### 3.4 应用：区间并的总长度

$n$ 个区间 $[l_i, r_i)$，坐标绝对值可达 $2^{31}$，求它们的并的总长度。端点离散化后，在"段"上做差分。

```cpp
const int N = 2e4 + 5;
int n, m, ans;
int l[N], r[N], x[2 * N], d[2 * N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> l[i] >> r[i], x[++m] = l[i], x[++m] = r[i];
    sort(x + 1, x + 1 + m);
    m = unique(x + 1, x + 1 + m) - x - 1;
    For(i, 1, n) {
        d[lower_bound(x + 1, x + 1 + m, l[i]) - x]++;
        d[lower_bound(x + 1, x + 1 + m, r[i]) - x]--;
    }
    int cur = 0;
    Rep(i, 1, m) {
        cur += d[i];
        if (cur > 0) ans += x[i + 1] - x[i];
    }
    cout << ans << endl;
}
```

`cur` 是第 $i$ 段 $[x_i, x_{i+1})$ 被覆盖的次数。把 `cur > 0` 改成 `cur >= k`，就是"至少被 $k$ 个区间覆盖的长度"。

### 3.5 应用：离线询问一起离散化

数轴上先进行 $n$ 次操作，每次在位置 $p_i$ 加上 $c_i$；再有 $q$ 次询问，求 $[l_i, r_i]$ 内所有位置的和。坐标范围 $10^9$。

```cpp
const int N = 3e5 + 5;
int n, q, m;
int p[N], c[N], ql[N], qr[N], x[N], s[N];

int pos(int v) {
    return lower_bound(x + 1, x + 1 + m, v) - x;
}

void solve() {
    cin >> n >> q;
    For(i, 1, n) cin >> p[i] >> c[i], x[++m] = p[i];
    For(i, 1, q) cin >> ql[i] >> qr[i], x[++m] = ql[i], x[++m] = qr[i];
    sort(x + 1, x + 1 + m);
    m = unique(x + 1, x + 1 + m) - x - 1;
    For(i, 1, n) s[pos(p[i])] += c[i];
    For(i, 1, m) s[i] += s[i - 1];
    For(i, 1, q) cout << s[pos(qr[i])] - s[pos(ql[i]) - 1] << endl;
}
```

询问的端点也加入了离散化，所以 `pos(ql[i])`、`pos(qr[i])` 一定能找到对应的位置。离散化后相邻下标之间没有其他有值的位置，所以前缀和仍然正确。数组大小是 $n + 2q$。

## 4. 复杂度

- 排序 $O(n \log n)$，去重 $O(n)$，每次映射二分 $O(\log n)$，总 $O(n \log n)$。
- 排序下标法同样是 $O(n \log n)$，只是少了二分。
- `map` 法 $O(n \log n)$，常数较大。
- 空间 $O(n)$：离散化后的值域就是不同值的个数 $m \le n$（加上询问值后是总的数值个数）。

离散化之后，原来依赖值域 $V$ 的算法（桶、树状数组）复杂度里的 $V$ 都变成了 $n$。

## 5. 常见题型与技巧

- **判断是否需要离散化**：数值很大，但个数不多，并且要拿数值当下标。
- **只关心相等关系**：比如"程序自动分析"里变量编号到 $10^9$，只需要判断两个变量是否是同一个，离散化后用并查集；这时不需要保序，用 `unordered_map` 编号也可以。
- **逆序对、按值统计**：离散化 + 树状数组，是最常见的组合。
- **区间覆盖、扫描线**：端点离散化 + 差分（或线段树），注意"点"和"段"的含义。
- **离线处理**：询问涉及的值和修改涉及的值放在一起离散化。
- **离散化后还原**：需要真实数值（长度、差值、输出原值）时用 $b$ 数组还原，别直接用排名做运算。
- **动态开点线段树 / `map` 替代**：值必须在线出现、无法离线时，就不能离散化，改用 `map` 或动态开点线段树（超出 CSP 常见范围）。

## 6. 易错点

- **忘记排序就 `unique`**：`unique` 只去掉相邻的重复。
- **`unique` 的返回值算错**：1 开始存储时，个数是 `unique(b + 1, b + 1 + n) - b - 1`。
- **`lower_bound` 的范围用了 $n$ 而不是去重后的 $m$**：去重后 $b_{m+1} \dots b_n$ 是垃圾数据，二分范围包含它们会出错。
- **漏加询问值**：询问的值不在 $b$ 里，`lower_bound` 找到的是比它大的第一个值，结果错误。
- **区间离散化丢失间隔**：离散的格子问题要补点（见 2.5）。
- **混淆排名和原值**：计算长度、差值时要用 $b$ 还原。
- **数组大小**：端点、询问都加入时，$b$ 的大小是它们的总数，不是 $n$。
