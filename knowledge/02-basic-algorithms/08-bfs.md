# 广度优先搜索

**组别**：J　**关键词**：广度优先搜索、队列、最短步数、多源 BFS、0-1 BFS、双向 BFS、状态搜索

## 1. 是什么 / 解决什么问题

迷宫里从起点走到终点，最少要几步？DFS 一条路走到底，找到的第一条路不一定最短，想求最短就得把所有路都试一遍。

**广度优先搜索（BFS）** 换了一种顺序：先访问所有离起点 1 步的位置，再访问所有 2 步的位置，再 3 步……像水波一样一圈一圈向外扩散。这样**第一次到达某个位置时，用的步数一定最少**。

BFS 主要用于：

- **边权都是 1（或都相等）的最短路**：迷宫最少步数、图上最少经过几条边；
- **状态空间最短路**：把"局面"看成点、"一次操作"看成边，求最少操作次数（八数码、倒水问题、电梯按钮）；
- 按层遍历：树的层序遍历、求每个点的深度；
- 连通块遍历（和 DFS 一样可以用，且不会爆栈）。

## 2. 核心原理

### 2.1 用队列实现"按层扩展"

用一个队列保存"已经发现、还没扩展"的点：

```text
起点入队，d[起点] = 0
while 队列非空:
    取出队首 u
    for u 的每个邻居 v:
        if v 没访问过:
            d[v] = d[u] + 1, 标记 v, v 入队
```

以下图为例，从 1 出发：

```text
  1 --- 2 --- 5
  |     |
  3 --- 4 --- 6
```

| 步骤 | 取出 | 新发现（距离） | 队列 |
|:-:|:-:|:-:|:-:|
| 初始 | | 1(0) | 1 |
| 1 | 1 | 2(1)、3(1) | 2 3 |
| 2 | 2 | 4(2)、5(2) | 3 4 5 |
| 3 | 3 | 无（4 已发现） | 4 5 |
| 4 | 4 | 6(3) | 5 6 |
| 5 | 5 | 无 | 6 |
| 6 | 6 | 无 | 空 |

### 2.2 为什么第一次到达就是最短

关键性质：**任何时刻，队列里的 $d$ 值从队首到队尾单调不降，且最多只有两种取值 $k$ 和 $k+1$**。

归纳证明：一开始队列只有起点（$d = 0$）。取出队首 $u$（$d_u = k$，是队列中最小的）后，新加入的点 $d = k + 1$，放在队尾；而原来队里的值都是 $k$ 或 $k + 1$，所以性质保持。

于是点是**按 $d$ 从小到大**被取出的：所有距离为 $k$ 的点都在距离为 $k+1$ 的点之前处理。若点 $v$ 的真实最短距离是 $D$，它在最短路上的前一个点距离是 $D - 1$，会在任何距离 $\ge D$ 的点之前被取出并发现 $v$，所以 $v$ 第一次被发现时 $d_v = D$。

### 2.3 入队时标记

一定要在**入队时**标记 `vis`（或给 $d$ 赋值），而不是出队时。否则一个点在出队前可能被多个点重复发现、重复入队，队列大小可能爆炸。入队时标记保证每个点只入队一次，复杂度 $O(n + m)$。

### 2.4 记录路径

发现 $v$ 时记下 `pre[v] = u`。结束后从终点沿 `pre` 往回走到起点，再倒过来，就是一条最短路径。

### 2.5 状态 BFS

点不一定是图里的点，可以是任意"状态"。例如八数码，状态是 $3 \times 3$ 棋盘的局面，每次把空格和相邻数字交换就是一条边。只要：

1. 每次操作代价相同；
2. 状态能被编码存下来判重（数组下标、整数编码、`string` + `map`）；
3. 状态总数可以接受；

就能用 BFS 求最少操作次数。

### 2.6 多源 BFS

问题：网格里有多个"源"（比如多个出口、多个感染者），求每个格子到**最近的**源的距离。

逐个源做 BFS 再取最小值是 $O(k \cdot nm)$。更好的做法是**一开始就把所有源都放进队列**，距离都设为 0，然后正常 BFS。可以想象有一个"超级源点"，它到每个源的边权为 0：第一层就是所有源。由 2.2 的性质，每个格子第一次被发现时的距离就是到最近源的距离。复杂度 $O(nm)$。

### 2.7 0-1 BFS

边权只有 0 和 1 时，普通 BFS 不对（走 0 权边不该让距离 +1），用 Dijkstra 又多一个 $\log$。**0-1 BFS** 用双端队列：

- 沿 0 权边更新的点放到**队首**（距离和当前点一样，应该先处理）；
- 沿 1 权边更新的点放到**队尾**。

这样仍能保持"队列中距离单调不降、最多两种取值"。和普通 BFS 不同的是，一个点可能先被 1 权边更新、后被 0 权边更新成更小的值，所以要用"能变小就更新"的松弛写法，并且一个点可能出队多次；第一次出队时它的距离已经最终确定，之后再出队的旧记录直接跳过即可。复杂度 $O(n + m)$。

### 2.8 双向 BFS

起点和终点都已知时，可以**从两头同时搜**，相遇时就得到答案。

为什么更快：若每个状态有 $b$ 个后继，答案是 $D$ 步，单向 BFS 要搜约 $b^D$ 个状态；双向各搜一半深度，约 $2 b^{D/2}$ 个。例如 $b = 3, D = 20$，前者约 $3.5 \times 10^9$，后者约 $1.2 \times 10^5$。

实现要点：

- 两边各一个队列、各一个距离表；
- **每次把某一边的一整层扩展完**（一般选当前队列较小的那边）；
- 扩展出的新状态如果已经被另一边访问过，答案就是 $d_A(u) + 1 + d_B(v)$。

必须"整层扩展"：设 A 已搜完 $\le d_A$ 层、B 已搜完 $\le d_B$ 层，且两边还没相遇，可以推出真实答案 $D \ge d_A + d_B + 1$；而这一层发现的任何相遇都满足 $d_A + 1 + d_B(v) \le d_A + 1 + d_B$，所以一旦相遇就恰好等于 $D$。如果一层没扩展完就换边，这个论证就不成立了。

### 2.9 BFS 与 DFS 对比

| | DFS | BFS |
|:-:|:-:|:-:|
| 数据结构 | 递归（系统栈） | 队列 |
| 访问顺序 | 一条路走到底 | 按距离一层一层 |
| 求最短步数 | 要搜完所有路 | 第一次到达即最短 |
| 空间 | 与深度成正比 | 与最宽的一层成正比 |
| 适合 | 枚举所有方案、回溯 | 最短步数、层序 |

## 3. 代码模板

### 3.1 网格最短步数

`S` 起点，`T` 终点，`#` 障碍，每步上下左右移动一格，求最少步数，到不了输出 $-1$。

```cpp
const int N = 1005;
int n, m, sx, sy, tx, ty;
char g[N][N];
int d[N][N];
int dx[] = {-1, 1, 0, 0}, dy[] = {0, 0, -1, 1};

void solve() {
    cin >> n >> m;
    For(i, 1, n) {
        cin >> (g[i] + 1);
        For(j, 1, m) {
            if (g[i][j] == 'S') sx = i, sy = j;
            if (g[i][j] == 'T') tx = i, ty = j;
        }
    }
    mset(d, -1);
    queue<pii> q;
    d[sx][sy] = 0;
    q.push({sx, sy});
    while (!q.empty()) {
        int x = q.front().F, y = q.front().S;
        q.pop();
        Rep(k, 0, 4) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
            if (g[nx][ny] == '#' || d[nx][ny] != -1) continue;
            d[nx][ny] = d[x][y] + 1;
            q.push({nx, ny});
        }
    }
    cout << d[tx][ty] << endl;
}
```

`d` 初始化为 $-1$，同时充当 `vis`：$d \ne -1$ 就是访问过。

### 3.2 图上 BFS 与路径还原

$n$ 个点 $m$ 条无向边，求 1 到 $n$ 最少经过几条边，并输出一条最短路径。

```cpp
const int N = 1e5 + 5;
int n, m;
int d[N], pre[N];
vector<int> g[N];

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    For(i, 1, n) d[i] = -1;
    queue<int> q;
    d[1] = 0;
    q.push(1);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : g[u]) {
            if (d[v] != -1) continue;
            d[v] = d[u] + 1, pre[v] = u;
            q.push(v);
        }
    }
    if (d[n] == -1) {
        cout << -1 << endl;
        return;
    }
    cout << d[n] << endl;
    vector<int> path;
    for (int u = n; u != 1; u = pre[u]) path.pb(u);
    path.pb(1);
    reverse(path.begin(), path.end());
    for (int u : path) cout << u << ' ';
    cout << endl;
}
```

### 3.3 多源 BFS

$n \times m$ 的 01 矩阵，求每个格子到最近的 1 的距离（曼哈顿意义下走格子）。

```cpp
const int N = 1005;
int n, m;
int a[N][N], d[N][N];
int dx[] = {-1, 1, 0, 0}, dy[] = {0, 0, -1, 1};

void solve() {
    cin >> n >> m;
    queue<pii> q;
    mset(d, -1);
    For(i, 1, n) For(j, 1, m) {
        cin >> a[i][j];
        if (a[i][j] == 1) d[i][j] = 0, q.push({i, j});
    }
    while (!q.empty()) {
        int x = q.front().F, y = q.front().S;
        q.pop();
        Rep(k, 0, 4) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 1 || nx > n || ny < 1 || ny > m || d[nx][ny] != -1) continue;
            d[nx][ny] = d[x][y] + 1;
            q.push({nx, ny});
        }
    }
    For(i, 1, n) {
        For(j, 1, m) cout << d[i][j] << ' ';
        cout << endl;
    }
}
```

和单源 BFS 唯一的区别是初始时把所有源一起入队。

### 3.4 0-1 BFS

网格每格有一个字母，走到相邻的**同字母**格子代价 0，走到**不同字母**格子代价 1，求起点到终点的最小代价。

```cpp
const int N = 505;
int n, m, sx, sy, tx, ty;
char g[N][N];
int d[N][N];
bool done[N][N];
int dx[] = {-1, 1, 0, 0}, dy[] = {0, 0, -1, 1};

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> (g[i] + 1);
    cin >> sx >> sy >> tx >> ty;
    For(i, 1, n) For(j, 1, m) d[i][j] = LINF;
    deque<pii> q;
    d[sx][sy] = 0;
    q.push_back({sx, sy});
    while (!q.empty()) {
        int x = q.front().F, y = q.front().S;
        q.pop_front();
        if (done[x][y]) continue;
        done[x][y] = true;
        Rep(k, 0, 4) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
            int w = g[nx][ny] != g[x][y];
            if (d[x][y] + w >= d[nx][ny]) continue;
            d[nx][ny] = d[x][y] + w;
            if (w == 0) q.push_front({nx, ny});
            else q.push_back({nx, ny});
        }
    }
    cout << d[tx][ty] << endl;
}
```

`done` 保证每个格子只扩展一次（第一次出队时距离已确定）。

### 3.5 双向 BFS：八数码

$3 \times 3$ 棋盘上有 1~8 和空格（用 0 表示），每次把空格与相邻数字交换，求从给定局面到 `123804765` 的最少步数。局面用长度 9 的字符串表示，下标 $p$ 对应第 $p / 3$ 行、第 $p \bmod 3$ 列（这里用 0 开始的下标，方便和行列互相换算）。

```cpp
const string T = "123804765";
map<string, int> da, db;
queue<string> qa, qb;
int dx[] = {-1, 1, 0, 0}, dy[] = {0, 0, -1, 1};

int expand(queue<string> &q, map<string, int> &d, map<string, int> &o) {
    int sz = q.size();
    while (sz--) {
        string u = q.front();
        q.pop();
        int p = u.find('0'), x = p / 3, y = p % 3;
        Rep(k, 0, 4) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 0 || nx > 2 || ny < 0 || ny > 2) continue;
            string v = u;
            swap(v[p], v[nx * 3 + ny]);
            if (d.count(v)) continue;
            if (o.count(v)) return d[u] + 1 + o[v];
            d[v] = d[u] + 1;
            q.push(v);
        }
    }
    return -1;
}

void solve() {
    string s;
    cin >> s;
    if (s == T) {
        cout << 0 << endl;
        return;
    }
    da[s] = 0, db[T] = 0;
    qa.push(s), qb.push(T);
    while (!qa.empty() && !qb.empty()) {
        int r = qa.size() <= qb.size() ? expand(qa, da, db) : expand(qb, db, da);
        if (r != -1) {
            cout << r << endl;
            return;
        }
    }
    cout << -1 << endl;
}
```

`expand` 一次扩展一整层（先记下当前队列大小 `sz`，只处理这么多个）。每次挑队列较小的一边扩展，两边规模更均衡。

## 4. 复杂度

- 普通 BFS、多源 BFS、0-1 BFS：每个点入队 $O(1)$ 次，每条边检查 $O(1)$ 次，时间 $O(n + m)$；网格上是 $O(nm)$。
- 状态 BFS：$O(\text{状态数} \times \text{每个状态的操作数} \times \text{判重代价})$。用 `map` 判重要多乘 $\log$，能用数组或整数编码就别用 `map`。
- 双向 BFS：最坏和单向相同，但在状态"指数膨胀"时能把 $b^D$ 降到约 $b^{D/2}$。
- 空间：队列最多 $O(n)$，加上距离数组。

## 5. 常见题型与技巧

- **迷宫 / 网格最短路**：最基础的形式。注意题目的移动方式，比如马走"日"字有 8 个方向（马的遍历），只是方向数组不同。
- **隐式图**：电梯每层只能上 $k_i$ 或下 $k_i$ 层、数字每次 $\times 2$ 或 $-1$……这些都是图，但不需要把边存下来，扩展时现算邻居。
- **拆点 / 加维度**：最短路需要额外信息时，把信息并进状态。例如"路径长度的奇偶性"——状态变成 $(u, 0/1)$；"手里有没有钥匙"——状态变成 $(x, y, 钥匙集合)$。
- **从终点反向 BFS**：多个起点、一个终点时，从终点出发 BFS 一次（无向图直接做，有向图在反图上做）。
- **从边界出发**：判断哪些区域被围住，从边界上的空地出发 BFS，能到达的都是"外面"。
- **所有点对距离**：$n$ 较小（几千）时从每个点做一次 BFS，总 $O(n(n + m))$，比 Floyd 的 $O(n^3)$ 快。
- **边权不全相同**：只有 0 和 1 用 0-1 BFS；一般非负权要用 Dijkstra（见图论最短路）。
- **层序遍历**：BFS 天然按深度顺序访问；按 BFS 序**倒序**处理，就能保证"儿子先于父亲"，可以代替递归 DFS 做自底向上的统计，避免爆栈。

## 6. 易错点

- **出队时才标记**：同一个点被多次入队，队列和时间都会爆。
- **起点忘记标记 / 设距离**：起点可能被再次入队。
- **越界检查要放在访问数组之前**：先判 `nx`、`ny` 在范围内，再看 `g[nx][ny]`。
- **多组数据忘记清空**：距离数组、`vis`、队列都要重置。
- **0-1 BFS 用普通 BFS 的"发现即确定"写法**：0 权边可能让已发现的点距离变小，必须用松弛写法。
- **双向 BFS 没有整层扩展**：可能得到比最短路更长的答案。
- **状态编码冲突**：编码不是一一对应时，不同状态会被误判为同一个。
- **起点就是终点**：答案是 0，有的写法会漏判（比如双向 BFS 只在扩展新状态时判断相遇）。
- **无解情况**：到不了终点时按题目要求输出 $-1$ 等。
