# 排序

**组别**：J　**关键词**：冒泡排序、选择排序、插入排序、计数排序、归并排序、快速排序、稳定性、逆序对

## 1. 是什么 / 解决什么问题

排序就是把一组元素按某种顺序（从小到大、按分数从高到低……）重新排列。它几乎是所有算法题的预处理：

- 排好序后，相同的元素挨在一起，方便去重、计数；
- 有序数组可以**二分查找**；
- 很多**贪心**都是"按某个关键字排序后依次处理"；
- 求排名、第 $k$ 小、中位数都离不开排序。

比赛中绝大多数时候直接用 STL 的 `sort`。但各种排序算法的原理仍然要掌握：初赛常考复杂度和稳定性；复赛里，计数排序、归并排序（求逆序对）、插入排序（维护有序序列）的思想会单独出现在题目里。

## 2. 核心原理

下面都以"从小到大排序 $a_1 \sim a_n$"为例。

### 2.1 冒泡排序

从左往右扫，相邻两个数逆序就交换。一轮之后，**最大的数一定"冒"到了最后**；第二轮之后次大的数到了倒数第二个……共 $n - 1$ 轮。

```
初始    5 3 4 1
第 1 轮 3 4 1 5    (5 一路换到末尾)
第 2 轮 3 1 4 5
第 3 轮 1 3 4 5
```

优化：某一轮一次交换都没发生，说明已经有序，可以提前结束。这样对已排好序的数组只需 $O(n)$。

一个重要性质：**冒泡排序的交换次数等于逆序对个数**。逆序对指 $i < j$ 且 $a_i > a_j$ 的数对。交换相邻的一对逆序元素，恰好让逆序对总数减少 1（只有这两个数的相对顺序变了），而排好序时逆序对为 0。所以"只能交换相邻元素时，最少交换次数 = 逆序对数"。

### 2.2 选择排序

第 $i$ 轮在 $a_i \sim a_n$ 里找最小的，和 $a_i$ 交换。比较次数固定为 $\frac{n(n-1)}{2}$，交换次数最多 $n - 1$。

### 2.3 插入排序

像打牌时整理手牌：前 $i - 1$ 个已经有序，把 $a_i$ 拿出来，从后往前把比它大的元素依次后移一位，空出的位置放 $a_i$。

```
已排 [1 4 6] | 3     拿出 3
     [1 4 _ 6]       6 > 3 后移
     [1 _ 4 6]       4 > 3 后移
     [1 3 4 6]       1 ≤ 3，放下
```

插入排序对**基本有序**的数据非常快：每个元素只需移动它前面比它大的元素个数，总移动次数就是逆序对数。所以如果只有少数元素位置不对，插入排序接近 $O(n)$。CSP-J 2021 插入排序一题就利用了这一点：修改一个元素后，只需要把这一个元素向左或向右"插"到正确位置，$O(n)$ 维护整个有序序列。

### 2.4 计数排序（桶排序）

如果值域很小（比如分数 $0 \sim 600$），开一个数组 `cnt[v]` 统计每个值出现的次数，然后从小到大按次数输出即可，不需要比较。

如果要排的是**带附加信息的记录**（按分数排学号），需要知道每条记录放在第几个位置：

1. `cnt[v]` 做前缀和后，表示"值 $\le v$ 的元素个数"，也就是值为 $v$ 的元素中**最后一个**应该放的位置；
2. **从后往前**扫原数组，把 $a_i$ 放到 `cnt[a[i]]`，然后 `cnt[a[i]]--`。

从后往前放，保证了相同值的元素保持原来的相对顺序（稳定）。

### 2.5 归并排序

典型的**分治**：

1. 把区间 $[l, r]$ 从中点 $mid$ 分成两半；
2. 递归地分别排好两半；
3. 把两个有序序列**合并**成一个。

合并时用两个指针分别指向两半的开头，每次取较小的那个放进临时数组：

```
左 [2 5 7]  右 [1 3 8]
取 1 (右)  -> 1
取 2 (左)  -> 1 2
取 3 (右)  -> 1 2 3
取 5 (左)  -> 1 2 3 5
取 7 (左)  -> 1 2 3 5 7
左空，右边剩下的 8 直接接上 -> 1 2 3 5 7 8
```

递归树共 $\log n$ 层，每层合并的总长度是 $n$，所以总时间 $O(n \log n)$，且**最坏情况也是** $O(n \log n)$。需要 $O(n)$ 的临时数组。

**归并求逆序对。** 逆序对 $(i, j)$ 要么都在左半，要么都在右半（递归时已经数过），要么 $i$ 在左、$j$ 在右。第三种在合并时统计：当从右半取出 $a_j$ 时，左半还没取的元素 $a_i \sim a_{mid}$ 都比 $a_j$ 大（左半有序，且它们没被先取出），它们都和 $a_j$ 构成逆序对，答案加上 $mid - i + 1$。

上例中：取 1 时左边剩 3 个（2, 5, 7），加 3；取 3 时左边剩 2 个（5, 7），加 2；取 8 时左边已空。跨两半的逆序对共 5 个。

注意合并时左右相等要先取左边（`a[i] <= a[j]`），否则会把相等的数也算成逆序对，同时也保证了稳定性。

### 2.6 快速排序

也是分治，但思路和归并相反：**先划分，再递归**，不需要合并。

1. 在区间里选一个基准值 $x$；
2. 把区间调整成"左边都 $\le x$、右边都 $\ge x$"；
3. 分别递归左右两部分。

划分用双指针：$i$ 从左往右找 $\ge x$ 的元素，$j$ 从右往左找 $\le x$ 的元素，找到后交换，直到两指针交错。

每次划分 $O(\text{区间长度})$。如果每次都分得比较均匀，递归 $\log n$ 层，总共 $O(n \log n)$；如果每次都分得极不均匀（比如数组已经有序、又总选第一个数做基准），递归 $n$ 层，退化成 $O(n^2)$。解决办法是**随机选基准**，期望复杂度 $O(n \log n)$。

**快速选择（求第 $k$ 小）。** 划分完后，第 $k$ 小只可能在其中一边，只需递归那一边。期望复杂度 $T(n) = T(n/2) + O(n) = O(n)$。STL 里对应 `nth_element(a + 1, a + k, a + n + 1)`，执行后 $a_k$ 就是第 $k$ 小，左边都不比它大，右边都不比它小。

### 2.7 稳定性

**稳定**是指：值相等的元素，排序后仍保持原来的相对顺序。只排数字时稳定性无所谓，但按某个关键字排结构体时就有影响。

选择排序为什么不稳定？看 $[2_a, 2_b, 1]$：第一轮把最小值 1 和第一个位置的 $2_a$ 交换，得到 $[1, 2_b, 2_a]$，两个 2 的顺序反了。快速排序同样因为远距离交换而不稳定。冒泡、插入只交换相邻的逆序元素，相等时不动，所以稳定；归并合并时相等先取左边，也稳定。

### 2.8 STL 的 sort 与自定义比较

```
sort(a + 1, a + 1 + n);                      // 1-indexed，从小到大
sort(a + 1, a + 1 + n, greater<int>());     // 从大到小
sort(a + 1, a + 1 + n, cmp);                // 自定义规则
stable_sort(a + 1, a + 1 + n, cmp);         // 稳定版本
```

`sort` 平均和最坏都是 $O(n \log n)$，但**不稳定**；需要稳定时用 `stable_sort`，或者在比较函数里加上"原下标"作为最后一个关键字。

`cmp(x, y)` 的含义是"$x$ 是否应该排在 $y$ **前面**"。它必须是**严格**的：两个元素相等时必须返回 `false`。写成 `<=` 会让 `sort` 行为未定义，可能越界导致运行错误。

**多关键字排序**：按优先级依次比较，前面的关键字不同就直接决定，相同才看下一个。

**排序下标**：不想打乱原数组时，对下标数组 `id[]` 排序，比较函数里比较 `a[id]`。排好后 `id[k]` 就是第 $k$ 名的原编号。

## 3. 代码模板

**三种 $O(n^2)$ 排序**：

```cpp
const int N = 1e3 + 5;
int n;
int a[N];

void bsort() {
    For(i, 1, n - 1) {
        bool ok = true;
        For(j, 1, n - i)
            if (a[j] > a[j + 1]) swap(a[j], a[j + 1]), ok = false;
        if (ok) break;
    }
}

void ssort() {
    For(i, 1, n - 1) {
        int p = i;
        For(j, i + 1, n)
            if (a[j] < a[p]) p = j;
        swap(a[i], a[p]);
    }
}

void isort() {
    For(i, 2, n) {
        int x = a[i], j = i - 1;
        while (j >= 1 && a[j] > x) a[j + 1] = a[j], j--;
        a[j + 1] = x;
    }
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    isort();
    For(i, 1, n) cout << a[i] << " ";
}
```

**稳定的计数排序**：值域 $[0, V]$，输出排好序后每个位置的原下标。

```cpp
const int N = 1e6 + 5, V = 1e6;
int n;
int a[N], cnt[V + 5], id[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i], cnt[a[i]]++;
    For(v, 1, V) cnt[v] += cnt[v - 1];
    for (int i = n; i >= 1; i--) id[cnt[a[i]]--] = i;
    For(i, 1, n) cout << id[i] << " ";
}
```

**归并排序求逆序对**：

```cpp
const int N = 5e5 + 5;
int n, ans;
int a[N], t[N];

void msort(int l, int r) {
    if (l == r) return;
    int mid = (l + r) / 2;
    msort(l, mid), msort(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) t[k++] = a[i++];
        else t[k++] = a[j++], ans += mid - i + 1;
    }
    while (i <= mid) t[k++] = a[i++];
    while (j <= r) t[k++] = a[j++];
    For(p, l, r) a[p] = t[p];
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    msort(1, n);
    cout << ans;
}
```

**快速排序与快速选择**：先求第 $k$ 小，再整体排序输出。

```cpp
const int N = 1e5 + 5;
int n, k;
int a[N];

void qs(int l, int r) {
    if (l >= r) return;
    int x = a[l + rand() % (r - l + 1)], i = l, j = r;
    while (i <= j) {
        while (a[i] < x) i++;
        while (a[j] > x) j--;
        if (i <= j) swap(a[i], a[j]), i++, j--;
    }
    qs(l, j), qs(i, r);
}

int kth(int l, int r, int k) {
    if (l == r) return a[l];
    int x = a[l + rand() % (r - l + 1)], i = l, j = r;
    while (i <= j) {
        while (a[i] < x) i++;
        while (a[j] > x) j--;
        if (i <= j) swap(a[i], a[j]), i++, j--;
    }
    if (k <= j) return kth(l, j, k);
    if (k >= i) return kth(i, r, k);
    return x;
}

void solve() {
    cin >> n >> k;
    For(i, 1, n) cin >> a[i];
    cout << kth(1, n, k) << endl;
    qs(1, n);
    For(i, 1, n) cout << a[i] << " ";
}
```

划分结束时 $j < i$，$[l, j]$ 都 $\le x$，$[i, r]$ 都 $\ge x$，夹在中间的（如果有）都等于 $x$，所以快速选择里 $j < k < i$ 时直接返回 $x$。

**结构体多关键字排序**：按总分降序，总分相同按语文降序，再相同按学号升序。

```cpp
const int N = 1e5 + 5;
int n;
struct stu { int id, c, m, e, s; } a[N];

bool cmp(const stu &a, const stu &b) {
    if (a.s != b.s) return a.s > b.s;
    if (a.c != b.c) return a.c > b.c;
    return a.id < b.id;
}

void solve() {
    cin >> n;
    For(i, 1, n) {
        cin >> a[i].c >> a[i].m >> a[i].e;
        a[i].id = i, a[i].s = a[i].c + a[i].m + a[i].e;
    }
    sort(a + 1, a + 1 + n, cmp);
    For(i, 1, n) cout << a[i].id << " " << a[i].s << endl;
}
```

## 4. 复杂度

| 算法 | 最好 | 平均 | 最坏 | 额外空间 | 稳定 |
| --- | --- | --- | --- | --- | --- |
| 冒泡排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |
| 选择排序 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 否 |
| 插入排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |
| 计数排序 | $O(n + V)$ | $O(n + V)$ | $O(n + V)$ | $O(n + V)$ | 是 |
| 归并排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | 是 |
| 快速排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ 栈 | 否 |
| 堆排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | 否 |

$V$ 是值域大小。冒泡的"最好 $O(n)$"指带提前结束优化的版本。基于比较的排序在最坏情况下至少需要 $\Omega(n \log n)$ 次比较，计数排序不做比较，所以能突破这个下界，代价是依赖值域。

## 5. 常见题型与技巧

1. **排序 + 贪心**：按结束时间、单价、差值等排序后依次决策，见《贪心》。
2. **求排名**：排序后相邻比较处理并列名次；或者用计数（值域小时，比 $v$ 大的个数 + 1 就是排名）。
3. **值域小用计数**：每次加入一个数后都要求第 $k$ 大时，不必每次重排，开桶从大往小累加即可（CSP-J 2020 直播获奖）。
4. **维护有序序列**：修改少、询问多时，每次修改像插入排序一样只移动被修改的那个元素（CSP-J 2021 插入排序）。
5. **逆序对**：相邻交换的最少次数、冒泡排序的交换次数，都等于逆序对数。用归并 $O(n \log n)$ 求，也可以用树状数组。
6. **第 $k$ 小**：`nth_element` 期望 $O(n)$，比完整排序快。
7. **按自定义规则拼接**：如把若干数字串拼成最大的数，比较规则是 $x + y > y + x$，见《贪心》中的邻项交换。

## 6. 易错点

- **排序范围**：1-indexed 时写 `sort(a + 1, a + 1 + n)`，写成 `sort(a, a + n)` 会把 $a_0$ 排进去、漏掉 $a_n$。
- **比较函数不严格**：`return a.x <= b.x;` 是错的，相等时必须返回 `false`。
- **多关键字漏写**：题目说"相同时按编号"，比较函数就必须写出这一层，不能依赖 `sort` 保持原序（它不稳定）。
- **逆序对计数溢出**：$n = 5 \times 10^5$ 时逆序对可达约 $1.25 \times 10^{11}$，超过 32 位整数。
- **相等元素算不算逆序**：归并时要写 `a[i] <= a[j]` 才不会把相等的算进去。
- **手写快排不随机**：遇到有序数据退化成 $O(n^2)$，递归深度 $n$ 还可能爆栈。
- **计数排序的值域**：值域上限要看清楚，有负数时整体加一个偏移量。
- **函数名冲突**：自己写的函数不要叫 `qsort`、`select` 之类与 C 库重名的名字。
