# 并查集

**组别**：S　**关键词**：并查集、路径压缩、按秩合并、带权并查集、扩展域并查集、连通性、倒序处理

## 1. 是什么 / 解决什么问题

并查集（Disjoint Set Union, DSU）维护若干个**互不相交的集合**，支持两种操作：

- **合并**（Union）：把两个元素所在的集合合并成一个；
- **查询**（Find）：查询某个元素属于哪个集合，从而判断两个元素是否在同一集合。

典型场景：亲戚关系（"A 和 B 是亲戚、B 和 C 是亲戚，那 A 和 C 呢"）、图的连通性（一条条加边，问两点是否连通）、Kruskal 最小生成树。

只能合并、不能拆分——这是并查集最大的限制。

## 2. 核心原理

### 2.1 用树表示集合

每个集合是一棵树，树根作为这个集合的**代表**。每个元素只记录父亲 `f[x]`，根的父亲是自己。

- 查询：从 $x$ 沿父亲一直走到根，根就是代表；
- 合并：找到两边的根，把一个根的父亲设为另一个根。

```text
初始：每个点自成一个集合   f = [1, 2, 3, 4, 5]

merge(1, 2)、merge(3, 4)、merge(2, 4)：

      4               f[1] = 2
     / \              f[2] = 4
    3   2             f[3] = 4
        |             f[4] = 4
        1             f[5] = 5
                      find(1) = 4 = find(3)，所以 1、3 在同一集合
```

### 2.2 路径压缩

朴素做法下树可能退化成一条长链，查询变成 $O(n)$。**路径压缩**：查询 $x$ 时，把路径上每个点的父亲直接改成根。下次再查就是一步到位。

```text
压缩前：1 -> 2 -> 4      压缩后：1 -> 4, 2 -> 4
```

递归写法最好理解：

```cpp
int find(int x) { return f[x] == x ? x : f[x] = find(f[x]); }
```

递归深度等于链长，链很长时（$10^6$）有爆栈风险。等价的非递归写法（路径减半，每个点指向祖父）：

```cpp
int find(int x) {
    while (f[x] != x) x = f[x] = f[f[x]];
    return x;
}
```

### 2.3 按秩合并（启发式合并）

合并时把**小树挂到大树下面**（按集合大小 `sz` 或树高）。这样一个点每被挂到别人下面一次，它所在集合的大小至少翻倍，所以深度不超过 $\log_2 n$。

只用路径压缩，均摊复杂度是 $O(\log n)$；两者都用，是 $O(\alpha(n))$，$\alpha$ 是反阿克曼函数，对任何实际的 $n$ 都不超过 4，可以当成常数。比赛中**只写路径压缩**通常已经足够快，需要维护集合大小时顺手按大小合并。

## 3. 代码模板

### 3.1 基础并查集

操作 `1 x y` 合并，`2 x y` 询问是否在同一集合。

```cpp
const int N = 2e5 + 5;
int n, m;
int f[N], sz[N];

int find(int x) {
    while (f[x] != x) x = f[x] = f[f[x]];
    return x;
}

void merge(int x, int y) {
    x = find(x), y = find(y);
    if (x == y) return;
    if (sz[x] < sz[y]) swap(x, y);
    f[y] = x, sz[x] += sz[y];
}

void solve() {
    cin >> n >> m;
    For(i, 1, n) f[i] = i, sz[i] = 1;
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) merge(x, y);
        else cout << (find(x) == find(y) ? "Y" : "N") << endl;
    }
}
```

顺带能得到的信息：

- **连通块个数**：初始 $n$，每次成功合并（两根不同）减 1；
- **集合大小**：`sz[find(x)]`；
- **无向图判环**：加边 $(u, v)$ 时若两端已在同一集合，这条边就形成了环。

### 3.2 带权并查集

除了父亲，每个点还记录一个**到父亲的边权** `d[x]`（例如距离、差值、奇偶关系）。路径压缩时，$x$ 直接指向根，`d[x]` 要改成 $x$ 到根的权值之和：先递归压缩父亲（此时 `d[f[x]]` 已是父亲到根的值），再 `d[x] += d[f[x]]`。

例（银河英雄传说）：$30000$ 列战舰，每列一开始只有一艘。`M x y` 把 $x$ 所在的整列接到 $y$ 所在列的尾部；`C x y` 询问 $x, y$ 是否同列，同列则输出它们之间隔了几艘。

设 `d[x]` 为 $x$ 到所在列**队头**（根）的距离，`sz[r]` 为列的长度。把列 $a$ 接到列 $b$ 后面：$a$ 的根到 $b$ 的根的距离就是 $b$ 原来的长度。

```cpp
const int N = 3e4 + 5;
int t;
int f[N], d[N], sz[N];

int find(int x) {
    if (f[x] == x) return x;
    int r = find(f[x]);
    d[x] += d[f[x]];
    return f[x] = r;
}

void solve() {
    Rep(i, 1, N) f[i] = i, sz[i] = 1;
    cin >> t;
    while (t--) {
        char op;
        int x, y;
        cin >> op >> x >> y;
        int a = find(x), b = find(y);
        if (op == 'M') {
            if (a != b) d[a] = sz[b], f[a] = b, sz[b] += sz[a];
        } else
            cout << (a == b ? abs(d[x] - d[y]) - 1 : -1) << endl;
    }
}
```

注意 `d[x] += d[f[x]]` 必须在递归**之后**、修改 `f[x]` **之前**。

带权并查集常用于维护"差值关系"：已知 $x_a - x_b = w$ 若干条，判断矛盾或求某两个量的差。合并根 $a$ 到根 $b$ 时，根据 $x - y = w$、`d[x]`、`d[y]` 列方程求出 `d[a]`。

### 3.3 扩展域并查集（种类并查集）

当关系不只是"相同"，还有"敌对""吃与被吃"这类时，可以把每个点拆成几个**域**，每个域表示"$x$ 处于某种身份"这件事；在同一集合里的事件**同时成立**。

食物链：A 吃 B、B 吃 C、C 吃 A。每只动物 $x$ 拆成三个点：

- $x$：$x$ 本身的种类；
- $x + n$：$x$ 吃的种类；
- $x + 2n$：吃 $x$ 的种类。

"$x$ 和 $y$ 同类"：三个域对应合并。"$x$ 吃 $y$"：$x$ 吃的种类 = $y$ 的种类，吃 $x$ 的种类 = $y$ 吃的种类（三角循环），$x$ 的种类 = 吃 $y$ 的种类。

判断一句话与之前矛盾：

- 说"同类"，但已知 $x$ 吃 $y$（$x+n$ 与 $y$ 同集合）或 $y$ 吃 $x$（$x$ 与 $y+n$ 同集合）；
- 说"$x$ 吃 $y$"，但已知同类（$x$ 与 $y$ 同集合）或 $y$ 吃 $x$。

```cpp
const int N = 5e4 + 5;
int n, k, ans;
int f[N * 3];

int find(int x) {
    while (f[x] != x) x = f[x] = f[f[x]];
    return x;
}

inline void merge(int x, int y) { f[find(x)] = find(y); }

void solve() {
    cin >> n >> k;
    For(i, 1, 3 * n) f[i] = i;
    while (k--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (x > n || y > n) {
            ans++;
            continue;
        }
        if (op == 1) {
            if (find(x + n) == find(y) || find(x) == find(y + n)) ans++;
            else merge(x, y), merge(x + n, y + n), merge(x + 2 * n, y + 2 * n);
        } else {
            if (find(x) == find(y) || find(x) == find(y + n)) ans++;
            else merge(x + n, y), merge(x + 2 * n, y + n), merge(x, y + 2 * n);
        }
    }
    cout << ans;
}
```

两种关系（朋友/敌人、二分图染色）只需拆成两个域：$x$ 与 $y + n$ 合并表示"$x$ 和 $y$ 是敌人"。同样的问题也可以用带权并查集（权值模 2 或模 3）解决。

### 3.4 并查集跳过已处理的位置

问题：$m$ 次操作，第 $i$ 次把区间 $[l_i, r_i]$ 涂成颜色 $c_i$（后涂的覆盖先涂的），求最终每个位置的颜色。

**倒序**处理操作：后面的操作先涂，每个位置只需要被涂一次，涂过的位置以后都跳过。用 `f[i]` 表示"$\ge i$ 的第一个还没涂的位置"，涂完 $i$ 就令 `f[i] = i + 1`，`find` 自动跳过一整段已涂的位置。

```cpp
const int N = 1e6 + 5;
int n, m;
int l[N], r[N], c[N], f[N], col[N];

int find(int x) {
    while (f[x] != x) x = f[x] = f[f[x]];
    return x;
}

void solve() {
    cin >> n >> m;
    For(i, 1, m) cin >> l[i] >> r[i] >> c[i];
    For(i, 1, n + 1) f[i] = i;
    for (int i = m; i >= 1; i--)
        for (int j = find(l[i]); j <= r[i]; j = find(j))
            col[j] = c[i], f[j] = j + 1;
    For(i, 1, n) cout << col[i] << ' ';
}
```

每个位置只被涂一次，总复杂度 $O((n + m)\,\alpha(n))$。`f` 要开到 $n + 1$ 作为哨兵。

## 4. 复杂度

| 实现 | 单次操作（均摊） |
| --- | --- |
| 朴素 | 最坏 $O(n)$ |
| 只用路径压缩 | $O(\log n)$ |
| 只按秩合并 | $O(\log n)$ |
| 路径压缩 + 按秩合并 | $O(\alpha(n))$ |

空间 $O(n)$，扩展域并查集是 $O(kn)$（$k$ 为域数）。

## 5. 常见题型与技巧

- **连通性**：动态加边判断两点是否连通、统计连通块个数和大小。
- **Kruskal**：边按权值排序，用并查集判断两端是否已连通（见"最小生成树"）。
- **倒序处理删除**：只删不加的问题（删点、删边后问连通块个数）倒过来就变成只加不减，用并查集。
- **离线 + 排序**：询问"只用权值 $\le w$ 的边时 $u, v$ 是否连通"，把边和询问都按权值排序，边一条条加入。
- **约束判断**：先合并所有"相等"约束，再检查"不等"约束是否矛盾。"相等"关系有传递性，"不等"没有，所以先处理相等。
- **关系类问题**：敌人的敌人是朋友、食物链、奇偶性——扩展域或带权并查集。
- **跳过已处理元素**：区间覆盖、"找下一个空位"，用 `f[i] = i + 1` 的技巧让每个元素只处理一次。
- **维护集合的附加信息**：大小、最值、边数等，在合并时累加到新根上。

## 6. 易错点

- 忘记初始化 `f[i] = i`；扩展域要初始化全部 $kn$ 个点；多组数据要重新初始化。
- 合并时要合并**根**：`f[find(x)] = find(y)`，写成 `f[x] = y` 是错的。
- 附加信息只在根上有效：集合大小要用 `sz[find(x)]`。
- 带权并查集路径压缩时更新权值的顺序；合并时新的边权要按关系方程算对。
- 递归 `find` 在长链上可能爆栈，用非递归写法。
- 并查集**不支持拆分**。需要撤销时只能用"按秩合并、不路径压缩 + 栈记录"的可撤销并查集（超出 CSP 常规范围）。
