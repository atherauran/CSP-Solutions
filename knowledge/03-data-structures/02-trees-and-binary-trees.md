# 树与二叉树

**组别**：J　**关键词**：树、二叉树、先序中序后序遍历、层序遍历、完全二叉树、二叉搜索树、哈夫曼树、表达式树

## 1. 是什么 / 解决什么问题

**树**是 $n$ 个点、$n-1$ 条边、连通且没有环的图。等价说法：任意两点之间有且只有一条简单路径。家谱、文件夹目录、比赛对阵表、表达式的运算结构都是树。

选定一个点作为**根**后，树就有了"上下"关系：

```text
          1          根：1
        / | \        1 的孩子：2、3、4
       2  3  4       2 的父亲：1；2、3、4 互为兄弟
      / \     \      叶子（没有孩子）：5、6、3、7
     5   6     7     深度：1 在第 1 层，2/3/4 在第 2 层，5/6/7 在第 3 层
```

基本术语：

- **父亲 / 孩子 / 兄弟**：相邻两层的上、下关系；同一父亲的孩子互为兄弟。
- **祖先 / 后代**：从根到 $u$ 路径上的点（不含 $u$）都是 $u$ 的祖先。
- **子树**：$u$ 和它的所有后代构成以 $u$ 为根的子树。
- **度**：在有根树里一般指孩子个数（注意图论里的度是相连边数，初赛题会说明是哪种）。
- **深度 / 高度**：根的深度通常记为 1（也有题记为 0，以题目为准）；树的高度 = 最大深度。
- **森林**：若干棵互不相交的树。

**二叉树**：每个结点最多两个孩子，并且区分**左孩子**和**右孩子**（只有一个孩子时，它是左还是右，算两棵不同的二叉树）。

## 2. 树的存储与遍历

### 2.1 一般的树

- **邻接表**：`vector<int> g[N];`，无向边两头都存，DFS 时传父亲避免走回头路。
- **父亲数组**：`fa[u]`，适合只需要往上走的场合。
- 题目经常保证 $fa_u < u$，这时按编号从小到大处理就是"先父后子"，从大到小就是"先子后父"，可以不写 DFS。

一次 DFS 可以求出每个点的父亲、深度、子树大小：

```cpp
const int N = 1e5 + 5;
int n;
int fa[N], dep[N], sz[N];
vector<int> g[N];

void dfs(int u, int f) {
    fa[u] = f, dep[u] = dep[f] + 1, sz[u] = 1;
    for (int v : g[u]) {
        if (v == f) continue;
        dfs(v, u);
        sz[u] += sz[v];
    }
}

void solve() {
    cin >> n;
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    dfs(1, 0);
    For(i, 1, n) cout << fa[i] << ' ' << dep[i] << ' ' << sz[i] << endl;
}
```

递归深度等于树高。一条 $10^6$ 个点的链会让递归深度达到 $10^6$，在栈空间小的环境下可能爆栈，这时用手写栈或利用编号顺序递推。

### 2.2 二叉树的四种遍历

二叉树用 `ls[u]`、`rs[u]` 存左右孩子（0 表示没有）。按"根在什么时候访问"分三种深度优先遍历：

- **先序（前序）**：根 → 左子树 → 右子树
- **中序**：左子树 → 根 → 右子树
- **后序**：左子树 → 右子树 → 根

再加上按层从上到下、每层从左到右的**层序遍历**（用队列 BFS）。

```text
        A
       / \
      B   C          先序：A B D E C F
     / \   \         中序：D B E A C F
    D   E   F        后序：D E B F C A
                     层序：A B C D E F
```

```cpp
const int N = 1e5 + 5;
int n;
int ls[N], rs[N], q[N];

void pre(int u) {
    if (!u) return;
    cout << u << ' ';
    pre(ls[u]), pre(rs[u]);
}

void mid(int u) {
    if (!u) return;
    mid(ls[u]);
    cout << u << ' ';
    mid(rs[u]);
}

void post(int u) {
    if (!u) return;
    post(ls[u]), post(rs[u]);
    cout << u << ' ';
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> ls[i] >> rs[i];
    pre(1), cout << endl;
    mid(1), cout << endl;
    post(1), cout << endl;
    int h = 1, t = 0;
    q[++t] = 1;
    while (h <= t) {
        int u = q[h++];
        cout << u << ' ';
        if (ls[u]) q[++t] = ls[u];
        if (rs[u]) q[++t] = rs[u];
    }
}
```

### 2.3 由遍历序列还原二叉树

关键观察：先序的**第一个**是根，后序的**最后一个**是根；在中序里找到根，左边是左子树、右边是右子树。知道左子树大小后，就能在先序/后序里切出左右子树的部分，递归下去。

例：先序 `ABDECF`，中序 `DBEACF`。

1. 根是 `A`。中序中 `A` 左边 `DBE`（左子树 3 个点），右边 `CF`。
2. 先序去掉根后，前 3 个 `BDE` 是左子树的先序，后面 `CF` 是右子树的先序。
3. 左子树：先序 `BDE`、中序 `DBE`，根 `B`，左 `D` 右 `E`。右子树：先序 `CF`、中序 `CF`，根 `C`，没有左子树，右孩子 `F`。

下面的代码由先序 + 中序直接输出后序（在递归返回时输出根，就是后序）：

```cpp
string a, b;

void build(int l1, int r1, int l2, int r2) {
    if (l1 > r1) return;
    int k = b.find(a[l1]), len = k - l2;
    build(l1 + 1, l1 + len, l2, k - 1);
    build(l1 + len + 1, r1, k + 1, r2);
    cout << a[l1];
}

void solve() {
    cin >> a >> b;
    build(0, (int)a.size() - 1, 0, (int)b.size() - 1);
}
```

结论：

- **先序 + 中序**、**后序 + 中序**都能唯一确定一棵二叉树（结点值互不相同时）。
- **先序 + 后序**不能唯一确定：只有一个孩子的结点，这个孩子放左边还是右边，先序和后序都一样。判断方法：先序中相邻的 `XY` 在后序中以 `YX` 出现，说明 $Y$ 是 $X$ 的唯一孩子。若有 $k$ 个这样的结点，对应的中序有 $2^k$ 种。

## 3. 二叉树的性质（初赛高频）

1. 第 $i$ 层最多 $2^{i-1}$ 个结点；深度为 $k$ 的二叉树最多 $2^k - 1$ 个结点。
2. 设度为 0、1、2 的结点数分别为 $n_0, n_1, n_2$，则 $n_0 = n_2 + 1$。
   **为什么**：结点总数 $n = n_0 + n_1 + n_2$；除根外每个结点上方恰有一条边，边数 $n - 1 = n_1 + 2n_2$。两式相减得 $n_0 = n_2 + 1$。
3. $n$ 个结点的不同形态二叉树有卡特兰数 $C_n = \dfrac{1}{n+1}\dbinom{2n}{n}$ 种（$n=3$ 时 5 种）。
   **为什么**：选一个点当根，左子树 $i$ 个点、右子树 $n-1-i$ 个点，$C_n = \sum_{i=0}^{n-1} C_i C_{n-1-i}$，这正是卡特兰数的递推式。
4. 树（一般树）转二叉树用"**左孩子右兄弟**"：每个点的第一个孩子作为左孩子，它的下一个兄弟作为右孩子。

### 3.1 满二叉树与完全二叉树

- **满二叉树**：每层都是满的，深度 $k$ 时恰好 $2^k - 1$ 个结点。
- **完全二叉树**：除最后一层外都是满的，最后一层的结点**从左往右连续**排列。

完全二叉树可以**直接用数组存**，不需要指针：按层序编号 $1 \sim n$，则

- 结点 $i$ 的左孩子 $2i$，右孩子 $2i + 1$，父亲 $\lfloor i/2 \rfloor$；
- $i > \lfloor n/2 \rfloor$ 的结点是叶子，所以叶子数为 $n - \lfloor n/2 \rfloor = \lceil n/2 \rceil$；
- 深度为 $\lfloor \log_2 n \rfloor + 1$。

```text
            1
         /     \
        2       3
       / \     / \
      4   5   6   7
     / \
    8   9            n = 9，叶子是 5~9，共 ⌈9/2⌉ = 5 个
```

堆和线段树都利用了这种编号方式。

## 4. 二叉搜索树

**二叉搜索树（BST）**：对每个结点，左子树所有值 $<$ 它，右子树所有值 $>$ 它（有重复值时约定放到一侧，或者在结点上记计数）。

性质：**中序遍历得到的是有序序列**。查找、插入都从根出发，比当前结点小就往左走，大就往右走，代价是树高。

```cpp
const int N = 1e5 + 5;
int n, m, tot, rt;
int val[N], ls[N], rs[N];

void ins(int &u, int x) {
    if (!u) {
        u = ++tot, val[u] = x;
        return;
    }
    if (x < val[u]) ins(ls[u], x);
    else ins(rs[u], x);
}

bool find(int u, int x) {
    while (u && val[u] != x) u = x < val[u] ? ls[u] : rs[u];
    return u;
}

void mid(int u) {
    if (!u) return;
    mid(ls[u]);
    cout << val[u] << ' ';
    mid(rs[u]);
}

void solve() {
    cin >> n >> m;
    For(i, 1, n) {
        int x;
        cin >> x;
        ins(rt, x);
    }
    mid(rt), cout << endl;
    while (m--) {
        int x;
        cin >> x;
        cout << (find(rt, x) ? "YES" : "NO") << endl;
    }
}
```

问题在于树高不受控制：按 $1, 2, 3, \dots, n$ 的顺序插入会退化成一条链，每次操作 $O(n)$。平衡树（Treap、Splay、红黑树等）通过旋转保持树高 $O(\log n)$，CSP 一般不要求手写，需要时直接用 STL 的 `set` / `map`（内部就是红黑树）。

删除结点（初赛可能考）：叶子直接删；只有一个孩子，用孩子顶替；有两个孩子，用**右子树最小值**（或左子树最大值）替换它的值，再去右子树删掉那个最小值。

## 5. 哈夫曼树

**问题**：给定 $n$ 个叶子的权值 $w_i$，构造一棵二叉树，使**带权路径长度** $WPL = \sum w_i \cdot d_i$ 最小（$d_i$ 是叶子 $i$ 到根的边数）。

**构造**：每次取出权值最小的两棵树，合并成一棵新树（新根的权值为两者之和），重复 $n - 1$ 次。

**为什么对**：权值最小的两个叶子，一定可以放在最深的一层并且互为兄弟（若不是，和最深层的叶子交换，WPL 不会变大）。把它们合并成一个权值为 $a+b$ 的叶子后，原问题的 WPL = 新问题的 WPL $+ (a + b)$，于是问题规模减 1，归纳即可。由此还可以得到：**WPL 等于每次合并的代价之和**。

例：权值 $5, 9, 12, 13, 16, 45$。

| 步骤 | 取出 | 合并得到 |
| --- | --- | --- |
| 1 | 5, 9 | 14 |
| 2 | 12, 13 | 25 |
| 3 | 14, 16 | 30 |
| 4 | 25, 30 | 55 |
| 5 | 45, 55 | 100 |

$WPL = 14 + 25 + 30 + 55 + 100 = 224$。

```cpp
int n, ans;
priority_queue<int, vector<int>, greater<int>> q;

void solve() {
    cin >> n;
    For(i, 1, n) {
        int x;
        cin >> x;
        q.push(x);
    }
    while (q.size() > 1) {
        int a = q.top();
        q.pop();
        int b = q.top();
        q.pop();
        ans += a + b;
        q.push(a + b);
    }
    cout << ans;
}
```

**哈夫曼编码**：把左边标 0、右边标 1，从根到叶子的 01 串就是该字符的编码。出现频率高的字符编码短，而且任何一个编码都不是另一个的前缀（**前缀码**），解码时不会有歧义。初赛常考"给出频率，求某字符的编码长度或总编码长度"——总长度就是 WPL。上例中 45 的编码长度为 1，12、13、16 为 3，5、9 为 4。

## 6. 表达式树

叶子是操作数，内部结点是运算符。`(a + b) * c - d`：

```text
          -
         / \
        *   d
       / \
      +   c
     / \
    a   b
```

- 先序：`- * + a b c d`（前缀表达式 / 波兰式）
- 中序：`a + b * c - d`（中缀，丢失了括号，需要按需补括号）
- 后序：`a b + c * d -`（后缀表达式 / 逆波兰式）

所以"中缀转后缀""求前缀表达式"之类的初赛题，本质就是画出表达式树再遍历。从后缀表达式建树的方法：遇到操作数新建叶子入栈；遇到二元运算符，弹出两个结点（先弹出的是右孩子）作为它的孩子，再把它入栈。

在表达式树上可以从下往上求值，也可以从上往下判断"某个叶子改变后会不会影响根的值"，见 CSP-J 2020 T3。

## 7. 复杂度

| 操作 | 复杂度 |
| --- | --- |
| 各种遍历、求深度和子树大小 | $O(n)$ |
| 先序 + 中序还原 | 每层在中序里查找根，$O(n^2)$；用数组记录每个值在中序中的位置可以做到 $O(n)$ |
| 二叉搜索树查找/插入 | $O(h)$，随机数据 $h = O(\log n)$，最坏 $O(n)$ |
| 哈夫曼树 | $O(n \log n)$（堆）；权值已排好序时用双队列 $O(n)$ |

## 8. 常见题型与技巧

- **初赛**：给遍历序列求另一种遍历；结点数、叶子数、深度的计算；完全二叉树编号；哈夫曼编码长度；前中后缀表达式互转；"左孩子右兄弟"转换。
- **子树问题**：DFS 求子树大小、子树和，"$u$ 在 $v$ 子树内"等价于"$v$ 是 $u$ 的祖先"。
- **编号有序的树**：$fa_u < u$（或 $fa_u > u$）时直接按编号顺序递推，避免递归。
- **从结构中发现树**：有些题表面不是树，但每个状态只有唯一的"下一个状态"，把它当父亲就得到一棵树，问题变成子树统计。
- **满二叉树结构**：比赛对阵、分治的递归结构天然是满二叉树，可以用 $2i, 2i+1$ 的编号直接存。

## 9. 易错点

- 根的深度是 0 还是 1，层数从 0 还是 1 开始，以题目为准。
- 无向边建树时 DFS 要跳过父亲，否则无限递归。
- 先序 + 后序**不能**唯一确定二叉树，不要直接套还原代码。
- 二叉搜索树遇到有序插入会退化，时间要求高时用 `set` / `map`。
- 哈夫曼合并时求和可能超过 int 范围（本仓库模板中 `int` 已是 64 位）。
- 递归深度过大会爆栈，链状数据要警惕。
