# 单调栈与单调队列

**组别**：S　**关键词**：单调栈、单调队列、下一个更大元素、最大矩形、滑动窗口、DP 优化、贡献法

## 1. 是什么 / 解决什么问题

两类非常常见的需求：

1. 对每个位置 $i$，找它**左边/右边第一个比它大（或小）的位置**。暴力往外找是 $O(n^2)$。
2. 一个长度固定（或左端点单调右移）的**窗口**在序列上滑动，每次求窗口里的最大/最小值。暴力扫窗口是 $O(nk)$。

**单调栈**解决第一类，**单调队列**解决第二类，都是 $O(n)$。它们的共同思想是一句话：

> 如果一个元素**比你晚出现**，还**比你更优**，那你就永远没用了，可以直接扔掉。

扔掉无用元素后，留下的元素自然形成单调序列。每个元素最多进一次、出一次，所以总复杂度线性。

## 2. 核心原理

### 2.1 单调栈：找右边第一个更大的数

从右往左扫，栈里存"可能成为后面某个位置答案"的下标。处理 $a_i$ 时：

- 栈顶若 $a_{top} \le a_i$，弹出。**为什么可以弹**：对 $i$ 左边的任何位置 $j$，向右看时先遇到 $i$，$a_i$ 又不比 $a_{top}$ 小，所以 $a_{top}$ 永远不会是 $j$ 的"第一个更大"——$i$ 更近、也不更差。
- 弹完后栈顶（若有）就是 $i$ 右边第一个比 $a_i$ 大的位置。
- 把 $i$ 入栈。

栈中从栈底到栈顶，下标递减、值**严格递减**，所以叫单调栈。

手推 $a = [2, 7, 3, 5, 4, 6]$（下标 1~6），从右往左：

| $i$ | $a_i$ | 弹出 | 答案（下标） | 栈（底→顶，写值） |
| --- | --- | --- | --- | --- |
| 6 | 6 | — | 0 | 6 |
| 5 | 4 | — | 6 | 6 4 |
| 4 | 5 | 4 | 6 | 6 5 |
| 3 | 3 | — | 4 | 6 5 3 |
| 2 | 7 | 3 5 6 | 0 | 7 |
| 1 | 2 | — | 2 | 7 2 |

```cpp
const int N = 3e6 + 5;
int n, top;
int a[N], f[N], st[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    for (int i = n; i >= 1; i--) {
        while (top && a[st[top]] <= a[i]) top--;
        f[i] = top ? st[top] : 0;
        st[++top] = i;
    }
    For(i, 1, n) cout << f[i] << ' ';
}
```

四种变体只需改两个地方：

| 求 | 扫描方向 | 弹出条件 |
| --- | --- | --- |
| 右边第一个 $>$ | 从右往左 | `a[st[top]] <= a[i]` |
| 右边第一个 $\ge$ | 从右往左 | `a[st[top]] < a[i]` |
| 左边第一个 $<$ | 从左往右 | `a[st[top]] >= a[i]` |
| 左边第一个 $\le$ | 从左往右 | `a[st[top]] > a[i]` |

记法：弹出条件就是"栈顶**不满足**要求"。

另一种写法是从左往右扫，**在弹出时**确定答案：$a_i$ 把栈顶弹出，说明 $i$ 就是栈顶右边第一个更大的数。两种写法等价。

### 2.2 例：直方图最大矩形

$n$ 个宽为 1 的柱子，高 $h_i$，求能放进去的最大矩形面积。

枚举矩形的**高度由哪根柱子决定**：以 $h_i$ 为高的最宽矩形，向左延伸到左边第一个比它矮的柱子 $l_i$ 之前，向右延伸到右边第一个比它矮的柱子 $r_i$ 之前，面积 $h_i \cdot (r_i - l_i - 1)$。两次单调栈求出 $l, r$ 即可。

```cpp
const int N = 1e5 + 5;
int n, top, ans;
int h[N], l[N], r[N], st[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> h[i];
    For(i, 1, n) {
        while (top && h[st[top]] >= h[i]) top--;
        l[i] = top ? st[top] : 0;
        st[++top] = i;
    }
    top = 0;
    for (int i = n; i >= 1; i--) {
        while (top && h[st[top]] >= h[i]) top--;
        r[i] = top ? st[top] : n + 1;
        st[++top] = i;
    }
    For(i, 1, n) ans = max(ans, h[i] * (r[i] - l[i] - 1));
    cout << ans;
}
```

### 2.3 单调队列：滑动窗口最值

窗口 $[i-k+1, i]$ 向右滑动，求每个窗口的最小值。

队列里存下标，维护：

- **下标递增**（按进入顺序），**值递增**（队头最小）。
- 新元素 $a_i$ 从**队尾**进来前，把队尾所有 $\ge a_i$ 的弹掉。**为什么**：它们比 $i$ 早离开窗口，值又不比 $a_i$ 小，在它们剩下的寿命里 $a_i$ 一直在窗口中且不比它们差，所以它们永远不会成为最小值。
- 队头下标若已经滑出窗口（$< i-k+1$），从**队头**弹掉。
- 此时队头就是窗口最小值。

手推 $a = [1, 3, -1, -3, 5, 3, 6, 7]$，$k = 3$，求最小值：

| $i$ | $a_i$ | 队列（写值） | 输出 |
| --- | --- | --- | --- |
| 1 | 1 | 1 | |
| 2 | 3 | 1 3 | |
| 3 | -1 | -1 | -1 |
| 4 | -3 | -3 | -3 |
| 5 | 5 | -3 5 | -3 |
| 6 | 3 | -3 3 | -3 |
| 7 | 6 | 3 6（-3 过期） | 3 |
| 8 | 7 | 3 6 7 | 3 |

因为两端都要弹出，所以需要双端队列。用数组 + 头尾指针最快：

```cpp
const int N = 1e6 + 5;
int n, k;
int a[N], q[N];

void solve() {
    cin >> n >> k;
    For(i, 1, n) cin >> a[i];
    int h = 1, t = 0;
    For(i, 1, n) {
        while (h <= t && a[q[t]] >= a[i]) t--;
        q[++t] = i;
        while (q[h] <= i - k) h++;
        if (i >= k) cout << a[q[h]] << ' ';
    }
    cout << endl;
    h = 1, t = 0;
    For(i, 1, n) {
        while (h <= t && a[q[t]] <= a[i]) t--;
        q[++t] = i;
        while (q[h] <= i - k) h++;
        if (i >= k) cout << a[q[h]] << ' ';
    }
}
```

单调队列的窗口不必定长，只要求**左右端点都单调不减**。

## 3. 用单调队列优化问题

### 3.1 长度不超过 $m$ 的最大子段和

子段 $(j, i]$ 的和是 $s_i - s_j$（$s$ 是前缀和）。固定右端点 $i$，要在 $j \in [i-m, i-1]$ 中找最小的 $s_j$——这正是一个滑动窗口最小值。

```cpp
const int N = 5e5 + 5;
int n, m, ans = -LINF;
int s[N], q[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> s[i], s[i] += s[i - 1];
    int h = 1, t = 0;
    q[++t] = 0;
    For(i, 1, n) {
        while (q[h] < i - m) h++;
        ans = max(ans, s[i] - s[q[h]]);
        while (h <= t && s[q[t]] >= s[i]) t--;
        q[++t] = i;
    }
    cout << ans;
}
```

注意顺序：先用窗口 $[i-m, i-1]$ 算答案，再把 $i$ 加进去给后面用。

### 3.2 DP 优化

形如
$$f_i = \min_{L(i) \le j \le R(i)} f_j + w_i$$
其中 $L(i)$、$R(i)$ 随 $i$ 单调不减，且被取最值的部分**只与 $j$ 有关**，就可以用单调队列把 $O(nk)$ 降到 $O(n)$。

例：$n$ 个位置，选位置 $i$ 的代价是 $a_i$，要求每连续 $k$ 个位置里至少选一个，求最小代价。

设 $f_i$ 为"选了位置 $i$，且前 $i$ 个位置合法"的最小代价，上一个选的位置 $j$ 满足 $i - j \le k$：
$$f_i = a_i + \min_{i-k \le j \le i-1} f_j,\quad f_0 = 0$$
答案是 $\min_{n-k+1 \le i \le n} f_i$。

```cpp
const int N = 2e5 + 5;
int n, k, ans = LINF;
int a[N], f[N], q[N];

void solve() {
    cin >> n >> k;
    For(i, 1, n) cin >> a[i];
    int h = 1, t = 0;
    q[++t] = 0;
    For(i, 1, n) {
        while (q[h] < i - k) h++;
        f[i] = f[q[h]] + a[i];
        while (h <= t && f[q[t]] >= f[i]) t--;
        q[++t] = i;
    }
    For(i, n - k + 1, n) ans = min(ans, f[i]);
    cout << ans;
}
```

更一般地，单调队列维护的不一定是"值"本身，而是某个关于 $j$ 的量，只要满足"后来者更优则前者无用"即可。CSP-S 2019 划分中，队列维护的是满足条件的最右分界点，判断条件是 $2s_j - s_{g_j} \le s_i$。

## 4. 复杂度

每个下标最多入栈/入队一次、出栈/出队一次，总复杂度 $O(n)$，空间 $O(n)$。代码里有 `while` 嵌套在 `for` 里，但内层循环的总次数不超过 $n$——这是**均摊分析**。

对比：

| 方法 | 下一个更大 | 滑动窗口最值 | 支持修改 |
| --- | --- | --- | --- |
| 暴力 | $O(n^2)$ | $O(nk)$ | — |
| ST 表 / 线段树 | 二分 $O(n\log n)$ | $O(n\log n)$ | 线段树可以 |
| 单调栈 / 单调队列 | $O(n)$ | $O(n)$ | 不行 |

## 5. 常见题型与技巧

- **最近的更大/更小元素**：直接套单调栈；"能看到多少人""每个人向右看到的第一个更高的人"都是这类。
- **以 $a_i$ 为最值的区间**：$a_i$ 作为最小值能管辖的最大区间是 $(l_i, r_i)$（左右第一个更小）。用于最大矩形、"区间最小值 × 区间和"的最大值等。
- **贡献法**：求所有子区间最小值之和。$a_i$ 是 $(i - l_i)(r_i - i)$ 个区间的最小值，贡献 $a_i(i-l_i)(r_i-i)$。**有相等元素时**一边取严格小于、另一边取小于等于，保证每个区间只被算一次。
- **二维**：$a \times b$ 子矩阵的最值，先对每行做长度 $b$ 的滑动窗口，再对结果的每列做长度 $a$ 的滑动窗口。
- **DP 优化**：转移来自一个单调移动的窗口，并且被比较的量只跟 $j$ 有关。如果还和 $i$、$j$ 都有关（如 $(s_i - s_j)^2$），单调队列不够用，需要斜率优化（超出 CSP-S 常规范围）。
- **前缀和 + 单调队列**：长度受限的最大子段和、"和不小于 $K$ 的最短子段"（对非负数组也可用双指针）。

## 6. 易错点

- 判空：`while (top && ...)`、`while (h <= t && ...)`，先判空再访问。
- 栈/队列里存**下标**而不是值：既能取值，又能判断是否过期、计算距离。
- 严格还是非严格（`<` 还是 `<=`）要和题意对应，尤其是"第一个大于"和"第一个大于等于"。
- 单调队列中"弹出过期队头"和"用队头更新答案"的顺序：先弹过期，再取答案；新元素何时入队要看窗口是否包含 $i$ 自身。
- DP 优化时别忘了把初始状态（如 $f_0$）先放进队列。
- 多组数据要重置 `top`、`h`、`t`。
