# 字典树

**组别**：S　**关键词**：字典树、Trie、前缀统计、01-Trie、最大异或、DFS 序

## 1. 是什么 / 解决什么问题

给一组字符串，要反复询问：某个串在不在里面？有多少个串以某个串为前缀？

用 `set<string>` 或哈希能判断"在不在"，但"有多少个串以 $t$ 为前缀"就不好做了。**字典树**（Trie，又叫前缀树）把所有字符串放进一棵树：从根往下的每条边是一个字符，**根到某个结点的路径**拼起来就是一个前缀。有公共前缀的串共用同一段路径，就像查字典时先翻到首字母、再找第二个字母一样。

插入、查找一个长度为 $L$ 的串都是 $O(L)$，与已有多少个串无关。

把整数看成二进制串放进字典树，就得到 **01-Trie**，它是处理"最大异或"类问题的标准工具。

## 2. 核心原理

### 2.1 结构

依次插入 `cat`、`car`、`cart`、`dog`、`do`：

```text
              0
           c/   \d
           1     6
          a|     |o
           2     7*
         t/ \r   |g
         3*  4*  8*
             |t
             5*
```

- 结点 0 是根，代表空串。其余结点按新建的顺序编号。
- 每条边上写一个字符。结点 3 代表 `cat`，结点 4 代表 `car`，结点 7 代表 `do`。
- 带 `*` 的结点表示"有一个串**在这里结束**"。`do` 是 `dog` 的前缀，所以结点 7 既是 `dog` 路径上的点，又是一个结尾。只看"能不能走到"是分不清 `do` 有没有被插入的，必须靠结尾标记。

存储：`ch[p][c]` 表示结点 $p$ 沿字符 $c$ 走到的儿子编号，0 表示没有这个儿子（根是 0，不会成为任何结点的儿子，所以 0 可以当"空"用）。

### 2.2 插入与查找

**插入** $s$：从根出发，对每个字符 $c$，若 `ch[p][c]` 不存在就新建结点，然后走过去。走完后在最后的结点打结尾标记。

**查找** $s$：同样从根往下走，中途某个儿子不存在就说明没有任何串以 $s$ 为前缀；走完后看结尾标记就知道 $s$ 本身是否出现过。

### 2.3 在结点上记信息

插入时，沿途经过的每个结点 `cnt[p]++`。由于结点 $p$ 代表前缀 $t$，而以 $t$ 为前缀的串插入时一定都经过 $p$，所以：

- `cnt[p]` = 以结点 $p$ 代表的串为前缀的串的个数；
- `ed[p]` = 恰好等于这个串的个数（结尾标记计数）。

上图中 `cnt[2] = 3`（`ca` 是 3 个串的前缀），`cnt[4] = 2`（`car`、`cart`），`ed[4] = 1`。

### 2.4 字典序

按字符从小到大的顺序 DFS 整棵树，依次经过的结尾结点就是**排好序的**字符串（父结点代表的串是儿子的前缀，前缀在字典序中排在前面）。这就是"字典树"名字的由来。

## 3. 代码模板

### 3.1 字符串 Trie

输入 $n$ 个只含小写字母的串，再有 $q$ 次询问，每次给出串 $t$，输出 $t$ 出现了几次、有几个串以 $t$ 为前缀。

```cpp
const int N = 1e6 + 5;
int n, q, tot;
signed ch[N][26];
int cnt[N], ed[N];

void insert(const string &s) {
    int p = 0;
    for (auto c : s) {
        int x = c - 'a';
        if (!ch[p][x]) ch[p][x] = ++tot;
        p = ch[p][x];
        cnt[p]++;
    }
    ed[p]++;
}

int find(const string &s) {
    int p = 0;
    for (auto c : s) {
        int x = c - 'a';
        if (!ch[p][x]) return 0;
        p = ch[p][x];
    }
    return p;
}

void solve() {
    cin >> n >> q;
    For(i, 1, n) {
        string s;
        cin >> s;
        insert(s);
    }
    while (q--) {
        string s;
        cin >> s;
        int p = find(s);
        cout << ed[p] << ' ' << cnt[p] << endl;
    }
}
```

`find` 走不下去时返回 0，而根的 `cnt[0]`、`ed[0]` 始终是 0，正好输出 `0 0`，不用特判。

**空间**：结点数最多是所有串的**总长度** + 1（每个字符最多新建一个结点），所以 $N$ 按总长开，而不是按串的个数开。`ch` 有 $N \times 26$ 个元素，本仓库模板中 `int` 是 64 位，这里用 `signed`（32 位）可以省一半内存：$10^6 \times 26 \times 4$ 字节约 104 MB。字符集更大时（大小写字母加数字共 62 种）内存成倍增长，写一个把字符映射到 $0 \sim 61$ 的函数，并按限制算好再开。

### 3.2 01-Trie 求最大异或对

给 $n$ 个数 $a_i < 2^{31}$，求 $\max_{i, j} a_i \oplus a_j$。

把每个数写成**固定 31 位**的二进制串（从最高位 $2^{30}$ 到最低位 $2^0$），插入一棵每个结点只有 0、1 两个儿子的 Trie。

对一个数 $x$，在树中找与它异或最大的数：从最高位往下走，**每一位都优先走和 $x$ 这一位相反的儿子**（这一位异或得 1），没有才走相同的。

**为什么贪心正确**：$2^i > 2^{i-1} + 2^{i-2} + \dots + 2^0$，第 $i$ 位得 1 比后面所有位都得 1 还大。所以高位能取 1 就一定要取，低位再怎么好也补不回来。

例：已插入 $10 = 1010_2$、$3 = 0011_2$（按 4 位看），查询 $x = 5 = 0101_2$：

| 位 | $x$ 这一位 | 想走 | 能走吗 | 结果这一位 |
| --- | --- | --- | --- | --- |
| 3 | 0 | 1 | 能（只有 1010 在这边） | 1 |
| 2 | 1 | 0 | 能 | 1 |
| 1 | 0 | 1 | 能 | 1 |
| 0 | 1 | 0 | 能 | 1 |

得到 $1111_2 = 15 = 5 \oplus 10$。

```cpp
const int N = 1e5 + 5, M = N * 31;
int n, tot, ans;
int a[N], ch[M][2];

void insert(int x) {
    int p = 0;
    for (int i = 30; i >= 0; i--) {
        int b = x >> i & 1;
        if (!ch[p][b]) ch[p][b] = ++tot;
        p = ch[p][b];
    }
}

int query(int x) {
    int p = 0, res = 0;
    for (int i = 30; i >= 0; i--) {
        int b = x >> i & 1;
        if (ch[p][b ^ 1]) res |= 1LL << i, p = ch[p][b ^ 1];
        else p = ch[p][b];
    }
    return res;
}

void solve() {
    cin >> n;
    For(i, 1, n) {
        cin >> a[i];
        insert(a[i]);
        ans = max(ans, query(a[i]));
    }
    cout << ans;
}
```

先插入再查询，保证树不空（最差也能和自己异或得 0）。每个数和它前面的数都比较过，等价于枚举了所有数对。

位数按值域定：$a_i < 2^{31}$ 就从第 30 位开始；值域到 $10^{18}$ 就要 60 位，结点数 $M$ 也要相应加大。**每个数必须补成同样的位数**，否则不同长度的数在树里没法对齐比较。

## 4. 复杂度

| 操作 | 复杂度 |
| --- | --- |
| 字符串 Trie 插入 / 查找 | $O(L)$，$L$ 为串长 |
| 01-Trie 插入 / 查询 | $O(\log V)$，$V$ 为值域 |
| 空间（字符串） | $O(\sum L \cdot \lvert\Sigma\rvert)$，$\lvert\Sigma\rvert$ 为字符集大小 |
| 空间（01-Trie） | $O(n \log V)$ |

## 5. 常见题型与技巧

**字符串 Trie**

- **前缀统计**：有多少串以 $t$ 为前缀（`cnt`）；$t$ 的前缀中有多少个在集合里（沿路径累加 `ed`）。
- **判断是否有串是另一个串的前缀**（如电话号码表）：插入时经过了别人的结尾，或者结束时还有儿子，都说明存在前缀关系。
- **字典序相关**：按字符顺序 DFS 得到排序结果；"能否通过重新规定字母顺序让某串排第一"这类问题，在 Trie 的每个分叉处得到字母间的先后约束，再判断约束有没有环（《拓扑排序》）。
- **在 Trie 上做 DP**：例如判断一篇文章能被字典中的单词拆分到多长，$f_i$ 表示前 $i$ 个字符能否拆分，从 $i$ 出发在 Trie 上往下走，遇到结尾结点 $j$ 就更新 $f_j$。
- **Trie + DFS 序**：Trie 中"$u$ 是 $v$ 的祖先"等价于"$u$ 代表的串是 $v$ 代表的串的前缀"，而祖先关系可以用 DFS 序的区间包含表示。于是前缀匹配问题能转化成区间/数点问题，交给《树状数组》或线段树。
- Trie 上再加上 KMP 的失配指针就是 **AC 自动机**（多模式串匹配），超出 CSP 常考范围。

**01-Trie**

- **区间（子数组）最大异或和**：令前缀异或 $s_i = a_1 \oplus \dots \oplus a_i$，则 $a_{l} \oplus \dots \oplus a_r = s_r \oplus s_{l-1}$，问题变成在 $s_0, s_1, \dots, s_n$ 中选两个使异或最大。别忘了先插入 $s_0 = 0$。
- **树上路径最大异或和**：令 $d_u$ 为根到 $u$ 路径上边权的异或，$u, v$ 之间路径的异或就是 $d_u \oplus d_v$（从根到 LCA 的公共部分异或两次抵消）。转化成最大异或对。
- **支持删除**：每个结点记经过次数 `cnt`，删除时沿路径减 1；查询时只走 `cnt > 0` 的儿子。
- **异或值 $\le k$ 的个数、第 $k$ 大异或值**：沿着 $k$ 的二进制往下走，每一位根据 $k$ 这一位是 0 还是 1 决定"整棵子树都算上"还是"继续往下"，用子树内的 `cnt` 计数。
- **限定在区间内选数**：需要可持久化 Trie，超出 CSP 常考范围。

## 6. 易错点

- 结点数组按**总字符数**开，不是按串的个数开；01-Trie 按"个数 × 位数"开。
- 只看能否走到不能判断串是否出现过，一定要有结尾标记。
- 字符映射要统一：只有小写字母时用 `c - 'a'`；混有大写或数字时要写映射函数，并把 `ch` 第二维开够。
- `ch` 数组很大时注意内存，用 `signed` 或减小第二维；不要随手 `memset` 整个数组清空。多组数据时只清空用过的 $0 \sim tot$ 号结点，再把 `tot` 归零。
- 01-Trie 中所有数位数要一致，且**从高位往低位**插入和查询；`1LL << i` 在 $i \ge 31$ 时必须用 `1LL`。
- 最大异或对要先插入再查询（或者先把所有数插完再逐个查），否则可能在空树上走。
