# 函数与递归

**组别**：J　**关键词**：函数、传值、传引用、作用域、递归、调用栈、递归深度、记忆化

## 1. 是什么 / 解决什么问题

**函数**把一段功能独立的代码起个名字，需要时调用。好处是代码不重复、逻辑分层清楚，例如 `check(x)` 判断答案 $x$ 是否可行、`dist(...)` 计算两点距离。

**递归**是函数调用它自己。很多问题天然具有"大问题由同类小问题组成"的结构：$n! = n \times (n-1)!$、树由根和若干子树组成、全排列 = 先选第一个数 + 剩下数的全排列。用递归写这类问题，代码几乎就是定义本身。递归也是深度优先搜索、分治、记忆化搜索、树形 DP 的基础。

## 2. 函数基础

### 2.1 定义与返回

```text
返回类型 函数名(参数列表) {
    函数体
}
```

- 返回类型为 `void` 表示不返回值；否则**每条执行路径都必须 `return`**。漏写 `return` 是未定义行为，开 `-O2` 后常表现为死循环或 RE，编译时加 `-Wall` 会给出警告。
- 函数要先定义（或先声明）再使用，所以辅助函数写在 `solve()` 上面。
- 很短的辅助函数加 `inline`，例如 `inline int sq(int x) { return x * x; }`。

### 2.2 传值与传引用

```cpp
void f1(int x) { x++; }
void f2(int &x) { x++; }
int sum1(vector<int> v) {
    int s = 0;
    for (int x : v) s += x;
    return s;
}
int sum2(const vector<int> &v) {
    int s = 0;
    for (int x : v) s += x;
    return s;
}

void solve() {
    int a = 1, b = 1;
    f1(a), f2(b);
    vector<int> v = {1, 2, 3};
    cout << a << " " << b << " " << sum1(v) << " " << sum2(v) << endl;
}
```

输出 `1 2 6 6`。

- **传值**（`int x`）：函数得到实参的一份**拷贝**，修改拷贝不影响外面的 `a`。
- **传引用**（`int &x`）：`x` 就是外面的 `b` 本身（起了个别名），修改会影响外面。需要"返回多个值"或修改外部变量时用它，如 `swap(int &a, int &b)`。
- **常引用**（`const vector<int> &v`）：不拷贝也不允许修改。传 `vector`、`string`、结构体等大对象时一定要这样写。`sum1` 每次调用都复制整个 `vector`，在循环或递归中调用会因为 $O(n)$ 的复制而超时。
- **数组**作参数时传的是首地址，函数内修改会影响原数组（相当于引用）。

### 2.3 作用域

- **全局变量**：定义在所有函数外，整个程序都能访问，初值为 0。本仓库把数据都放在全局。
- **局部变量**：定义在函数或 `{}` 内，离开就销毁，初值是**随机的**，必须手动初始化。
- 同名时内层**遮蔽**外层。典型 bug：全局有 `int n;`，在 `solve()` 里又写了 `int n; cin >> n;`，读入的是局部的 `n`，辅助函数看到的全局 `n` 仍是 0。
- `static` 局部变量只初始化一次，函数返回后值保留。

## 3. 递归

### 3.1 两个要素

1. **边界**（递归出口）：问题小到可以直接回答，如 $0! = 1$。
2. **递归式**：把问题化为规模更小的同类问题，如 $n! = n \times (n-1)!$。

写递归时不要试图在脑中展开所有层，而是像**数学归纳法**一样思考：假设 `f(n - 1)` 已经正确返回，怎样用它得到 `f(n)`？再确认边界正确，整个递归就正确。

### 3.2 调用栈

每次函数调用，系统在**栈**上分配一块空间（栈帧），存放参数、局部变量和"返回后从哪继续"。调用 `fact(3)` 的过程：

```text
fact(3) 调用 fact(2)            栈：fact(3)
  fact(2) 调用 fact(1)          栈：fact(3) fact(2)
    fact(1) 调用 fact(0)        栈：fact(3) fact(2) fact(1)
      fact(0) 返回 1            栈：fact(3) fact(2) fact(1) fact(0)
    fact(1) 返回 1*1=1
  fact(2) 返回 2*1=2
fact(3) 返回 3*2=6
```

先一路"递"下去到边界，再一路"归"回来。每一层有自己独立的局部变量，互不干扰。

### 3.3 递归深度与栈溢出

栈空间有限。递归 $d$ 层，就同时存在 $d$ 个栈帧，每帧几十到几百字节。

- 本地 Linux 默认栈 8MB，Windows 更小，深度 $10^5$ 左右就可能崩溃（RE，Segmentation fault）。
- NOI 系列评测机的栈空间一般与内存限制相同，深度 $10^6$ 的简单递归通常没问题。本地测试前先 `ulimit -s unlimited`。
- 递归函数里**不要开大的局部数组**，每层都会占用。
- 深度可能达到 $10^6 \sim 10^7$（例如退化成链的树），或者栈帧很大时，改成循环或手写栈更稳妥。

### 3.4 经典例子：汉诺塔

把 $n$ 个盘子从 A 柱移到 C 柱，借助 B 柱，大盘不能压小盘。

递归思路：要移动最大的盘子，必须先把上面 $n-1$ 个移到 B；然后最大盘 A→C；再把 $n-1$ 个从 B 移到 C。边界 $n = 0$ 什么也不做。

```cpp
int n, cnt;

void hanoi(int k, char a, char b, char c) {
    if (k == 0) return;
    hanoi(k - 1, a, c, b);
    cout << k << ": " << a << "->" << c << endl;
    cnt++;
    hanoi(k - 1, b, a, c);
}

void solve() {
    cin >> n;
    hanoi(n, 'A', 'B', 'C');
    cout << cnt << endl;
}
```

步数 $T(n) = 2T(n-1) + 1$，$T(0) = 0$，解得 $T(n) = 2^n - 1$。$n = 3$ 时输出 7 步。

### 3.5 重复计算与记忆化

斐波那契数 $f_n = f_{n-1} + f_{n-2}$ 直接递归：`f(5)` 调用 `f(4)` 和 `f(3)`，`f(4)` 又调用 `f(3)`……同一个值被算很多次，总调用次数和 $f_n$ 同阶，约 $1.618^n$，$n = 50$ 就算不完。

**记忆化**：第一次算出 `f(k)` 后存进数组，以后直接返回。每个 $k$ 只算一次，复杂度 $O(n)$。

```cpp
const int N = 95;
int f[N];

int fib(int k) {
    if (k <= 2) return 1;
    if (f[k]) return f[k];
    return f[k] = fib(k - 1) + fib(k - 2);
}

void solve() {
    cout << fib(10) << " " << fib(90) << endl;
}
```

输出 `55 2880067194370816120`。记忆化搜索是动态规划的一种写法，在 DP 部分会继续讲。

### 3.6 分治式递归：快速幂

$a^b$：$b$ 为偶数时 $a^b = (a^{b/2})^2$，为奇数时再乘一个 $a$。每层 $b$ 减半，深度 $O(\log b)$。

```cpp
int qpow(int a, int b) {
    if (b == 0) return 1;
    int t = qpow(a, b / 2);
    t = t * t % MOD;
    if (b & 1) t = t * a % MOD;
    return t;
}

void solve() {
    cout << qpow(2, 10) << " " << qpow(3, 1000000000000000000LL) << endl;
}
```

注意 `t` 只算一次再平方。写成 `qpow(a, b / 2) * qpow(a, b / 2)` 会让每层调用两次，复杂度退化成 $O(b)$。

### 3.7 递归枚举：全排列

按字典序输出 $1 \sim n$ 的全排列。`dfs(k)` 表示"正在填第 $k$ 个位置"：枚举一个没用过的数填进去，递归填下一个，回来后把它标记回未使用（**回溯**）。

```cpp
const int N = 15;
int n;
int p[N], used[N];

void dfs(int k) {
    if (k > n) {
        For(i, 1, n) cout << p[i] << " ";
        cout << endl;
        return;
    }
    For(x, 1, n) {
        if (used[x]) continue;
        used[x] = 1, p[k] = x;
        dfs(k + 1);
        used[x] = 0;
    }
}

void solve() {
    cin >> n;
    dfs(1);
}
```

$n = 3$ 输出 6 行，从 `1 2 3` 到 `3 2 1`。共 $n!$ 个排列，每个输出 $O(n)$，复杂度 $O(n \cdot n!)$。更多内容见深度优先搜索与回溯。

### 3.8 递归改循环

所有递归都能用"手写栈"改成循环：把要处理的状态压进 `stack`，循环取出处理，再把子问题压进去。例如树的先序遍历：

```cpp
const int N = 1e5 + 5;
int n;
vector<int> g[N];
stack<int> st;

void solve() {
    cin >> n;
    For(i, 2, n) {
        int f;
        cin >> f;
        g[f].pb(i);
    }
    st.push(1);
    while (!st.empty()) {
        int u = st.top();
        st.pop();
        cout << u << " ";
        for (int i = (int)g[u].size() - 1; i >= 0; i--) st.push(g[u][i]);
    }
    cout << endl;
}
```

输入 $n = 5$ 和父亲 `1 1 2 2`（$2, 3$ 的父亲是 1，$4, 5$ 的父亲是 2），输出 `1 2 4 5 3`。孩子倒序入栈，才能按原顺序出栈。

很多题有更简单的办法：如果父亲编号总比孩子大（或小），按编号顺序扫一遍就能代替递归（见 [CSP-J 2020 T3 表达式](#/P7073)、[CSP-J 2026 T4 纸牌游戏](#/P17830) 的题解）。

## 4. 复杂度

- 递归的时间 = 调用次数 × 每次调用自身的工作量。画出**递归树**最直观：汉诺塔每个结点 2 个孩子、深度 $n$，共 $2^{n+1} - 1$ 个结点，即 $O(2^n)$；带记忆化的斐波那契每个值只展开一次，$O(n)$；快速幂是一条链，$O(\log b)$。
- 递归的空间 = 最大深度 × 每层栈帧大小，再加上全局数组。
- 复杂度用递推式描述，如 $T(n) = 2T(n/2) + O(n)$，求解方法见《时间与空间复杂度》。

## 5. 常见题型与技巧

- **按定义递归**：阶乘、组合数 $C(n, k) = C(n-1, k-1) + C(n-1, k)$、格雷码这类有递归定义的对象。
- **分治**：把问题分成两半分别解决再合并，如快速幂、归并排序、二分。
- **搜索与回溯**：枚举排列、组合、子集；修改全局状态后递归，回来要恢复。
- **记忆化搜索**：参数相同的调用结果相同时，用数组缓存，把指数级降为状态数级。
- **树上递归**：求子树大小、深度、表达式树求值，`dfs(u)` 先处理孩子再合并到 $u$。
- 递归求解中**传引用**可以让函数修改外部状态；需要回溯时注意恢复。

## 6. 易错点

- 没有边界或边界写错，无限递归直到栈溢出。
- 有返回值的函数某条分支漏了 `return`。
- 传大对象没写引用，每层复制导致超时、超内存。
- 局部变量遮蔽同名全局变量。
- 回溯时忘记恢复标记；或者恢复的状态和修改的不一致。
- 重复计算：同一个递归调用写了两遍（如快速幂），或没有记忆化。
- 递归太深栈溢出；本地没开大栈误以为程序有错。
- 记忆化用 0 表示"没算过"，但结果本身可能就是 0，应改用 $-1$ 或单独的 `vis` 数组。
