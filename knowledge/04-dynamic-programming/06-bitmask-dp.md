# 状态压缩动态规划

**组别**：S　**关键词**：状压 DP、二进制集合、旅行商问题、棋盘状压、子集枚举、popcount

## 1. 是什么 / 解决什么问题

有些问题的状态里需要记录"一个集合"：哪些城市已经去过、这一行哪些格子放了棋子、哪些物品已经分配……如果元素个数 $n$ 很小（一般 $n \le 20$），就可以用一个 $n$ 位二进制数表示这个集合：第 $i$ 位是 1 表示元素 $i$ 在集合里。

```
n = 5，集合 {0, 2, 3}
位：    4 3 2 1 0
二进制：0 1 1 0 1   = 13
```

这样集合就变成了一个 $0 \sim 2^n - 1$ 的整数，可以直接当数组下标。这种把集合"压缩"成整数作为状态的 DP 就是**状态压缩 DP**（状压 DP）。

看到 $n \le 15 \sim 20$ 这样的小数据范围，而且暴力是 $n!$ 级别（枚举排列），就要想到状压：它把 $n!$ 降到 $2^n \cdot \text{poly}(n)$。

| $n$ | $n!$ | $2^n \cdot n^2$ |
| --- | --- | --- |
| 10 | $3.6 \times 10^6$ | $10^5$ |
| 15 | $1.3 \times 10^{12}$ | $7.4 \times 10^6$ |
| 20 | $2.4 \times 10^{18}$ | $4.2 \times 10^8$ |

## 2. 核心原理

### 2.1 集合操作

为了和二进制位对应，状压 DP 中元素一般编号为 $0 \sim n-1$。

| 操作 | 写法 |
| --- | --- |
| 全集 | `(1 << n) - 1` |
| 判断 $i \in S$ | `S >> i & 1` |
| 加入 $i$ | `S | 1 << i` |
| 删除 $i$ | `S & ~(1 << i)` |
| 并、交、差 | `S | T`、`S & T`、`S & ~T` |
| $T \subseteq S$ | `(S & T) == T` |
| 元素个数 | `__builtin_popcount(S)` |
| 最低位的 1 | `S & -S`（lowbit） |
| 最低位 1 的编号 | `__builtin_ctz(S)` |

模板中 `int` 是 `long long`，对 64 位数要用 `__builtin_popcountll`、`__builtin_ctzll`；`1 << i` 在 $i \ge 31$ 时要写成 `1LL << i`。运算符优先级：`<<` 比 `&` `|` 高，`==` 比 `&` 高，所以 `(S & T) == T` 的括号不能省。

### 2.2 例：旅行商问题（TSP）

$n$ 个城市，两两之间有距离，从城市 0 出发，每个城市恰好经过一次，最后回到 0，求最短总路程。

暴力枚举 $(n-1)!$ 种顺序。观察：走到某一步时，**后面怎么走只取决于"已经去过哪些城市"和"现在在哪"**，与去过的顺序无关。所以：

> $f_{S,i}$ = 已经访问的城市集合为 $S$、当前在城市 $i$（$i \in S$）时的最短路程。

$$f_{S \cup \{j\},\, j} \gets \min\big(f_{S \cup \{j\},\, j},\ f_{S,i} + d_{i,j}\big) \quad (j \notin S)$$

初值 $f_{\{0\},0} = 0$，答案 $\min_i f_{全集,i} + d_{i,0}$。

**计算顺序**：$S \cup \{j\}$ 作为整数一定比 $S$ 大，所以 $S$ 从小到大枚举就保证了依赖的状态已经算完。这是状压 DP 很方便的一点。

### 2.3 例：棋盘型（逐行状压）

$n \times n$ 的棋盘放 $k$ 个国王，国王会攻击周围 8 个格子，求互不攻击的放法数。

逐行放置。第 $i$ 行能怎么放，只和第 $i-1$ 行的摆放有关，所以把**一行的摆放**压成一个 $n$ 位二进制数 $s$：

- 行内不相邻：`(s & (s << 1)) == 0`；
- 与上一行 $t$ 不冲突：`(s & t) == 0`（正上方）、`(s & (t << 1)) == 0` 和 `(s & (t >> 1)) == 0`（斜上方）。

$$f_{i,s,c} = \sum_{t \text{ 与 } s \text{ 兼容}} f_{i-1,t,c - |s|}$$

$|s|$ 是 $s$ 中 1 的个数。

**预处理合法状态**：$n = 9$ 时 $2^9 = 512$ 个状态里行内不相邻的只有 89 个，先把它们存进数组，只在这些状态之间转移，速度快很多。

如果第 $i$ 行受前**两**行影响（炮兵阵地），状态就记录两行：$f_{i,s,t}$ 表示第 $i$ 行为 $s$、第 $i-1$ 行为 $t$。

### 2.4 枚举子集

很多状压 DP 的转移是"从 $S$ 中拿出一个子集 $T$"：

$$f_S = \min_{T \subseteq S,\ T \ne \varnothing} f_{S \setminus T} + \text{cost}(T)$$

枚举 $S$ 的所有非空子集：

```
for (T = S; T; T = (T - 1) & S)
```

原理：$T - 1$ 把 $T$ 最低位的 1 变成 0、它下面的 0 都变成 1；再与 $S$ 取交，只留下 $S$ 中有的位。这正好是"在 $S$ 的位上做二进制减一"，按从大到小的顺序访问 $S$ 的每个子集恰好一次。

**复杂度 $O(3^n)$**：对所有 $S$ 枚举子集的总次数，相当于每个元素有三种情况（不在 $S$、在 $S$ 不在 $T$、在 $T$ 中），共 $3^n$。$n = 16$ 时约 $4.3 \times 10^7$，$n = 20$ 时约 $3.5 \times 10^9$ 就不行了。

例：$n$ 个物品，重量 $w_i$，每个箱子容量 $W$，最少几个箱子装下所有物品。$f_S$ 为装完集合 $S$ 的最少箱子数，枚举最后一个箱子装的子集 $T$（要求 $\sum_{i \in T} w_i \le W$）。

### 2.5 按元素个数推进：分配问题

$n$ 个人做 $n$ 项工作，每人一项，第 $i$ 个人做第 $j$ 项的代价为 $c_{i,j}$，求最小总代价。

设 $f_S$ 为"前 $|S|$ 个人已经分配完，用掉的工作集合为 $S$"的最小代价。人是按顺序分配的，所以"下一个人是谁"可以由 $|S|$ 推出，不必存进状态：

$$f_{S \cup \{j\}} \gets f_S + c_{|S|+1,\, j}$$

复杂度 $O(2^n n)$。这里体现了状压 DP 的一个技巧：**能从集合本身推出的信息不要放进状态**。

### 2.6 状态设计要点

- 集合维只放**真正影响未来**的信息。TSP 中需要"当前在哪"，分配问题中则不需要。
- 有时状态的合法性很强（如行内不相邻），先预处理合法状态及兼容关系。
- 集合维可以是"已用的元素"、"一行的占用情况"、"已满足的条件"等，不一定是题目字面上的集合。

## 3. 代码模板

### 3.1 旅行商问题

输入 $n$ 和 $n \times n$ 的距离矩阵。城市编号用 $0 \sim n-1$ 与二进制位对应：

```cpp
const int N = 20;
int n;
signed d[N][N], f[1 << N][N];

void solve() {
    cin >> n;
    Rep(i, 0, n) Rep(j, 0, n) cin >> d[i][j];
    mset(f, 0x3f);
    f[1][0] = 0;
    Rep(s, 1, 1 << n) {
        if (!(s & 1)) continue;
        Rep(i, 0, n) {
            if (!(s >> i & 1) || f[s][i] >= INF) continue;
            Rep(j, 0, n)
                if (!(s >> j & 1)) f[s | 1 << j][j] = min(f[s | 1 << j][j], f[s][i] + d[i][j]);
        }
    }
    signed ans = INF;
    Rep(i, 0, n) ans = min(ans, f[(1 << n) - 1][i] + d[i][0]);
    cout << ans;
}
```

$f$ 有 $2^{20} \times 20$ 个元素，用 64 位要 160MB，所以这里特意用 32 位的 `signed`（80MB），$d$ 也用 `signed` 以便和 $f$ 一起取 `min`。`mset(f, 0x3f)` 把每个 32 位元素设为 `0x3f3f3f3f`，即 `INF`。

### 3.2 互不侵犯（逐行状压计数）

输入 $n, k$，求 $n \times n$ 棋盘放 $k$ 个国王的方案数：

```cpp
const int N = 10;
int n, k, cnt;
int st[1 << N], num[1 << N], f[N][1 << N][N * N];

void solve() {
    cin >> n >> k;
    Rep(s, 0, 1 << n)
        if (!(s & (s << 1))) st[++cnt] = s, num[cnt] = __builtin_popcountll(s);
    f[0][1][0] = 1;
    For(i, 1, n) For(a, 1, cnt) For(b, 1, cnt) {
        int s = st[a], t = st[b];
        if ((s & t) || (s & (t << 1)) || (s & (t >> 1))) continue;
        For(c, num[a], k) f[i][a][c] += f[i - 1][b][c - num[a]];
    }
    int ans = 0;
    For(a, 1, cnt) ans += f[n][a][k];
    cout << ans;
}
```

$f$ 的第二维存的是合法状态的**编号**而不是状态本身。`st[1] = 0`（空行），所以 $f_{0,1,0} = 1$ 表示"第 0 行什么都不放"。

### 3.3 子集枚举：最少箱子数

输入 $n, W$ 和 $n$ 个重量（保证每个 $w_i \le W$）：

```cpp
const int N = 16;
int n, W;
int w[N], sum[1 << N], f[1 << N];

void solve() {
    cin >> n >> W;
    Rep(i, 0, n) cin >> w[i];
    Rep(s, 1, 1 << n) sum[s] = sum[s & (s - 1)] + w[__builtin_ctzll(s)];
    Rep(s, 1, 1 << n) {
        f[s] = LINF;
        for (int t = s; t; t = (t - 1) & s)
            if (sum[t] <= W) f[s] = min(f[s], f[s ^ t] + 1);
    }
    cout << f[(1 << n) - 1];
}
```

`s & (s - 1)` 去掉最低位的 1，`__builtin_ctzll(s)` 是最低位的编号，所以 `sum` 可以 $O(2^n)$ 递推。`s ^ t` 在 $t \subseteq s$ 时就是差集。

### 3.4 分配问题

输入 $n$ 和 $n \times n$ 代价矩阵 $c_{i,j}$（人 $i$ 做工作 $j$，均 1-indexed）：

```cpp
const int N = 20;
int n;
int c[N + 1][N + 1], f[1 << N];

void solve() {
    cin >> n;
    For(i, 1, n) For(j, 1, n) cin >> c[i][j];
    Rep(s, 1, 1 << n) f[s] = LINF;
    Rep(s, 0, 1 << n) {
        int i = __builtin_popcountll(s) + 1;
        if (i > n) continue;
        Rep(j, 0, n)
            if (!(s >> j & 1)) f[s | 1 << j] = min(f[s | 1 << j], f[s] + c[i][j + 1]);
    }
    cout << f[(1 << n) - 1];
}
```

## 4. 复杂度

| 类型 | 状态数 | 转移 | 总计 |
| --- | --- | --- | --- |
| TSP | $2^n \cdot n$ | $O(n)$ | $O(2^n n^2)$ |
| 逐行状压 | $n \cdot (\text{合法状态数}) \cdot k$ | 合法状态数 | 视预处理后的状态数 |
| 子集枚举 | $2^n$ | 子集数 | $O(3^n)$ |
| 分配问题 | $2^n$ | $O(n)$ | $O(2^n n)$ |

空间往往是瓶颈：$2^{20} \times 20$ 个 `long long` 就是 160MB。必要时用 32 位类型，或滚动掉某一维（逐行状压只依赖上一行）。

## 5. 常见题型与技巧

- **识别**：$n \le 20$（或网格的一边 $\le 10$），暴力需要枚举排列或子集。
- **哈密顿路径 / TSP 类**：$f_{S,i}$，"去过哪些 + 现在在哪"。起点不固定时，令所有 $f_{\{i\},i} = 0$。
- **网格逐行**：一边很短时按行（或按列）状压，预处理行内合法状态和行间兼容关系。
- **子集划分**：$O(3^n)$ 的子集枚举。若只关心"能否装下"，可以把转移改成"每次加入一个元素"：$f_S$ 记 (箱子数, 最后一个箱子已用容量) 的最优对，复杂度降到 $O(2^n n)$。
- **状压 + 其他算法**：先用最短路/BFS 算出关键点两两之间的距离，再在关键点上做 TSP；或者二进制枚举一小部分元素的选法，剩下的用别的算法（如枚举选哪些乡镇再求最小生成树）。
- **记忆化搜索**：合法状态很稀疏时，用记忆化搜索只访问可达状态。

## 6. 易错点

- 运算符优先级：`s >> i & 1` 是对的（`>>` 优先），但 `s & 1 << i == 0` 会被解析成 `s & ((1 << i) == 0)`，要写成 `!(s >> i & 1)` 或加括号。
- `int` 是 `long long`，`__builtin_popcount` 会截断成 32 位；超过 31 位时 `1 << i` 也会溢出，要写 `1LL << i`。
- 元素编号从 0 开始，与 1-indexed 的输入混用时要换算。
- 状压数组太大爆内存。
- 枚举子集时漏掉了空集或全集，或者 `for (t = s; t; ...)` 不包含空集，需要时单独处理。
- 逐行状压忘记检查行内合法性，或者兼容关系漏掉斜方向。
- 初值：TSP 的 $f$ 要先设成 $+\infty$，只有起点状态为 0。
