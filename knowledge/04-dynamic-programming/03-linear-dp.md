# 线性动态规划

**组别**：J　**关键词**：最大子段和、最长上升子序列、最长公共子序列、编辑距离、网格 DP、序列划分

## 1. 是什么 / 解决什么问题

状态沿着一个"线性"的顺序推进的 DP 统称线性 DP：序列的前缀、两个序列的前缀对、网格的行列、时间轴……每个状态只依赖"更靠前"的状态，按下标从小到大递推即可。

它是最常见的一类 DP，也是背包、区间 DP 等的基础。这里整理几个必须熟练掌握的经典模型：

| 模型 | 状态 | 复杂度 |
| --- | --- | --- |
| 最大子段和 | $f_i$：以 $i$ 结尾 | $O(n)$ |
| 最长上升子序列 LIS | $f_i$：以 $i$ 结尾 | $O(n^2)$ / $O(n \log n)$ |
| 最长公共子序列 LCS | $f_{i,j}$：两个前缀 | $O(nm)$ |
| 编辑距离 | $f_{i,j}$：两个前缀 | $O(nm)$ |
| 网格路径 | $f_{i,j}$：走到 $(i,j)$ | $O(nm)$ |
| 序列划分 | $f_i$：前 $i$ 个已划分完 | $O(n^2)$ 起 |

## 2. 核心原理

### 2.1 最大子段和

求一段连续子数组的最大和（至少选一个数）。

设 $f_i$ 为**以 $a_i$ 结尾**的最大子段和。以 $a_i$ 结尾的子段要么只有 $a_i$ 自己，要么是"以 $a_{i-1}$ 结尾的某一段"再接上 $a_i$：

$$f_i = \max(f_{i-1}, 0) + a_i, \qquad \text{答案} = \max_i f_i$$

直觉：前面那段如果和为负，还不如扔掉重新开始。

为什么要定义成"以 $i$ 结尾"而不是"前 $i$ 个数中"？因为子段要求**连续**，转移时必须知道上一段是不是恰好到 $i-1$ 结束。"以 $i$ 结尾"正好提供了这个信息。

### 2.2 最长上升子序列（LIS）

子序列：从原序列中删去若干元素，剩下的保持原来的顺序（不要求连续）。求最长的严格上升子序列。

**$O(n^2)$ 做法**：设 $f_i$ 为以 $a_i$ 结尾的 LIS 长度，上一个元素可以是任何 $j < i$ 且 $a_j < a_i$：

$$f_i = 1 + \max_{j < i,\ a_j < a_i} f_j \quad (\text{没有这样的 } j \text{ 时 } f_i = 1)$$

例：$a = 3, 1, 4, 1, 5, 9, 2, 6$。

| $i$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| $a_i$ | 3 | 1 | 4 | 1 | 5 | 9 | 2 | 6 |
| $f_i$ | 1 | 1 | 2 | 1 | 3 | 4 | 2 | 4 |

答案 4（如 $3, 4, 5, 9$）。

**$O(n \log n)$ 做法**：换一个角度，维护数组 $d$：

> $d_k$ = 所有长度为 $k$ 的上升子序列中，**结尾元素的最小值**。

结尾越小，后面越容易接上新元素，所以对每个长度只保留最小结尾就够了。

**性质**：$d$ 严格递增。因为长度为 $k+1$ 的上升子序列，去掉最后一个元素就得到长度为 $k$ 的、结尾更小的上升子序列，所以 $d_k < d_{k+1}$。

依次处理每个 $a_i$：

- 若 $a_i > d_{len}$：接在最长的后面，$d_{++len} = a_i$；
- 否则找到第一个 $d_k \ge a_i$ 的位置，令 $d_k = a_i$（$a_i$ 可以接在长度 $k-1$ 的序列后面，并且结尾比原来的 $d_k$ 更小或相等）。

因为 $d$ 有序，找位置用二分（`lower_bound`）。同样的例子：

| 处理 | $d$ |
| --- | --- |
| 3 | 3 |
| 1 | 1 |
| 4 | 1 4 |
| 1 | 1 4 |
| 5 | 1 4 5 |
| 9 | 1 4 5 9 |
| 2 | 1 2 5 9 |
| 6 | 1 2 5 6 |

长度 4。注意最后的 $d = 1, 2, 5, 6$ 并不是一个真实的子序列（2 在 5 后面），$d$ 只用来求长度。

**变体**：

| 要求 | 二分 |
| --- | --- |
| 严格上升 | `lower_bound`（第一个 $\ge a_i$） |
| 不下降 | `upper_bound`（第一个 $> a_i$） |
| 严格下降 / 不上升 | 把所有数取相反数，或者改比较函数 |

**Dilworth 定理（结论）**：把序列划分成最少几个**不上升**子序列，个数等于最长**严格上升**子序列的长度。经典的"导弹拦截"第二问就是这个结论。

### 2.3 最长公共子序列（LCS）

两个序列 $a_{1..n}$、$b_{1..m}$，求最长的、同时是两者子序列的序列长度。

设 $f_{i,j}$ 为 $a$ 的前 $i$ 个与 $b$ 的前 $j$ 个的 LCS 长度。看最后一个字符：

- $a_i = b_j$：这两个字符可以配对，$f_{i,j} = f_{i-1,j-1} + 1$；
- 否则 $a_i$ 和 $b_j$ 至少有一个不在公共子序列里：$f_{i,j} = \max(f_{i-1,j}, f_{i,j-1})$。

为什么 $a_i = b_j$ 时直接配对不会更差？假设某个最优解没有让它们配对，那么 $a_i$、$b_j$ 至少有一个没被用上（两者不可能分别和别的字符配对，否则两条配对会交叉）；把末尾那条配对换成 $(a_i, b_j)$，长度不变。

**特殊情况**：两个序列都是 $1 \sim n$ 的排列时，把 $b$ 中每个数换成它在 $a$ 中的位置，LCS 就变成新序列的 LIS，可以 $O(n \log n)$。

### 2.4 编辑距离

把字符串 $a$ 变成 $b$，每次可以插入、删除或替换一个字符，求最少操作次数。

$f_{i,j}$ = 把 $a$ 的前 $i$ 个变成 $b$ 的前 $j$ 个的最少次数。考虑最后一步：

$$f_{i,j} = \min\begin{cases} f_{i-1,j} + 1 & \text{删掉 } a_i \\ f_{i,j-1} + 1 & \text{末尾插入 } b_j \\ f_{i-1,j-1} + [a_i \ne b_j] & \text{替换（相等时不用操作）} \end{cases}$$

边界：$f_{i,0} = i$（删光），$f_{0,j} = j$（全插入）。

这类"两个序列的前缀"的 DP 一般都用二维表格理解：$f_{i,j}$ 依赖左边、上边、左上方三个格子，按行从上到下、每行从左到右填即可。

### 2.5 网格 DP

只能向右、向下走时，$f_{i,j}$ 从 $(i-1,j)$ 和 $(i,j-1)$ 转移，按行列顺序递推。

**两条路径同时走**（方格取数、传纸条）：从左上到右下走两次，同一个格子的数只能取一次，求总和最大。分开走两次贪心是错的（第一次的最优路径可能破坏第二次）。正确做法是让两条路径**同时出发、同步前进**：

- 走了相同步数时，两个点都在同一条反对角线 $x + y = k$ 上；
- 状态 $f_{k,x_1,x_2}$：两条路径各走到 $(x_1, k - x_1)$ 和 $(x_2, k - x_2)$；
- 每一步两条路径各有"向下/向右"两种选择，共 4 种前驱；
- 两点重合时数字只加一次。

因为两条路径同步，重合只可能发生在同一步，这样就能判断"同一格只取一次"。

### 2.6 序列划分

把序列切成若干段，每段有一个代价，求总代价最小。设 $f_i$ 为前 $i$ 个元素划分完的最小代价，枚举最后一段的起点：

$$f_i = \min_{0 \le j < i} f_j + \text{cost}(j+1, i)$$

例如每段代价是 $(\text{段和})^2 + C$：用前缀和 $s$ 就是 $f_i = \min_j f_j + (s_i - s_j)^2 + C$。这是 $O(n^2)$ 的，用斜率优化可以降到 $O(n)$（见"动态规划优化"）。

如果还限制段数，就加一维：$f_{i,k}$ 表示前 $i$ 个分成 $k$ 段。

## 3. 代码模板

### 3.1 最大子段和

```cpp
const int N = 2e5 + 5;
int n, ans = -LINF;
int a[N], f[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    For(i, 1, n) {
        f[i] = max(f[i - 1], 0LL) + a[i];
        ans = max(ans, f[i]);
    }
    cout << ans;
}
```

`f[0] = 0`，所以 $i = 1$ 时 $f_1 = a_1$。`int` 是 `long long`，所以 `max` 里写 `0LL`。

### 3.2 LIS（$O(n^2)$）

```cpp
const int N = 5e3 + 5;
int n, ans;
int a[N], f[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    For(i, 1, n) {
        f[i] = 1;
        Rep(j, 1, i) if (a[j] < a[i]) f[i] = max(f[i], f[j] + 1);
        ans = max(ans, f[i]);
    }
    cout << ans;
}
```

### 3.3 LIS（$O(n \log n)$）

```cpp
const int N = 2e5 + 5;
int n, len;
int a[N], d[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    For(i, 1, n) {
        if (len == 0 || a[i] > d[len]) d[++len] = a[i];
        else *lower_bound(d + 1, d + 1 + len, a[i]) = a[i];
    }
    cout << len;
}
```

### 3.4 LCS

```cpp
const int N = 5e3 + 5;
int n, m;
int f[N][N];
string a, b;

void solve() {
    cin >> a >> b;
    n = a.size(), m = b.size();
    a = " " + a, b = " " + b;
    For(i, 1, n) For(j, 1, m) {
        if (a[i] == b[j]) f[i][j] = f[i - 1][j - 1] + 1;
        else f[i][j] = max(f[i - 1][j], f[i][j - 1]);
    }
    cout << f[n][m];
}
```

前面补一个空格，让字符串也 1-indexed。

### 3.5 编辑距离

```cpp
const int N = 2e3 + 5;
int n, m;
int f[N][N];
string a, b;

void solve() {
    cin >> a >> b;
    n = a.size(), m = b.size();
    a = " " + a, b = " " + b;
    For(i, 0, n) f[i][0] = i;
    For(j, 0, m) f[0][j] = j;
    For(i, 1, n) For(j, 1, m)
        f[i][j] = min({f[i - 1][j] + 1, f[i][j - 1] + 1, f[i - 1][j - 1] + (a[i] != b[j])});
    cout << f[n][m];
}
```

### 3.6 两条路径同时走（方格取数）

$n \times m$ 网格，数值非负，从 $(1,1)$ 到 $(n,m)$ 走两次，每格的数只能取一次：

```cpp
const int N = 55;
int n, m;
int a[N][N], f[N * 2][N][N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) For(j, 1, m) cin >> a[i][j];
    For(k, 2, n + m) For(x1, max(1LL, k - m), min(n, k - 1)) For(x2, max(1LL, k - m), min(n, k - 1)) {
        int val = a[x1][k - x1];
        if (x1 != x2) val += a[x2][k - x2];
        f[k][x1][x2] = max({f[k - 1][x1][x2], f[k - 1][x1 - 1][x2], f[k - 1][x1][x2 - 1], f[k - 1][x1 - 1][x2 - 1]}) + val;
    }
    cout << f[n + m][n][n];
}
```

$x$ 的范围由 $1 \le y = k - x \le m$ 推出。越界的前驱状态值为 0，而每个状态至少有一个合法前驱且数值非负，所以取 $\max$ 不受影响；数值可能为负时要把非法状态设为 $-\infty$。

### 3.7 序列划分

每段代价为 $(\text{段和})^2 + C$，求最小总代价：

```cpp
const int N = 5e3 + 5;
int n, c;
int s[N], f[N];

void solve() {
    cin >> n >> c;
    For(i, 1, n) cin >> s[i], s[i] += s[i - 1];
    For(i, 1, n) {
        f[i] = LINF;
        Rep(j, 0, i) f[i] = min(f[i], f[j] + (s[i] - s[j]) * (s[i] - s[j]) + c);
    }
    cout << f[n];
}
```

## 4. 复杂度

| 模型 | 时间 | 空间 |
| --- | --- | --- |
| 最大子段和 | $O(n)$ | $O(n)$，可 $O(1)$ |
| LIS | $O(n^2)$ / $O(n \log n)$ | $O(n)$ |
| LCS、编辑距离 | $O(nm)$ | $O(nm)$，可滚动到 $O(m)$ |
| 两条路径 | $O((n+m)n^2)$ | 同左，可滚动 $k$ |
| 序列划分 | $O(n^2)$ | $O(n)$ |

LCS 的 $f_{i,\cdot}$ 只依赖 $f_{i-1,\cdot}$，可以开两行滚动；$n = m = 10^4$ 时二维表要 $10^8$ 个 `long long`，必须滚动。

## 5. 常见题型与技巧

- **"以 $i$ 结尾"是线性 DP 最常用的状态**：只要转移需要知道"上一个选的是谁"（比较大小、要求相邻、要求连续），就用它。答案通常是 $\max_i f_i$ 而不是 $f_n$。
- **带附加代价的 LIS**：CSP-J 2022 上升点列在 LIS 上加了一维"用了几个补充点"。
- **双向 LIS**：合唱队形一类问题，正着求以 $i$ 结尾的 LIS，倒着求以 $i$ 开头的最长下降，两者相加减 1。
- **LIS 求方案**：$O(n^2)$ 写法记录 `pre[i]` 即可；$O(n \log n)$ 写法要额外记录每个 $d_k$ 对应的下标和每个元素接在谁后面。
- **最长回文子序列**：等于原串与反串的 LCS；也可以用区间 DP 做。
- **状态机型**：每一步有几种"模式"（持有/不持有、上一步方向、已用次数），把模式作为状态的第二维，画出模式之间的转移图再写方程。
- **转移是"区间最值/区间和"**：$f_i = \max_{j \in [i-k, i-1]} f_j + \dots$ 可以用单调队列、前缀和优化，见"动态规划优化"。
- **"同一格只取一次"的多路径问题**：让多条路径按步数同步。

## 6. 易错点

- 最大子段和要求至少选一个数时，答案初值要设为 $-\infty$ 而不是 0。
- LIS 的严格/非严格搞反了 `lower_bound` 和 `upper_bound`。
- 把 $d$ 数组当成真实的 LIS 输出。
- LCS 中字符串 0-indexed 和 1-indexed 混用，导致错位。
- 编辑距离忘记初始化 $f_{i,0}$ 和 $f_{0,j}$。
- 两条路径的 DP 中，坐标范围没算对（$y = k - x$ 要在 $[1, m]$ 内）。
- 序列划分中 $j$ 的范围漏掉 $j = 0$（第一段从 1 开始）。
- 二维表太大爆内存，需要滚动或者换状态。
