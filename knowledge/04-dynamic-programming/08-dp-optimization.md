# 动态规划优化

**组别**：S　**关键词**：前缀和优化、单调队列优化、多重背包、滚动数组、状态精简、决策单调性、斜率优化

## 1. 是什么 / 解决什么问题

一个 DP 的复杂度是

$$\text{状态数} \times \text{每个状态的转移代价}$$

DP 写对之后如果超时或超内存，优化就从这两个因子入手：

| 方向 | 手段 | 典型效果 |
| --- | --- | --- |
| 降低转移代价 | 前缀和、前缀最值 | 一段连续状态求和/求最值 $O(n) \to O(1)$ |
| | 单调队列 | 滑动窗口内求最值 $O(k) \to$ 均摊 $O(1)$ |
| | 数据结构（树状数组、线段树） | 按值域条件求最值 $O(n) \to O(\log n)$ |
| | 决策单调性、斜率优化（了解） | 最优转移点有规律，跳过不可能的决策 |
| 减少状态 | 删去能被别的量推出的维度 | 少一维，时间空间都降一个因子 |
| | 下标与值互换 | 值域大、答案小时换个东西当下标 |
| | 收紧枚举范围、只枚举有效状态 | 跳过不可达或无用的状态 |
| 节省空间 | 滚动数组 | $O(nm)$ 空间 $\to O(m)$ |

优化的前提永远是**先写出正确的朴素转移方程**。优化只是换一种更快的方式算同一个式子，所以写完优化版后，最好和朴素版对拍。

## 2. 核心原理

### 2.1 前缀和优化

转移是"上一层的一段**连续区间**的和"时，先求上一层的前缀和，每个状态就能 $O(1)$ 转移。

**例（摆花）**：$n$ 种花，第 $i$ 种最多摆 $a_i$ 盆，同种花必须摆在一起且按种类编号顺序摆放，共摆 $m$ 盆，求方案数。

设 $f_{i,j}$ 为前 $i$ 种花共摆 $j$ 盆的方案数，枚举第 $i$ 种摆 $k$ 盆：

$$f_{i,j} = \sum_{k=0}^{\min(j, a_i)} f_{i-1,\,j-k}$$

朴素是 $O(nm^2)$。注意右边是 $f_{i-1}$ 在区间 $[j - \min(j, a_i),\ j]$ 上的和。令 $s_j = \sum_{t=0}^{j} f_{i-1,t}$，则

$$f_{i,j} = s_j - s_{l-1},\quad l = j - \min(j, a_i)$$

（$l = 0$ 时减数为 0）。复杂度降到 $O(nm)$。

手推 $n = 2$，$m = 4$，$a = (3, 2)$：

| $j$ | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| $f_{1,j}$ | 1 | 1 | 1 | 1 | 0 |
| $s_j$（$f_1$ 的前缀和） | 1 | 2 | 3 | 4 | 4 |
| $f_{2,j}$ | 1 | 2 | 3 | 3 | $s_4 - s_1 = 2$ |

答案 $f_{2,4} = 2$（$3+1$ 或 $2+2$）。

同类的还有"逆序对数恰为 $k$ 的排列个数"：$f_{i,j} = \sum_{t=0}^{i-1} f_{i-1,\,j-t}$，也是上一层一段区间的和。

### 2.2 前缀最值优化

如果转移是

$$f_i = \max_{j < i} \big(g(j)\big) + h(i)$$

其中括号里**只和 $j$ 有关**，那么把 $j$ 的那部分整体看成一个数，边算边维护前缀最大值 $mx = \max_{j<i} g(j)$ 即可，$O(n^2) \to O(n)$。

关键是把式子**拆成"只含 $j$"和"只含 $i$"的两部分**。例如 CSP-S 2024 染色：

$$dp_i = \max_{j < i}\big(dp_j - s_j\big) + s_{i-1}$$

$dp_j - s_j$ 只和 $j$ 有关，$s_{i-1}$ 只和 $i$ 有关，维护 $\max(dp_j - s_j)$ 就行。

含绝对值时先分类讨论去掉绝对值：$\max_j (f_j - |x_i - x_j|)$ 按 $x_j \le x_i$ 和 $x_j > x_i$ 拆成 $\max(f_j + x_j) - x_i$ 和 $\max(f_j - x_j) + x_i$ 两部分，各自维护。如果 $j$ 的范围不是前缀，而是"$x_j \le x_i$"这种**按值**的条件，就把 $x$ 离散化后用树状数组或线段树维护区间最值（见《树状数组》《线段树》），最长上升子序列的 $O(n \log n)$ 做法就是这样。

### 2.3 单调队列优化

转移形如

$$f_i = \max_{L(i) \le j \le R(i)} \big(g(j)\big) + h(i)$$

其中**窗口的左右端点都随 $i$ 单调不减**，被取最值的部分**只与 $j$ 有关**，就可以用单调队列维护窗口最值，$O(nk) \to O(n)$。单调队列本身的原理见《单调栈与单调队列》，这里只讲在 DP 中使用时的几个细节。

**例（琪露诺）**：格子编号 $0 \sim n$，从 0 出发，每次从 $i$ 跳到 $[i+L,\ i+R]$ 中的某格，得到该格的分数 $a_i$（可能为负），跳到编号 $> n$ 的位置就结束，求最大得分。

$$f_i = a_i + \max_{i-R \le j \le i-L} f_j$$

和"窗口包含 $i-1$"的情况不同，这里窗口是 $[i-R,\ i-L]$，**右端点比 $i$ 落后 $L$**。所以处理 $i$ 时，新进入窗口的是 $j = i - L$，而不是 $i$ 本身：

```
对 i = L .. n：
    把 j = i - L 从队尾加入（先弹掉队尾所有 f 不比 f[j] 大的）
    弹掉队头所有下标 < i - R 的
    f[i] = f[队头] + a[i]
```

另一个细节是**不可达状态**：有的格子根本跳不到（例如 $0 < i < L$），设为 $-\infty$；队头是 $-\infty$ 时 $f_i$ 也是 $-\infty$，不要直接相加，否则 $-\infty$ 加上负数会溢出。

### 2.4 多重背包的单调队列优化

第 $i$ 种物品重 $w$、价值 $v$、有 $c$ 个。设 $g$ 是加入它之前的数组，朴素转移是

$$f_j = \max_{0 \le k \le c} \big(g_{j - kw} + kv\big)$$

转移来源 $j, j-w, j-2w, \dots$ 都和 $j$ **模 $w$ 同余**。所以按余数 $r = j \bmod w$ 分组，每组单独处理。组内把 $j$ 写成 $r + tw$，来源写成 $r + sw$（$k = t - s$）：

$$f_{r+tw} = \max_{t-c \le s \le t} \big(g_{r+sw} - sv\big) + tv$$

括号里只和 $s$ 有关，窗口 $[t-c,\ t]$ 随 $t$ 右移——正是单调队列的形式。

例：$w = 3$，$v = 2$，$c = 2$，看余数 $r = 0$ 这一组 $j = 0, 3, 6, 9$（$t = 0, 1, 2, 3$）。窗口宽度 $c + 1 = 3$：

| $t$ | $j$ | 窗口 $s$ | 含义 |
| --- | --- | --- | --- |
| 0 | 0 | $\{0\}$ | 不拿 |
| 1 | 3 | $\{0, 1\}$ | 从 $g_0$ 拿 1 个，或从 $g_3$ 不拿 |
| 2 | 6 | $\{0, 1, 2\}$ | 最多拿 2 个 |
| 3 | 9 | $\{1, 2, 3\}$ | $g_0$ 需要拿 3 个，超过 $c$，滑出窗口 |

每组长度约 $m / w$，共 $w$ 组，所以一种物品总共 $O(m)$，整个多重背包 $O(nm)$，比二进制拆分的 $O(m \sum \log c_i)$ 更快（二进制拆分见《背包问题》）。

为什么要先把旧数组复制到 $g$？因为同一组内 $f_{r+tw}$ 算出来后，后面的 $t' > t$ 还要用**旧**的 $g_{r+tw}$。0/1 背包靠倒序避免这个问题，这里窗口要从小往大滑，只能复制一份。

### 2.5 状态精简：删去能推出来的维度

如果某一维的值能由其他维**算出来**，这一维就是多余的。

**例（方格取数 / 传纸条）**：$n \times n$ 网格，从左上走到右下（只能向右或向下）走两次，格子里的数只能取一次，求最大和。

两条路径同时走，最直接的状态是 $f_{x_1,y_1,x_2,y_2}$，$O(n^4)$。但两条路径同时走了 $k$ 步时，$x_1 + y_1 = x_2 + y_2 = k + 2$，所以只要记 $f_{k, x_1, x_2}$，$y$ 都能算出来，状态降到 $O(n^3)$。另外这样设计还有个好处：两条路径只可能在**同一步**走到同一个格子（同一格的 $x + y$ 固定），所以"是否重复取数"只需判断 $x_1 = x_2$。

其他常见的"能推出来"的量：

- **从两端取数**：剩下区间 $[l, r]$ 时已经取了 $n - (r - l + 1)$ 次，不用另记次数（《区间动态规划》）。
- **只关心差值**：CSP-S 2019 Emiya 家今天的饭，原本要记"选了 $c$ 列几道"和"选了其他列几道"两个数，但只关心它们的大小关系，于是改记**差值**，少一维。差值可能为负，下标整体加偏移量。
- **只关心某个数是否超过阈值**：大于等于阈值的值全部压成一个状态（例如"至少两个人"和"任意多人"等价）。

### 2.6 下标与值互换

0/1 背包的状态 $f_j$ = 容量 $j$ 能得到的最大价值，复杂度 $O(nm)$。如果容量 $m$ 达到 $10^9$，但物品价值很小（总价值 $\le 10^5$），就**把价值当下标、重量当值**：

$$f_v = \text{凑出总价值恰好 } v \text{ 的最小总重量}$$

最后找最大的 $v$ 使 $f_v \le m$。复杂度 $O(n \sum v_i)$。

原则：DP 的下标应该放**范围小**的那个量，最优化的目标或范围大的量放在值里。

### 2.7 滚动数组

如果第 $i$ 层只依赖第 $i-1$ 层，就不用保存所有层：

- **两行滚动**：开 `f[2][M]`，第 $i$ 层存在 `f[i & 1]`，上一层是 `f[(i & 1) ^ 1]`。
- **一行原地**：转移只用到 $f_{i-1,j}$ 和 $f_{i-1,j-w}$ 这类"同列或左边"的值时，可以只用一行，靠枚举方向保证读到的是旧值（0/1 背包倒序）或新值（完全背包正序）。

以最长公共子序列为例，$n, m = 5000$ 时二维 `long long` 表需要约 200MB，两行滚动后只需 80KB。

滚动的代价：**丢失了历史层**，无法再倒推方案（要输出方案时保留完整表）。另外两行滚动时，如果新的一层不是每个位置都会被重新赋值，要先清空，否则会读到两层之前的旧数据。

### 2.8 换枚举顺序，减少无效状态

状态的上界往往比实际能达到的松很多。几个常用做法：

- **按实际范围收紧上界**：0/1 背包处理前 $i$ 个物品时，容量不会超过 $\sum_{t \le i} w_t$，内层循环从 $\min(m, \sum_{t \le i} w_t)$ 开始倒序。树形背包用子树大小作为上界，可以把 $O(nm^2)$ 降到 $O(nm)$（见《树形动态规划》）。
- **只需要的部分**：如果只会查询 $\le A$ 的状态，大于 $A$ 的部分直接截断不算（CSP-J 2025 多边形中背包只维护到 5000）。
- **刷表法跳过不可达状态**：填表法（"$f_i$ 从哪些状态来"）会对每个状态枚举所有来源；刷表法（"$f_i$ 能更新哪些状态"）可以先判断 $f_i$ 是否可达，不可达直接 `continue`。可达状态稀疏时（例如数位、状压中大量状态为 0），能省下大量无效转移。
- **换外层变量，让转移变成区间**：例如二维状态 $f_{i,j}$ 中，固定 $j$、让 $i$ 在外层时转移来源是一个随 $i$ 滑动的窗口，就能套单调队列；换个顺序则不行。设计循环顺序时，要让"被优化的那一维"在**最内层**连续变化。
- **拆方向**：CSP-J 2020 方格取数中，一列里到达第 $i$ 行可以来自上方或下方的任意一段，直接枚举是 $O(n)$；拆成"从上往下"和"从下往上"两个数组分别递推，每个状态 $O(1)$。

### 2.9 决策单调性（了解）

记 $opt(i)$ 为 $f_i$ 取到最优值时的转移点 $j$。很多题中 $opt(i)$ 随 $i$ **单调不减**，这叫决策单调性。有了它就不必对每个 $i$ 都从头枚举 $j$。

**区间 DP 的四边形不等式优化**：对石子合并这类转移

$$f_{l,r} = \min_{l \le k < r}\big(f_{l,k} + f_{k+1,r}\big) + w(l,r)$$

若代价 $w$ 满足四边形不等式 $w(a,c) + w(b,d) \le w(a,d) + w(b,c)$（$a \le b \le c \le d$）且区间包含时 $w$ 单调（区间和就满足），则

$$opt(l, r-1) \le opt(l, r) \le opt(l+1, r)$$

$k$ 只需在这个范围内枚举。固定长度时，对所有 $l$ 求和，枚举量是 $\sum_l \big(opt(l+1,r) - opt(l,r-1) + 1\big)$，相邻项相互抵消，只剩 $O(n)$，所以总复杂度从 $O(n^3)$ 降到 $O(n^2)$。

**分治优化**：如果 $f_i = \min_{j < i} g_j + w(j, i)$（$g$ 是上一层，与 $f$ 无关）且有决策单调性，可以先求中点 $mid$ 的最优决策 $p$，那么左半边的决策都 $\le p$、右半边都 $\ge p$，递归下去。每层总枚举量 $O(n)$，共 $O(\log n)$ 层，单层 $O(n \log n)$。常用于"把序列分成 $k$ 段"这类分层 DP。

考场上通常不去证明四边形不等式，而是写出朴素 DP，把 $opt$ 打表出来看是否单调。

### 2.10 斜率优化（了解）

当转移里有 $i$ 和 $j$ 的**乘积项**时，前面的方法都不能用。例如把序列分段，每段代价是 $(\text{段和})^2 + C$：

$$f_i = \min_{j < i} \big(f_j + (s_i - s_j)^2\big) + C$$

展开，把只含 $j$ 的、只含 $i$ 的、两者相乘的分开：

$$f_i = \min_{j < i}\big(\underbrace{f_j + s_j^2}_{Y_j} - \underbrace{2s_i}_{k} \cdot \underbrace{s_j}_{X_j}\big) + s_i^2 + C$$

把每个 $j$ 看成平面上的点 $(X_j, Y_j)$，对固定的 $i$，要最小化 $Y_j - kX_j$，即"过点 $(X_j, Y_j)$、斜率为 $k$ 的直线的**截距**"。想象一条斜率为 $k$ 的直线从下往上平移，第一个碰到的点就是最优决策，它一定在点集的**下凸壳**上：

```
  Y
  |  *           *
  |      *    *
  |   *    o           o：下凸壳上的点
  |  o   *     o       斜率为 k 的直线从下方平移上来，
  |    o     o         最先碰到的凸壳顶点就是最优 j
  |      o o
  +-------------------- X
```

若 $X_j$ 随 $j$ 递增（$s$ 单调）、$k$ 随 $i$ 递增，则最优点在凸壳上单调右移。用一个双端队列维护凸壳：

- 队头：若前两个点连线的斜率 $\le k$，队头不再最优，弹出；
- 队尾：加入新点前，若它让队尾的点不再是凸壳顶点（斜率不再递增），弹出队尾。

每个点进出队一次，$O(n)$。斜率优化超出 CSP-S 的常规考查范围，知道"含 $i \cdot j$ 交叉项 → 斜率优化"即可，典型题是玩具装箱。

## 3. 代码模板

### 3.1 前缀和优化：摆花

答案对 $10^6 + 7$ 取模。

```cpp
const int N = 1e2 + 5, P = 1e6 + 7;
int n, m;
int a[N], f[N][N], s[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i];
    f[0][0] = 1;
    For(i, 1, n) {
        s[0] = f[i - 1][0];
        For(j, 1, m) s[j] = (s[j - 1] + f[i - 1][j]) % P;
        For(j, 0, m) {
            int l = j - min(j, a[i]);
            f[i][j] = (s[j] - (l ? s[l - 1] : 0) + P) % P;
        }
    }
    cout << f[n][m];
}
```

### 3.2 单调队列优化：窗口 $[i-R,\ i-L]$

格子 $0 \sim n$，输入 $a_0 \dots a_n$。

```cpp
const int N = 2e5 + 5;
int n, L, R, ans = -LINF;
int a[N], f[N], q[N];

void solve() {
    cin >> n >> L >> R;
    For(i, 0, n) cin >> a[i];
    For(i, 1, n) f[i] = -LINF;
    f[0] = a[0];
    int h = 1, t = 0;
    For(i, L, n) {
        int j = i - L;
        while (h <= t && f[q[t]] <= f[j]) t--;
        q[++t] = j;
        while (q[h] < i - R) h++;
        if (f[q[h]] != -LINF) f[i] = f[q[h]] + a[i];
    }
    For(i, max(0LL, n - R + 1), n) ans = max(ans, f[i]);
    cout << ans;
}
```

$j = i - L$ 刚加入，队列一定非空，所以 `q[h]` 总是有效的。

### 3.3 多重背包单调队列优化

每行 $v_i, w_i, c_i$（价值、重量、数量），容量 $m$。队列里存的是组内编号 $s$。

```cpp
const int M = 4e4 + 5;
int n, m;
int f[M], g[M], q[M];

void solve() {
    cin >> n >> m;
    For(i, 1, n) {
        int v, w, c;
        cin >> v >> w >> c;
        memcpy(g, f, sizeof(f));
        Rep(r, 0, min(w, m + 1)) {
            int h = 1, t = 0;
            for (int k = 0; r + k * w <= m; k++) {
                int j = r + k * w;
                while (h <= t && g[r + q[t] * w] - q[t] * v <= g[j] - k * v) t--;
                q[++t] = k;
                while (q[h] < k - c) h++;
                f[j] = g[r + q[h] * w] + (k - q[h]) * v;
            }
        }
    }
    cout << f[m];
}
```

### 3.4 状态精简：方格取数

输入 $n$，然后若干行 `x y v`，以 `0 0 0` 结束。

```cpp
const int N = 12;
int n;
int a[N][N], f[2 * N][N][N];

void solve() {
    cin >> n;
    int x, y, v;
    while (cin >> x >> y >> v && x) a[x][y] = v;
    For(k, 2, 2 * n) For(x1, 1, n) For(x2, 1, n) {
        int y1 = k - x1, y2 = k - x2;
        if (y1 < 1 || y1 > n || y2 < 1 || y2 > n) continue;
        int mx = max(max(f[k - 1][x1][x2], f[k - 1][x1 - 1][x2]), max(f[k - 1][x1][x2 - 1], f[k - 1][x1 - 1][x2 - 1]));
        f[k][x1][x2] = mx + a[x1][y1] + (x1 == x2 ? 0 : a[x2][y2]);
    }
    cout << f[2 * n][n][n];
}
```

这里 $k$ 直接用 $x + y$ 表示（从 2 到 $2n$）。四个来源分别是两条路径各自"从上来/从左来"。越界的来源状态值为 0，因为格子里的数非负，它不会比合法来源更大，所以不用特判；若有负数，非法状态要设为 $-\infty$。

### 3.5 下标与值互换：大容量 0/1 背包

每行 $w_i, v_i$。

```cpp
const int N = 1e2 + 5, V = 1e5 + 5;
int n, m, sv;
int w[N], v[N], f[V];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> w[i] >> v[i], sv += v[i];
    mset(f, 0x3f), f[0] = 0;
    For(i, 1, n) for (int j = sv; j >= v[i]; j--) f[j] = min(f[j], f[j - v[i]] + w[i]);
    for (int j = sv; j >= 0; j--)
        if (f[j] <= m) {
            cout << j;
            return;
        }
}
```

### 3.6 滚动数组：最长公共子序列

```cpp
const int N = 5e3 + 5;
int n, m;
int f[2][N];
string s, t;

void solve() {
    cin >> s >> t;
    n = s.size(), m = t.size(), s = " " + s, t = " " + t;
    For(i, 1, n) For(j, 1, m) {
        int c = i & 1, p = c ^ 1;
        if (s[i] == t[j]) f[c][j] = f[p][j - 1] + 1;
        else f[c][j] = max(f[p][j], f[c][j - 1]);
    }
    cout << f[n & 1][m];
}
```

每一层 $j = 1 \dots m$ 都会被重新赋值，$f_{\cdot,0}$ 始终为 0，所以不用清空。

## 4. 复杂度

| 问题 | 朴素 | 优化后 | 手段 |
| --- | --- | --- | --- |
| 摆花 | $O(nm^2)$ | $O(nm)$ | 前缀和 |
| 窗口转移 | $O(nk)$ | $O(n)$ | 单调队列 |
| 多重背包 | $O(m\sum c_i)$ | $O(nm)$ | 单调队列（二进制拆分为 $O(m \sum \log c_i)$） |
| 方格取数 | $O(n^4)$ | $O(n^3)$ | 删维 |
| 大容量背包 | $O(nm)$，$m$ 很大 | $O(n\sum v_i)$ | 下标与值互换 |
| LCS 空间 | $O(nm)$ | $O(m)$ | 滚动数组 |
| 石子合并 | $O(n^3)$ | $O(n^2)$ | 四边形不等式（了解） |
| 平方代价分段 | $O(n^2)$ | $O(n)$ | 斜率优化（了解） |

## 5. 常见题型与技巧

**看转移式的形状选优化方法**：

| 转移形状 | 方法 |
| --- | --- |
| $\sum_{j \in [l, r]} f_{i-1,j}$ | 前缀和 |
| $\max_{j < i} g(j) + h(i)$ | 维护前缀最值 |
| $\max_{j \in [L(i), R(i)]} g(j) + h(i)$，$L, R$ 单调 | 单调队列 |
| $\max_{x_j \le x_i} g(j) + h(i)$ | 离散化 + 树状数组/线段树 |
| $\min_j g(j) + w(j, i)$，$opt$ 单调 | 决策单调性（了解） |
| 含 $a_i \cdot b_j$ 交叉项 | 斜率优化（了解） |

- **先拆式子**：任何优化的第一步都是把转移式里"只含 $i$""只含 $j$""两者都含"的项分开。只含 $i$ 的提到 $\max$ 外面；只含 $j$ 的当作一个整体维护；两者都含的决定了要用什么方法。
- **看数据范围**：数据范围给到 $10^6 \sim 10^7$ 而 DP 是 $O(nk)$ 时，几乎一定要 $O(n)$ 的单调队列或前缀和；给到 $5000$ 而状态 $O(n^2)$ 时，要警惕内存，考虑滚动。
- **状态里的维度能否推出**：写出状态后，检查每一维是否可以由其他维和"已经走了几步"之类的量算出。
- **转移是"是否存在"**：如 CSP-J 2024 接龙，问的是窗口 $[i-k+1, i-1]$ 内是否存在合法位置，只需记录**最近的**合法位置，比单调队列更简单。
- **滚动数组与方案输出冲突**：需要输出方案时，要么保留完整表，要么另存决策。

## 6. 易错点

- 前缀和优化取模时，$s_j - s_{l-1}$ 可能为负，要加模数；$l = 0$ 时没有 $s_{-1}$。
- 单调队列优化时，窗口右端点是 $i - L$ 而不是 $i - 1$，加入队列的应是"刚进入窗口的 $j$"，不是 $i$。
- 单调队列先弹队头还是先用队头：保证用队头时窗口已经正确（过期的已弹出、新进入的已加入）。
- 不可达状态 $-\infty$ 参与加法导致溢出；用 `-LINF` 时判断后再加。
- 多重背包单调队列忘记复制旧数组，导致同一种物品被拿了超过 $c$ 个。
- 两行滚动时，新一层没有被完全覆盖却没有清空。
- 一行原地滚动时，枚举方向写反（0/1 背包写成正序就变成了完全背包）。
- 删维后，判断"两条路径是否重合"等条件要用推出来的量重新写对。
- 下标偏移（差值可能为负）忘记加偏移量，或数组大小没有乘 2。
