# 区间动态规划

**组别**：S　**关键词**：区间 DP、枚举分割点、石子合并、断环成链、括号匹配、回文

## 1. 是什么 / 解决什么问题

有一类问题，一个大区间的答案由它内部的小区间合并而来：

- 一排石子，每次合并**相邻**两堆，代价是两堆的总数，求合并成一堆的最小代价；
- 一个括号串，最长的合法括号子序列；
- 一个字符串，最少插入几个字符变成回文。

它们的共同点：操作只发生在**相邻**的元素之间，或者只和区间的**两端**有关。于是状态设为区间 $[l, r]$：

> $f_{l,r}$ = 只考虑区间 $[l, r]$ 时的最优值（或方案数）。

答案一般是 $f_{1,n}$。

为什么线性 DP 不行？以石子合并为例，最后一次合并把 $[l,k]$ 和 $[k+1,r]$ 两堆合在一起，而 $[k+1,r]$ 是"中间的一段"，不是前缀，前缀状态描述不了它。

## 2. 核心原理

### 2.1 两种转移方式

**枚举分割点**：区间的最后一步把它分成左右两部分，左右各自独立求解：

$$f_{l,r} = \min_{l \le k < r} \big(f_{l,k} + f_{k+1,r}\big) + \text{cost}(l, r)$$

石子合并就是这样：不管之前怎么合并，最后一步一定是把 $[l,k]$ 合成的一堆和 $[k+1,r]$ 合成的一堆合起来，代价是 $[l,r]$ 的总数。

**从两端缩小**：只看区间两端的元素怎么处理：

$$f_{l,r} \leftarrow f_{l+1,r},\ f_{l,r-1},\ f_{l+1,r-1}$$

回文类问题多是这样：$s_l = s_r$ 时两端可以配对，转为 $f_{l+1,r-1}$；否则去掉一端。

很多题两种转移都要用，例如括号匹配：$s_l$ 和 $s_r$ 配对是"两端缩小"，并列的两段是"分割点"。

### 2.2 计算顺序

$f_{l,r}$ 依赖的都是**更短**的区间，所以按**区间长度从小到大**计算：

```
for len = 1 .. n
    for l = 1 .. n - len + 1
        r = l + len - 1
        计算 f[l][r]
```

常见错误是直接写 `for l = 1..n, for r = l..n`：计算 $f_{1,5}$ 时要用 $f_{2,5}$，但 $l = 2$ 那一行还没算。

另一种正确顺序是 **$l$ 从大到小、$r$ 从小到大**：$f_{l,r}$ 依赖的 $f_{l+1,\cdot}$ 已在上一轮算好，$f_{l,r'}$（$r' < r$）已在本轮算好。只用"两端缩小"转移时这种写法更简洁。

### 2.3 例：石子合并

一排 4 堆石子 $1, 3, 5, 2$。前缀和 $s$，$\text{cost}(l,r) = s_r - s_{l-1}$，$f_{i,i} = 0$。

| 区间 | 计算 | $f$ |
| --- | --- | --- |
| $[1,2]$ | $0 + 0 + 4$ | 4 |
| $[2,3]$ | $0 + 0 + 8$ | 8 |
| $[3,4]$ | $0 + 0 + 7$ | 7 |
| $[1,3]$ | $\min(f_{1,1}+f_{2,3},\ f_{1,2}+f_{3,3}) + 9 = \min(8, 4) + 9$ | 13 |
| $[2,4]$ | $\min(0 + 7,\ 8 + 0) + 10$ | 17 |
| $[1,4]$ | $\min(0 + 17,\ 4 + 7,\ 13 + 0) + 11$ | **22** |

最优方案：先合并 $1,3$（代价 4），再合并 $5,2$（代价 7），最后合并（代价 11）。

注意它和"合并果子"的区别：合并果子可以合并**任意**两堆，用贪心（哈夫曼）；石子合并只能合并**相邻**的，贪心不对，必须区间 DP。

### 2.4 环形：断环成链

石子排成一个环时，第 $n$ 堆和第 1 堆也相邻。环上 $n$ 堆石子之间有 $n$ 条"缝"，每次合并消掉一条缝，总共只合并 $n-1$ 次，所以**总有一条缝从来没被合并过**。在那里把环剪开，整个过程就是一条链上的合并。

做法：把数组复制一遍接在后面，$a_{n+i} = a_i$，在长度 $2n$ 的链上做区间 DP（区间长度不超过 $n$），答案是

$$\min_{1 \le i \le n} f_{i,\, i+n-1}$$

复杂度仍是 $O(n^3)$（常数变大）。比起枚举 $n$ 个断点各做一次 $O(n^3)$，快了 $n$ 倍。

### 2.5 括号匹配

由 `()[]` 组成的串，求最长的合法括号子序列长度。

- 若 $s_l$ 与 $s_r$ 能配对：$f_{l,r} \gets f_{l+1,r-1} + 2$；
- 并列：$f_{l,r} \gets \max_k f_{l,k} + f_{k+1,r}$。

合法括号序列的结构就是"嵌套（$(A)$）或并列（$AB$）"，正好对应这两种转移。

### 2.6 回文

最少插入几个字符使 $s$ 变成回文：

- $s_l = s_r$：两端已经对称，$f_{l,r} = f_{l+1,r-1}$；
- 否则，要么在右边补一个 $s_l$ 和它对称（$f_{l+1,r} + 1$），要么在左边补一个 $s_r$（$f_{l,r-1} + 1$）。

（答案也等于 $n$ 减去最长回文子序列长度。）

### 2.7 涂色

一条木板要涂成目标颜色串，每次可以把一段连续区间涂成同一种颜色（后涂的覆盖先涂的），求最少次数。

- $f_{i,i} = 1$；
- $s_l = s_r$：第一次涂 $s_l$ 时可以顺便一直涂到 $r$，所以 $f_{l,r} = \min(f_{l+1,r}, f_{l,r-1})$；
- 否则两端颜色不同，必然存在分界：$f_{l,r} = \min_k f_{l,k} + f_{k+1,r}$。

### 2.8 区间计数与"不重不漏"

用区间 DP 计数时，分割点转移最容易**重复计数**。例如数"合法括号序列的个数"，$()()()$ 可以拆成 $()\,|\,()()$ 也可以拆成 $()()\,|\,()$，被算了两次。

解决办法是让分解方式**唯一**：规定左边那一段必须是"不可再分的最小块"（如以 $s_l$ 和它的配对括号为第一块），即

$$f_{l,r} = \sum_k g_{l,k} \cdot f_{k+1,r}$$

其中 $g_{l,k}$ 表示 $[l,k]$ 是一个整体（$s_l$ 与 $s_k$ 配对）的方案数。CSP-S 2021 括号序列正是这样拆状态的。

### 2.9 其他常见形态

- **从两端取数**：每次从序列左端或右端取一个数，第 $t$ 次取的得分与 $t$ 有关。剩下的总是一个区间 $[l, r]$，而已经取了几次可以由 $n - (r - l + 1)$ 推出，$f_{l,r} = \max(f_{l+1,r} + \dots,\ f_{l,r-1} + \dots)$。
- **矩阵链乘 / 能量项链**：合并相邻两个"矩阵"，代价与两端和分割点的值有关，$f_{l,r} = \min_k f_{l,k} + f_{k,r} + a_l a_k a_r$。
- **区间作为子树**：中序遍历为 $1 \sim n$ 的二叉树，以 $[l,r]$ 为子树时枚举根 $k$，左子树 $[l,k-1]$、右子树 $[k+1,r]$（加分二叉树）。
- **区间 DP 加维度**：如果合并还和"左边/右边接了什么"有关，就加一维，如 $f_{l,r,0/1}$ 表示区间的最后一步停在左端/右端（关路灯类问题）。

## 3. 代码模板

### 3.1 石子合并（链）

```cpp
const int N = 3e2 + 5;
int n;
int s[N], f[N][N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> s[i], s[i] += s[i - 1];
    For(len, 2, n) For(l, 1, n - len + 1) {
        int r = l + len - 1;
        f[l][r] = LINF;
        Rep(k, l, r) f[l][r] = min(f[l][r], f[l][k] + f[k + 1][r] + s[r] - s[l - 1]);
    }
    cout << f[1][n];
}
```

### 3.2 石子合并（环，同时求最小与最大）

```cpp
const int N = 2e2 + 5;
int n;
int a[N], s[N], f[N][N], g[N][N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i], a[i + n] = a[i];
    For(i, 1, 2 * n) s[i] = s[i - 1] + a[i];
    For(len, 2, n) For(l, 1, 2 * n - len + 1) {
        int r = l + len - 1;
        f[l][r] = LINF, g[l][r] = 0;
        Rep(k, l, r) {
            f[l][r] = min(f[l][r], f[l][k] + f[k + 1][r] + s[r] - s[l - 1]);
            g[l][r] = max(g[l][r], g[l][k] + g[k + 1][r] + s[r] - s[l - 1]);
        }
    }
    int mn = LINF, mx = 0;
    For(i, 1, n) mn = min(mn, f[i][i + n - 1]), mx = max(mx, g[i][i + n - 1]);
    cout << mn << endl << mx;
}
```

### 3.3 最长合法括号子序列

```cpp
const int N = 5e2 + 5;
int n;
int f[N][N];
string s;

inline bool match(char a, char b) {
    return (a == '(' && b == ')') || (a == '[' && b == ']');
}

void solve() {
    cin >> s;
    n = s.size(), s = " " + s;
    For(len, 2, n) For(l, 1, n - len + 1) {
        int r = l + len - 1;
        if (match(s[l], s[r])) f[l][r] = f[l + 1][r - 1] + 2;
        Rep(k, l, r) f[l][r] = max(f[l][r], f[l][k] + f[k + 1][r]);
    }
    cout << f[1][n];
}
```

$len = 2$ 时 $f_{l+1,r-1} = f_{l+1,l}$ 是空区间，值为 0，正好作为边界。

### 3.4 最少插入成回文

这里用"$l$ 倒序、$r$ 正序"的顺序：

```cpp
const int N = 5e3 + 5;
int n;
int f[N][N];
string s;

void solve() {
    cin >> s;
    n = s.size(), s = " " + s;
    for (int l = n; l >= 1; l--) For(r, l + 1, n) {
        if (s[l] == s[r]) f[l][r] = f[l + 1][r - 1];
        else f[l][r] = min(f[l + 1][r], f[l][r - 1]) + 1;
    }
    cout << f[1][n];
}
```

$n = 5000$ 时二维 `long long` 表约 200MB，内存紧张时改用 `signed` 或滚动 $l$ 这一维。

### 3.5 涂色

```cpp
const int N = 55;
int n;
int f[N][N];
string s;

void solve() {
    cin >> s;
    n = s.size(), s = " " + s;
    For(i, 1, n) f[i][i] = 1;
    For(len, 2, n) For(l, 1, n - len + 1) {
        int r = l + len - 1;
        if (s[l] == s[r]) {
            f[l][r] = min(f[l + 1][r], f[l][r - 1]);
            continue;
        }
        f[l][r] = LINF;
        Rep(k, l, r) f[l][r] = min(f[l][r], f[l][k] + f[k + 1][r]);
    }
    cout << f[1][n];
}
```

## 4. 复杂度

- 状态 $O(n^2)$ 个，枚举分割点 $O(n)$，总时间 $O(n^3)$，一般适用于 $n \le 300 \sim 500$。
- 只有"两端缩小"转移时是 $O(n^2)$，$n$ 可到 $5000$ 左右（注意内存）。
- 环形断环成链后区间数约为 $2n \times n$，时间约为链的 4 倍（常数）。
- 石子合并这类代价满足"四边形不等式"的题，最优分割点有单调性，可以优化到 $O(n^2)$，CSP 中了解即可（见"动态规划优化"）。

## 5. 常见题型与技巧

- **识别区间 DP**：操作只涉及相邻元素（合并、消除）、问题有嵌套结构（括号、表达式、回文）、或者每次只能从两端处理。数据范围 $n \le 500$ 而且有 $O(n^3)$ 的感觉时，优先考虑。
- **想清楚"最后一步"**：是最后一次合并（分割点），还是第一个/最后一个元素怎么处理（两端）。不同的视角给出不同的转移，选能保证不重不漏的那个。
- **环形**：复制一倍断环成链。
- **计数要保证分解唯一**：规定第一块"不可再分"，必要时把状态拆成"整体被一对括号包住"和"任意"两种。
- **附加维度**：区间外部的信息影响区间内部时（例如区间左边还挂着几个和 $s_l$ 同色的元素可以一起消），就把这个信息加进状态，$f_{l,r,k}$。
- **预处理代价**：$\text{cost}(l,r)$ 如果是区间和，用前缀和 $O(1)$ 得到；更复杂的代价可以先 $O(n^2)$ 预处理成表。

## 6. 易错点

- 循环顺序写成 `for l, for r`，用到了未计算的状态。
- 初值：求最小值时 $f_{l,r}$（$l < r$）要先设为 $+\infty$，而 $f_{i,i}$ 按题意设（石子合并为 0，涂色为 1）。
- 分割点范围：$k \in [l, r-1]$，右半部分是 $[k+1, r]$；能量项链类是 $f_{l,k} + f_{k,r}$，共用端点 $k$，范围是 $(l, r)$。
- 环形断开后，区间长度上限是 $n$，左端点范围要到 $2n - len + 1$；数组开 $2n$。
- 计数时分割点转移重复计数。
- 二维表在 $n$ 较大时爆内存。
