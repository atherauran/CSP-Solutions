# 最小生成树

**组别**：S　**关键词**：Kruskal、Prim、并查集、切分性质、环性质、最小瓶颈路、次小生成树

## 1. 是什么 / 解决什么问题

给一张连通的无向带权图，从中选出若干条边，使所有点连通，并且选出的边权和最小。

- 选出的边一定不含环（有环就能去掉环上一条边，仍然连通、权值更小或不变），所以恰好是 $n - 1$ 条边构成的一棵树，叫**生成树**。
- 边权和最小的生成树叫**最小生成树**（MST）。

典型场景：在 $n$ 个城市之间修路 / 铺光缆，已知每对城市间修路的费用，求让所有城市连通的最小总费用。

两个经典算法：

- **Kruskal**：按边权从小到大加边，用并查集避免成环，$O(m \log m)$，适合稀疏图。
- **Prim**：从一个点开始，每次把离当前树最近的点拉进来，朴素 $O(n^2)$，适合稠密图。

## 2. 核心原理

### 2.1 切分性质：为什么"贪心选最小边"是对的

把点集任意分成两部分 $S$ 和 $V \setminus S$（称为一个**切分**），一端在 $S$、一端在 $V \setminus S$ 的边叫**横跨边**。

> **切分性质**：横跨某个切分的边中权值最小的边 $e$，一定属于某棵最小生成树。

证明（交换论证）：取一棵不含 $e$ 的最小生成树 $T$。把 $e$ 加进 $T$，会形成一个环。这个环从 $S$ 出发、经过 $e$ 到了 $V \setminus S$，还得再回到 $S$，所以环上还有另一条横跨边 $f$。因为 $e$ 是最小的横跨边，$w(e) \le w(f)$。把 $f$ 删掉，$T - f + e$ 仍是生成树，权值不增，所以它也是最小生成树，而且含有 $e$。

Kruskal 和 Prim 每一步选的边，都是某个切分的最小横跨边，所以都是对的。

### 2.2 环性质：哪些边一定不用

> **环性质**：如果边 $e$ 是某个环上**严格最大**的边，那么 $e$ 不在任何最小生成树中。

证明：若 $e$ 在某棵生成树 $T$ 中，删掉 $e$ 后 $T$ 分成两块，环上除 $e$ 外还有一条边 $f$ 连接这两块，且 $w(f) < w(e)$，换成 $f$ 更优，矛盾。

一个很有用的推论：**往图里加点、加边之后，原图中不在 MST 上的边仍然不会被用到**（它所在的那个环还在）。所以面对"在原图基础上增加一些边，多次求 MST"的题，可以先把原图的边集缩小到原 MST 的 $n - 1$ 条。

### 2.3 Kruskal

1. 把所有边按权值从小到大排序；
2. 依次考虑每条边 $(u, v)$：若 $u, v$ 已经连通，跳过（加上会成环）；否则加入这条边，合并 $u, v$ 所在的集合；
3. 加够 $n - 1$ 条边就结束。如果所有边都考虑完还不够 $n - 1$ 条，说明图不连通。

"判断两点是否连通、合并两个集合"用**并查集**，见《并查集》。

为什么对：考虑某条被加入的边 $(u, v)$，取 $S$ 为 $u$ 当前所在的连通块。比它小的边都已处理过——要么在树中，要么两端已经连通（在某个块内部），都不横跨 $S$ 的边界。所以 $(u, v)$ 是这个切分的最小横跨边。

手推：5 个点，边为 $(1,2,1)$、$(2,3,2)$、$(1,3,3)$、$(3,4,4)$、$(2,4,5)$、$(4,5,6)$、$(3,5,7)$。

| 边 | 权 | 操作 | 当前集合 |
| --- | --- | --- | --- |
| 1-2 | 1 | 加入 | {1,2} {3} {4} {5} |
| 2-3 | 2 | 加入 | {1,2,3} {4} {5} |
| 1-3 | 3 | 跳过（已连通） | |
| 3-4 | 4 | 加入 | {1,2,3,4} {5} |
| 2-4 | 5 | 跳过 | |
| 4-5 | 6 | 加入，凑够 4 条边 | {1,2,3,4,5} |

总权值 $1 + 2 + 4 + 6 = 13$。

### 2.4 Prim

Prim 的过程和 Dijkstra 非常像：

1. 维护已在树中的点集 $T$，初始只有点 1；$d_v$ 表示 $v$ 到 $T$ 中**任意一点**的最短边；
2. 每次选不在 $T$ 中、$d_v$ 最小的点 $u$，把它加入 $T$，答案加上 $d_u$；
3. 用 $u$ 的出边更新：$d_v \gets \min(d_v, w(u, v))$。

和 Dijkstra 唯一的区别是更新式：Dijkstra 是 $d_u + w$（到起点的距离），Prim 是 $w$（到树的距离）。

正确性同样来自切分性质：取 $S = T$，$d_u$ 最小意味着选的是最小横跨边。

- 朴素实现每次 $O(n)$ 找最小值，总共 $O(n^2)$，**不需要存边**，只要能 $O(1)$ 算出任意两点间的边权。在完全图（比如平面上 $n$ 个点两两连边，$m = \frac{n(n-1)}{2}$）上比 Kruskal 的 $O(n^2 \log n)$ 更快，空间也只要 $O(n)$。
- 用堆优化可以做到 $O(m \log m)$，写法和堆优化 Dijkstra 一样，但稀疏图上一般直接用 Kruskal。

### 2.5 MST 的几条性质

- **只和边权的相对大小有关**：Kruskal 只用到了排序，所以把所有边权做任何单调递增的变换（如平方、开根号、加常数），MST 不变。比如平面点用距离平方代替距离，可以避免浮点数。
- **边权多重集唯一**：所有最小生成树的边权排序后完全相同。所以 MST 中的最大边、第 $k$ 小边都是确定的。
- **MST 是最小瓶颈生成树**：所有生成树中，MST 的**最大边最小**。并且对任意两点 $u, v$，MST 上 $u$ 到 $v$ 路径的最大边，就是原图中所有 $u$-$v$ 路径里"最大边"的最小值（**最小瓶颈路**）。直觉：Kruskal 从小到大加边，$u, v$ 第一次连通时加入的那条边，就是最小的可能瓶颈。

### 2.6 常见变体

- **最大生成树**：按边权从大到小排序即可。"两点间所有路径中，最小边最大是多少"就在最大生成树上找路径最小边。
- **连成 $k$ 个连通块**：Kruskal 每加一条边，连通块数减 1，加到只剩 $k$ 块时停止，即加 $n - k$ 条边。
- **某些边已经修好 / 必须选**：先把这些边在并查集中合并（并计入费用），再对其余边做 Kruskal。
- **每个点也可以"自建"**：比如每个村子可以花 $c_i$ 自己打井，也可以从别的村子引水。建一个虚拟点 0，向每个点 $i$ 连权为 $c_i$ 的边，在 $n + 1$ 个点上求 MST。
- **有 $k$ 条边免费**：把免费机会给 MST 中最大的 $k$ 条边。问总费用就是其余 $n - 1 - k$ 条边之和，问最大边就是 MST 中第 $n - 1 - k$ 小的边。
- **次小生成树**：第二小的生成树一定可以由 MST **换一条边**得到。枚举每条非树边 $(u, v, w)$，加入它后删掉树上 $u$-$v$ 路径上的最大边，取最小值。路径最大值可以用倍增维护（见《树的直径、重心与最近公共祖先》）；$n$ 较小时也可以从每个点 DFS 一遍预处理。若要求**严格**次小，当最大边等于 $w$ 时要改用路径上的严格次大边。
- **判断 MST 是否唯一**：Kruskal 时把边权相同的边作为一组处理。处理一组之前，先数出这组中两端不连通的边数 $a$（都"可以"加入）；再逐条加入，数出实际加入的边数 $b$。若某组 $a > b$，说明有可以互相替换的边，MST 不唯一。

## 3. 代码模板

### 3.1 Kruskal

输出最小生成树的边权和，不连通输出 `orz`。

```cpp
const int N = 5005, M = 2e5 + 5;
int n, m, ans, cnt;
int f[N];
struct edge { int u, v, w; } e[M];

inline bool cmp(const edge &a, const edge &b) { return a.w < b.w; }

int find(int x) { return f[x] == x ? x : f[x] = find(f[x]); }

void solve() {
    cin >> n >> m;
    For(i, 1, m) cin >> e[i].u >> e[i].v >> e[i].w;
    sort(e + 1, e + 1 + m, cmp);
    For(i, 1, n) f[i] = i;
    For(i, 1, m) {
        int x = find(e[i].u), y = find(e[i].v);
        if (x == y) continue;
        f[x] = y, ans += e[i].w, cnt++;
        if (cnt == n - 1) break;
    }
    if (cnt < n - 1) cout << "orz";
    else cout << ans;
}
```

### 3.2 Prim（邻接矩阵）

输入 $n$ 和 $n \times n$ 的邻接矩阵。

```cpp
const int N = 1005;
int n, ans;
int a[N][N], d[N];
bool vis[N];

void solve() {
    cin >> n;
    For(i, 1, n) For(j, 1, n) cin >> a[i][j];
    mset(d, 0x3f);
    d[1] = 0;
    For(t, 1, n) {
        int u = 0;
        For(i, 1, n)
            if (!vis[i] && (!u || d[i] < d[u])) u = i;
        vis[u] = true, ans += d[u];
        For(v, 1, n)
            if (!vis[v]) d[v] = min(d[v], a[u][v]);
    }
    cout << ans;
}
```

如果图可能不连通，取出的 $d_u$ 会是 `LINF`，据此判断即可。

### 3.3 Prim（完全图，边权现算）

平面上 $n$ 个点，任意两点可以直接相连，代价为欧几里得距离。求使所有点连通时，所选边中最长边的最小值（最小瓶颈生成树）。用距离的平方做比较，不用存边，也不用浮点数。

```cpp
const int N = 5005;
int n, mx;
int x[N], y[N], d[N];
bool vis[N];

inline int dist(int i, int j) { return (x[i] - x[j]) * (x[i] - x[j]) + (y[i] - y[j]) * (y[i] - y[j]); }

void solve() {
    cin >> n;
    For(i, 1, n) cin >> x[i] >> y[i];
    mset(d, 0x3f);
    d[1] = 0;
    For(t, 1, n) {
        int u = 0;
        For(i, 1, n)
            if (!vis[i] && (!u || d[i] < d[u])) u = i;
        vis[u] = true, mx = max(mx, d[u]);
        For(v, 1, n)
            if (!vis[v]) d[v] = min(d[v], dist(u, v));
    }
    cout << fixed << setprecision(2) << sqrt((double)mx);
}
```

## 4. 复杂度

| 算法 | 时间 | 空间 | 适用 |
| --- | --- | --- | --- |
| Kruskal | $O(m \log m)$（排序）$+ O(m \alpha(n))$（并查集） | $O(n + m)$ | 稀疏图，最常用 |
| 朴素 Prim | $O(n^2)$ | $O(n)$（边权现算）或 $O(n^2)$（矩阵） | 稠密图、完全图 |
| 堆优化 Prim | $O(m \log m)$ | $O(n + m)$ | 很少需要 |

平面上 $n = 5000$ 个点的完全图有约 $1.25 \times 10^7$ 条边，Kruskal 要先存下并排序，时间和空间都吃紧；朴素 Prim 只要 $2.5 \times 10^7$ 次运算。

## 5. 常见题型与技巧

- **直接求 MST**：题目说"使所有点连通的最小代价"，基本就是它。
- **最小化最大边 / 最大化最小边**：最小瓶颈路、最大生成树。多次询问两点间的瓶颈，就建出 MST 后用倍增 LCA 查路径最值。
- **虚拟点**：每个点有"自己解决"的代价时，加一个超级点连边。
- **按阈值连通**：问"至少要多大的 $D$，才能让距离 $\le D$ 的点对把所有点连通"，答案就是 MST 的最大边；问"分成 $k$ 组时组间最小距离最大"，答案是 MST 第 $n - k + 1$ 小的边（Kruskal 加到剩 $k$ 块时，下一条会被加入的边）。
- **缩小边集**：利用环性质，原图非 MST 边在加点加边后依然无用，只保留 $n - 1$ 条树边再做后续计算。
- **枚举 + MST**：额外元素很少（如 $k \le 10$ 个可选的新点）时，枚举选哪些，每次求 MST；预先把边排好序，每次只需线性扫一遍。

## 6. 易错点

- **忘记排序**，或比较函数写成了按端点排序。
- **并查集不做路径压缩**，退化成 $O(n)$ 一次查询。
- **不判断连通**：加入的边数不足 $n - 1$ 时图不连通。
- **边权和溢出**：$n$ 个点、每条边 $10^9$，和超过 `int`（本仓库 `int` 已是 `long long`）。
- **Prim 更新式写成 Dijkstra 的 $d_u + w$**。
- **Prim 选点时没跳过已选的点**。
- **把有向图当无向图求 MST**：有向图的"最小树形图"是另一个问题，不能用 Kruskal。
- **完全图用 Kruskal 存所有边**导致 MLE。
