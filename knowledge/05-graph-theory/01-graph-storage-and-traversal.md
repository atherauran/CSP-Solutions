# 图的存储与遍历

**组别**：J　**关键词**：邻接矩阵、邻接表、链式前向星、DFS、BFS、连通块、反向建图

## 1. 是什么 / 解决什么问题

**图**由若干个**点**（顶点）和连接点的**边**组成，记作 $G = (V, E)$。通常用 $n$ 表示点数，$m$ 表示边数。

很多问题本质上都是图：城市和道路、网页和链接、人和好友关系、游戏中"状态"和"一步操作"……只要能说清"有哪些东西"和"谁能一步到谁"，就能建成图。

图论题的第一步永远是两件事：

1. **把图存下来**：选一种合适的存储方式；
2. **把图走一遍**：用 DFS 或 BFS 访问所有能到达的点，回答"能不能到""有几块""最少几步"之类的问题。

后面的最短路、最小生成树、拓扑排序等算法，全都建立在这两件事之上。

## 2. 核心原理

### 2.1 基本概念

| 概念 | 含义 |
| --- | --- |
| 无向图 / 有向图 | 边 $(u, v)$ 没有方向（双向通行）/ 边 $u \to v$ 只能从 $u$ 走到 $v$ |
| 边权 | 边上附带的数值，如长度、费用。没有边权的图叫无权图（可看作边权都为 1） |
| 度 | 无向图中与点相连的边数；有向图分**入度**（指向它的边数）和**出度**（从它出发的边数） |
| 自环 / 重边 | 边 $(u, u)$ / 同一对点之间有多条边。题目没说没有，就要假设可能有 |
| 路径 / 简单路径 | 一串首尾相接的边 / 不经过重复点的路径 |
| 环 | 起点和终点相同的路径 |
| 连通 / 连通块 | 无向图中两点间有路径就叫连通；互相连通的极大点集叫一个**连通块**（连通分量） |
| 稀疏图 / 稠密图 | $m$ 与 $n$ 同阶 / $m$ 接近 $n^2$ |

几种常见的特殊图：

- **树**：$n$ 个点、$n-1$ 条边的连通无向图，等价于"连通且无环"。任意两点之间恰有一条简单路径。
- **DAG**（有向无环图）：没有有向环的有向图，可以做拓扑排序和 DP。
- **完全图**：任意两点之间都有边，无向完全图有 $\frac{n(n-1)}{2}$ 条边。
- **二分图**：点能分成两组，每条边都连接不同组的点。

**握手定理**：无向图中所有点的度数之和等于 $2m$（每条边给两个端点各贡献 1 度）。由此可知度数为奇数的点一定有偶数个。

### 2.2 四种存储方式

以下面这张无向带权图为例（$n = 4$，$m = 4$）：

```
 1 ---(5)--- 2
 |           |
(3)         (7)
 |           |
 3 ---(2)--- 4
```

边为 $(1,2,5)$、$(1,3,3)$、$(2,4,7)$、$(3,4,2)$。

**邻接矩阵**：开二维数组 `a[u][v]` 表示 $u$ 到 $v$ 的边权（没有边记为 0 或 $\infty$）。

|   | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 1 | 0 | 5 | 3 | 0 |
| 2 | 5 | 0 | 0 | 7 |
| 3 | 3 | 0 | 0 | 2 |
| 4 | 0 | 7 | 2 | 0 |

- 优点：$O(1)$ 判断两点间有没有边、边权是多少；写法最简单。
- 缺点：空间 $O(n^2)$，遍历一个点的邻居要扫一整行 $O(n)$。$n = 10^4$ 时 `long long` 矩阵就要 800MB，只适合 $n \le$ 几千的稠密图（如 Floyd）。
- 重边要取最小值：`a[u][v] = min(a[u][v], w)`。

**邻接表**（`vector`）：每个点开一个 `vector`，存它的所有出边。

```
g[1]: (2,5) (3,3)
g[2]: (1,5) (4,7)
g[3]: (1,3) (4,2)
g[4]: (2,7) (3,2)
```

- 空间 $O(n + m)$，遍历一个点的邻居只花它的度数那么多时间。**这是最常用的存法。**
- 无向图每条边要存两次（$u \to v$ 和 $v \to u$）。
- 带权时存 `pii`，`.F` 是终点、`.S` 是边权。

**链式前向星**：用数组模拟邻接表，每个点的出边串成一个链表。

- `head[u]`：$u$ 的最后一条加入的边的编号；
- `to[i]`、`nxt[i]`：第 $i$ 条边的终点、同一起点的下一条边。

加边 $u \to v$ 就是"头插法"：`to[++tot] = v, nxt[tot] = head[u], head[u] = tot`。遍历 $u$ 的邻居：`for (int i = head[u]; i; i = nxt[i])`。

它和 `vector` 效率相近，优点是边有了**编号**：若从 `tot = 1` 开始加边（第一条边编号为 2），无向边的两个方向编号是 $2k$ 和 $2k+1$，用 `i ^ 1` 就能找到反向边，求桥、网络流时很方便。

**边集数组**：直接把边存成结构体 `{u, v, w}`。不能快速找某个点的邻居，但适合"按边处理"的算法：Kruskal（要按边权排序）、Bellman-Ford（每轮扫所有边）。

| 存法 | 空间 | 找 $u$ 的所有邻居 | 判断 $(u, v)$ 是否有边 | 典型用途 |
| --- | --- | --- | --- | --- |
| 邻接矩阵 | $O(n^2)$ | $O(n)$ | $O(1)$ | Floyd、稠密图、$n$ 很小 |
| 邻接表 | $O(n+m)$ | $O(\deg u)$ | $O(\deg u)$ | 几乎所有图论算法 |
| 链式前向星 | $O(n+m)$ | $O(\deg u)$ | $O(\deg u)$ | 需要边编号、反向边 |
| 边集数组 | $O(m)$ | $O(m)$ | $O(m)$ | Kruskal、Bellman-Ford |

### 2.3 深度优先搜索（DFS）

DFS 的策略是"一条路走到黑，走不通再回头"：从起点出发，每次走向一个**没访问过**的邻居，递归下去；当前点的邻居都访问过了，就回溯到上一个点。

用 `vis` 数组标记访问过的点，保证每个点只进入一次。对上面的图从 1 出发（邻居按编号从小到大）：

```
dfs(1) → dfs(2) → dfs(4) → dfs(3)
                            3 的邻居 1、4 都访问过，回溯
访问顺序：1 2 4 3
```

DFS 走过的边（$1-2$、$2-4$、$4-3$）构成一棵**DFS 树**。后面的强连通分量、割点都要在 DFS 树上分析。

### 2.4 广度优先搜索（BFS）

BFS 的策略是"一圈一圈往外扩"：用队列，先访问起点，再访问所有距离为 1 的点，再访问所有距离为 2 的点……

```
队列：[1]        取出 1，加入 2、3
队列：[2, 3]     取出 2，加入 4
队列：[3, 4]     取出 3，4 已在队中
队列：[4]        取出 4
访问顺序：1 2 3 4
```

**为什么 BFS 能求无权图最短路**：队列中的点距离是"非递减"的，而且相邻两段距离最多差 1（前面是距离 $d$ 的点，后面是距离 $d+1$ 的点）。一个点第一次被发现时，是从距离最小的点扩展过来的，所以第一次的距离就是最短距离。

**标记要在入队时做**，不要等出队时才做，否则同一个点会被多个邻居重复加入队列，最坏情况下队列会爆炸。

### 2.5 连通块

无向图中，从一个没访问过的点出发 DFS/BFS 一次，能访问到的所有点就是它所在的连通块。对每个点都试一下，"发起搜索"的次数就是连通块的个数。

连通块问题也可以用**并查集**解决，而且并查集支持边一条条加入，见《并查集》。

### 2.6 隐式图与网格图

很多题不会直接给出图，而是给出"状态"和"操作"，需要自己意识到这是图：

- **网格图**：每个格子是点，上下左右相邻的格子之间有边。用方向数组 `dx`、`dy` 枚举邻居，不必真的建图。
- **状态图**：比如"一个数可以 $+1$、$\times 2$，最少几步变到 $t$"，每个数就是一个点。
- **拆点**：如果光知道"在哪个点"不够，还要知道额外信息（如走过路径的奇偶性、用了几次特权），就把点拆成 $(u, k)$ 这样的二元组。详见《最短路》中的分层图。

### 2.7 一笔画（欧拉路径）

经过每条边**恰好一次**的路径叫欧拉路径，回到起点的叫欧拉回路。判定方法只看度数（前提是有边的点都连通）：

- 无向图：奇度点为 0 个时有欧拉回路；为 2 个时有欧拉路径，且必须从一个奇度点出发、到另一个结束；其余情况都没有。
- 有向图：所有点入度等于出度时有欧拉回路；恰有一个点出度比入度大 1（起点）、一个点入度比出度大 1（终点）、其余相等时有欧拉路径。

直觉：除了起点和终点，路径每经过一个点，都是"进去一次、出来一次"，用掉两个度数。

## 3. 代码模板

### 3.1 三种存法的读入

读入 $n$ 个点、$m$ 条无向带权边，分别存进邻接矩阵、邻接表、边集数组（实际做题只选一种）。最后用邻接表输出每个点的邻居。

```cpp
const int N = 1005, M = 2e5 + 5;
int n, m;
int a[N][N];
vector<pii> g[N];
struct edge { int u, v, w; } e[M];

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v, w;
        cin >> u >> v >> w;
        a[u][v] = a[v][u] = w;
        g[u].pb({v, w}), g[v].pb({u, w});
        e[i] = {u, v, w};
    }
    For(u, 1, n) {
        cout << u << ':';
        for (auto p : g[u]) cout << " (" << p.F << ", " << p.S << ")";
        cout << endl;
    }
}
```

### 3.2 邻接表 + DFS / BFS

有向图，从 1 出发，邻居按编号从小到大访问，分别输出 DFS 序和 BFS 序。

```cpp
const int N = 1e5 + 5;
int n, m;
bool vis[N];
vector<int> g[N];

void dfs(int u) {
    vis[u] = true;
    cout << u << ' ';
    for (int v : g[u])
        if (!vis[v]) dfs(v);
}

void bfs(int s) {
    queue<int> q;
    q.push(s), vis[s] = true;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        cout << u << ' ';
        for (int v : g[u])
            if (!vis[v]) vis[v] = true, q.push(v);
    }
}

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v);
    }
    For(i, 1, n) sort(g[i].begin(), g[i].end());
    dfs(1);
    cout << endl;
    mset(vis, 0);
    bfs(1);
}
```

### 3.3 链式前向星 + 连通块计数

```cpp
const int N = 1e5 + 5, M = 4e5 + 5;
int n, m, tot, cnt;
int head[N], nxt[M], to[M];
bool vis[N];

inline void add(int u, int v) { to[++tot] = v, nxt[tot] = head[u], head[u] = tot; }

void dfs(int u) {
    vis[u] = true;
    for (int i = head[u]; i; i = nxt[i])
        if (!vis[to[i]]) dfs(to[i]);
}

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        add(u, v), add(v, u);
    }
    For(i, 1, n)
        if (!vis[i]) cnt++, dfs(i);
    cout << cnt;
}
```

无向图每条边存两次，所以边数组 `M` 要开到 $2m$ 以上。

### 3.4 网格 BFS 求最短步数

$n \times m$ 的迷宫，`#` 是墙，`S` 是起点，`T` 是终点，每步走到上下左右相邻的格子。输出最少步数，走不到输出 $-1$。

```cpp
const int N = 1005;
int n, m, sx, sy, tx, ty;
int d[N][N];
char a[N][N];
int dx[4] = {-1, 1, 0, 0}, dy[4] = {0, 0, -1, 1};

void solve() {
    cin >> n >> m;
    For(i, 1, n) For(j, 1, m) {
        cin >> a[i][j];
        if (a[i][j] == 'S') sx = i, sy = j;
        if (a[i][j] == 'T') tx = i, ty = j;
    }
    mset(d, -1);
    queue<pii> q;
    q.push({sx, sy}), d[sx][sy] = 0;
    while (!q.empty()) {
        int x = q.front().F, y = q.front().S;
        q.pop();
        Rep(k, 0, 4) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 1 || nx > n || ny < 1 || ny > m || a[nx][ny] == '#' || d[nx][ny] != -1) continue;
            d[nx][ny] = d[x][y] + 1;
            q.push({nx, ny});
        }
    }
    cout << d[tx][ty];
}
```

`d` 同时充当 `vis`：$-1$ 表示还没到过。

### 3.5 反向建图

有向图中，对每个点 $u$ 求它能到达的编号最大的点。

正着做要从每个点搜一遍，$O(n(n+m))$。反过来想：从大到小枚举点 $c$，在**反图**上从 $c$ 出发，能走到的点 $u$ 在原图中都能到达 $c$。第一次走到 $u$ 的 $c$ 就是最大的，之后不用再访问 $u$，每个点只访问一次，总共 $O(n+m)$。

```cpp
const int N = 1e5 + 5;
int n, m;
int ans[N];
vector<int> g[N];

void dfs(int u, int c) {
    ans[u] = c;
    for (int v : g[u])
        if (!ans[v]) dfs(v, c);
}

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        g[v].pb(u);
    }
    for (int i = n; i >= 1; i--)
        if (!ans[i]) dfs(i, i);
    For(i, 1, n) cout << ans[i] << ' ';
}
```

## 4. 复杂度

| 操作 | 邻接矩阵 | 邻接表 / 链式前向星 |
| --- | --- | --- |
| 空间 | $O(n^2)$ | $O(n + m)$ |
| 一次完整 DFS / BFS | $O(n^2)$ | $O(n + m)$ |

用邻接表时每个点进入一次、每条边被检查一次（无向边两次），所以遍历是 $O(n + m)$。从**每个点**出发各搜一次是 $O(n(n+m))$，$n$ 在几千以内才能接受。

## 5. 常见题型与技巧

- **可达性 / 连通块**：从起点 DFS/BFS，看能到哪些点；统计"发起搜索"的次数得到连通块数。
- **无权图最短路**：BFS。边权只有 0 和 1 时用 0-1 BFS，多个起点时用多源 BFS，见《广度优先搜索》。
- **全源可达 / 全源最短步数**：$n$ 不大时从每个点 BFS 一次，$O(n(n+m))$。
- **反向建图**：问"哪些点能到达 $t$"时，在反图上从 $t$ 出发搜；问"每个点能到的最大编号"时，按编号从大到小在反图上搜。
- **拆点**：把"点 + 额外状态"作为新的点再 BFS，例如"到达 $u$ 时路径长度的奇偶性"。
- **网格图**：方向数组 + 边界判断；八方向、马走日只需改方向数组。
- **先建图再分析**：遇到"$a$ 依赖 $b$""$a$ 能变成 $b$"一类的关系，先想能不能建成图。

## 6. 易错点

- **无向图忘记存两条边**，或边数组只开了 $m$ 而不是 $2m$。
- **多组数据没清空**：`vector` 要 `g[i].clear()`，链式前向星要清 `head` 和 `tot`，`vis` 也要清。只清 $1 \sim n$ 即可，别每组都 `memset` 整个大数组。
- **BFS 在出队时才标记**，导致同一个点多次入队。
- **递归 DFS 爆栈**：一条长链就能让递归深度达到 $n$。$10^5$ 级一般没问题，$10^6$ 级要小心，可以改用 BFS 或手写栈。
- **邻接矩阵开太大**：先算空间，`long long` 的 $5000 \times 5000$ 已经 200MB。
- **网格越界**：先判边界再访问数组，或者让坐标从 1 开始、四周留一圈空。
- **点的编号从 0 开始**的题，读入时统一 $+1$ 转成 1-indexed。
