# 二分图

**组别**：S　**关键词**：二分图、染色法、扩展域并查集、匈牙利算法、最大匹配、最小点覆盖、最大独立集、行列建图

## 1. 是什么 / 解决什么问题

如果一个无向图的点能分成两个集合 $L$、$R$，使得**每条边的两个端点分别在两个集合里**（集合内部没有边），这个图就叫**二分图**。

```
  L        R
  1 ────── a
    ╲
  2 ────── b
         ╱
  3 ────── c
```

很多问题天然就是二分图：男生和女生、工人和任务、棋盘的行和列、黑格和白格。围绕二分图有两类问题：

1. **判定**：一个图是不是二分图？等价于"能不能把点分成两组，使每条边都跨组"。例如"把罪犯分进两个监狱，使有仇的人不在一起"。
2. **匹配**：选一些边，使**任意两条选中的边没有公共端点**，这些边叫一个**匹配**。边数最多的匹配叫**最大匹配**；如果所有点都被匹配上，叫**完美匹配**。例如"每个工人最多做一个任务、每个任务最多给一个工人，最多能安排几对"。

匹配还引出了两个重要的结论：**最小点覆盖 = 最大匹配**，**最大独立集 = 点数 − 最大匹配**。很多看起来不像匹配的题，就是靠它们转化的。

## 2. 核心原理

### 2.1 判定：二分图 ⇔ 没有奇环

**定理**：一个图是二分图，当且仅当它不含**长度为奇数的环**。

- 有奇环则不是二分图：沿着环走，每走一条边就换一次集合。走奇数步回到起点，起点就必须和自己在不同集合，矛盾。
- 没有奇环则是二分图：下面的染色法要么成功染完，要么找到一条两端同色的边，而这条边一定和 BFS 树上的路径构成奇环。所以没有奇环时染色一定成功。

**染色法**：用两种颜色给点染色，相邻点必须异色。

1. 任选一个未染色的点染成 1，从它开始 BFS / DFS；
2. 对当前点 $u$ 的每个邻居 $v$：若 $v$ 未染色，染成和 $u$ 相反的颜色；若 $v$ 已染色且与 $u$ 同色，则不是二分图；
3. 图可能不连通，每个连通块都要做一次。

每个连通块的染色方案只有两种（整体交换两种颜色），因为第一个点的颜色一旦定了，其余点的颜色都被边逼出来了。这一点常被用来计数或求最值：例如"每条边恰好选一个端点，最少选几个点"，就是每个连通块取两种颜色中较少的那一种。

### 2.2 判定的另一种做法：扩展域并查集

（并查集本身见《并查集》。）给每个点 $x$ 开两个元素：$x$ 表示"$x$ 在 A 组"，$x + n$ 表示"$x$ 在 B 组"。同一个集合里的元素表示"同时成立"。

- 边 $(u, v)$ 要求 $u, v$ 异组：合并 $u$ 与 $v + n$，合并 $u + n$ 与 $v$；
- 若某时刻 $u$ 和 $v$ 在同一集合，说明"$u, v$ 必须同组"，与这条边矛盾，不是二分图。

它的优点是**可以一条一条地加边，随时判断是否矛盾**。例如"按怨气从大到小依次要求分开，第一次无法满足的那条边就是答案"，用染色法每次都要重染，用并查集则顺手完成（见 3.4）。

### 2.3 匹配的基本概念

固定一个匹配 $M$：

- 在 $M$ 中的边叫**匹配边**，其他叫**非匹配边**；
- 被匹配边连着的点叫**匹配点**，其他叫**未匹配点**；
- **交错路**：匹配边和非匹配边交替出现的路径；
- **增广路**：起点和终点**都是未匹配点**的交错路。

增广路一定以非匹配边开头、以非匹配边结尾，非匹配边比匹配边**多一条**。把路上所有边的状态**取反**（匹配边变非匹配边，非匹配边变匹配边），得到的仍是一个合法匹配，而且边数加 1。

```
增广路：  1 ─── a ═══ 2 ─── b      （═ 是匹配边，1 和 b 未匹配）
取反后：  1 ═══ a ─── 2 ═══ b      匹配数 1 → 2
```

**Berge 定理**：$M$ 是最大匹配，当且仅当图中不存在关于 $M$ 的增广路。

所以求最大匹配的思路是：**不断找增广路，找不到了就是最大匹配**。

### 2.4 匈牙利算法

依次考虑左边的每个点 $u$，尝试为它找一条增广路：

- 枚举 $u$ 的邻居 $v$（右边的点），本轮没尝试过的才考虑，标记 `vis[v]`；
- 如果 $v$ 还没匹配，直接把 $v$ 给 $u$，成功；
- 如果 $v$ 已经匹配给了 $u'$ = `mt[v]`，就递归地让 $u'$ **换一个**（`dfs(u')`）。如果 $u'$ 能换到别的点，就把 $v$ 让给 $u$，成功；
- 所有邻居都不行，失败。

通俗说法就是"**有空位就坐，没空位就让占座的人挪一挪**"。递归中"让 $u'$ 挪"的那一串，恰好就是一条增广路；递归成功返回时依次更新 `mt[v] = u`，就是把增广路取反。

`vis` 的作用：同一轮里，一个右点只尝试一次。如果它已经尝试过了，要么正在递归栈上（再走就绕圈），要么已经确认"从它挪不动"，再试也没用。每一轮（每个新的 $u$）开始前要清空 `vis`。

**手推**：左边 1、2、3，右边 a、b、c，邻接表（按顺序尝试）：

```
1: a, b
2: a
3: b, c
```

| 轮次 | 过程 | 匹配结果 |
| --- | --- | --- |
| u = 1 | a 空，1 拿 a | 1-a |
| u = 2 | a 被 1 占，让 1 挪：1 试 a（本轮已试过，跳过），试 b，空，1 拿 b；于是 2 拿 a | 1-b，2-a |
| u = 3 | b 被 1 占，让 1 挪：1 试 a，被 2 占，让 2 挪：2 只有 a，已试过，失败；1 试 b，已试过，失败。所以 b 拿不到。3 试 c，空，3 拿 c | 1-b，2-a，3-c |

最大匹配为 3。第二轮找到的增广路是 2 → a ═ 1 → b。

**为什么每个左点只需尝试一次**：可以证明，如果某一轮从 $u$ 出发找不到增广路，之后无论匹配怎么变化，从 $u$ 出发也永远找不到。所以按顺序每个左点试一次，结束时就不存在增广路了，由 Berge 定理就是最大匹配。

### 2.5 最小点覆盖与最大独立集（结论）

**点覆盖**：选一些点，使**每条边至少有一个端点被选中**。选的点最少的叫最小点覆盖。

**König 定理**：二分图中，**最小点覆盖的点数 = 最大匹配的边数**。

- "$\ge$" 很直观：最大匹配的 $k$ 条边两两没有公共点，要覆盖它们，每条边至少要选一个端点，且不能共用，所以至少 $k$ 个点。
- "能取到等号"是定理的核心，记住结论即可（构造方法：从左边未匹配点出发沿交错路标记，取"左边未标记的点 + 右边标记的点"）。

**独立集**：选一些点，使**任意两个选中的点之间没有边**。选的点最多的叫最大独立集。

**最大独立集 = 总点数 − 最大匹配**。

原因：一个点集是独立集，当且仅当它的**补集**是点覆盖（每条边都至少有一个端点不在独立集里，即在补集里）。所以最大独立集 = $n$ − 最小点覆盖 = $n$ − 最大匹配。这里 $n$ 是**两边点数之和**。

再补充两个常用结论：

- **最小边覆盖**（选最少的边，使每个点都至少被一条选中的边碰到，要求没有孤立点）= 总点数 − 最大匹配。
- **DAG 最小路径覆盖**（用最少的不相交路径覆盖 DAG 的所有点）：把每个点 $x$ 拆成左点 $x$ 和右点 $x'$，原图边 $u \to v$ 连 $u - v'$。答案 = 点数 − 这个二分图的最大匹配。每匹配一条边，就是把两条路径接成一条，路径数减 1。

这些结论把"选点 / 选边"的最值问题全部归结为求最大匹配。

## 3. 代码模板

### 3.1 染色法判定二分图

例题：$n$ 个点 $m$ 条边的无向图（可能不连通），要选一些点，使每条边**恰好**有一个端点被选。求最少选几个点，无解输出 `Impossible`。

"每条边恰好一个端点被选"就是相邻点状态不同，即二分图染色；每个连通块取点数较少的那种颜色。

```cpp
const int N = 1e4 + 5;
int n, m, ans;
int col[N];
vector<int> g[N];

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    For(s, 1, n) {
        if (col[s]) continue;
        int c[3] = {0, 0, 0};
        queue<int> q;
        col[s] = 1, c[1]++, q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (!col[v]) {
                    col[v] = 3 - col[u], c[col[v]]++;
                    q.push(v);
                } else if (col[v] == col[u]) {
                    cout << "Impossible";
                    return;
                }
            }
        }
        ans += min(c[1], c[2]);
    }
    cout << ans;
}
```

颜色用 1、2 表示，0 表示未染色，`3 - col[u]` 就是另一种颜色。只判定的话，去掉计数部分即可。

### 3.2 匈牙利算法：二分图最大匹配

左边 $n$ 个点，右边 $m$ 个点，$e$ 条边 `u v` 表示左边第 $u$ 个点和右边第 $v$ 个点相连。求最大匹配数。

```cpp
const int N = 505;
int n, m, e, ans;
int mt[N];
bool vis[N];
vector<int> g[N];

bool dfs(int u) {
    for (int v : g[u]) {
        if (vis[v]) continue;
        vis[v] = true;
        if (!mt[v] || dfs(mt[v])) {
            mt[v] = u;
            return true;
        }
    }
    return false;
}

void solve() {
    cin >> n >> m >> e;
    For(i, 1, e) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v);
    }
    For(u, 1, n) {
        mset(vis, 0);
        if (dfs(u)) ans++;
    }
    cout << ans;
}
```

- `mt[v]` 是右点 $v$ 匹配的左点，0 表示未匹配。左右两边各自编号，只需要存左到右的边。
- 要输出方案时，遍历右点 $v$，`mt[v]` 非 0 的就是一对 `(mt[v], v)`。

### 3.3 行列建图：矩阵游戏

多组数据（在 `main` 中打开 `cin >> tests;`）。$n \times n$ 的 0/1 矩阵，可以任意交换两行或两列。问能否让主对角线全是 1。

**建模**：交换行列不会改变"哪一行的哪一列有 1"这种行列对应关系，只是换了位置。最终第 $i$ 行在对角线上的那个 1 来自原来的某一列，不同行用的列必须不同。所以：**行作为左点，列作为右点，格子 $(i, j)$ 是 1 就连边 $i - j$**，有解当且仅当存在完美匹配。反过来，有完美匹配"第 $i$ 行 → 第 $p_i$ 列"时，把第 $p_i$ 列换到第 $i$ 个位置即可。

```cpp
const int N = 205;
int n;
int mt[N], vis[N];
vector<int> g[N];

bool dfs(int u, int t) {
    for (int v : g[u]) {
        if (vis[v] == t) continue;
        vis[v] = t;
        if (!mt[v] || dfs(mt[v], t)) {
            mt[v] = u;
            return true;
        }
    }
    return false;
}

void solve() {
    cin >> n;
    For(i, 1, n) g[i].clear(), mt[i] = vis[i] = 0;
    For(i, 1, n)
        For(j, 1, n) {
            int x;
            cin >> x;
            if (x) g[i].pb(j);
        }
    For(i, 1, n)
        if (!dfs(i, i)) {
            cout << "No" << endl;
            return;
        }
    cout << "Yes" << endl;
}
```

这里用了**时间戳**代替清空：第 $t$ 轮把 `vis[v]` 记为 $t$，`vis[v] == t` 就表示本轮访问过。省掉每轮 `mset` 的 $O(\text{右点数})$，在左点多、边少的题里很有用。只要有一个左点匹配失败，就不可能是完美匹配，直接输出 `No`。

### 3.4 扩展域并查集：关押罪犯

$n$ 个罪犯分进两个监狱，$m$ 对罪犯之间有怨气值 $c$，同一监狱里的一对会爆发冲突，影响力为 $c$。要让最大的冲突影响力最小，输出它（没有冲突输出 0）。

贪心：按怨气**从大到小**依次尽量把两人分开。第一次发现"这两人已经被迫在同一监狱"时，这条边的怨气就是答案——更大的都已经成功分开了。

```cpp
const int N = 2e4 + 5, M = 1e5 + 5;
int n, m;
int fa[2 * N];
struct rel { int a, b, c; } e[M];

bool cmp(const rel &x, const rel &y) {
    return x.c > y.c;
}

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

void solve() {
    cin >> n >> m;
    For(i, 1, m) cin >> e[i].a >> e[i].b >> e[i].c;
    sort(e + 1, e + 1 + m, cmp);
    For(i, 1, 2 * n) fa[i] = i;
    For(i, 1, m) {
        int a = e[i].a, b = e[i].b;
        if (find(a) == find(b)) {
            cout << e[i].c;
            return;
        }
        fa[find(a)] = find(b + n), fa[find(a + n)] = find(b);
    }
    cout << 0;
}
```

这题也可以二分答案 + 染色：二分最大冲突值 $x$，只保留怨气 $> x$ 的边，判断是否为二分图。

## 4. 复杂度

设 $n$ 为点数，$m$ 为边数（匹配问题中 $n$ 为左点数）。

| 算法 | 时间 |
| --- | --- |
| 染色法判定 | $O(n + m)$ |
| 扩展域并查集判定 | $O(m \, \alpha(n))$，排序另加 $O(m \log m)$ |
| 匈牙利算法（邻接表） | $O(nm)$ |
| 匈牙利算法（邻接矩阵） | $O(n^3)$ |

匈牙利算法每个左点做一次 DFS，每次 DFS 每条边最多走一次。$O(nm)$ 是很松的上界，实际运行通常快得多，$n, m$ 在几千、边数 $10^5$ 左右一般都能过。更大规模的匹配要用网络流（Dinic），带权匹配要用 KM 算法，都超出 CSP 常规范围。

## 5. 常见题型与技巧

- **分两组 / 判矛盾**：关系是"必须不同"的，就是二分图判定。关系里既有"相同"又有"不同"时，用扩展域并查集（"相同"合并 $u, v$ 和 $u+n, v+n$；"不同"交叉合并）。
- **二分答案 + 二分图判定**：最小化"同组中最大的代价"。
- **每个连通块两种染色取优**：染色方案只有两种，比较两种颜色的点数、权值和。
- **行列建图**：格子 $(i, j)$ 看成连接"第 $i$ 行"和"第 $j$ 列"的边。
  - 每行每列至多选一个格子，最多选几个 → 最大匹配（不互相攻击的车）；
  - 用最少的"整行 / 整列"操作清除所有目标格子 → 最小点覆盖 = 最大匹配。
- **棋盘黑白染色**：$(i + j)$ 的奇偶性把格子分成两类，相邻格子一定异色，所以"相邻格"关系构成二分图。
  - $1 \times 2$ 骨牌最多放几块：相邻的两个可用格子连边，求最大匹配；
  - 放尽量多的棋子使两两不攻击（如马走"日"字，每一步都改变颜色）：攻击关系是二分图，答案是最大独立集 = 可用格数 − 最大匹配。
- **物品 / 属性匹配**：每件物品有两个可选属性，属性值作左点、物品作右点；"从 1 开始连续用到几"之类的问题，按属性值从小到大匹配，第一次失败就停。左点很多时用时间戳代替清空 `vis`。
- **DAG 最小路径覆盖**：拆点建二分图，点数 − 最大匹配。
- **输出匹配方案**：直接读 `mt` 数组。

## 6. 易错点

- **每轮忘记清空 `vis`**（或时间戳没有每轮更新）：后面的左点会被前面的标记挡住，匹配数偏小。
- **`vis` 标记在左点上**：标准写法标记的是右点。
- **在同一个编号空间里跑匹配**：如棋盘上所有格子统一编号时，要只从**一种颜色**的格子出发调用 `dfs`，边也只从这一侧连向另一侧。如果两边都出发、建双向边，每对会被算两次。
- **最大独立集用错点数**：$n$ 是二分图**两边点数之和**（棋盘题是所有可用格子数），不是一边的点数。
- **图不连通**：染色要对每个连通块都做一次。
- **扩展域并查集数组开小**：要开 $2n$。
- **完美匹配的判断**：左右点数不同时不可能完美匹配；中途有一个左点失败就可以提前结束。
- **多组数据**：清空邻接表、`mt`、`vis`（时间戳写法的 `vis` 也要清，因为 $t$ 会从 1 重新开始）。
