# 数组与结构体

**组别**：J　**关键词**：一维数组、二维数组、数组越界、memset、结构体、自定义排序、方向数组

## 1. 是什么 / 解决什么问题

**数组**是一串类型相同、在内存中连续存放的变量，用下标访问，`a[i]` 可以在 $O(1)$ 时间读写任意一个元素。几乎所有题目的数据都存在数组里。

**结构体**把几个相关的量（如一个学生的学号、语文成绩、总分）打包成一个整体，配合排序可以方便地处理"按多个条件排名"之类的问题。

## 2. 一维数组

### 2.1 声明与下标

```text
const int N = 1e5 + 5;
int a[N];
```

- 大小用常量 `N`，按数据范围最大值再多开一点（`+ 5`），防止边界上差一越界。
- **开在全局**：全局数组自动初始化为 0，且放在静态存储区，可以开到几百 MB；`solve()` 内的局部数组放在栈上，开太大会栈溢出，而且初值是随机的。
- 本仓库约定**下标从 1 开始**：`For(i, 1, n) cin >> a[i];`。好处是 `a[0]` 天然可以当"哨兵"或"空前缀"，例如前缀和 $s_i = s_{i-1} + a_i$ 在 $i = 1$ 时不用特判。

### 2.2 桶（计数数组）

当值域不大时，用值本身当下标：`cnt[x]++` 记录 $x$ 出现的次数。这就是**桶**，可以 $O(1)$ 判断某个值是否出现、出现几次，也是计数排序的基础。

```cpp
const int N = 1e5 + 5, V = 1e6 + 5;
int n, ans;
int a[N], s[N], cnt[V];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i], s[i] = s[i - 1] + a[i], cnt[a[i]]++;
    For(i, 0, 1000000) if (cnt[i] > cnt[ans]) ans = i;
    cout << s[n] << " " << ans << " " << cnt[ans] << endl;
}
```

输入 `6` 和 `3 1 3 2 3 1`，输出 `13 3 3`：总和 13，出现最多的是 3，出现 3 次。

### 2.3 越界

访问 `a[-1]` 或 `a[N]` 等不存在的位置叫**越界**。C++ 不检查越界，后果不确定：

- 写到别的变量上，导致莫名其妙的 WA（最难查）；
- 访问到非法内存，运行错误（RE）；
- 本地正常、评测机出错。

防越界的习惯：数组多开几个；循环边界想清楚是 $n$ 还是 $n+1$；访问 `a[i - 1]`、`a[i + 1]` 时检查 $i$ 的范围；本地用 `-fsanitize=address` 编译检查。

### 2.4 清空与填充

| 写法 | 作用 | 复杂度 |
| --- | --- | --- |
| `mset(a, 0)` | 全部置 0 | $O(\text{数组大小})$ |
| `mset(a, -1)` | 全部置 $-1$ | 同上 |
| `mset(a, 0x3f)` | 全部置为一个很大的数（64 位下为 `LINF`） | 同上 |
| `fill(a + 1, a + 1 + n, x)` | 把 $a_1 \sim a_n$ 置为任意值 $x$ | $O(n)$ |
| `For(i, 1, n) a[i] = 0;` | 只清用到的部分 | $O(n)$ |

`memset` 按**字节**赋值，所以 `mset(a, 1)` 得到的每个元素是 `0x0101010101010101`，不是 1。

多组数据时注意：如果数组开了 $10^7$、数据有 $10^5$ 组，每组 `mset` 一次就是 $10^{12}$ 次操作，必然超时。应该只清空本组用到的 $1 \sim n$。

### 2.5 数组作为函数参数

数组传给函数时只传了首地址（退化为指针），函数里修改会影响原数组，`sizeof` 也不再是数组大小。本仓库把数据放在全局，函数直接使用全局数组，一般不需要传参。

复制数组用 `memcpy(b, a, sizeof(a))`，两数组类型、大小相同。

## 3. 二维数组

`int g[N][M];` 表示 $N$ 行 $M$ 列的表格，`g[i][j]` 是第 $i$ 行第 $j$ 列。在内存中按**行**连续存放：`g[0][0], g[0][1], ..., g[0][M-1], g[1][0], g[1][1], ...`。

- 双重循环时，外层枚举行、内层枚举列，访问内存连续，速度快；反过来对大数组会慢好几倍。
- 空间是 $N \times M \times$ 元素大小。$5000 \times 5000$ 的 64 位数组是 200MB，要先算清楚。
- 网格题常用**方向数组**：把"上下左右"写成 `dx`、`dy`，用循环代替四段重复代码。网格外再留一圈（下标从 1 开始，`0` 和 $n+1$ 行列都是空的），越界检查可以省掉一部分。

例：扫雷游戏，给出 $n \times m$ 的地图（`*` 为雷，`?` 为空），输出每个空格周围 8 格的雷数。

```cpp
const int N = 105;
int n, m;
char g[N][N];
int dx[8] = {-1, -1, -1, 0, 0, 1, 1, 1};
int dy[8] = {-1, 0, 1, -1, 1, -1, 0, 1};

void solve() {
    cin >> n >> m;
    For(i, 1, n) For(j, 1, m) cin >> g[i][j];
    For(i, 1, n) {
        For(j, 1, m) {
            if (g[i][j] == '*') {
                cout << '*';
                continue;
            }
            int c = 0;
            Rep(k, 0, 8) c += g[i + dx[k]][j + dy[k]] == '*';
            cout << c;
        }
        cout << endl;
    }
}
```

`g` 是全局数组，第 0 行、第 $n+1$ 行、第 0 列、第 $m+1$ 列都是 `'\0'`，不是 `*`，所以边界格子不需要特判。输入

```text
3 3
*??
???
?*?
```

输出

```text
*10
221
1*1
```

四方向时只取 `dx = {-1, 1, 0, 0}`、`dy = {0, 0, -1, 1}`。如果题目规定了方向的顺序（如"东南西北"、"右转"），方向数组的顺序必须与题目一致，这样"右转"就是 `d = (d + 1) % 4`。

## 4. 结构体

### 4.1 定义

```text
struct stu { int id, a, b, c, sum; } s[N];
```

定义类型 `stu`，紧接着声明数组 `s`。访问成员用点号：`s[i].sum`。结构体可以整体赋值、整体交换（`swap(s[i], s[j])`）。

只有两个量时也可以直接用 `pair`（模板中的 `pii`），`p.F`、`p.S` 访问，自带"先比第一关键字、再比第二关键字"的比较。

### 4.2 结构体排序

`sort` 默认用 `<` 比较。结构体没有 `<`，需要写比较函数 `cmp(a, b)`：**当 `a` 应该排在 `b` 前面时返回 `true`**。多个关键字时逐个比较：

```cpp
const int N = 305;
int n;
struct stu { int id, a, b, c, sum; } s[N];

bool cmp(const stu &x, const stu &y) {
    if (x.sum != y.sum) return x.sum > y.sum;
    if (x.a != y.a) return x.a > y.a;
    return x.id < y.id;
}

void solve() {
    cin >> n;
    For(i, 1, n) {
        cin >> s[i].a >> s[i].b >> s[i].c;
        s[i].id = i, s[i].sum = s[i].a + s[i].b + s[i].c;
    }
    sort(s + 1, s + 1 + n, cmp);
    For(i, 1, min(n, 5LL)) cout << s[i].id << " " << s[i].sum << endl;
}
```

这是"奖学金"一题：按总分降序，总分相同按语文降序，再相同按学号升序，输出前 5 名。输入

```text
6
90 67 80
87 66 91
78 89 91
88 99 77
67 89 64
78 89 98
```

输出

```text
6 265
4 264
3 258
2 244
1 237
```

要点：

- 排序范围是 `s + 1` 到 `s + 1 + n`（左闭右开），对应 1-indexed 的 $s_1 \sim s_n$。
- `cmp` 参数写成 `const stu &`，避免每次比较都复制结构体。
- `min(n, 5LL)`：`n` 是 64 位，常量也要是 64 位（见《C++ 基础与竞赛规范》）。
- **`cmp` 在两者"相等"时必须返回 `false`**。写成 `x.sum >= y.sum` 违反了 `sort` 的要求（严格弱序），可能导致越界、死循环或 RE。

### 4.3 重载小于号

`set`、`priority_queue` 等容器需要元素自带 `<`，可以在结构体里重载：

```cpp
struct node {
    int d, u;
    bool operator<(const node &o) const { return d < o.d; }
} t[5];

void solve() {
    t[1] = {3, 1}, t[2] = {1, 2}, t[3] = {2, 3};
    sort(t + 1, t + 4);
    For(i, 1, 3) cout << t[i].u << " ";
    cout << endl;
}
```

输出 `2 3 1`（按 `d` 升序）。两个 `const` 都不能省，否则放进 `set`、`priority_queue` 时编译错误。

### 4.4 排序下标而不是排序数据

有时排序后还需要知道每个元素原来的位置，可以另开下标数组 `id[i] = i`，按 `a[id[i]]` 排序 `id`，原数组不动。或者把原下标作为结构体的一个成员一起排序。

## 5. 复杂度

- 数组下标访问 $O(1)$；遍历 $O(n)$；二维遍历 $O(nm)$。
- `memset`、`fill` 与填充的长度成正比。
- `sort` 为 $O(n \log n)$ 次比较；结构体很大时每次交换的代价也大，可以改为排序下标。
- 空间：元素个数 × 每个元素字节数。结构体大小是各成员之和（可能有少量对齐填充），用 `sizeof(stu)` 可以查看。

## 6. 常见题型与技巧

- **桶计数**：值域小时 `cnt[x]++`，统计出现次数、去重、找众数、计数排序（[CSP-J 2020 T2 直播获奖](#/P7072)）。
- **标记数组**：`vis[i] = 1` 表示访问过，模拟走格子、筛选。
- **网格模拟**：二维字符数组 + 方向数组；外围留空省去边界判断。
- **多关键字排序**：结构体 + `cmp`；或把要比较的量依次放进 `pair`。
- **哨兵**：`a[0]`、`a[n + 1]` 放一个特殊值，让循环不用判断边界。
- **滚动数组**：只需要上一行时，用 `f[2][M]` 交替使用（`i & 1`），节省空间。

## 7. 易错点

- 数组开小、下标 $0$ 和 $n+1$ 越界；二维数组行列写反。
- 局部大数组导致栈溢出；局部数组不初始化。
- `mset(a, 1)`；对传入函数的数组参数用 `mset`（只清 8 字节）。
- 多组数据每组 `mset` 整个大数组导致超时；或者忘记清空。
- `cmp` 用了 `>=` / `<=`；`sort(a, a + n)` 与 1-indexed 不一致，漏排 $a_n$、多排了 $a_0$。
- 二维数组内存估算错误。
