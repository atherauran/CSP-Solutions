# 位运算

**组别**：J　**关键词**：按位与、按位或、异或、移位、lowbit、状态压缩、子集枚举、按位贪心

## 1. 是什么 / 解决什么问题

计算机中整数以**二进制**存储。位运算直接对二进制的每一位进行操作，速度极快（一条机器指令）。它的用途包括：

- 快速完成乘除 2 的幂、判断奇偶、取某一位等基本操作；
- 用一个整数表示一个集合（**状态压缩**），枚举所有子集；
- 利用异或的特殊性质解题（成对抵消、前缀异或）；
- 按位拆分：每一位独立考虑，把问题化简（按位贪心、按位统计贡献）。

## 2. 二进制与补码

十进制 $13 = 8 + 4 + 1 = (1101)_2$。从右往左第 $k$ 位（从 0 开始编号）代表 $2^k$。

有符号整数用**补码**表示：非负数就是它的二进制；负数 $-x$ 的补码等于 $x$ 按位取反再加 1，即 $-x = \sim x + 1$。8 位为例：

```text
 5 = 0000 0101
~5 = 1111 1010 = -6
-5 = 1111 1011
```

所以 `~x == -x - 1` 恒成立。最高位是符号位，为 1 表示负数。详细内容见数学部分《进制与编码》。

## 3. 六种位运算

| 运算 | 符号 | 规则（逐位） | 例：$a = 12 = (1100)_2$，$b = 10 = (1010)_2$ |
| --- | --- | --- | --- |
| 按位与 | `&` | 都为 1 才为 1 | `a & b` $= (1000)_2 = 8$ |
| 按位或 | `\|` | 有一个 1 就为 1 | `a \| b` $= (1110)_2 = 14$ |
| 按位异或 | `^` | 不同为 1，相同为 0 | `a ^ b` $= (0110)_2 = 6$ |
| 按位取反 | `~` | 0 变 1，1 变 0 | `~a` $= -13$ |
| 左移 | `<<` | 整体左移，低位补 0 | `a << 2` $= 48$，即 $\times 2^2$ |
| 右移 | `>>` | 整体右移，丢掉低位 | `a >> 1` $= 6$，即 $\div 2$ 向下取整 |

```cpp
void solve() {
    int a = 12, b = 10;
    cout << (a & b) << " " << (a | b) << " " << (a ^ b) << " " << ~a << endl;
    cout << (a << 2) << " " << (a >> 1) << " " << (-7 >> 1) << " " << -7 / 2 << endl;
    cout << bitset<8>(a) << " " << bitset<8>(-a) << endl;
}
```

输出 `8 14 6 -13`、`48 6 -4 -3`、`00001100 11110100`。

注意 `-7 >> 1` 是 $-4$（向下取整），而 `-7 / 2` 是 $-3$（向零取整），负数时二者不同。`bitset<8>(x)` 可以把 $x$ 的低 8 位按二进制输出，调试很方便。

### 3.1 优先级陷阱

`&`、`|`、`^` 的优先级**低于**比较运算，移位 `<<`、`>>` 的优先级低于加减：

- `x & 1 == 0` 实际是 `x & (1 == 0)`，恒为 0。要写 `(x & 1) == 0`。
- `1 << n - 1` 实际是 `1 << (n - 1)`。
- `a + b ^ c` 实际是 `(a + b) ^ c`。

位运算参与比较或与加减混用时，**一律加括号**。`x >> k & 1` 没问题（`>>` 比 `&` 优先）。

### 3.2 移位的范围

- `1 << k` 中 `1` 是 32 位，$k \ge 31$ 时溢出。需要更多位时写 `1LL << k`（最多到 62）。
- 移位位数 $\ge$ 类型位数（如 `1LL << 64`）是未定义行为。
- 对负数左移是未定义行为（C++20 前），尽量只对非负数做移位。

## 4. 常用技巧

以下 $x$ 为非负整数，第 $k$ 位从 0 开始数。

| 目的 | 写法 |
| --- | --- |
| 取第 $k$ 位 | `x >> k & 1` |
| 第 $k$ 位置 1 | `x \| (1LL << k)` |
| 第 $k$ 位置 0 | `x & ~(1LL << k)` |
| 第 $k$ 位取反 | `x ^ (1LL << k)` |
| 判断奇偶 | `x & 1`（1 为奇数） |
| 乘 / 除以 $2^k$ | `x << k` / `x >> k` |
| 最低位的 1（lowbit） | `x & -x` |
| 去掉最低位的 1 | `x & (x - 1)` |
| 判断 $2$ 的幂 | `x > 0 && (x & (x - 1)) == 0` |
| 低 $k$ 位全 1 | `(1LL << k) - 1` |
| 1 的个数 | `__builtin_popcountll(x)` |
| 末尾 0 的个数 | `__builtin_ctzll(x)`（$x \ne 0$） |
| 最高位的位置 $\lfloor \log_2 x \rfloor$ | `63 - __builtin_clzll(x)`，g++ 下也可写 `__lg(x)`（$x \ne 0$） |

**lowbit 为什么是 `x & -x`**：设 $x$ 最低的 1 在第 $k$ 位，即 $x$ 形如 `...1000`（末尾 $k$ 个 0）。取反得 `...0111`，再加 1，末尾的 1 全部进位，得到 `...1000`。所以 $-x = \sim x + 1$ 在第 $k$ 位及以下与 $x$ 完全相同，而更高的位都与 $x$ 相反。两者按位与，高位全变成 0，只剩第 $k$ 位的那个 1。例如 $x = 12 = (1100)_2$，$-x$ 的低 4 位是 $(0100)_2$，`x & -x` $= 4$。lowbit 是树状数组的核心。

**`x & (x - 1)`**：$x - 1$ 把最低的 1 变成 0，它下面的 0 全变成 1，再与 $x$ 相与就去掉了最低的 1。反复执行直到 0，执行次数就是 1 的个数。

```cpp
inline int cnt1(int x) {
    int c = 0;
    while (x) x &= x - 1, c++;
    return c;
}

void solve() {
    int x = 44;
    cout << (x >> 3 & 1) << " " << (x | 1) << " " << (x & ~(1LL << 2)) << " " << (x ^ 8) << endl;
    cout << (x & -x) << " " << (x & (x - 1)) << " " << cnt1(x) << " " << __builtin_popcountll(x) << endl;
    cout << __builtin_ctzll(x) << " " << 63 - __builtin_clzll(x) << " " << ((x & (x - 1)) == 0) << " " << ((64 & 63) == 0) << endl;
}
```

$x = 44 = (101100)_2$，输出 `1 45 40 36`、`4 40 3 3`、`2 5 0 1`。

模板里 `int` 是 64 位，计数要用带 `ll` 后缀的 `__builtin_popcountll`、`__builtin_ctzll`；不带后缀的版本只看低 32 位。

## 5. 异或的性质

异或是"不进位的加法"，满足：

- $a \oplus 0 = a$，$a \oplus a = 0$；
- 交换律、结合律：一串数异或的结果与顺序无关；
- 自反性：$a \oplus b \oplus b = a$，所以若 $a \oplus b = c$，则 $a = b \oplus c$；
- $a + b = (a \oplus b) + 2(a \mathbin{\&} b)$：异或是不进位的和，与运算给出进位；由此 $a \oplus b \le a + b$。

应用：

1. **成对抵消**：一堆数中只有一个出现奇数次，其余都出现偶数次，全部异或起来就是它。
2. **前缀异或**：$pre_i = a_1 \oplus \dots \oplus a_i$，则区间 $[l, r]$ 的异或和为 $pre_r \oplus pre_{l-1}$（$pre_{l-1}$ 中的部分出现两次被抵消），与前缀和的思路一样，但不需要减法。
3. **翻转**：`x ^= 1` 在 0、1 之间切换；`v ^ 1` 可以在成对编号 $(2k, 2k+1)$ 间互相转换。

```cpp
const int N = 1e5 + 5;
int n, q, odd;
int a[N], pre[N];

void solve() {
    cin >> n >> q;
    For(i, 1, n) cin >> a[i], pre[i] = pre[i - 1] ^ a[i], odd ^= a[i];
    cout << odd << endl;
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << (pre[r] ^ pre[l - 1]) << endl;
    }
}
```

输入 `5 2`、`3 5 3 7 5`、询问 `1 3` 和 `2 5`。全部异或得 $7$（3、5 都出现两次被抵消），两个区间的异或和为 $3 \oplus 5 \oplus 3 = 5$ 和 $5 \oplus 3 \oplus 7 \oplus 5 = 4$。输出 `7`、`5`、`4`。

## 6. 状态压缩：用整数表示集合

$n$ 个元素（编号 $0 \sim n-1$）的子集可以用一个 $n$ 位二进制数 $s$ 表示：第 $i$ 位为 1 表示元素 $i$ 在集合中。例如 $n = 4$，$\{0, 2, 3\}$ 表示为 $(1101)_2 = 13$。

| 集合操作 | 位运算 |
| --- | --- |
| 元素 $i$ 是否在 $s$ 中 | `s >> i & 1` |
| 加入 / 删除元素 $i$ | `s \| (1 << i)` / `s & ~(1 << i)` |
| 并集 / 交集 | `a \| b` / `a & b` |
| 差集 $a \setminus b$ | `a & ~b` |
| 补集 | `((1 << n) - 1) ^ s` |
| $a$ 是否为 $b$ 的子集 | `(a & b) == a` |
| 元素个数 | `__builtin_popcountll(s)` |
| 全集 | `(1 << n) - 1` |

### 6.1 枚举所有子集

$0 \sim 2^n - 1$ 恰好对应全部 $2^n$ 个子集。例：$n$ 个物品重量为 $w_i$，有多少个子集的重量和恰好为 $m$？

```cpp
const int N = 25;
int n, m, ans;
int w[N];

void solve() {
    cin >> n >> m;
    Rep(i, 0, n) cin >> w[i];
    Rep(s, 0, 1 << n) {
        int sum = 0;
        Rep(i, 0, n) if (s >> i & 1) sum += w[i];
        if (sum == m) ans++;
    }
    cout << ans << endl;
}
```

输入 `4 5` 和 `1 2 3 4`，和为 5 的子集有 $\{1, 4\}$、$\{2, 3\}$，输出 `2`。复杂度 $O(n \cdot 2^n)$，$n \le 20$ 左右可行。这里物品从 0 编号，与二进制位对应更自然。

### 6.2 枚举一个集合的所有子集

```cpp
void solve() {
    int s = 13;
    for (int t = s; t; t = (t - 1) & s) cout << t << " ";
    cout << 0 << endl;
}
```

$s = 13 = (1101)_2$，输出 `13 12 9 8 5 4 1 0`，按从大到小的顺序给出全部 $2^3 = 8$ 个子集。`(t - 1) & s` 是"比 $t$ 小的最大的 $s$ 的子集"：减 1 把 $t$ 最低的 1 变 0、下面全变 1，再与 $s$ 相与只保留 $s$ 中有的位。空集 $0$ 要单独处理（循环条件是 `t` 非 0）。

如果对 $0 \sim 2^n - 1$ 的每个 $s$ 都枚举它的子集，总次数是 $3^n$：每个元素有"不在 $s$ 中""在 $s$ 中不在 $t$ 中""在 $t$ 中"三种状态。$n = 15$ 时 $3^{15} \approx 1.4 \times 10^7$，可行。

状态压缩更多用于**状压 DP**，见动态规划部分。

## 7. 按位拆分

不同二进制位之间，与、或、异或运算**互不影响**（没有进位）。所以很多问题可以每一位单独考虑。

### 7.1 按位统计贡献

求 $\sum_{i < j} (a_i \oplus a_j)$。直接枚举是 $O(n^2)$。按位看：第 $k$ 位上，若有 $c$ 个数该位为 1、$n - c$ 个为 0，那么恰好 $c(n - c)$ 对的异或在这一位上是 1，贡献 $c(n - c) \cdot 2^k$。

```cpp
const int N = 1e5 + 5;
int n, ans;
int a[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    Rep(k, 0, 30) {
        int c = 0;
        For(i, 1, n) c += a[i] >> k & 1;
        ans += c * (n - c) * (1LL << k);
    }
    cout << ans << endl;
}
```

输入 `3` 和 `1 2 3`：$1 \oplus 2 + 1 \oplus 3 + 2 \oplus 3 = 3 + 2 + 1 = 6$，输出 `6`。复杂度 $O(30n)$。与、或同理：与运算在第 $k$ 位为 1 需要两个都是 1，有 $\binom{c}{2}$ 对。

### 7.2 按位贪心

二进制下，第 $k$ 位的 1 比所有更低位的 1 加起来还大（$2^k > 2^{k-1} + \dots + 1$）。所以求"最大的与 / 或 / 异或值"时，可以**从高位到低位**依次尝试让这一位为 1：能做到就固定下来，再考虑下一位。[CSP-J 2026 T3 按位与](#/P17829) 就是这种做法。

### 7.3 格雷码

$n$ 位格雷码中相邻两个数只有一位不同。第 $i$ 个格雷码有闭式 $G(i) = i \oplus (i \gg 1)$。

```cpp
int n;

void solve() {
    cin >> n;
    Rep(i, 0, 1 << n) {
        int g = i ^ (i >> 1);
        for (int k = n - 1; k >= 0; k--) cout << (g >> k & 1);
        cout << " ";
    }
    cout << endl;
}
```

$n = 3$ 输出 `000 001 011 010 110 111 101 100`。

## 8. 复杂度

- 单个位运算 $O(1)$，比乘除、取模快。`__builtin_popcountll` 等内建函数也是 $O(1)$。
- 枚举 $n$ 元集合的全部子集 $O(2^n)$；对每个集合枚举其子集，总共 $O(3^n)$。
- 按位拆分通常是 $O(n \log V)$，$V$ 为值域。
- 状态压缩的空间：$2^n$ 个状态，$n = 20$ 时约 $10^6$，$n = 25$ 时约 $3.3 \times 10^7$。

## 9. 常见题型与技巧

- **二进制拆分**：任何正整数可以唯一表示为若干不同的 2 的幂之和（[CSP-J 2020 T1 优秀的拆分](#/P7071)）。这也是倍增、二进制优化多重背包的依据。
- **集合用整数表示**：小集合（$n \le 20$）的枚举、判重、状压 DP。
- **异或抵消**：找出现奇数次的数；前缀异或把区间异或转化为两个前缀的关系（[CSP-J 2025 T3 异或和](#/P14359)）。
- **按位独立**：每一位分别统计、分别判断（[CSP-S 2020 T2 动物园](#/P7076)）。
- **按位贪心**：从高位到低位确定答案。
- **用 64 位整数当 64 个布尔值**：`bitset<N>` 支持 `&`、`|`、`^`、`<<`、`count()` 等，一次运算处理 64 位，可以把某些 $O(n^2)$ 的布尔运算加速 64 倍。

## 10. 易错点

- 优先级：`x & 1 == 0`、`a ^ b > 0` 之类没有加括号。
- `1 << k` 溢出，应写 `1LL << k`；`1LL << 64` 未定义。
- 在 64 位下使用 `__builtin_popcount`（只算低 32 位）。
- `__builtin_ctzll(0)`、`__builtin_clzll(0)`、`__lg(0)` 结果未定义。
- 负数右移向下取整，与 `/ 2` 不同；负数的位运算结果不直观，尽量用非负数。
- 状态压缩时位编号从 0 还是 1 开始要统一。
- 子集枚举 `for (t = s; t; t = (t - 1) & s)` 漏掉空集。
- 异或交换 `a ^= b ^= a ^= b` 不要用：可读性差，`a`、`b` 是同一个变量时会变成 0。
