# 模拟与枚举

**组别**：J　**关键词**：模拟、枚举、暴力、方向数组、日期计算、子集枚举、排列枚举

## 1. 是什么 / 解决什么问题

- **模拟**：题目把过程描述得很清楚（机器人怎么走、规则怎么判、时间怎么流逝），我们就用程序**照着过程一步一步做**。难点不在算法，而在把文字准确翻译成代码。
- **枚举**：答案落在一个有限的集合里，就把集合里的每个候选**逐一列出来检验**。难点在于"列什么、列多大范围、怎么判断"。

两者合起来就是常说的**暴力**。它们是所有算法的起点：

1. CSP-J 的 T1、T2 经常就是纯模拟或枚举；CSP-S 的 T1 也常是"枚举 + 一点观察"。
2. 想不出正解时，暴力能稳拿部分分。
3. 写出正解后，暴力可以用来和正解比对结果，检查正解对不对。

## 2. 核心原理

### 2.1 模拟：把题面翻译成代码

写模拟题的通用步骤：

1. **逐句读题，列出状态**：过程中有哪些量在变？（位置、方向、时间、每个人的分数……）把它们设计成变量或数组。
2. **列出操作**：每一步状态怎么变？分成几种情况？把每种操作写成一个函数，主流程只负责调用。
3. **确认终止条件**：走多少步、什么时候停。
4. **手推样例**：对照样例一步步核对中间状态，最容易发现理解偏差。

几个常用技巧：

**方向数组。** 在网格里移动时，把四个方向的坐标变化存进数组，用一个整数 $d$ 表示朝向：

```
d:   0   1   2   3
     东  南  西  北
dx:  0   1   0  -1      (行号 +1 表示往下)
dy:  1   0  -1   0
```

"右转"就是 $d \gets (d + 1) \bmod 4$，"左转"是 $d \gets (d + 3) \bmod 4$，"掉头"是 $d \gets (d + 2) \bmod 4$。方向按顺时针排好，转向就只剩取模，不用写一堆 `if`。八方向同理，开长度为 8 的数组。

**环形结构取模。** $n$ 个人围成一圈，编号 $0 \sim n-1$ 时，第 $i$ 个人往右数 $k$ 个是 $(i + k) \bmod n$，往左数是 $(i - k \bmod n + n) \bmod n$。编号从 1 开始时先减 1 再取模再加 1。

**日期计算。** 闰年规则：能被 4 整除且不能被 100 整除，或者能被 400 整除。用 `days[13]` 存每月天数，2 月单独判断。逐日推进很好写，但如果要推进 $10^9$ 天就必须**整段跳**：先按 400 年（恰好 146097 天）跳，再按年跳，最后按月、按日（CSP-S 2020 儒略日就是这样）。

**按周期或按段加速。** 当步数达到 $10^9$ 这种量级，逐步模拟一定超时。常见的加速方法：

- 过程有周期：找到周期长度后直接取模；
- 每一步让规模按比例缩小：比如每轮去掉 $\lceil n/3 \rceil$ 个，只需 $O(\log n)$ 轮；
- 很多步效果相同：把它们合成一步（整年、整月地跳）。

### 2.2 枚举：三个要素

设计枚举时要想清楚三件事：

| 要素 | 问自己 |
| --- | --- |
| 枚举对象 | 枚举什么？（一个数、一对数、一个子集、一个排列） |
| 枚举范围 | 每个变量的上下界是多少？能不能缩小？ |
| 判断条件 | 怎么检验一个候选合不合法？检验要花多久？ |

总复杂度 = 候选个数 × 检验一个候选的代价。

**例：百钱买百鸡。** 公鸡 5 元一只，母鸡 3 元一只，小鸡 1 元三只，100 元买 100 只鸡，求所有方案。

- 直接枚举公鸡 $x$、母鸡 $y$、小鸡 $z$ 三重循环，每个都到 100，约 $10^6$ 次。
- **减少枚举变量**：$z = 100 - x - y$ 由前两个决定，只需两重循环。
- **缩小范围**：$5x \le 100$ 得 $x \le 20$；$3y \le 100$ 得 $y \le 33$。只剩 $21 \times 34 \approx 700$ 次。

这个例子展示了枚举优化的两个基本手段。更多的手段：

- **换枚举对象。** 求"满足条件的数对 $(i, j)$ 个数"时，如果枚举 $i$ 后满足条件的 $j$ 能直接算出（用桶或数组查表），就从 $O(n^2)$ 降到 $O(n)$。
- **枚举答案再检验。** 与其枚举所有过程，不如枚举最终答案。CSP-S 2023 密码锁：与其枚举"正确密码是什么"再检验，不如从每个已知状态出发反推出它可能对应的 81 个密码，计数后看哪些密码被每个状态都覆盖。
- **枚举中间、两边预处理。** 要选 $A \to B \to C \to D$ 四个点时，枚举中间的 $(B, C)$，两端的 $A$、$D$ 预先为每个点算好"最优的几个"，把 $O(n^4)$ 变成 $O(n^2)$（CSP-S 2022 假期计划）。
- **利用对称性和单调性剪掉不可能的情况**，比如规定 $x \le y \le z$ 避免重复枚举同一组。

### 2.3 子集枚举

$n$ 个物品，每个选或不选，共 $2^n$ 种方案。用一个 $n$ 位二进制数 $s$ 表示方案：第 $i$ 位为 1 表示选第 $i$ 个物品。$s$ 从 $0$ 枚举到 $2^n - 1$ 就遍历了所有子集。

```
n = 3, 物品 a1 a2 a3
s = 0 (000): {}
s = 1 (001): {a1}
s = 2 (010): {a2}
s = 3 (011): {a1, a2}
...
s = 7 (111): {a1, a2, a3}
```

判断第 $i$ 位（从 0 开始）：`s >> i & 1`。$n \le 20$ 时 $2^n \approx 10^6$，再乘一个 $n$ 的检验代价也能接受。

### 2.4 排列枚举

要枚举 $1 \sim n$ 的所有排列（$n!$ 种），可以用 STL 的 `next_permutation`：它把数组变成字典序的下一个排列，已经是最后一个时返回 `false`。所以先把数组排成升序，再用 `do ... while` 循环。$n \le 10$ 时 $10! \approx 3.6 \times 10^6$ 可以接受，$n = 11$ 就已经接近 $4 \times 10^7$ 再乘检验代价，要小心。

需要剪枝的排列、组合枚举一般用 DFS 回溯来写，见《深度优先搜索与回溯》。

## 3. 代码模板

**网格模拟（方向数组）**：$n \times m$ 地图，`.` 可走、`x` 是障碍。机器人从 $(x, y)$ 出发朝向 $d$，共操作 $k$ 次：前方能走就前进一格，否则右转。求经过的不同格子数。

```cpp
const int N = 1e3 + 5;
int n, m, k, x, y, d, ans;
int dx[4] = {0, 1, 0, -1}, dy[4] = {1, 0, -1, 0};
char g[N][N];
bool vis[N][N];

void solve() {
    cin >> n >> m >> k >> x >> y >> d;
    For(i, 1, n) cin >> (g[i] + 1);
    vis[x][y] = true, ans = 1;
    while (k--) {
        int nx = x + dx[d], ny = y + dy[d];
        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m && g[nx][ny] == '.') {
            x = nx, y = ny;
            if (!vis[x][y]) vis[x][y] = true, ans++;
        } else d = (d + 1) % 4;
    }
    cout << ans;
}
```

**日期推进**：输出 $y$ 年 $m$ 月 $d$ 日之后第 $k$ 天的日期。$k$ 很大时要改成整年整月地跳。

```cpp
int y, m, d, k;
int days[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

inline bool leap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
}

inline int mdays(int y, int m) {
    return m == 2 && leap(y) ? 29 : days[m];
}

void solve() {
    cin >> y >> m >> d >> k;
    while (k--) {
        d++;
        if (d > mdays(y, m)) d = 1, m++;
        if (m > 12) m = 1, y++;
    }
    cout << y << " " << m << " " << d;
}
```

**百钱买百鸡（减少枚举变量 + 缩小范围）**：

```cpp
void solve() {
    For(x, 0, 20) For(y, 0, 33) {
        int z = 100 - x - y;
        if (z >= 0 && z % 3 == 0 && 5 * x + 3 * y + z / 3 == 100) cout << x << " " << y << " " << z << endl;
    }
}
```

**子集枚举**：$n \le 20$ 个数中选若干个，和恰好为 $m$ 的方案数。

```cpp
const int N = 25;
int n, m, ans;
int a[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i];
    Rep(s, 0, 1 << n) {
        int sum = 0;
        Rep(i, 0, n)
            if (s >> i & 1) sum += a[i + 1];
        if (sum == m) ans++;
    }
    cout << ans;
}
```

**排列枚举**：把 $1 \sim 9$ 分成三个三位数，比例为 $1:2:3$。

```cpp
int p[10];

void solve() {
    For(i, 1, 9) p[i] = i;
    do {
        int a = p[1] * 100 + p[2] * 10 + p[3];
        int b = p[4] * 100 + p[5] * 10 + p[6];
        int c = p[7] * 100 + p[8] * 10 + p[9];
        if (b == 2 * a && c == 3 * a) cout << a << " " << b << " " << c << endl;
    } while (next_permutation(p + 1, p + 10));
}
```

## 4. 复杂度

- 模拟：**总步数 × 每步代价**。网格模拟 $O(k)$；逐日推进 $O(k)$，按年月跳后约 $O(\text{年数} + 12)$。
- 枚举：**候选个数 × 检验代价**。

| 枚举方式 | 候选个数 | 大致可承受的规模 |
| --- | --- | --- |
| 单变量 | $n$ | $n \le 10^8$ |
| 两重循环 | $n^2$ | $n \le 10^4$ |
| 三重循环 | $n^3$ | $n \le 500$ |
| 子集 | $2^n$ | $n \le 20 \sim 25$ |
| 排列 | $n!$ | $n \le 10$ |

估算时以"每秒约 $10^8$ 次简单运算"为准，具体见《时间与空间复杂度》。

## 5. 常见题型与技巧

1. **规则型模拟**：字符串处理、成绩排名、座位安排、游戏规则。关键是读准题，例如"严格大于"还是"大于等于"、编号从 0 还是从 1 开始、平局怎么处理。
2. **大模拟**：规则多、代码长（CSP-S 2023 结构体）。按功能拆函数，每个函数单独测试；变量名起得清楚一点；先写主干，再补特殊情况。
3. **时间类模拟**：日期、时刻、周期。注意闰年、跨月跨年，规模大时整段跳。
4. **用数据结构辅助模拟**：要频繁"找最早的""删掉某个"时，配合队列、链表、`set`、优先队列来模拟，避免每次线性扫描。
5. **枚举 + 观察**：先写朴素枚举，再想"哪个变量能由其他变量算出""哪一层循环能用预处理替代"，一层一层地把复杂度降下来。
6. **状态压缩枚举**：可选项很少（如 $k \le 10$）而其他部分很大时，枚举这 $2^k$ 种选法，每种再跑一遍多项式算法（CSP-S 2025 道路修复）。
7. **暴力拿部分分**：读完题先看数据范围，写出能过小数据的暴力，再想正解。暴力本身也是检验正解的工具。

## 6. 易错点

- **越界**：方向数组走出网格前先判边界；字符串下标、数组下标从 0 还是 1 要统一。
- **溢出**：模拟乘方、累乘时中间结果可能超过 $2^{63}$。可以在每一步检查是否已经超过上限，超过就提前停止（CSP-J 2022 乘方）。
- **整数除法与取模**：C++ 中负数除法向 0 取整，`-7 % 3` 等于 `-1`；环形下标往左走要先加 $n$ 再取模。
- **闰年判断写错**：1900 年不是闰年，2000 年是。
- **多组数据没清空**：全局数组、计数器、标记数组在每组开始时要重置。
- **枚举范围少一个**：`For` 是闭区间、`Rep` 是半开区间，循环上界写错会漏掉边界情况。
- **浮点比较**：能用整数就用整数（比如把除法改写成乘法比较），必须用浮点时比较要带误差 $\varepsilon$。
- **低估规模**：步数或候选数达到 $10^9$ 时，必须找到跳跃或优化方法，不能硬模拟。
