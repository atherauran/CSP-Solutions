# 分治与递推

**组别**：J　**关键词**：分治、递推、递归、归并排序、快速幂、递推关系、卡特兰数、错排

## 1. 是什么 / 解决什么问题

分治和递推是两种"把大问题交给小问题"的思路：

- **分治**（分而治之）：把问题**拆成几个规模更小的同类子问题**，分别解决，再把子问题的答案**合并**起来。通常用递归实现，自顶向下。
- **递推**：找到第 $n$ 项和前面若干项之间的关系（递推式），从已知的初始项出发，**一项一项往后算**。通常用循环实现，自底向上。

二者都依赖"大问题的答案能由小问题的答案得到"。它们是后面很多内容的基础：归并排序、快速排序、二分是分治；动态规划本质上是带"选择"的递推；线段树也是分治结构。

## 2. 分治

### 2.1 三个步骤

1. **分解**：把原问题分成若干个规模更小、形式相同的子问题；
2. **解决**：递归地解决子问题，规模足够小时直接求解（递归边界）；
3. **合并**：把子问题的解组合成原问题的解。

分治的关键是第 3 步：**合并要比直接求解容易**。如果合并和原问题一样难，分治就没有意义。

### 2.2 例：归并排序与逆序对

把数组分成两半，各自排序，再把两个有序序列合并。合并是 $O(n)$ 的双指针，比直接排序容易得多。合并时顺便统计跨越两半的逆序对。详见《排序》。

### 2.3 例：快速幂

求 $a^b \bmod p$，$b$ 可达 $10^{18}$。逐个相乘要 $b$ 次，太慢。分治：

$$a^b = \begin{cases} 1 & b = 0 \\ (a^{b/2})^2 & b \text{ 为偶数} \\ (a^{\lfloor b/2 \rfloor})^2 \cdot a & b \text{ 为奇数} \end{cases}$$

只需要递归求一次 $a^{\lfloor b/2 \rfloor}$，平方一下就得到答案。每次 $b$ 减半，只需 $O(\log b)$ 次乘法。

注意：$(a^{b/2})^2$ 只递归**一次**，把结果存到变量里再相乘。如果写成 `qpow(a, b / 2) * qpow(a, b / 2)`，递归会分成两支，复杂度退化成 $O(b)$。非递归的写法（按 $b$ 的二进制位）见《模运算、快速幂与逆元》。

### 2.4 例：最大子段和

求数组中和最大的连续子段。从中点 $mid$ 切开，最优子段只有三种可能：

1. 完全在左半 $[l, mid]$：递归；
2. 完全在右半 $[mid + 1, r]$：递归；
3. **跨过中点**：它一定由"以 $mid$ 结尾的一段"和"以 $mid + 1$ 开头的一段"拼成。两段互不影响，分别从中点向两边扫一遍，求出最大后缀和、最大前缀和，相加即可，$O(r - l + 1)$。

```
          l          mid mid+1        r
a:        2  -4   3  -1 |  2  -4   3
以 mid 结尾的最大和:  3 + (-1) = 2
以 mid+1 开头的最大和: 2
跨中点的最优 = 2 + 2 = 4   (3 -1 2)
```

这道题也有 $O(n)$ 的递推做法（见下文和《前缀和与差分》），但"按中点切开，分别处理左、右、跨中点三种情况"是分治最典型的套路，很多更难的问题（平面最近点对、按中点统计点对）都用同样的框架。

### 2.5 例：分形与递归构造

很多题目的对象本身就是递归定义的：$n$ 级图形由 $n - 1$ 级图形拼成，$n$ 位编码由 $n - 1$ 位编码构造出来。这时求"第 $k$ 个位置是什么"不需要把整个对象造出来（它的长度往往是 $2^n$），只要判断 $k$ 落在哪一部分，就把问题变成规模减一的同类问题。

**例：** 字符串 $S_0 = \texttt{0}$，$S_n = S_{n-1} + \overline{S_{n-1}}$（$\overline{S}$ 表示把 $S$ 中的 0、1 互换）。

```
S0 = 0
S1 = 0 1
S2 = 01 10
S3 = 0110 1001
```

求 $S_n$ 的第 $k$ 个字符（从 0 开始编号），$n \le 60$。$S_n$ 长 $2^n$，前一半是 $S_{n-1}$，后一半是 $S_{n-1}$ 取反：

- $k < 2^{n-1}$：答案等于 $S_{n-1}$ 的第 $k$ 个；
- 否则：答案等于 $S_{n-1}$ 的第 $k - 2^{n-1}$ 个取反。

递归 $n$ 层就到 $S_0$。（观察这个递归可以发现：每遇到 $k$ 二进制的一个 1 就取反一次，所以答案就是 $k$ 二进制中 1 的个数的奇偶性。从递归出发找规律，是这类题常见的思路。）

CSP-S 2019 格雷码就是同样的结构：按前一半、后一半（逆序）递归确定每一位。

### 2.6 分治的复杂度

画出**递归树**，把每层的工作量加起来：

| 递推式 | 例子 | 结果 |
| --- | --- | --- |
| $T(n) = T(n/2) + O(1)$ | 二分查找、快速幂 | $O(\log n)$ |
| $T(n) = T(n/2) + O(n)$ | 快速选择（期望） | $O(n)$ |
| $T(n) = 2T(n/2) + O(1)$ | 遍历线段树的所有结点 | $O(n)$ |
| $T(n) = 2T(n/2) + O(n)$ | 归并排序、最大子段和分治 | $O(n \log n)$ |
| $T(n) = 2T(n/2) + O(n \log n)$ | 每层合并时排序 | $O(n \log^2 n)$ |

以 $T(n) = 2T(n/2) + O(n)$ 为例：第 0 层 1 个规模 $n$ 的问题，合并 $O(n)$；第 1 层 2 个规模 $n/2$ 的问题，合并共 $O(n)$；……每层都是 $O(n)$，共 $\log n$ 层，总计 $O(n \log n)$。

## 3. 递推

### 3.1 怎么找递推式

递推的核心是**设好状态，找到 $f(n)$ 与更小的状态之间的关系**。常用的切入点：

- **考虑最后一步**：最后一步有哪几种可能？每种可能之前是什么状态？
- **考虑第一个元素（或第 $n$ 个元素）的去向**：它放在哪里？放下之后剩下的部分是不是同类的更小问题？
- **加入第 $n$ 个元素会新增多少**：比如第 $n$ 条直线最多和前 $n - 1$ 条交出 $n - 1$ 个点，被分成 $n$ 段，每段多分出一个区域。

写递推时要明确三件事：**状态的含义、递推式、初始值**，以及计算顺序（保证用到的项已经算好）。

### 3.2 经典递推

**爬楼梯 / 斐波那契。** 每次走 1 级或 2 级，走到第 $n$ 级的方法数。最后一步从 $n - 1$ 级或 $n - 2$ 级上来：

$$f_n = f_{n-1} + f_{n-2}, \quad f_1 = 1,\ f_2 = 2.$$

**骨牌覆盖。** 用 $1 \times 2$ 的骨牌铺满 $2 \times n$ 的格子。看最左边一列：竖放一块，剩下 $2 \times (n - 1)$；横放的话上下必须各放一块，剩下 $2 \times (n - 2)$。递推式也是 $f_n = f_{n-1} + f_{n-2}$。

```
竖放:  |  + 2×(n-1)        横放:  ==  + 2×(n-2)
       |                          ==
```

**网格路径。** 只能向右或向下，从左上角走到 $(i, j)$ 的方法数：最后一步从上方或左方来，$f_{i,j} = f_{i-1,j} + f_{i,j-1}$。有障碍的格子 $f = 0$（过河卒）。

**汉诺塔。** 把 $n$ 个盘子从 A 移到 C：先把上面 $n - 1$ 个移到 B，再移最大的，再把 $n - 1$ 个移到 C。$H_n = 2H_{n-1} + 1$，$H_1 = 1$，解得 $H_n = 2^n - 1$。

**平面分割。** $n$ 条直线最多把平面分成几块？第 $n$ 条直线与前面每条都相交且交点各不相同时，被分成 $n$ 段，每段把一个区域一分为二：$L_n = L_{n-1} + n$，$L_0 = 1$，所以 $L_n = \frac{n(n+1)}{2} + 1$。

**错排。** $n$ 个人的帽子全部拿错（没有人拿到自己的）的方案数 $D_n$。考虑第 $n$ 个人拿到了第 $k$ 个人的帽子（$k$ 有 $n - 1$ 种选择）：

- 第 $k$ 个人恰好拿到第 $n$ 个人的帽子：两人互换，剩下 $n - 2$ 人错排，$D_{n-2}$ 种；
- 第 $k$ 个人没拿第 $n$ 个人的帽子：把"第 $n$ 个人的帽子"看作第 $k$ 个人"不能拿的那顶"，就是 $n - 1$ 人的错排，$D_{n-1}$ 种。

$$D_n = (n - 1)(D_{n-1} + D_{n-2}), \quad D_1 = 0,\ D_2 = 1.$$

**卡特兰数。** $1 \sim n$ 依次进栈，可能的出栈序列有多少种？设第一个进栈的元素 1 是第 $k$ 个出栈的。那么在它出栈前，$2 \sim k$ 这 $k - 1$ 个数已经进栈又出栈（一个规模 $k - 1$ 的子问题）；它出栈后，$k + 1 \sim n$ 这 $n - k$ 个数构成另一个独立的子问题：

$$h_n = \sum_{k=1}^{n} h_{k-1} h_{n-k}, \quad h_0 = 1.$$

$h_n$ 依次为 $1, 1, 2, 5, 14, 42, 132, \ldots$。同样的递推式还描述：$n$ 对括号的合法序列数、$n$ 个结点的二叉树形态数、凸 $n + 2$ 边形的三角剖分数、网格中不越过对角线的路径数。它也有通项 $h_n = \frac{1}{n+1}\binom{2n}{n}$。

**组合数（杨辉三角）。** $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$：第 $n$ 个元素选或不选。详见《排列组合与计数》。

### 3.3 递推与递归、记忆化

斐波那契数列也可以直接写成递归 `f(n) = f(n - 1) + f(n - 2)`，但这样 $f(n - 2)$ 会被 $f(n)$ 和 $f(n - 1)$ 各算一次，越往下重复越多，复杂度是指数级。

解决办法：

- **递推**：从小到大用循环算，每项只算一次，$O(n)$；
- **记忆化搜索**：保留递归写法，但算过的结果存进数组，下次直接返回。

两者等价，递推通常更快、不会爆栈；记忆化在计算顺序不好确定时更方便。

分治的子问题互不重叠（左半和右半没有公共部分），所以不需要记忆化；递推（以及动态规划）的子问题大量重叠，所以要保存结果。这是两种思路的一个本质区别。

### 3.4 递推的方向

递推不一定从前往后。只要每个状态依赖的状态先算好就行：

- **顺推**：$f_i$ 依赖 $f_{i-1}, f_{i-2}, \ldots$，从小到大算；
- **倒推**：$f_i$ 依赖 $f_{i+1}$ 或 $f_{nxt_i}$（$nxt_i > i$），从大到小算（CSP-J 2026 纸牌游戏）；
- **按编号**：树上如果保证父亲编号小于儿子，按编号从小到大递推就保证父亲先算，不需要 DFS（CSP-S 2019 括号树）。

### 3.5 数值处理

递推的数增长很快：斐波那契第 90 项就接近 $2^{63}$，卡特兰数第 36 项、错排第 21 项会超过 `long long`。题目通常让你**对某个数取模**（每次加法、乘法后都取模），或者要求**高精度**（如数楼梯，$n = 5000$）。

## 4. 代码模板

**快速幂（递归分治）**：求 $a^b \bmod p$。

```cpp
int a, b, p;

int qpow(int a, int b) {
    if (b == 0) return 1 % p;
    int t = qpow(a, b / 2);
    t = t * t % p;
    if (b % 2 == 1) t = t * a % p;
    return t;
}

void solve() {
    cin >> a >> b >> p;
    cout << qpow(a % p, b);
}
```

**最大子段和（分治）**：

```cpp
const int N = 2e5 + 5;
int n;
int a[N];

int calc(int l, int r) {
    if (l == r) return a[l];
    int mid = (l + r) / 2;
    int res = max(calc(l, mid), calc(mid + 1, r));
    int ls = -LINF, rs = -LINF, sum = 0;
    for (int i = mid; i >= l; i--) sum += a[i], ls = max(ls, sum);
    sum = 0;
    For(i, mid + 1, r) sum += a[i], rs = max(rs, sum);
    return max(res, ls + rs);
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    cout << calc(1, n);
}
```

**递归构造求第 $k$ 位**：

```cpp
int n, k;

int f(int n, int k) {
    if (n == 0) return 0;
    int h = 1LL << (n - 1);
    if (k < h) return f(n - 1, k);
    return 1 - f(n - 1, k - h);
}

void solve() {
    cin >> n >> k;
    cout << f(n, k);
}
```

**网格路径递推（过河卒）**：棋盘坐标 $(0, 0) \sim (n, m)$，马在 $(x, y)$，马和它能跳到的点都不能走。整体平移 1 变成 1-indexed，`f[1][0] = 1` 作为起点的"来源"。

```cpp
const int N = 25;
int n, m, x, y;
int f[N][N];
bool ban[N][N];
int dx[9] = {0, 1, 2, 2, 1, -1, -2, -2, -1}, dy[9] = {0, 2, 1, -1, -2, -2, -1, 1, 2};

void solve() {
    cin >> n >> m >> x >> y;
    n++, m++, x++, y++;
    Rep(k, 0, 9) {
        int nx = x + dx[k], ny = y + dy[k];
        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m) ban[nx][ny] = true;
    }
    f[1][0] = 1;
    For(i, 1, n) For(j, 1, m)
        if (!ban[i][j]) f[i][j] = f[i - 1][j] + f[i][j - 1];
    cout << f[n][m];
}
```

**卡特兰数与错排**：$n \le 20$，同时输出 $h_n$ 和 $D_n$。

```cpp
const int N = 40;
int n;
int h[N], d[N];

void solve() {
    cin >> n;
    h[0] = 1;
    For(i, 1, n) Rep(j, 0, i) h[i] += h[j] * h[i - 1 - j];
    d[1] = 0, d[2] = 1;
    For(i, 3, n) d[i] = (i - 1) * (d[i - 1] + d[i - 2]);
    cout << h[n] << " " << d[n];
}
```

## 5. 复杂度

- 快速幂：$O(\log b)$，递归深度 $O(\log b)$。
- 最大子段和分治：$O(n \log n)$，递归深度 $O(\log n)$。
- 递归构造求第 $k$ 位：$O(n)$。
- 一维递推（斐波那契、错排）：$O(n)$；二维网格递推：$O(nm)$；卡特兰数按定义递推：$O(n^2)$。

## 6. 常见题型与技巧

1. **规模减半**：$b$ 到 $10^{18}$、$n$ 到 $2^{60}$ 时，想"能不能每次减半"，即快速幂式的分治或逐位确定。
2. **按中点切开**：统计跨中点的贡献（逆序对、最大子段和、点对），左右各自递归。
3. **递归定义的对象**：分形图形、格雷码、倍增构造的字符串，判断目标在哪一部分，递归下去。
4. **计数题先找递推**：手算 $n = 1, 2, 3, 4$ 的答案，猜规律（如 $1, 2, 5, 14$ 就是卡特兰数），再用"最后一步/第一个元素"的方法证明。
5. **递推的方向和顺序**：依赖后面的状态就倒着推；依赖父亲的状态就按拓扑顺序推。
6. **递推就是没有"选择"的 DP**：当状态转移需要取 $\max$ / $\min$ 时，就进入了动态规划的范围，见《动态规划入门》。
7. **写不出递推时打表**：先用暴力（枚举、搜索）算出前若干项，再找规律。

## 7. 易错点

- **递归边界漏写或写错**：快速幂的 $b = 0$、分治的 $l = r$。没有边界会无限递归。
- **重复递归**：`qpow(a, b / 2) * qpow(a, b / 2)` 让复杂度从 $O(\log b)$ 退化成 $O(b)$；斐波那契直接递归是指数级。
- **中点划分**：写成 $[l, mid - 1]$ 和 $[mid, r]$ 时，$l + 1 = r$ 会出现 $mid = l$、左半为空的情况；统一用 $[l, mid]$ 和 $[mid + 1, r]$。
- **递归太深爆栈**：分治每次减半深度只有 $O(\log n)$；但"每次减 1"的递归深度是 $O(n)$，$n = 10^6$ 可能爆栈，改成循环递推。
- **初始值**：错排 $D_1 = 0$、卡特兰 $h_0 = 1$，初值错了后面全错；网格递推要处理第一行、第一列。
- **溢出**：递推数列增长很快，按题目要求取模（每一步都取），或者用高精度。乘法取模时两个数都要先小于模数。
- **计算顺序**：用到的项必须已经算好；二维递推的循环顺序要和依赖方向一致。
