# 双指针与滑动窗口

**组别**：J　**关键词**：双指针、滑动窗口、尺取法、对撞指针、单调性、子段计数

## 1. 是什么 / 解决什么问题

看一个问题：给定 $n$ 个正整数，求和 $\ge S$ 的最短连续子段。

最直接的做法是枚举左端点 $l$ 和右端点 $r$，$O(n^2)$。但仔细想：对于左端点 $l$，设最小的合法右端点是 $r_l$；当 $l$ 右移一格，子段少了一个正数，和变小，所以新的 $r_{l+1}$ **不可能比 $r_l$ 更靠左**。也就是说两个端点都只会往右走，每个端点最多走 $n$ 步，总共 $O(n)$。

这就是**双指针**：用两个下标在序列上移动，利用某种**单调性**，保证指针不回退，把 $O(n^2)$ 的枚举降到 $O(n)$。当两个指针一前一后、中间夹着一段区间时，这段区间像一个在序列上滑动的窗口，所以也叫**滑动窗口**或**尺取法**。

常见形式：

- **同向双指针（滑动窗口）**：$l, r$ 都从左往右走，维护窗口 $[l, r]$；
- **对撞指针**：$l$ 从左、$r$ 从右往中间走，多用于有序数组和回文判断；
- **两个序列各一个指针**：归并两个有序序列、判断子序列。

## 2. 核心原理

### 2.1 单调性是前提

同向双指针成立的条件是：**若 $[l, r]$ 满足条件，那么它的子区间也满足**（或者反过来：若 $[l, r]$ 不满足，扩大后也不满足）。有了这个"区间包含单调性"：

- 对每个 $r$，令 $l_r$ 为使 $[l, r]$ 合法的最小 $l$；
- $r$ 增大时 $l_r$ 单调不降。

证明：若 $[l_{r+1}, r+1]$ 合法，它的子区间 $[l_{r+1}, r]$ 也合法，所以 $l_r \le l_{r+1}$。

于是可以让 $r$ 从 1 到 $n$ 逐个右移，每次把 $l$ 向右推到第一个合法位置；$l$ 只增不减，总移动次数 $\le n$。

| 条件 | 是否满足包含单调性 |
|:-:|:-:|
| 子段和 $\le k$（元素非负） | 是 |
| 子段和 $\ge S$（元素非负） | 是（反向：超集也满足） |
| 子段内没有重复元素 | 是 |
| 子段内不同元素个数 $\le k$ | 是 |
| 子段最大值 − 最小值 $\le k$ | 是 |
| 子段和 $\le k$（元素**可能为负**） | **否** |

最后一行：有负数时，去掉一个负数反而让和变大，单调性被破坏，不能用双指针（改用前缀和 + 其他方法）。

### 2.2 通用框架

"求满足条件的最长子段"类：

```text
l = 1
for r = 1..n:
    把 a[r] 加入窗口
    while 窗口 [l, r] 不合法:
        把 a[l] 移出窗口, l++
    此时 [l, r] 是以 r 结尾的最长合法子段，用 r - l + 1 更新答案
```

"求满足条件的最短子段"（条件对超集成立，如和 $\ge S$）：

```text
l = 1
for r = 1..n:
    把 a[r] 加入窗口
    while 窗口 [l, r] 合法:
        用 r - l + 1 更新答案
        把 a[l] 移出窗口, l++
```

窗口需要支持"加入一个元素、删除一个元素、判断是否合法"，通常用一个变量（和）或桶数组（每种值出现次数）维护。

### 2.3 手推一个例子

$a = [2, 3, 1, 2, 4, 3]$，$S = 7$，求和 $\ge 7$ 的最短子段：

| $r$ | 加入后窗口 | 和 | 收缩过程 | 记录 |
|:-:|:-:|:-:|:-:|:-:|
| 1 | [2] | 2 | | |
| 2 | [2,3] | 5 | | |
| 3 | [2,3,1] | 6 | | |
| 4 | [2,3,1,2] | 8 | 记录 4，移出 2 → 6 | 4 |
| 5 | [3,1,2,4] | 10 | 记录 4，移出 3 → 7；记录 3，移出 1 → 6 | 3 |
| 6 | [2,4,3] | 9 | 记录 3，移出 2 → 7；记录 2，移出 4 → 3 | 2 |

答案 2（子段 $[4, 3]$）。

### 2.4 对撞指针

有序数组 $a_1 \le a_2 \le \dots \le a_n$，判断是否存在 $a_i + a_j = x$（$i < j$）。

令 $l = 1, r = n$：

- $a_l + a_r < x$：$a_l$ 和当前最大的 $a_r$ 配都不够，和其他数配更不够，$a_l$ 可以排除，$l$++；
- $a_l + a_r > x$：同理 $a_r$ 可以排除，$r$--；
- 相等：找到。

每一步排除一个数，$O(n)$。核心思想同样是单调性：排除掉的数不可能再出现在答案中。

判断回文串、从两端向中间配对也是对撞指针。

### 2.5 固定长度窗口

窗口长度固定为 $k$ 时更简单：$r$ 右移一格，加入 $a_r$、移出 $a_{r-k}$。求每个窗口的和、不同元素个数，都是 $O(1)$ 更新。

求每个窗口的**最大值 / 最小值**不能这样做（删除一个元素后不知道新的最值），要用**单调队列**，见数据结构"单调栈与单调队列"一篇。

## 3. 代码模板

### 3.1 和 $\ge S$ 的最短子段

元素均为正整数，不存在输出 0。

```cpp
const int N = 1e5 + 5;
int n, s, ans;
int a[N];

void solve() {
    cin >> n >> s;
    For(i, 1, n) cin >> a[i];
    int l = 1, sum = 0;
    ans = n + 1;
    For(r, 1, n) {
        sum += a[r];
        while (sum >= s) {
            ans = min(ans, r - l + 1);
            sum -= a[l++];
        }
    }
    cout << (ans == n + 1 ? 0 : ans) << endl;
}
```

### 3.2 无重复元素的最长子段

$0 \le a_i \le 10^6$。`cnt[x]` 记录 $x$ 在窗口中出现的次数。

```cpp
const int N = 1e5 + 5, V = 1e6 + 5;
int n, ans;
int a[N], cnt[V];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    int l = 1;
    For(r, 1, n) {
        cnt[a[r]]++;
        while (cnt[a[r]] > 1) cnt[a[l++]]--;
        ans = max(ans, r - l + 1);
    }
    cout << ans << endl;
}
```

只有新加入的 $a_r$ 可能造成重复，所以收缩条件只看 `cnt[a[r]]`。

### 3.3 包含全部 $m$ 种元素的最短子段

$a_i \in [1, m]$，求包含 $1 \sim m$ 每种值至少一次的最短子段，长度相同取左端点最小的（洛谷 P1638 逛画展）。`kind` 是窗口中出现的不同值个数。

```cpp
const int N = 1e6 + 5, M = 2005;
int n, m, kind, bl, br;
int a[N], cnt[M];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i];
    int l = 1;
    bl = 1, br = n;
    For(r, 1, n) {
        if (cnt[a[r]]++ == 0) kind++;
        while (cnt[a[l]] > 1) cnt[a[l++]]--;
        if (kind == m && r - l < br - bl) bl = l, br = r;
    }
    cout << bl << ' ' << br << endl;
}
```

这里换了一种收缩方式：只要左端元素在窗口里多于一次，删掉它不影响"包含全部种类"，就删。这样 $[l, r]$ 始终是以 $r$ 结尾、包含的种类不变的最短子段。

### 3.4 子段计数

元素非负，求和 $\le k$ 的子段个数。

```cpp
const int N = 1e5 + 5;
int n, k, ans;
int a[N];

void solve() {
    cin >> n >> k;
    For(i, 1, n) cin >> a[i];
    int l = 1, sum = 0;
    For(r, 1, n) {
        sum += a[r];
        while (sum > k) sum -= a[l++];
        ans += r - l + 1;
    }
    cout << ans << endl;
}
```

对每个 $r$，$[l, r], [l+1, r], \dots, [r, r]$ 都合法（子区间也合法），恰好 $r - l + 1$ 个；而 $l$ 左边的都不合法。所以按右端点分类累加即可。当 $l > r$ 时贡献为 0，公式依然成立。

### 3.5 对撞指针：两数之和不超过 $x$ 的对数

求满足 $i < j$ 且 $a_i + a_j \le x$ 的数对个数。

```cpp
const int N = 1e5 + 5;
int n, x, ans;
int a[N];

void solve() {
    cin >> n >> x;
    For(i, 1, n) cin >> a[i];
    sort(a + 1, a + 1 + n);
    int l = 1, r = n;
    while (l < r) {
        if (a[l] + a[r] <= x) ans += r - l, l++;
        else r--;
    }
    cout << ans << endl;
}
```

若 $a_l + a_r \le x$，那么 $a_l$ 和 $a_{l+1}, \dots, a_r$ 中任何一个配对都满足（它们都 $\le a_r$），一次统计 $r - l$ 对后 $l$ 就用完了；否则 $a_r$ 和剩下任何数配对都超过 $x$，排除 $a_r$。

### 3.6 差为定值的数对（多个指针同时单调）

求满足 $a_i - a_j = c$ 的有序数对 $(i, j)$ 个数，$c \ge 1$（洛谷 P1102 A-B 数对）。

```cpp
const int N = 2e5 + 5;
int n, c, ans;
int a[N];

void solve() {
    cin >> n >> c;
    For(i, 1, n) cin >> a[i];
    sort(a + 1, a + 1 + n);
    int l = 1, r = 1;
    For(i, 1, n) {
        while (l <= n && a[l] < a[i] + c) l++;
        while (r <= n && a[r] <= a[i] + c) r++;
        ans += r - l;
    }
    cout << ans << endl;
}
```

把循环中的 $a_i$ 看作减数，被减数必须等于 $a_i + c$。排序后值等于 $a_i + c$ 的元素是一段连续区间 $[l, r)$，个数为 $r - l$。$a_i$ 递增，$a_i + c$ 也递增，所以 $l$ 和 $r$ 都只往右移。这个问题也可以用 `lower_bound` / `upper_bound` 或 `map` 做，双指针省掉了 $\log$。

### 3.7 固定长度窗口：每个窗口的不同元素个数

输出所有长度为 $k$ 的窗口中不同元素的个数，$1 \le a_i \le 10^6$。

```cpp
const int N = 1e5 + 5, V = 1e6 + 5;
int n, k, kind;
int a[N], cnt[V];

void solve() {
    cin >> n >> k;
    For(i, 1, n) cin >> a[i];
    For(r, 1, n) {
        if (cnt[a[r]]++ == 0) kind++;
        if (r > k && --cnt[a[r - k]] == 0) kind--;
        if (r >= k) cout << kind << ' ';
    }
    cout << endl;
}
```

## 4. 复杂度

- 同向双指针：$l$、$r$ 各最多移动 $n$ 次，若窗口的加入/删除/判断都是 $O(1)$，总时间 $O(n)$。
- 对撞指针：每步至少移动一个指针，$O(n)$；若需要先排序，总 $O(n \log n)$。
- 看到 `for` 里套 `while` 不要以为是 $O(n^2)$：内层 `while` 的总执行次数受 $l$ 的总移动距离限制。这种分析叫**均摊分析**。
- 空间：桶数组大小取决于值域，值域很大时先离散化（见"离散化"一篇）或用 `map`（多一个 $\log$）。

## 5. 常见题型与技巧

- **最长 / 最短合法子段**：先验证包含单调性，再套框架。
- **合法子段计数**：按右端点统计，每个 $r$ 贡献 $r - l + 1$。
- **"恰好 $k$"转"至多 $k$"**：例如求不同元素个数**恰好**为 $k$ 的子段数，"恰好 $k$"没有单调性，但"至多 $k$"有。答案 = $f(k) - f(k - 1)$，$f(k)$ 表示至多 $k$ 种的子段数。
- **排序后双指针**：只关心值不关心位置时（选若干数、配对），先排序，原问题往往就有了单调性。例如"选一些数使最大值减最小值 $\le k$，最多选几个"，排序后就是滑动窗口。
- **配合前缀和**：窗口内的和、代价用前缀和 $O(1)$ 计算，判断时直接算 $[l, r]$ 的值。
- **对撞指针**：两数之和、回文、从两端取数的问题；三数之和可以外层枚举一个数、内层对撞，$O(n^2)$。
- **两个序列的指针**：归并两个有序序列；判断 $s$ 是否是 $t$ 的子序列（$t$ 上的指针一直前进，匹配上 $s$ 的当前字符就让 $s$ 的指针也前进）。
- **环形序列**：把序列复制一遍接在后面（断环成链），在长度 $2n$ 的序列上做，限制窗口长度不超过 $n$。

## 6. 易错点

- **没有单调性也用双指针**：最典型的是元素有负数时求"和 $\le k$ 的最长子段"。
- **收缩条件写成 `if`**：一次可能需要移出多个元素，要用 `while`。
- **加入 / 删除的顺序**：先加入 $a_r$ 再收缩，还是先判断再加入，要和窗口定义一致；删除时先更新计数再 `l++`（`a[l++]` 这种写法要想清楚用的是哪个下标）。
- **桶的计数和"种类数"不同步**：`cnt` 从 0 变 1 时种类 +1，从 1 变 0 时种类 −1，别漏。
- **答案初值**：最短子段的答案初始化为不可能的大值，最后判断是否被更新过（不存在时输出什么看题目）。
- **对撞指针的循环条件**：$i < j$ 时用 `l < r`；允许 $i = j$ 时用 `l <= r`。
- **计数溢出**：子段个数可达 $\frac{n(n+1)}{2}$，要用 64 位（模板里 `int` 已是 `long long`）。
- **多组数据**：桶数组要清空（只清用过的位置，或者按窗口内容逐个删回去）。
