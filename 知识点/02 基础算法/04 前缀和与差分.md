# 前缀和与差分

**组别**：J　**关键词**：前缀和、差分、二维前缀和、二维差分、区间修改、前缀异或、子段和计数

## 1. 是什么 / 解决什么问题

两个最常见的需求：

1. **区间求和**：数组不变，有 $m$ 次询问，每次问 $a_l + a_{l+1} + \cdots + a_r$。每次都循环累加是 $O(n)$，总共 $O(nm)$，$n, m = 10^5$ 时就超时了。
2. **区间加**：有 $m$ 次操作，每次把 $a_l \sim a_r$ 都加上 $x$，最后输出整个数组。每次都循环也是 $O(nm)$。

**前缀和**把区间求和变成 $O(1)$，**差分**把区间加变成 $O(1)$。它们互为逆运算，是最基础、用得最多的技巧之一，也经常作为其他算法里的一个小步骤出现。

## 2. 核心原理

### 2.1 一维前缀和

定义 $s_i = a_1 + a_2 + \cdots + a_i$，并规定 $s_0 = 0$。它可以递推：$s_i = s_{i-1} + a_i$。

区间和就是两个前缀和相减：

$$a_l + \cdots + a_r = s_r - s_{l-1}.$$

因为 $s_r$ 是前 $r$ 个的和，$s_{l-1}$ 是前 $l - 1$ 个的和，相减正好剩下第 $l$ 到第 $r$ 个。

```
i    0  1  2  3  4  5
a       3  1  4  1  5
s    0  3  4  8  9 14

a2 + a3 + a4 = s4 - s1 = 9 - 3 = 6   (1 + 4 + 1 = 6)
```

规定 $s_0 = 0$ 并让数组从 1 开始，$l = 1$ 时就不需要特判。这也是我们坚持数组 1-indexed 的原因之一。

### 2.2 二维前缀和

定义 $s_{i,j}$ 为以 $(1, 1)$ 为左上角、$(i, j)$ 为右下角的矩形中所有元素之和。

**递推**（容斥）：上方矩形加左方矩形，左上角的重叠部分被加了两次，减掉一次，再加上自己：

$$s_{i,j} = s_{i-1,j} + s_{i,j-1} - s_{i-1,j-1} + a_{i,j}.$$

**查询**左上角 $(x_1, y_1)$、右下角 $(x_2, y_2)$ 的子矩形和：

$$\text{sum} = s_{x_2,y_2} - s_{x_1-1,y_2} - s_{x_2,y_1-1} + s_{x_1-1,y_1-1}.$$

```
+---------+--------+
|    D    |   B    |     s[x2][y2] = A + B + C + D
+---------+--------+     要求的是 A
|    C    |   A    |     减去 s[x1-1][y2] = B + D
|         |        |     减去 s[x2][y1-1] = C + D
+---------+--------+     D 被减了两次，加回 s[x1-1][y1-1] = D
```

记忆方法：右下角加，"上面一条"和"左边一条"减，左上角加。

### 2.3 一维差分

定义差分数组 $d_i = a_i - a_{i-1}$（$a_0 = 0$）。反过来，$a_i = d_1 + d_2 + \cdots + d_i$，即 **$a$ 是 $d$ 的前缀和**。

把 $a_l \sim a_r$ 都加上 $x$，差分数组怎么变？

- $d_l = a_l - a_{l-1}$：$a_l$ 加了 $x$，$a_{l-1}$ 没变，$d_l$ 增加 $x$；
- $l < i \le r$：$a_i$ 和 $a_{i-1}$ 都加了 $x$，差不变；
- $d_{r+1} = a_{r+1} - a_r$：$a_r$ 加了 $x$，$d_{r+1}$ 减少 $x$；
- 其他位置不变。

所以**区间加只需改两个点**：`d[l] += x, d[r + 1] -= x`。所有操作做完后，对 $d$ 求一遍前缀和就得到最终数组。

```
初始 a     0 0 0 0 0 0
[2,4] 加 3
     d     0 3 0 0 -3 0
[3,6] 加 1
     d     0 3 1 0 -3 0 (位置 7 减 1，越过末尾)
前缀和 a   0 3 4 4 1 1
```

直观理解：$d_l$ 加 $x$ 相当于"从 $l$ 开始往后全部加 $x$"，$d_{r+1}$ 减 $x$ 相当于"从 $r + 1$ 开始往后全部减回去"。

### 2.4 二维差分

同理，二维差分数组 $d$ 满足"$a$ 是 $d$ 的二维前缀和"。给子矩形 $(x_1, y_1) \sim (x_2, y_2)$ 全部加 $c$：

```
d[x1][y1]         += c      从 (x1,y1) 往右下全部加 c
d[x2 + 1][y1]     -= c      下方多加的部分减掉
d[x1][y2 + 1]     -= c      右方多加的部分减掉
d[x2 + 1][y2 + 1] += c      右下角被减了两次，加回来
```

所有修改结束后做一次二维前缀和即得结果。

### 2.5 前缀和与差分互逆

把"求前缀和"记作 $P$，"求差分"记作 $D$，那么 $P(D(a)) = a$，$D(P(a)) = a$。它们的分工是：

| 需求 | 在哪个数组上操作 | 代价 |
| --- | --- | --- |
| 区间求和 | 前缀和数组上查两个点 | $O(1)$ |
| 区间加 | 差分数组上改两个点 | $O(1)$ |
| 单点查询（区间加之后） | 差分数组求前缀和 | 一次性 $O(n)$ |

注意：前缀和只适合**数组不再改变**时的查询；差分只适合**先做完所有修改、最后再统一查询**。如果修改和查询交替进行（在线），就需要树状数组或线段树。

**高阶差分。** 如果要给 $a_l \sim a_r$ 依次加上 $1, 2, \ldots, len$（等差数列，$len = r - l + 1$），对差分数组 $d$ 来说就是 $d_l \sim d_r$ 每个加 1、$d_{r+1}$ 减 $len$——这又是一次区间加，再对 $d$ 做差分即可。最终对"差分的差分"做如下修改，然后**求两次前缀和**：

```
d2[l] += 1, d2[r + 1] -= len + 1, d2[r + 2] += len
```

### 2.6 推广：前缀和能用于哪些运算

前缀和"用两个前缀相减得到区间"，要求运算**可以撤销**：

- **加法**：减法撤销。
- **异或**：异或自身撤销，$a_l \oplus \cdots \oplus a_r = x_r \oplus x_{l-1}$，其中 $x_i$ 是前缀异或。
- **乘法**：模质数时可以乘逆元撤销，但要小心 0。
- **最大值、最小值**：不能撤销。前缀最值只能回答"前 $i$ 个的最值"，任意区间最值要用 ST 表或线段树。

### 2.7 区间条件转化为两个前缀的关系

"子段和满足某条件"的问题，几乎都可以转化成"两个前缀和满足某条件"：

- 子段和等于 $k$：$s_r - s_{l-1} = k$，即 $s_{l-1} = s_r - k$。从左往右扫，用 `map` 或桶记录每个前缀和出现的次数，对每个 $r$ 查 $s_r - k$ 出现过几次。
- 子段和是 $k$ 的倍数：$s_r \equiv s_{l-1} \pmod k$，统计余数相同的前缀对数。
- 子段异或和等于 $k$：$x_{l-1} = x_r \oplus k$（CSP-J 2025 异或和）。
- 最大子段和：对每个 $r$，用 $s_r$ 减去之前最小的前缀和 $\min_{j < r} s_j$。

## 3. 代码模板

**一维前缀和**：$m$ 次询问区间和。

```cpp
const int N = 1e5 + 5;
int n, m;
int a[N], s[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i], s[i] = s[i - 1] + a[i];
    while (m--) {
        int l, r;
        cin >> l >> r;
        cout << s[r] - s[l - 1] << endl;
    }
}
```

**二维前缀和**：$q$ 次询问子矩形和。

```cpp
const int N = 1e3 + 5;
int n, m, q;
int a[N][N], s[N][N];

void solve() {
    cin >> n >> m >> q;
    For(i, 1, n) For(j, 1, m) {
        cin >> a[i][j];
        s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + a[i][j];
    }
    while (q--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        cout << s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1] + s[x1 - 1][y1 - 1] << endl;
    }
}
```

**一维差分**：$m$ 次区间加，输出最终数组。

```cpp
const int N = 1e5 + 5;
int n, m;
int a[N], d[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i], d[i] = a[i] - a[i - 1];
    while (m--) {
        int l, r, x;
        cin >> l >> r >> x;
        d[l] += x, d[r + 1] -= x;
    }
    For(i, 1, n) a[i] = a[i - 1] + d[i], cout << a[i] << " ";
}
```

**二维差分**：初始全 0 的矩阵，$q$ 次子矩形加 $c$，输出最终矩阵。

```cpp
const int N = 1e3 + 5;
int n, m, q;
int d[N][N];

void solve() {
    cin >> n >> m >> q;
    while (q--) {
        int x1, y1, x2, y2, c;
        cin >> x1 >> y1 >> x2 >> y2 >> c;
        d[x1][y1] += c, d[x2 + 1][y1] -= c, d[x1][y2 + 1] -= c, d[x2 + 1][y2 + 1] += c;
    }
    For(i, 1, n) {
        For(j, 1, m) {
            d[i][j] += d[i - 1][j] + d[i][j - 1] - d[i - 1][j - 1];
            cout << d[i][j] << " ";
        }
        cout << endl;
    }
}
```

**和为 $k$ 的子段个数**：

```cpp
int n, k, s, ans;
map<int, int> cnt;

void solve() {
    cin >> n >> k;
    cnt[0] = 1;
    For(i, 1, n) {
        int x;
        cin >> x;
        s += x, ans += cnt[s - k], cnt[s]++;
    }
    cout << ans;
}
```

`cnt[0] = 1` 对应 $s_0 = 0$，表示以第 1 个元素开头的子段。先查询再把 $s_r$ 加进去，保证 $l - 1 < r$。

## 4. 复杂度

| 操作 | 预处理 | 单次 |
| --- | --- | --- |
| 一维前缀和查询 | $O(n)$ | $O(1)$ |
| 二维前缀和查询 | $O(nm)$ | $O(1)$ |
| 一维差分区间加 | — | $O(1)$，最后还原 $O(n)$ |
| 二维差分子矩形加 | — | $O(1)$，最后还原 $O(nm)$ |
| 子段和计数 | — | 总共 $O(n \log n)$（`map`），值域小用桶 $O(n)$ |

空间都是和原数组同阶。二维数组 $5000 \times 5000$ 的 `long long` 就要 200MB，注意内存限制。

## 5. 常见题型与技巧

1. **静态区间和 / 子矩形和**：直接用前缀和。"边长为 $r$ 的正方形最多覆盖多少价值"一类题，二维前缀和后枚举右下角。
2. **离线区间加**：多次区间加最后统一查询，用差分。例如"每趟火车经过 $[l, r]$ 的站点，问每个站点被经过几次"。
3. **差分数组本身的性质**：把数组变成全 0 需要几次"区间减 1"？答案是差分数组中正数之和（铺设道路）。把数组变成全相等，看差分数组中正数之和与负数之和。
4. **子段计数**：子段和等于 $k$、是 $k$ 的倍数、异或和等于 $k$，都转成"前缀的配对计数"。
5. **前缀和优化 DP**：转移形如 $f_i = \sum_{j=i-k}^{i-1} f_j$ 时，维护 $f$ 的前缀和，每次 $O(1)$ 转移。
6. **前缀和 + 二分**：前缀和数组在 $a_i \ge 0$ 时单调不降，可以二分找"前缀和第一次超过 $x$ 的位置"。差分也常作为二分答案的检验工具（借教室：二分订单数，用差分检验是否超出）。
7. **计算代价**：把一段数都调整到同一个值的代价，往往能写成"个数 × 目标值 − 区间和"，用前缀和 $O(1)$ 算出。
8. **树上差分**：把差分搬到树上，用来处理"路径上每个点加 $x$"，需要配合最近公共祖先，见图论部分。

## 6. 易错点

- **下标从 0 开始**：$l = 1$ 时访问 $s_0$，所以 $s$ 数组要从下标 1 开始存、$s_0 = 0$。
- **差分的 $r + 1$ 越界**：$r = n$ 时会写 $d_{n+1}$，数组至少开 $n + 2$。二维差分同理。
- **二维容斥的符号**：查询时是"加、减、减、加"，推导时画图核对。
- **溢出**：$10^5$ 个 $10^9$ 的数求和会超过 32 位整数。
- **多组数据**：前缀和与差分数组要清空，或者每次从下标 1 开始重新递推覆盖。
- **负数取模**：统计"子段和是 $k$ 的倍数"时，C++ 中负数取模结果为负，要写成 `(s % k + k) % k`。
- **在线修改**：修改和询问交替时前缀和失效，每次重算就退化成 $O(n)$。
- **差分还原后忘记再求一次前缀和**：差分 → 原数组是一次前缀和；如果还要查区间和，需要再求一次。
