# 深度优先搜索与回溯

**组别**：J　**关键词**：深度优先搜索、回溯、搜索树、排列组合枚举、剪枝、记忆化搜索、连通块

## 1. 是什么 / 解决什么问题

很多问题的答案要从大量"方案"里找：$n$ 个数的所有排列、从 $n$ 个物品里选若干个、迷宫里的所有走法……这些方案都可以**一步一步构造**：第 1 步做一个选择，第 2 步再做一个选择……直到方案完整。把所有可能的选择过程画出来，就得到一棵**搜索树**：根是"还什么都没选"，每条边是一次选择，每个叶子是一个完整方案。

**深度优先搜索（DFS）** 按"一条路走到底，走不通再退回来换一条"的顺序遍历这棵树。退回上一步、撤销刚才的选择，叫做**回溯**。

DFS 适用于：

- 枚举所有方案：输出全部排列、组合，或者统计方案数；
- 数据范围很小（$n \le 10 \sim 25$）的最优化问题，也是很多题拿部分分、写对拍暴力的首选；
- 图和网格上的遍历：找连通块、判断能否到达。

## 2. 核心原理

### 2.1 搜索树与回溯

以 $1 \sim 3$ 的全排列为例。第 1 位有 3 种选法，第 2 位在剩下的 2 个里选，第 3 位只剩 1 个：

```text
                     (空)
           /          |          \
          1           2           3
         / \         / \         / \
       12   13     21   23     31   32
       |     |     |     |     |     |
      123   132   213   231   312   321
```

DFS 的访问顺序是：(空) → 1 → 12 → 123（输出）→ 退回 12 → 退回 1 → 13 → 132（输出）→ 退回 13 → 退回 1 → 退回 (空) → 2 → ……

关键在"退回"：从 `12` 退回 `1` 时，必须撤销"2 已经用过"的标记，否则构造 `13?` 时 2 就再也用不了了。回溯的核心就是一句话：**进入下一层前改了什么，回来后就原样改回去**。这样每一层在循环中看到的全局状态，始终和刚进入这一层时一样。

通用框架：

```text
dfs(当前状态):
    if 到达终点: 记录答案, return
    for 每个可选的选择:
        if 不合法: continue
        做出选择（修改状态）
        dfs(下一个状态)
        撤销选择（恢复状态）
```

递归本身由系统栈实现，所以 DFS 不需要手写栈；递归深度等于搜索树的深度。

### 2.2 三种基本枚举

| 枚举对象 | 第 $d$ 层做什么 | 方案数 | 实现要点 |
|:-:|:-:|:-:|:-:|
| 子集 | 决定第 $d$ 个元素选或不选 | $2^n$ | 两个分支各递归一次 |
| 组合（$n$ 选 $k$） | 选第 $d$ 个元素，且编号比上一个大 | $\binom{n}{k}$ | 传入起点 `st` |
| 排列 | 在没用过的元素里选一个放在第 $d$ 位 | $n!$ | `used[]` 标记 |

组合和排列的区别在于是否关心顺序。$\{1,2\}$ 和 $\{2,1\}$ 是同一个组合，所以规定**选出的编号递增**：每层只从上一个选的位置之后开始选，自然不重不漏。

### 2.3 剪枝

搜索树往往非常大。**剪枝**就是在能确定"这棵子树里不可能有（更好的）答案"时直接返回，不再往下搜。

1. **可行性剪枝**：当前状态已经不合法，或者以后怎么选都不可能合法。例如选组合时，剩下的数已经不够凑满 $k$ 个。
2. **最优性剪枝**：求最优解时，"当前值 + 未来最乐观的收益"仍然不比已知最优解好，就返回。例如求不超过 $m$ 的最大和时，若"当前和 + 剩下所有数之和 $\le$ 已知答案"，再搜也没用。
3. **优化搜索顺序**：先搜更可能出好答案、或者分支更少的选择。例如把物品从大到小排序后再搜，能更早得到较大的答案，让最优性剪枝更早生效；填数独时先填候选数最少的格子。
4. **排除等效冗余**：几个分支本质相同时只搜一个。例如有重复元素的排列，相同的数在同一层只试一次。

剪枝的前提是**正确**：只能剪掉确定没有答案的分支，条件写得太强就会 WA。

### 2.4 记忆化搜索

有的搜索会反复访问同一个子问题。比如求网格里从 $(x, y)$ 出发的最长下降路径：从不同起点出发都可能经过 $(x, y)$，每次都重新算一遍就是指数级。

如果 `dfs(x, y)` 的返回值**只取决于参数**，不依赖路径上的其他全局状态，就可以把算过的结果存进数组，下次直接返回。这就是**记忆化搜索**：每个状态只算一次，复杂度变成"状态数 × 每个状态的转移数"。

记忆化搜索本质上就是动态规划，只是用递归"按需"计算，不用操心计算顺序。能写出"带参数、无副作用"的搜索，离 DP 就只差一个数组。

**不能记忆化的情况**：结果与路径有关。比如"每个格子最多经过一次的路径数"，从 $(x, y)$ 出发的方案数取决于之前已经走过哪些格子，不只取决于 $(x, y)$。

### 2.5 图与网格上的 DFS

在图上 DFS 时，"选择"就是走向一个相邻点。两种目的要分清：

- **遍历 / 连通性**（找连通块、判断可达）：每个点只需访问一次，`vis` 标记**不撤销**，复杂度 $O(n + m)$。
- **枚举路径**（数简单路径、找所有走法）：同一个点会出现在不同路径中，`vis` 标记**要撤销**，复杂度是指数级。

## 3. 代码模板

### 3.1 全排列

按字典序输出 $1 \sim n$ 的全排列。

```cpp
const int N = 15;
int n;
int p[N];
bool used[N];

void dfs(int dep) {
    if (dep > n) {
        For(i, 1, n) cout << p[i] << ' ';
        cout << endl;
        return;
    }
    For(i, 1, n) {
        if (used[i]) continue;
        used[i] = true, p[dep] = i;
        dfs(dep + 1);
        used[i] = false;
    }
}

void solve() {
    cin >> n;
    dfs(1);
}
```

`used[i]` 表示 $i$ 已经在当前排列里。外层循环从小到大试，所以输出天然是字典序。`p[dep]` 不需要撤销，因为下次会被直接覆盖。

**有重复元素的排列**：先把 $a$ 排序，循环里改为枚举下标 $i$，并加一句 `if (i > 1 && a[i] == a[i - 1] && !used[i - 1]) continue;`。含义是相同的数只能按下标顺序使用，同一层不会把相同的值试两次。

### 3.2 组合

按字典序输出从 $1 \sim n$ 中选 $k$ 个的所有组合。

```cpp
const int N = 25;
int n, k;
int p[N];

void dfs(int dep, int st) {
    if (dep > k) {
        For(i, 1, k) cout << p[i] << ' ';
        cout << endl;
        return;
    }
    For(i, st, n - k + dep) {
        p[dep] = i;
        dfs(dep + 1, i + 1);
    }
}

void solve() {
    cin >> n >> k;
    dfs(1, 1);
}
```

循环上界 `n - k + dep` 是可行性剪枝：第 $dep$ 位选了 $i$ 之后，还要再选 $k - dep$ 个比 $i$ 大的数，所以 $i \le n - (k - dep)$。

### 3.3 子集枚举与剪枝

$n$ 个物品，重量为 $a_i$，选若干个使总重不超过 $m$ 且尽量大。

```cpp
const int N = 45;
int n, m, ans;
int a[N], suf[N];

void dfs(int i, int sum) {
    ans = max(ans, sum);
    if (i > n || sum + suf[i] <= ans) return;
    if (sum + a[i] <= m) dfs(i + 1, sum + a[i]);
    dfs(i + 1, sum);
}

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i];
    sort(a + 1, a + 1 + n, greater<int>());
    for (int i = n; i >= 1; i--) suf[i] = suf[i + 1] + a[i];
    dfs(1, 0);
    cout << ans << endl;
}
```

三处优化：

- `sum + a[i] <= m` 才进入"选"的分支（可行性剪枝）；
- `suf[i]` 是后面所有物品的重量和，`sum + suf[i] <= ans` 说明把剩下的全选上也不会更好（最优性剪枝）；
- 从大到小排序，先搜"选"，能尽早得到较大的 $ans$（搜索顺序）。

这里状态 `sum` 通过参数传递，递归返回时自动"撤销"，不用手动恢复。

### 3.4 N 皇后

在 $n \times n$ 棋盘上放 $n$ 个互不攻击的皇后，求方案数。逐行放置，第 $dep$ 行枚举放在哪一列。同一条"\\"方向对角线上 `行 - 列` 相同，同一条"/"方向对角线上 `行 + 列` 相同，用三个数组 $O(1)$ 判断冲突。

```cpp
const int N = 15;
int n, ans;
bool col[N], d1[2 * N], d2[2 * N];

void dfs(int dep) {
    if (dep > n) {
        ans++;
        return;
    }
    For(i, 1, n) {
        if (col[i] || d1[dep - i + n] || d2[dep + i]) continue;
        col[i] = d1[dep - i + n] = d2[dep + i] = true;
        dfs(dep + 1);
        col[i] = d1[dep - i + n] = d2[dep + i] = false;
    }
}

void solve() {
    cin >> n;
    dfs(1);
    cout << ans << endl;
}
```

`dep - i` 可能为负，加 $n$ 平移到 $[1, 2n - 1]$。

### 3.5 网格连通块（标记不撤销）

`#` 表示陆地，`.` 表示水，上下左右相邻的陆地属于同一块，求块数。

```cpp
const int N = 105;
int n, m, ans;
char g[N][N];
bool vis[N][N];
int dx[] = {-1, 1, 0, 0}, dy[] = {0, 0, -1, 1};

void dfs(int x, int y) {
    vis[x][y] = true;
    Rep(k, 0, 4) {
        int nx = x + dx[k], ny = y + dy[k];
        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
        if (g[nx][ny] == '#' && !vis[nx][ny]) dfs(nx, ny);
    }
}

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> (g[i] + 1);
    For(i, 1, n) For(j, 1, m) if (g[i][j] == '#' && !vis[i][j]) ans++, dfs(i, j);
    cout << ans << endl;
}
```

每个格子只进入一次，复杂度 $O(nm)$。这种"从一个点出发把整块染上标记"的操作也叫**洪水填充（flood fill）**。

### 3.6 迷宫路径计数（标记要撤销）

求从 $(sx, sy)$ 到 $(tx, ty)$、每个格子最多经过一次的路径条数（`#` 是障碍）。

```cpp
const int N = 10;
int n, m, sx, sy, tx, ty, ans;
char g[N][N];
bool vis[N][N];
int dx[] = {-1, 1, 0, 0}, dy[] = {0, 0, -1, 1};

void dfs(int x, int y) {
    if (x == tx && y == ty) {
        ans++;
        return;
    }
    Rep(k, 0, 4) {
        int nx = x + dx[k], ny = y + dy[k];
        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
        if (g[nx][ny] == '#' || vis[nx][ny]) continue;
        vis[nx][ny] = true;
        dfs(nx, ny);
        vis[nx][ny] = false;
    }
}

void solve() {
    cin >> n >> m >> sx >> sy >> tx >> ty;
    For(i, 1, n) cin >> (g[i] + 1);
    vis[sx][sy] = true;
    dfs(sx, sy);
    cout << ans << endl;
}
```

和上一个模板只差一行 `vis[nx][ny] = false`，但含义完全不同：这里 `vis` 表示"当前这条路径上走过的格子"，而不是"曾经访问过的格子"。起点要先标记，否则路径可能绕回起点。

### 3.7 记忆化搜索：最长下降路径

$n \times m$ 的高度网格，每步走到上下左右**严格更低**的格子，求最长路径经过的格子数。

```cpp
const int N = 105;
int n, m, ans;
int h[N][N], f[N][N];
int dx[] = {-1, 1, 0, 0}, dy[] = {0, 0, -1, 1};

int dfs(int x, int y) {
    if (f[x][y]) return f[x][y];
    f[x][y] = 1;
    Rep(k, 0, 4) {
        int nx = x + dx[k], ny = y + dy[k];
        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
        if (h[nx][ny] < h[x][y]) f[x][y] = max(f[x][y], dfs(nx, ny) + 1);
    }
    return f[x][y];
}

void solve() {
    cin >> n >> m;
    For(i, 1, n) For(j, 1, m) cin >> h[i][j];
    For(i, 1, n) For(j, 1, m) ans = max(ans, dfs(i, j));
    cout << ans << endl;
}
```

$f_{x,y}$ 是从 $(x, y)$ 出发的最长路径长度，它只取决于 $(x, y)$：因为每步都严格下降，路径不可能绕回来，不需要 `vis`。答案至少是 1，所以可以用 0 表示"还没算过"。每个格子只算一次，复杂度 $O(nm)$。

## 4. 复杂度

搜索的复杂度 ≈ 搜索树结点数 × 每个结点的工作量。

| 枚举类型 | 叶子数 | 1 秒内大约能承受 |
|:-:|:-:|:-:|
| 排列 | $n!$ | $n \le 10 \sim 11$（$10! \approx 3.6 \times 10^6$，$11! \approx 4 \times 10^7$） |
| 子集 | $2^n$ | $n \le 20 \sim 25$（$2^{25} \approx 3.4 \times 10^7$） |
| 组合 | $\binom{n}{k}$ | 看具体值，如 $\binom{30}{15} \approx 1.55 \times 10^8$ |
| 记忆化搜索 | 状态数 × 转移数 | 与 DP 相同 |
| 图 / 网格遍历 | $O(n + m)$ | 与 BFS 相同 |

剪枝后的真实复杂度很难精确分析，通常远小于上界，但不能指望剪枝把指数降成多项式。估算时按最坏情况判断能拿多少分，剪枝作为"多拿一些点"的手段。

空间主要是递归栈：深度 × 每层的局部变量。递归深度到 $10^5 \sim 10^6$（例如链状图上 DFS）时有爆栈风险，Windows 本地默认栈很小，更容易崩。这种情况可以改写成非递归（手写栈，或按 BFS 序倒序处理）。

## 5. 常见题型与技巧

- **枚举所有方案**：输出排列、组合、子集，数据很小，直接套模板。
- **选数问题**：从 $n$ 个数中选 $k$ 个满足某条件（和为质数、和最接近某值）——组合枚举 + 检查。
- **棋盘放置**：N 皇后、数独。逐行或逐格搜索，用标记数组 $O(1)$ 判冲突。
- **网格 / 图遍历**：连通块计数；"填涂颜色"类题从边界出发 DFS，把能到达边界的区域标记为外部，剩下的就是被围住的部分。
- **部分分与对拍**：正解是 DP 或贪心的题，先写 DFS 暴力拿小数据分，也用来对拍验证正解。
- **从搜索到 DP**：先写出朴素搜索；若返回值只取决于参数，加数组记忆化，就得到 DP 的复杂度。
- **状态放参数还是放全局**：小的数值（当前和、当前位置）放参数，递归返回时自动恢复，不易出错；大的结构（标记数组、当前路径）放全局，手动修改和撤销。
- **其他枚举方式**：全排列也可以用 `next_permutation`（见 STL 一篇），子集也可以用二进制数枚举（见位运算一篇）。需要中途剪枝时 DFS 更灵活。

## 6. 易错点

- **忘记撤销**：全局状态改了没改回来，后面的分支全部出错。
- **不该撤销时撤销**：连通块遍历如果撤销 `vis`，会退化成指数级。
- **起点忘记标记**：路径计数时起点没标记，路径会绕回起点。
- **记忆化的"未计算"标记与合法值冲突**：如果答案可能是 0，就不能用 0 表示没算过，应该 `mset(f, -1)` 或另开一个 `vis` 数组。
- **记忆化了依赖全局状态的函数**：返回值和路径有关时记忆化是错的。
- **在递归函数里用全局变量当循环变量或临时变量**：会被下一层覆盖。递归里的循环变量一律用局部变量。
- **剪枝条件写错**：比如最优性剪枝用了 `<` 还是 `<=` 要想清楚；不确定时宁可剪得弱一点。
- **输出量大**：$9! = 362880$ 行，用 `'\n'` 而不是 `std::endl`（模板里的 `endl` 已经定义成 `'\n'`）。
- **递归太深爆栈**：见第 4 节。
