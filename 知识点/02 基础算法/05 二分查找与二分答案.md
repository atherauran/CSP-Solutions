# 二分查找与二分答案

**组别**：J　**关键词**：二分查找、二分答案、单调性、lower_bound、upper_bound、实数二分、最小化最大值

## 1. 是什么 / 解决什么问题

猜数游戏：对方心里想一个 $1 \sim 1000$ 的数，你每猜一次，对方告诉你"大了"或"小了"。最聪明的猜法是每次猜中间，每次把范围缩小一半，最多 10 次就能猜中（$2^{10} = 1024$）。

这就是二分。它解决两类问题：

1. **二分查找**：在**有序**数组里找某个值、找第一个大于等于 $x$ 的位置、统计某个值出现几次。$O(\log n)$。
2. **二分答案**：直接求最优答案很难，但"给定一个答案 $x$，判断它行不行"比较容易，而且可行性关于 $x$ **单调**。于是二分 $x$，每次调用检验函数。典型标志是"最大值最小""最小值最大"。

## 2. 核心原理

### 2.1 本质：找单调谓词的分界点

把所有二分统一成一个问题：有一个关于整数 $x$ 的判断 $check(x)$，它在某个位置之前全是 `false`、之后全是 `true`：

```
x       1  2  3  4  5  6  7  8
check   F  F  F  F  T  T  T  T
                    ^ 要找的分界点：第一个 T
```

每次看中点 $mid$：如果 $check(mid)$ 为真，分界点在 $mid$ 或它左边；否则在 $mid$ 右边。区间每次减半。

在有序数组里找"第一个 $\ge x$ 的位置"，就是取 $check(i) = [a_i \ge x]$，数组有序保证了它是 FF...FTT...T 的形状。**任何二分都要先问自己：check 是什么？它为什么单调？**

### 2.2 整数二分的两种写法

**找第一个 T**（$check$ 形如 FFFTTT）：

```
while (l < r) {
    int mid = (l + r) / 2;
    if (check(mid)) r = mid;
    else l = mid + 1;
}
// 结束时 l == r，就是答案
```

**找最后一个 T**（$check$ 形如 TTTFFF）：

```
while (l < r) {
    int mid = (l + r + 1) / 2;
    if (check(mid)) l = mid;
    else r = mid - 1;
}
```

两者的区别在 $mid$ 的取整方向。**为什么第二种要 $+1$？** 设 $l = 2, r = 3$。如果写 $mid = (2 + 3) / 2 = 2$，且 $check(2)$ 为真，执行 `l = mid` 后 $l$ 仍是 2，区间没有缩小，死循环。规律是：**出现 `l = mid` 时，$mid$ 必须向上取整**；出现 `r = mid` 时向下取整。这样 $mid$ 永远不会等于"不动的那一端"，每次区间都严格缩小。

记忆方法：写完 `if` 的两个分支后看一眼——有 `l = mid` 就补 `+1`。

**另一种常见写法**（记录答案）：

```
while (l <= r) {
    int mid = (l + r) / 2;
    if (check(mid)) ans = mid, r = mid - 1;
    else l = mid + 1;
}
```

每次可行就记下来，再往更优的方向找。这种写法不会死循环，$ans$ 的初值可以设成"无解"的标记。两种写法选一种练熟即可。

**区间的初值要包含答案。** 如果答案可能不存在（所有 $check$ 都是 F），把右端点多放一格作为"哨兵"：比如找第一个 $\ge x$ 的位置时设 $r = n + 1$，结果为 $n + 1$ 就表示不存在。

### 2.3 有序数组上的四种查找

设数组 $a_1 \le a_2 \le \cdots \le a_n$：

| 要找的 | check | 写法 | STL |
| --- | --- | --- | --- |
| 第一个 $\ge x$ | $a_i \ge x$ | 第一个 T | `lower_bound(a + 1, a + 1 + n, x) - a` |
| 第一个 $> x$ | $a_i > x$ | 第一个 T | `upper_bound(a + 1, a + 1 + n, x) - a` |
| 最后一个 $\le x$ | $a_i \le x$ | 最后一个 T | 第一个 $> x$ 的位置减 1 |
| 最后一个 $< x$ | $a_i < x$ | 最后一个 T | 第一个 $\ge x$ 的位置减 1 |

```
下标   1  2  3  4  5  6
a      1  3  3  3  7  9      x = 3
lower_bound -> 2   (第一个 >= 3)
upper_bound -> 5   (第一个 > 3)
3 出现的次数 = 5 - 2 = 3
```

STL 的 `lower_bound` / `upper_bound` 返回的是**指针**，减去 `a` 得到下标；找不到时返回末尾 `a + 1 + n`，即下标 $n + 1$。对 `vector` 用 `lower_bound(v.begin(), v.end(), x) - v.begin()`。降序数组要传 `greater<int>()`。

### 2.4 实数二分

答案是实数时没有"相邻整数"，区间不会缩成一个点。两种控制方式：

- **固定次数**：循环 100 次，区间长度缩小到原来的 $2^{-100}$，对任何题都足够；
- **按精度**：`while (r - l > 1e-7)`，精度一般取比题目要求多两位。

实数二分里永远写 `l = mid` 和 `r = mid`，不需要 $\pm 1$。固定次数的写法更稳，不会因为精度设得太小、浮点数无法再缩小而死循环。

### 2.5 二分答案

**例：跳石头。** 起点 0、终点 $L$ 之间有 $n$ 块石头，最多移走 $m$ 块，使相邻两次跳跃的最短距离尽量大。

直接求"最短跳跃的最大值"很难。换个问题：**如果要求每次跳跃都 $\ge x$，最少要移走几块石头？** 这个问题可以贪心：从起点出发，下一块石头离上一个落脚点不足 $x$ 就移走它，否则跳过去。移走数 $\le m$ 就说明 $x$ 可行。

单调性：$x$ 可行时，任何更小的 $x'$ 也可行（同样的移法就满足要求）。所以可行性形如 TTT...TFFF，二分找最后一个 T。

二分答案的一般步骤：

1. **确定答案范围** $[l, r]$；
2. **写检验函数** $check(x)$：答案为 $x$ 时能否做到。常常是一个贪心，也可能是前缀和、BFS、DP；
3. **证明单调性**：$x$ 可行能推出更宽松的 $x'$ 也可行；
4. **确定方向**：求最大可行值找最后一个 T，求最小可行值找第一个 T。

**识别信号**：

- "最大值最小""最小值最大"；
- "至少/至多需要多少……才能……"；
- 答案范围很大（$10^9$、$10^{18}$），但验证一个答案只需 $O(n)$ 或 $O(n \log n)$。

**为什么二分答案能简化问题？** 把"求最优值"变成"判断可行性"，相当于多知道了一个条件。比如"最小化分段和的最大值"本身没有直接的做法，但"每段和不超过 $x$，至少要分几段"可以贪心：能往当前段加就加，加不下就新开一段。

## 3. 代码模板

**手写二分**：对有序数组的每个询问 $x$，输出第一个 $\ge x$ 的位置（不存在为 $n+1$）、最后一个 $\le x$ 的位置（不存在为 $0$），以及 $x$ 的出现次数。

```cpp
const int N = 1e5 + 5;
int n, q;
int a[N];

int fst(int x) {
    int l = 1, r = n + 1;
    while (l < r) {
        int mid = (l + r) / 2;
        if (a[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return l;
}

int lst(int x) {
    int l = 0, r = n;
    while (l < r) {
        int mid = (l + r + 1) / 2;
        if (a[mid] <= x) l = mid;
        else r = mid - 1;
    }
    return l;
}

void solve() {
    cin >> n >> q;
    For(i, 1, n) cin >> a[i];
    while (q--) {
        int x;
        cin >> x;
        cout << fst(x) << " " << lst(x) << " " << lst(x) - fst(x) + 1 << endl;
    }
}
```

**STL 二分**：

```cpp
const int N = 1e5 + 5;
int n, q;
int a[N];

void solve() {
    cin >> n >> q;
    For(i, 1, n) cin >> a[i];
    sort(a + 1, a + 1 + n);
    while (q--) {
        int x;
        cin >> x;
        int p = lower_bound(a + 1, a + 1 + n, x) - a;
        int c = upper_bound(a + 1, a + 1 + n, x) - lower_bound(a + 1, a + 1 + n, x);
        cout << p << " " << c << endl;
    }
}
```

**实数二分**：求 $c \ge 0$ 的立方根，保留 6 位小数。

```cpp
double c;

void solve() {
    cin >> c;
    double l = 0, r = max(1.0, c);
    Rep(t, 0, 100) {
        double mid = (l + r) / 2;
        if (mid * mid * mid >= c) r = mid;
        else l = mid;
    }
    cout << fixed << setprecision(6) << l;
}
```

右端点取 $\max(1, c)$，因为 $c < 1$ 时立方根比 $c$ 大。

**二分答案：最小值最大（跳石头）**：

```cpp
const int N = 5e4 + 5;
int len, n, m;
int d[N];

bool check(int x) {
    int cnt = 0, last = 0;
    For(i, 1, n + 1) {
        if (d[i] - last < x) cnt++;
        else last = d[i];
    }
    return cnt <= m;
}

void solve() {
    cin >> len >> n >> m;
    For(i, 1, n) cin >> d[i];
    d[n + 1] = len;
    int l = 1, r = len;
    while (l < r) {
        int mid = (l + r + 1) / 2;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    cout << l;
}
```

终点不能移走。把终点当作第 $n + 1$ 块石头一起判断：如果终点离上一个落脚点太近，等价于把那个落脚点移走，移走的块数一样。

**二分答案：最大值最小（数列分段）**：把 $n$ 个正整数分成 $m$ 段连续的段，使最大的段和最小。

```cpp
const int N = 1e5 + 5;
int n, m;
int a[N];

bool check(int x) {
    int cnt = 1, sum = 0;
    For(i, 1, n) {
        if (sum + a[i] > x) cnt++, sum = 0;
        sum += a[i];
    }
    return cnt <= m;
}

void solve() {
    cin >> n >> m;
    int l = 0, r = 0;
    For(i, 1, n) cin >> a[i], l = max(l, a[i]), r += a[i];
    while (l < r) {
        int mid = (l + r) / 2;
        if (check(mid)) r = mid;
        else l = mid + 1;
    }
    cout << l;
}
```

下界取最大元素（每段至少要装下单个最大的数，否则检验函数会出错），上界取总和。

## 4. 复杂度

- 二分查找：$O(\log n)$，$n = 10^9$ 时约 30 次，$10^{18}$ 时约 60 次。
- 二分答案：$O(\log V \cdot C)$，$V$ 是答案范围，$C$ 是一次检验的代价。比如检验 $O(n)$、答案范围 $10^9$，总共约 $30n$。
- 实数二分固定 100 次：$O(100 \cdot C)$。
- 二分前通常要排序，$O(n \log n)$。

## 5. 常见题型与技巧

1. **有序数组查找、计数**：值为 $x$ 的个数、落在 $[L, R]$ 内的个数（`upper_bound(R) - lower_bound(L)`）。
2. **对每个元素二分配对**：如"统计 $a_i - a_j = c$ 的对数"，排序后对每个 $a_i$ 二分查找 $a_i - c$ 的个数。
3. **最大值最小 / 最小值最大**：二分答案 + 贪心检验，如数列分段、跳石头、砍树、木材加工。
4. **二分 + 前缀和 / 差分**：检验函数里用前缀和或差分 $O(n)$ 判断（借教室：二分能满足前几个订单，用差分检验）。
5. **二分 + 图论或 DP**：检验函数是一次 BFS、最短路或树形 DP（CSP-S 2023 种树、CSP-S 2026 研发基地）。
6. **平均值最大**：要求一个子段（长度 $\ge L$）的平均值最大。二分答案 $x$，把每个数都减去 $x$，问题变成"是否存在长度 $\ge L$ 的子段和 $\ge 0$"，用前缀和加前缀最小值 $O(n)$ 判断。这是实数二分答案的典型。
7. **在单调函数上二分**：求最小的 $k$ 使某个递增的式子 $\ge$ 目标值，比如求平方根的整数部分。
8. **答案太大要二分**：答案可能到 $10^{18}$ 时，注意 $mid$ 相关的计算不要溢出（比如 $mid \times mid$ 可能超过 $2^{63}$，改成 $mid \le c / mid$ 比较）。

## 6. 易错点

- **死循环**：`l = mid` 却没把 $mid$ 向上取整。
- **区间不含答案**：$r$ 设小了、或者无解情况没有留哨兵。先想清楚"答案最小可能是多少、最大可能是多少"。
- **数组没排序就二分**：`lower_bound` 要求有序，否则结果无意义。
- **单调性没想清楚**：check 不单调时二分会给出错误答案。写之前先说服自己"$x$ 可行 ⇒ 更宽松的也可行"。
- **方向搞反**：求"最大的可行值"要找最后一个 T；求"最小的可行值"找第一个 T。
- **负数取中点**：C++ 整数除法向 0 取整，$l, r$ 可能为负时 $(l + r) / 2$ 不是向下取整，改用 `(l + r) >> 1`（算术右移，向下取整）。
- **检验函数的边界**：数列分段里如果下界小于最大元素，会出现"一个数自己就装不下"的情况；检验函数要么保证 $x$ 不会过小，要么单独处理。
- **实数二分精度**：输出要求 2 位小数时，二分精度至少要到 $10^{-4}$；用固定次数最省心。
- **STL 返回值**：`lower_bound` 返回指针或迭代器，要减去数组首地址；1-indexed 时减 `a` 而不是 `a + 1`。
