# 倍增

**组别**：S　**关键词**：倍增、二进制拆分、跳跃表、试跳、路径信息合并、k 级祖先、LCA

## 1. 是什么 / 解决什么问题

有 $n$ 个点，每个点 $i$ 有一个唯一的"下一个点" $nxt_i$。问：从 $x$ 出发，沿 $nxt$ 走 $t$ 步后到哪里？$t$ 可达 $10^{18}$，询问有很多次。

一步一步走要 $O(t)$，太慢。但任何正整数都能写成若干个 2 的幂之和，比如 $13 = 8 + 4 + 1$。如果我们事先知道"从每个点走 $1, 2, 4, 8, \dots$ 步分别到哪里"，那么走 13 步就是：先走 8 步，再走 4 步，再走 1 步，只需 3 次跳跃。

这就是**倍增**：预处理每个状态跳 $2^k$ 步的结果，查询时把步数**二进制拆分**，只需 $O(\log t)$ 次跳跃。存放"跳 $2^k$ 步结果"的二维数组叫**跳跃表**。

倍增的典型用途：

- 在"每个状态有唯一后继"的结构上跳很多步（函数图、链表、贪心的下一步）；
- 在单调的条件下**从大到小试跳**，找最远能到的位置（相当于二分）；
- 树上求 $k$ 级祖先、最近公共祖先（LCA）、路径上的最值或和；
- 快速幂、ST 表的思想也都是倍增。

## 2. 核心原理

### 2.1 跳跃表的递推

令 $f_{k,i}$ 表示从 $i$ 出发走 $2^k$ 步到达的点。

- $f_{0,i} = nxt_i$（走 1 步）；
- 走 $2^k$ 步 = 先走 $2^{k-1}$ 步，再走 $2^{k-1}$ 步：

$$f_{k,i} = f_{k-1,\ f_{k-1,i}}$$

计算 $f_k$ 时要用到整层 $f_{k-1}$，所以**外层循环是 $k$**，内层是 $i$。

以链 $1 \to 2 \to 3 \to \dots \to 8 \to 8$（8 指向自己）为例：

| $i$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| $f_0$（1 步） | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 8 |
| $f_1$（2 步） | 3 | 4 | 5 | 6 | 7 | 8 | 8 | 8 |
| $f_2$（4 步） | 5 | 6 | 7 | 8 | 8 | 8 | 8 | 8 |

例如 $f_{2,1} = f_{1, f_{1,1}} = f_{1,3} = 5$：从 1 走 2 步到 3，再走 2 步到 5。

### 2.2 查询：二进制拆分

从 $x$ 走 $t$ 步：枚举 $t$ 的每个二进制位 $k$，若第 $k$ 位是 1，就 $x \leftarrow f_{k,x}$。

例如 $t = 6 = 110_2$，从 1 出发：第 1 位是 1，$x = f_{1,1} = 3$；第 2 位是 1，$x = f_{2,3} = 7$。确实从 1 走 6 步到 7。

由于"走 $a$ 步再走 $b$ 步"和"走 $b$ 步再走 $a$ 步"结果一样（都是走 $a + b$ 步），二进制位从低到高、从高到低处理都可以。

### 2.3 试跳：找最远满足条件的位置

另一类问题：从 $x$ 出发，**最多**能走多少步，使得某个条件仍然满足？要求条件具有单调性——走 $s$ 步满足，那么走更少的步也满足。

做法是**从大到小**尝试每个 $k$：如果再跳 $2^k$ 步后条件仍满足，就跳；否则不跳。

为什么对：设答案是 $T$。从最高位往下看，这个过程就是在逐位确定 $T$ 的二进制表示。处理到第 $k$ 位时，已经跳了 $s$ 步（$s$ 等于 $T$ 的高位部分）；若 $s + 2^k \le T$ 则条件满足、会跳，否则不满足、不跳。所以最后恰好跳了 $T$ 步。这和二分查找本质相同，但不需要"随机访问第 $mid$ 步的位置"——只需要跳跃表。

### 2.4 维护路径信息

很多题不只要知道跳到哪，还要知道**一路上经过的信息**：路径和、最小值、最大值……可以再开一个表 $g_{k,i}$ 表示从 $i$ 出发跳 $2^k$ 步这一段的信息：

$$g_{k,i} = g_{k-1,i} \oplus g_{k-1,\ f_{k-1,i}}$$

$\oplus$ 是合并运算（加法、取 min、取 max……）。查询时边跳边合并。要求合并运算满足**结合律**，否则分段合并的结果和逐步计算不一样。如果运算不满足交换律（比如矩阵乘法），合并顺序要和行走顺序一致。

### 2.5 与其他算法的联系

- **快速幂**：$a^{2^k} = (a^{2^{k-1}})^2$，把指数二进制拆分，就是"跳跃表只有一个状态"的倍增（见数学"模运算、快速幂与逆元"）。
- **ST 表**：$st_{k,i}$ 表示区间 $[i, i + 2^k)$ 的最大值，$st_{k,i} = \max(st_{k-1,i},\ st_{k-1,\ i + 2^{k-1}})$，跳跃表的"下一个点"就是 $i + 2^{k-1}$（见数据结构"ST 表"）。
- **树上倍增**：每个点的"下一个点"是父亲，$f_{k,u}$ 就是 $u$ 的 $2^k$ 级祖先，可以求 $k$ 级祖先和 LCA（见图论"树的直径、重心与最近公共祖先"）。

## 3. 代码模板

### 3.1 后继跳 $t$ 步

$n$ 个点，第 $i$ 个点的后继是 $nxt_i$。$q$ 次询问：从 $x$ 出发走 $t$ 步（$t \le 10^{18}$）到哪里。

```cpp
const int N = 1e5 + 5, LOG = 60;
int n, q;
int f[LOG][N];

void solve() {
    cin >> n >> q;
    For(i, 1, n) cin >> f[0][i];
    Rep(k, 1, LOG) For(i, 1, n) f[k][i] = f[k - 1][f[k - 1][i]];
    while (q--) {
        int x, t;
        cin >> x >> t;
        Rep(k, 0, LOG) if (t >> k & 1) x = f[k][x];
        cout << x << endl;
    }
}
```

$2^{60} > 10^{18}$，所以 60 层够用。`f` 有 $60 \times 10^5$ 个 64 位整数，约 48MB；内存紧时可以把它声明成 32 位的 `signed` 数组（点的编号用不到 64 位）。

### 3.2 跳 $t$ 步的路径和

每个点 $i$ 有后继 $nxt_i$ 和权值 $w_i$，从 $x$ 出发走 $t$ 步（$t \le 10^9$），求经过的 $t$ 个起点的权值和（即每一步出发点的权值之和）。

```cpp
const int N = 1e5 + 5, LOG = 30;
int n, q;
int f[LOG][N], g[LOG][N];

void solve() {
    cin >> n >> q;
    For(i, 1, n) cin >> f[0][i] >> g[0][i];
    Rep(k, 1, LOG) For(i, 1, n) {
        f[k][i] = f[k - 1][f[k - 1][i]];
        g[k][i] = g[k - 1][i] + g[k - 1][f[k - 1][i]];
    }
    while (q--) {
        int x, t, s = 0;
        cin >> x >> t;
        Rep(k, 0, LOG) if (t >> k & 1) s += g[k][x], x = f[k][x];
        cout << s << endl;
    }
}
```

注意 `s += g[k][x]` 要在 `x = f[k][x]` **之前**：先累加这一段的信息，再跳到段的终点。把 `+` 换成 `min` / `max` 就是路径最小值 / 最大值。

### 3.3 从大到小试跳（代替二分）

非负数组 $a$，$q$ 次询问 $(x, s)$：从 $x$ 开始往右，最多能取几个连续的数使和 $\le s$。

```cpp
const int N = 1e5 + 5, LOG = 17;
int n, q;
int a[N], pre[N];

void solve() {
    cin >> n >> q;
    For(i, 1, n) cin >> a[i], pre[i] = pre[i - 1] + a[i];
    while (q--) {
        int x, s, p;
        cin >> x >> s;
        p = x - 1;
        for (int k = LOG - 1; k >= 0; k--)
            if (p + (1 << k) <= n && pre[p + (1 << k)] - pre[x - 1] <= s) p += 1 << k;
        cout << p - x + 1 << endl;
    }
}
```

$p$ 是当前取到的最后一个位置。$2^{17} > 10^5$，所以 17 层够用。这里的"跳 $2^k$ 步"就是下标加 $2^k$，不需要跳跃表，体现的是 2.3 的试跳思想。

### 3.4 贪心 + 倍增：区间最少分段数

数组 $a$（每个 $a_i \le S$），$q$ 次询问 $[l, r]$：把这一段切成若干连续段，每段和 $\le S$，最少几段。

单次询问的贪心：从 $l$ 开始，每段尽量往右延伸。记 $nxt_i$ 为从 $i$ 开始一段最远延伸后的**下一段起点**，那么答案就是从 $l$ 沿 $nxt$ 跳、直到超过 $r$ 的跳跃次数。$nxt$ 用双指针求，跳跃用倍增。

```cpp
const int N = 1e5 + 5, LOG = 17;
int n, q, S;
int a[N], f[LOG][N];

void solve() {
    cin >> n >> q >> S;
    For(i, 1, n) cin >> a[i];
    int j = 1, sum = 0;
    For(i, 1, n) {
        while (j <= n && sum + a[j] <= S) sum += a[j++];
        f[0][i] = j, sum -= a[i];
    }
    f[0][n + 1] = n + 1;
    Rep(k, 1, LOG) For(i, 1, n + 1) f[k][i] = f[k - 1][f[k - 1][i]];
    while (q--) {
        int l, r, cnt = 0;
        cin >> l >> r;
        for (int k = LOG - 1; k >= 0; k--)
            if (f[k][l] <= r) l = f[k][l], cnt += 1 << k;
        cout << cnt + 1 << endl;
    }
}
```

- $n + 1$ 是"走出数组"的哨兵，指向自己，防止跳出边界。
- 试跳条件是"跳完后的新起点仍 $\le r$"，即这些段还没盖住整个 $[l, r]$；跳完以后，从当前 $l$ 开始的最后一段一定能盖到 $r$，所以答案再加 1。

### 3.5 树上倍增：$k$ 级祖先与 LCA

以 1 为根的树，询问 `1 u k` 输出 $u$ 的 $k$ 级祖先（不存在输出 0），询问 `2 u v` 输出 $u, v$ 的最近公共祖先。

```cpp
const int N = 1e5 + 5, LOG = 17;
int n, q;
int dep[N], f[LOG][N];
vector<int> g[N];

void dfs(int u, int fa) {
    dep[u] = dep[fa] + 1, f[0][u] = fa;
    Rep(k, 1, LOG) f[k][u] = f[k - 1][f[k - 1][u]];
    for (int v : g[u])
        if (v != fa) dfs(v, u);
}

int kth(int u, int k) {
    Rep(i, 0, LOG) if (k >> i & 1) u = f[i][u];
    return u;
}

int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    u = kth(u, dep[u] - dep[v]);
    if (u == v) return u;
    for (int k = LOG - 1; k >= 0; k--)
        if (f[k][u] != f[k][v]) u = f[k][u], v = f[k][v];
    return f[0][u];
}

void solve() {
    cin >> n >> q;
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    dfs(1, 0);
    while (q--) {
        int op, u, v;
        cin >> op >> u >> v;
        if (op == 1) cout << kth(u, v) << endl;
        else cout << lca(u, v) << endl;
    }
}
```

- 树上不是"先算完整层再算下一层"，而是 DFS 到 $u$ 时它的所有祖先都已经算好，所以可以直接对 $u$ 算出所有 $k$。
- 0 号点是哨兵：根的父亲是 0，$f_{k,0} = 0$，跳过头就停在 0。
- LCA 的思路：先把较深的点跳到同一深度；若重合就是答案；否则两点**从大到小试跳**，只要跳后的祖先不同就跳（保证仍在 LCA 下方），最后两点的父亲就是 LCA。这正是 2.3 的试跳，条件是"跳完仍未相遇"。详细讲解见图论篇。

## 4. 复杂度

设状态数为 $n$，最大步数为 $T$，层数 $L = \lceil \log_2 (T + 1) \rceil$：

| | 时间 | 空间 |
|:-:|:-:|:-:|
| 预处理跳跃表 | $O(nL)$ | $O(nL)$ |
| 单次跳 $t$ 步 / 试跳 | $O(L)$ | |
| 树上倍增预处理 | $O(n \log n)$ | $O(n \log n)$ |
| $k$ 级祖先、LCA 查询 | $O(\log n)$ | |

倍增最大的代价是空间：$n = 10^5$、$L = 60$ 时，一个 64 位跳跃表就要 48MB，再加上一个信息表就翻倍。内存紧张时用 32 位数组，或者把能离线的询问离线处理。

## 5. 常见题型与技巧

- **超大步数的模拟**：每个状态有唯一后继（函数图、"每个人把东西传给固定的人"、置换），步数达到 $10^9 \sim 10^{18}$，直接倍增。
- **贪心的"下一步"可以预处理**：分段、区间覆盖、跳跃游戏等，单次询问的贪心是"不断走到最远的下一步"，多次询问时把"下一步"做成跳跃表。
- **环形问题**：把环断开复制一倍成长度 $2n$ 的链，再在链上倍增（例如环上用最少区间覆盖一圈）。
- **多人交替行动**：如果一"轮"由几个人依次行动组成，把一整轮当作跳跃表的"一步"，就又变成了唯一后继的模型。
- **树上路径问题**：$k$ 级祖先、LCA、路径最大边权、路径和；配合 2.4 同时维护路径信息。
- **代替二分**：答案在一个单调的序列上，试跳和二分等价；当"第 $mid$ 个位置"不能直接访问、只能"跳"过去时，只能用倍增。
- **倍增 + 其他结构**：倍增 Floyd（$2^k$ 步可达）、矩阵快速幂（见数学篇）。

## 6. 易错点

- **层数不够**：$L$ 要满足 $2^L > T$。$t \le 10^{18}$ 要 60 层，树上 $n \le 5 \times 10^5$ 要 19 层。
- **循环顺序写反**：非树结构的跳跃表必须先算完 $f_{k-1}$ 整层再算 $f_k$，外层循环是 $k$。
- **跳出边界**：后继可能"不存在"时，设一个哨兵状态指向自己（数组的 $n + 1$、树上的 0），并让试跳条件能识别哨兵。
- **试跳顺序**：单纯跳 $t$ 步时顺序无所谓，**试跳必须从大到小**。
- **信息合并的时机**：先用跳之前的位置累加信息，再跳。
- **`1 << k` 溢出**：$k \ge 31$ 时要写 `1LL << k`；判断 $t$ 的第 $k$ 位用 `t >> k & 1` 更安全。
- **LCA 忘了先调到同一深度**，或者调完没判断 $u = v$。
- **内存超限**：$L \times n$ 的 `long long` 数组很大，开之前先算一下。
