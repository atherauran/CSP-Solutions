# 背包问题

**组别**：J　**关键词**：0/1 背包、完全背包、多重背包、二进制拆分、分组背包、二维费用背包、背包计数、恰好装满

## 1. 是什么 / 解决什么问题

有一个容量为 $m$ 的背包和 $n$ 个物品，第 $i$ 个物品的体积（重量、花费）为 $w_i$，价值为 $v_i$。选若干物品放进背包，总体积不超过 $m$，求最大总价值。

根据每种物品能选几次，分成：

| 类型 | 每种物品可选次数 |
| --- | --- |
| 0/1 背包 | 0 或 1 次 |
| 完全背包 | 无限次 |
| 多重背包 | 最多 $c_i$ 次 |
| 分组背包 | 物品分组，每组最多选 1 个 |

还有很多变形：二维费用（体积和重量都有限制）、恰好装满、求方案数、求具体方案、有依赖……它们的核心都是同一个 DP。

背包为什么不能贪心？按"性价比" $v_i/w_i$ 从大到小装，在物品可以切开时是对的，但物品不可分割时会留下装不满的空隙。例如 $m = 4$，物品 $(3, 5)$ 和两个 $(2, 3)$：贪心先拿性价比 $5/3$ 的，剩下 1 装不下别的，得 5；而拿两个 $(2,3)$ 得 6。

## 2. 核心原理

### 2.1 0/1 背包

**状态**：$f_{i,j}$ = 只考虑前 $i$ 个物品、总体积不超过 $j$ 时的最大价值。

**转移**：看第 $i$ 个物品选不选：

$$f_{i,j} = \max\big(f_{i-1,j},\ f_{i-1,j-w_i} + v_i\big) \quad (j \ge w_i \text{ 时才有第二项})$$

**边界**：$f_{0,j} = 0$。**答案**：$f_{n,m}$。

例：$m = 5$，物品 $(w, v)$ 为 $(1,2), (2,4), (3,4), (4,5)$。

| $i$ \ $j$ | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 1：$(1,2)$ | 0 | 2 | 2 | 2 | 2 | 2 |
| 2：$(2,4)$ | 0 | 2 | 4 | 6 | 6 | 6 |
| 3：$(3,4)$ | 0 | 2 | 4 | 6 | 6 | 8 |
| 4：$(4,5)$ | 0 | 2 | 4 | 6 | 6 | **8** |

例如 $f_{3,5} = \max(f_{2,5}, f_{2,2} + 4) = \max(6, 8) = 8$，即选物品 2、3。

### 2.2 空间优化：倒序枚举容量

第 $i$ 行只依赖第 $i-1$ 行，可以只用一维数组 $f_j$。关键是**容量 $j$ 要从大到小枚举**：

```
for j = m down to w[i]:  f[j] = max(f[j], f[j - w[i]] + v[i])
```

更新 $f_j$ 时要用到 $f_{j-w_i}$，它的下标更小。倒序时 $f_{j-w_i}$ 还没被本轮更新，仍然是"前 $i-1$ 个物品"的值，正好对应 $f_{i-1,j-w_i}$。

如果正序枚举，$f_{j-w_i}$ 已经在本轮更新过、可能已经放了物品 $i$，再加一次就等于物品 $i$ 选了多次——这恰好是**完全背包**。

### 2.3 "不超过"与"恰好"

| 要求 | 初值 | 答案 |
| --- | --- | --- |
| 总体积**不超过** $m$ | $f_j = 0$（全部） | $f_m$ |
| 总体积**恰好**为 $m$ | $f_0 = 0$，其余 $-\infty$ | $f_m$（仍为 $-\infty$ 说明无解） |

理解：初值 $f_j$ 表示"一个物品都不选、体积为 $j$"的价值。不选物品时体积只能是 0，所以"恰好"语义下只有 $f_0$ 合法；而"不超过"语义下空背包对所有 $j$ 都合法。求最小值的问题把 $-\infty$ 换成 $+\infty$。

### 2.4 完全背包

每种物品无限个。朴素转移枚举选了 $k$ 个：

$$f_{i,j} = \max_{k \ge 0} f_{i-1,j-kw_i} + k v_i$$

注意到 $f_{i,j-w_i} = \max_{k \ge 0} f_{i-1,j-w_i-kw_i} + kv_i$，把它代进来（相当于把"$k \ge 1$"的部分整体提出一个物品）：

$$f_{i,j} = \max\big(f_{i-1,j},\ f_{i,j-w_i} + v_i\big)$$

和 0/1 背包只差一个下标：第二项来自**本行** $f_{i,\cdot}$。一维写法就是 $j$ **从小到大**枚举。

### 2.5 多重背包

第 $i$ 种物品有 $c_i$ 个。

**朴素做法**：拆成 $c_i$ 个相同的 0/1 物品，复杂度 $O(m \sum c_i)$。

**二进制拆分**：把 $c_i$ 拆成 $1, 2, 4, \dots, 2^{k-1}, r$，其中 $r = c_i - (2^k - 1)$，$0 < r \le 2^k$（或不足时停止）。每一份打包成一个 0/1 物品（体积 $\times$ 份数、价值 $\times$ 份数）。

为什么能凑出 $0 \sim c_i$ 的所有数？$1, 2, \dots, 2^{k-1}$ 能凑出 $0 \sim 2^k - 1$；再加上 $r$ 就能凑出 $r \sim c_i$；因为 $r \le 2^k$，这两段连上了。例如 $13 = 1 + 2 + 4 + 6$：前三个凑 $0 \sim 7$，加 6 凑 $6 \sim 13$。而且拆出来的组合不会超过 $c_i$。

复杂度 $O(m \sum \log c_i)$。更快的单调队列优化 $O(nm)$ 见"动态规划优化"。

### 2.6 混合背包

有的物品 0/1、有的无限、有的有限：对每个物品按自己的类型选择循环方式即可——转移只看当前物品，和别的物品是什么类型无关。

### 2.7 分组背包

物品分成若干组，每组最多选一个。对每一组：

```
for j = m down to 0:
    for 组内每个物品 k:  if j >= w[k]: f[j] = max(f[j], f[j - w[k]] + v[k])
```

**容量在外、组内物品在内**。对同一个 $j$，组内所有物品读取的 $f_{j-w_k}$ 都还是"上一组"的值，所以只会选到其中一个。如果把物品放在外层，就变成了组内物品各做一次 0/1 背包，可能选多个。

**有依赖的背包**（如金明的预算方案：附件必须和主件一起买，每个主件最多 2 个附件）：把"主件 + 附件的每种搭配"列出来作为一组，组内最多选一种，就是分组背包。依赖关系是一棵树时用树上背包，见"树形动态规划"。

### 2.8 二维费用背包

每个物品有两种花费 $(a_i, b_i)$，两种容量上限 $(A, B)$。状态加一维：$f_{j,k}$，两维都倒序枚举。复杂度 $O(nAB)$。

### 2.9 背包计数与可行性

- **方案数**：把 $\max$ 换成加法：$f_j \mathrel{+}= f_{j-w_i}$，初值 $f_0 = 1$（恰好装满的语义）。
- **可行性**：$f_j$ 为 bool，表示能否恰好凑出 $j$，$f_j \mathrel{|}= f_{j-w_i}$。可以用 `bitset` 加速：`b |= b << w`，复杂度除以 64。

完全背包计数的一个细节：**物品在外层、容量在内层**，算的是**组合数**（不计顺序，$1+2$ 和 $2+1$ 算一种）；**容量在外层、物品在内层**，算的是**排列数**（计顺序，如爬楼梯每步走 1 或 2）。

### 2.10 求具体方案

保留二维表 $f_{i,j}$，从 $(n, m)$ 往回走：若 $f_{i,j} \ne f_{i-1,j}$，说明物品 $i$ 必须选，$j \gets j - w_i$；否则不选。一维滚动数组无法倒推。

### 2.11 交换"体积"与"价值"

如果体积很大（如 $10^9$）而价值总和很小，就以价值为下标：$g_v$ = 恰好获得价值 $v$ 的最小体积。最后找满足 $g_v \le m$ 的最大 $v$。

## 3. 代码模板

输入格式统一为：第一行 $n, m$，接下来 $n$ 行描述物品。

### 3.1 0/1 背包（二维）

```cpp
const int N = 1e3 + 5;
int n, m;
int w[N], v[N], f[N][N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> w[i] >> v[i];
    For(i, 1, n) For(j, 0, m) {
        f[i][j] = f[i - 1][j];
        if (j >= w[i]) f[i][j] = max(f[i][j], f[i - 1][j - w[i]] + v[i]);
    }
    cout << f[n][m];
}
```

### 3.2 0/1 背包（一维）

```cpp
const int N = 1e5 + 5;
int n, m;
int w[N], v[N], f[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> w[i] >> v[i];
    For(i, 1, n) for (int j = m; j >= w[i]; j--) f[j] = max(f[j], f[j - w[i]] + v[i]);
    cout << f[m];
}
```

### 3.3 完全背包

```cpp
const int N = 1e5 + 5;
int n, m;
int w[N], v[N], f[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> w[i] >> v[i];
    For(i, 1, n) For(j, w[i], m) f[j] = max(f[j], f[j - w[i]] + v[i]);
    cout << f[m];
}
```

### 3.4 多重背包（二进制拆分）

每行 $w_i, v_i, c_i$：

```cpp
const int N = 1e5 + 5;
int n, m, cnt;
int w[N], v[N], f[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) {
        int a, b, c;
        cin >> a >> b >> c;
        for (int k = 1; k <= c; k *= 2) {
            w[++cnt] = a * k, v[cnt] = b * k;
            c -= k;
        }
        if (c > 0) w[++cnt] = a * c, v[cnt] = b * c;
    }
    For(i, 1, cnt) for (int j = m; j >= w[i]; j--) f[j] = max(f[j], f[j - w[i]] + v[i]);
    cout << f[m];
}
```

数组大小要按拆分后的物品数 $\sum \lceil \log_2 (c_i + 1) \rceil$ 开。

### 3.5 分组背包

每行 $w_i, v_i, g_i$（$g_i$ 为组号，$1 \le g_i \le n$）：

```cpp
const int N = 1e3 + 5;
int n, m;
int w[N], v[N], f[N];
vector<int> g[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) {
        int x;
        cin >> w[i] >> v[i] >> x;
        g[x].pb(i);
    }
    For(t, 1, n) for (int j = m; j >= 0; j--)
        for (int k : g[t])
            if (j >= w[k]) f[j] = max(f[j], f[j - w[k]] + v[k]);
    cout << f[m];
}
```

### 3.6 二维费用背包

第一行 $n, A, B$，每行 $a_i, b_i, v_i$：

```cpp
const int N = 2e2 + 5;
int n, A, B;
int a[N], b[N], v[N], f[N][N];

void solve() {
    cin >> n >> A >> B;
    For(i, 1, n) cin >> a[i] >> b[i] >> v[i];
    For(i, 1, n)
        for (int j = A; j >= a[i]; j--)
            for (int k = B; k >= b[i]; k--) f[j][k] = max(f[j][k], f[j - a[i]][k - b[i]] + v[i]);
    cout << f[A][B];
}
```

### 3.7 方案数（恰好凑出 $m$）

$n$ 个物品，每行一个 $w_i$，每个最多用一次，求总和恰好为 $m$ 的选法数：

```cpp
const int N = 1e4 + 5;
int n, m;
int w[N], f[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> w[i];
    f[0] = 1;
    For(i, 1, n) for (int j = m; j >= w[i]; j--) f[j] = (f[j] + f[j - w[i]]) % MOD;
    cout << f[m];
}
```

### 3.8 输出具体方案

在 0/1 背包二维表上倒推，输出选中的物品编号：

```cpp
const int N = 1e3 + 5;
int n, m;
int w[N], v[N], f[N][N];
vector<int> res;

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> w[i] >> v[i];
    For(i, 1, n) For(j, 0, m) {
        f[i][j] = f[i - 1][j];
        if (j >= w[i]) f[i][j] = max(f[i][j], f[i - 1][j - w[i]] + v[i]);
    }
    cout << f[n][m] << endl;
    int j = m;
    for (int i = n; i >= 1; i--)
        if (f[i][j] != f[i - 1][j]) res.pb(i), j -= w[i];
    reverse(res.begin(), res.end());
    for (int x : res) cout << x << " ";
}
```

### 3.9 体积很大：以价值为下标

$w_i \le 10^9$，$\sum v_i \le 10^5$：

```cpp
const int N = 1e5 + 5;
int n, m, sum;
int w[N], v[N], g[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> w[i] >> v[i], sum += v[i];
    For(j, 1, sum) g[j] = LINF;
    For(i, 1, n) for (int j = sum; j >= v[i]; j--) g[j] = min(g[j], g[j - v[i]] + w[i]);
    for (int j = sum; j >= 0; j--)
        if (g[j] <= m) {
            cout << j;
            return;
        }
}
```

## 4. 复杂度

| 类型 | 时间 | 空间 |
| --- | --- | --- |
| 0/1、完全 | $O(nm)$ | $O(m)$ |
| 多重（朴素） | $O(m \sum c_i)$ | $O(m)$ |
| 多重（二进制拆分） | $O(m \sum \log c_i)$ | $O(m)$ |
| 多重（单调队列） | $O(nm)$ | $O(m)$ |
| 分组 | $O(m \cdot \text{物品总数})$ | $O(m)$ |
| 二维费用 | $O(nAB)$ | $O(AB)$ |

背包的复杂度和容量 $m$ 成正比，$m$ 是数值而不是输入长度，所以 $m$ 到 $10^9$ 时不能直接做（这种复杂度叫"伪多项式"）。

## 5. 常见题型与技巧

- **识别背包**：题目里出现"若干个东西，每个选或不选，总和有上限/恰好等于某值"，就往背包想。"容量"不一定是体积，可能是钱、时间、步数、和的大小。
- **容量的上界**：有时题目没直接给容量，但可以推出总和的上界（如 CSP-J 2025 多边形只需维护到 $\max a$），超过的部分不会被用到，直接截断。
- **把复杂过程拆成背包**：CSP-J 2019 纪念品把多天持有拆成相邻两天"今天买明天卖"，每一天是一个完全背包。
- **补集与计数**：要数"和大于 $x$"的方案，可以用总方案减去"和不超过 $x$"的方案，后者是背包计数。
- **可行性 + bitset**：只关心能否凑出某个和时，`bitset<N> b; b[0] = 1; b |= b << w;` 速度是普通 bool 数组的 64 倍左右。
- **物品数很多但种类少**：相同物品合并成多重背包。
- **价值可负 / 求最小值**：初值相应改成 $\pm\infty$，并注意不可达状态不能参与转移。

## 6. 易错点

- 0/1 背包一维写成了正序（变成完全背包），完全背包写成了倒序（变成 0/1）。
- "恰好装满"忘记把 $f_1 \sim f_m$ 初始化为 $-\infty$。
- 分组背包把组内物品放在外层循环，导致同组选了多个。
- 二进制拆分后的物品数组开小了。
- 多组数据没有清空 $f$。
- 价值总和超过 `int` 范围（模板里 `int` 是 64 位，一般不用担心；若为了省内存改成 32 位要特别注意）。
- 方案数忘记取模；或者把组合数和排列数的循环顺序弄反。
- 想输出方案却用了滚动数组。
