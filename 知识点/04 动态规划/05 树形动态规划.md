# 树形动态规划

**组别**：S　**关键词**：子树、最大独立集、最小点覆盖、最小支配集、树上背包、换根 DP、二次扫描

## 1. 是什么 / 解决什么问题

在树上做 DP，状态通常定义在**子树**上：

> $f_{u,\dots}$ = 只考虑以 $u$ 为根的子树时的最优值（或方案数）。

树天然适合 DP：以 $u$ 为根的子树由 $u$ 自己和若干棵**互不相交**的孩子子树组成，孩子子树之间除了都连着 $u$ 以外没有任何联系。所以只要知道每个孩子子树的答案，再考虑 $u$ 本身怎么选，就能合并出 $u$ 的答案。

计算顺序是**先孩子后父亲**，即 DFS 回溯时（后序）计算。

典型问题：

- 树上选点，相邻点有约束（独立集、点覆盖、支配集）；
- 树上选一个包含根的连通块，大小有限制（树上背包）；
- 对**每个点**作为根都求一次答案（换根 DP）。

## 2. 核心原理

### 2.1 基本框架

```
dfs(u, fa):
    初始化 f[u]（只有 u 自己时的值）
    for v in u 的孩子（v != fa）:
        dfs(v, u)
        用 f[v] 更新 f[u]
```

题目给的是无向边时，DFS 时传入父亲以避免走回去。树的深度可能达到 $n$（一条链），递归深度过大时可能爆栈：可以先 BFS 求出访问顺序，再**按 BFS 序倒序**处理（倒序时孩子一定先于父亲），完全不用递归。

### 2.2 最大独立集（没有上司的舞会）

每个点有权值 $a_u$，选出若干点，**相邻的两点不能都选**，求权值和最大。

只记"$u$ 子树的最大值"不够——父亲选不选取决于 $u$ 选没选。所以加一维：

- $f_{u,0}$：$u$ 不选时子树的最大值；
- $f_{u,1}$：$u$ 选时子树的最大值。

$$f_{u,0} = \sum_{v} \max(f_{v,0}, f_{v,1}), \qquad f_{u,1} = a_u + \sum_v f_{v,0}$$

$u$ 不选，孩子随意；$u$ 选，孩子都不能选。答案 $\max(f_{1,0}, f_{1,1})$。

例：根 1 有孩子 2、3，2 有孩子 4、5，权值 $a = (1, 5, 2, 3, 4)$。

| 点 | $f_0$ | $f_1$ |
| --- | --- | --- |
| 4 | 0 | 3 |
| 5 | 0 | 4 |
| 3 | 0 | 2 |
| 2 | $3 + 4 = 7$ | $5 + 0 + 0 = 5$ |
| 1 | $7 + 2 = 9$ | $1 + 7 + 0 = 8$ |

答案 9（选 3、4、5）。

### 2.3 最小点覆盖

选最少的点，使**每条边至少有一个端点被选**。

$$f_{u,0} = \sum_v f_{v,1}, \qquad f_{u,1} = 1 + \sum_v \min(f_{v,0}, f_{v,1})$$

$u$ 不选时，边 $(u, v)$ 只能靠 $v$ 覆盖，所以孩子必须选。

### 2.4 最小支配集

每个点有代价 $c_u$，选若干点，使**每个点要么被选、要么和某个被选的点相邻**，求最小代价。

这次 $u$ 不选时还要区分"被谁覆盖"——被孩子覆盖还是被父亲覆盖，三种状态：

- $f_{u,0}$：$u$ 被选；
- $f_{u,1}$：$u$ 不选，被某个孩子覆盖；
- $f_{u,2}$：$u$ 不选，也没被孩子覆盖，**等父亲来覆盖**。

转移：

$$f_{u,0} = c_u + \sum_v \min(f_{v,0}, f_{v,1}, f_{v,2})$$

$u$ 被选，孩子无论什么状态都已被覆盖（$f_{v,2}$ 等的正是 $u$）。

$$f_{u,2} = \sum_v \min(f_{v,0}, f_{v,1})$$

$u$ 没选，孩子不能指望 $u$，只能自己选或被自己的孩子覆盖。

$f_{u,1}$ 在 $f_{u,2}$ 的基础上要求**至少有一个孩子被选**。先让每个孩子取 $\min(f_{v,0}, f_{v,1})$，如果没有一个孩子取的是 $f_{v,0}$，就把"改选代价"最小的那个孩子强制改成选：

$$f_{u,1} = f_{u,2} + \max\Big(0,\ \min_v \big(f_{v,0} - \min(f_{v,0}, f_{v,1})\big)\Big)$$

叶子没有孩子，$f_{leaf,1} = +\infty$。答案是 $\min(f_{1,0}, f_{1,1})$（根没有父亲）。

这个例子说明了树形 DP 设计状态的要点：**状态要描述"子树和外界的接口"**——子树里的情况会怎样影响父亲，以及子树需要父亲提供什么。

### 2.5 树上背包

每个点有价值，选恰好 $m$ 个点，要求**选了一个点就必须选它的父亲**（选课问题），求最大价值。

设 $f_{u,j}$ 为在 $u$ 的子树中选 $j$ 个点（必须包含 $u$）的最大价值。$u$ 的每个孩子子树相当于一组物品，"在 $v$ 子树中选 $k$ 个"就是这一组里体积为 $k$、价值为 $f_{v,k}$ 的物品，每组最多选一个——**分组背包**：

$$f_{u,j} \gets \max_k \big(f_{u,j-k} + f_{v,k}\big)$$

逐个合并孩子，$j$ 倒序。初始 $f_{u,1} = a_u$。

**复杂度的关键**：枚举 $j$ 和 $k$ 时，用当前已合并的子树大小 $sz_u$ 和 $sz_v$ 作为上界，而不是直接枚举到 $m$：

$$j \le \min(sz_u + sz_v, m), \qquad k \le \min(sz_v, j - 1)$$

这样总复杂度是 $O(n^2)$（有上限 $m$ 时为 $O(nm)$），而不是 $O(nm^2)$。直观理解：合并 $u$ 已有部分（大小 $sz_u$）和 $v$（大小 $sz_v$）的代价是 $sz_u \cdot sz_v$，相当于让"左边的每个点"和"右边的每个点"各配对一次；任意两个点只会在它们的 LCA 处配对一次，所以总数不超过 $n^2$。

森林（有多个没有前置的点）时，加一个虚拟根 0 连向所有根，价值为 0，要选 $m+1$ 个。

### 2.6 换根 DP

有些题要求**以每个点为根**分别求答案。对每个点各做一次 DFS 是 $O(n^2)$。换根 DP（也叫二次扫描）在 $O(n)$ 内完成：

1. **第一次 DFS（自底向上）**：以 1 为根，求出每个点"向下"的信息（子树内的答案）。
2. **第二次 DFS（自顶向下）**：利用父亲的完整答案，推出孩子的完整答案。

**例 1：每个点到所有点的距离和。**

第一遍求出子树大小 $sz_u$ 和 $g_1 = \sum_v \text{depth}_v$（以 1 为根的距离和）。

根从 $u$ 移到孩子 $v$ 时：$v$ 子树里的 $sz_v$ 个点距离都减 1，其余 $n - sz_v$ 个点距离都加 1：

$$g_v = g_u - sz_v + (n - sz_v)$$

```
        u               根从 u 换到 v：
       / \              v 子树（sz_v 个点）各近 1
      v   ...           其他（n - sz_v 个点）各远 1
     / \
```

**例 2：每个点到最远点的距离。**

$v$ 的最远点要么在 $v$ 的子树里（向下），要么在子树外（向上）。

- 向下：$d_{1,u}$ 为 $u$ 向下的最长路径，第一遍求出。
- 向上：$up_v$ 为从 $v$ 先走到父亲 $u$、再不回到 $v$ 子树的最长路径：

$$up_v = w(u,v) + \max(up_u,\ \text{$u$ 向下但不经过 $v$ 的最长路径})$$

"不经过 $v$ 的最长路径"是换根 DP 的典型难点：如果 $u$ 向下最长的路径恰好经过 $v$，就要用**次长**的那条。所以第一遍要同时记录最长 $d_1$、次长 $d_2$（来自不同孩子）以及最长来自哪个孩子。

答案 $\max(d_{1,v}, up_v)$。

**一般方法**：换根时需要"去掉孩子 $v$ 的贡献"。

- 贡献可减（和、计数）：直接减掉，如例 1。
- 贡献不可减（最大值）：记录最大和次大，或对孩子做前缀/后缀合并。

## 3. 代码模板

以下代码的输入均为：第一行 $n$（及其他参数），接下来是点权，再是 $n-1$ 条无向边，以 1 为根。

### 3.1 最大独立集

```cpp
const int N = 1e5 + 5;
int n;
int a[N], f[N][2];
vector<int> g[N];

void dfs(int u, int fa) {
    f[u][1] = a[u];
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        f[u][0] += max(f[v][0], f[v][1]);
        f[u][1] += f[v][0];
    }
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    dfs(1, 0);
    cout << max(f[1][0], f[1][1]);
}
```

### 3.2 最小支配集

```cpp
const int N = 1e5 + 5;
int n;
int c[N], f[N][3];
vector<int> g[N];

void dfs(int u, int fa) {
    f[u][0] = c[u];
    int d = LINF;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        int t = min(f[v][0], f[v][1]);
        f[u][0] += min(t, f[v][2]);
        f[u][2] += t;
        d = min(d, f[v][0] - t);
    }
    f[u][1] = f[u][2] + d;
}

void solve() {
    cin >> n;
    For(i, 1, n) cin >> c[i];
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    dfs(1, 0);
    cout << min(f[1][0], f[1][1]);
}
```

$d = \min_v (f_{v,0} - t_v) \ge 0$，所以不需要再和 0 取 $\max$；叶子没有孩子，$d$ 保持 `LINF`，$f_{u,1}$ 自然是"不可能"。

### 3.3 树上背包（选课）

第一行 $n, m$，接下来 $n$ 行，第 $i$ 行是前置课 $k_i$（0 表示没有）和学分 $s_i$：

```cpp
const int N = 3e2 + 5;
int n, m;
int s[N], sz[N], f[N][N];
vector<int> g[N];

void dfs(int u) {
    sz[u] = 1, f[u][1] = s[u];
    for (int v : g[u]) {
        dfs(v);
        for (int j = min(sz[u] + sz[v], m + 1); j >= 1; j--)
            For(k, max(1LL, j - sz[u]), min(sz[v], j - 1)) f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);
        sz[u] += sz[v];
    }
}

void solve() {
    cin >> n >> m;
    For(i, 1, n) {
        int k;
        cin >> k >> s[i];
        g[k].pb(i);
    }
    dfs(0);
    cout << f[0][m + 1];
}
```

$k \ge j - sz_u$ 保证 $f_{u,j-k}$ 中的 $j - k$ 不超过已合并的大小，读到的都是有意义的值。

### 3.4 换根：每个点到所有点的距离和（非递归）

```cpp
const int N = 1e5 + 5;
int n;
int fa[N], dep[N], sz[N], ans[N];
vector<int> g[N], ord;

void solve() {
    cin >> n;
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    ord.pb(1);
    Rep(i, 0, n) {
        int u = ord[i];
        for (int v : g[u])
            if (v != fa[u]) fa[v] = u, dep[v] = dep[u] + 1, ord.pb(v);
    }
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        sz[u]++, sz[fa[u]] += sz[u];
        ans[1] += dep[u];
    }
    Rep(i, 1, n) {
        int v = ord[i];
        ans[v] = ans[fa[v]] + n - 2 * sz[v];
    }
    For(i, 1, n) cout << ans[i] << " ";
}
```

BFS 序 `ord` 中父亲总在孩子前面：倒序扫描是自底向上，正序扫描是自顶向下。点 1 的父亲记为 0，`sz[0]` 被顺带累加，不影响结果。

### 3.5 换根：每个点到最远点的距离

边带非负权，输入 $n$ 和 $n-1$ 行 $u, v, w$：

```cpp
const int N = 1e5 + 5;
int n;
int d1[N], d2[N], son[N], up[N];
vector<pii> g[N];

void dfs1(int u, int fa) {
    for (auto e : g[u]) {
        int v = e.F, w = e.S;
        if (v == fa) continue;
        dfs1(v, u);
        int t = d1[v] + w;
        if (t > d1[u]) d2[u] = d1[u], d1[u] = t, son[u] = v;
        else if (t > d2[u]) d2[u] = t;
    }
}

void dfs2(int u, int fa) {
    for (auto e : g[u]) {
        int v = e.F, w = e.S;
        if (v == fa) continue;
        up[v] = w + max(up[u], son[u] == v ? d2[u] : d1[u]);
        dfs2(v, u);
    }
}

void solve() {
    cin >> n;
    Rep(i, 1, n) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].pb({v, w}), g[v].pb({u, w});
    }
    dfs1(1, 0);
    dfs2(1, 0);
    For(i, 1, n) cout << max(d1[i], up[i]) << " ";
}
```

`son[u]` 记录 $d_1$ 来自哪个孩子；$v$ 正是那个孩子时改用 $d_2$。

## 4. 复杂度

- 一般树形 DP：每个点的状态数 × 每条边的合并代价，常见为 $O(n)$ 或 $O(nk)$。
- 树上背包：用子树大小限制枚举范围后为 $O(n^2)$，有容量上限 $m$ 时为 $O(nm)$。
- 换根 DP：两遍 DFS，$O(n)$（乘上状态大小）。

## 5. 常见题型与技巧

- **状态 = 子树 + 与父亲的接口**：先想"父亲需要知道这棵子树的什么"，比如 $u$ 选没选、$u$ 是否已被覆盖、子树里还有几条没配对的链……这些就是额外的维度。
- **求所有点作为根的答案** → 换根 DP；**求所有子树的答案** → 普通树形 DP 一遍就有。
- **贡献法**：问"所有点对的距离和"之类的问题时，考虑每条边被多少条路径经过：边 $(u, fa_u)$ 被 $sz_u \cdot (n - sz_u)$ 对点经过。这不需要复杂的 DP，只要子树大小。
- **树上路径问题**：经过 $u$ 的路径 = $u$ 向下的两条不同孩子方向的链拼起来（树的直径就是这样求的），所以常常需要记录最大值和次大值。
- **按编号递推**：如果题目保证父亲编号小于孩子（$fa_i < i$），按编号倒序就是自底向上，不需要 DFS。
- **把序列问题看成树**：有些递推关系形成一棵树（如 $f(i)$ 依赖 $f(nxt_i)$），把它建出来，答案就变成子树大小、子树和之类的树上量。
- **树的重心**：$u$ 的"最大子树"为 $\max(\max_v sz_v,\ n - sz_u)$，使它最小的点是重心。这也是一个简单的换根思想。

## 6. 易错点

- 无向边 DFS 忘记跳过父亲，死循环。
- 链状数据递归过深爆栈，改用 BFS 序。
- 树上背包枚举上界直接写 $m$，复杂度退化成 $O(nm^2)$；或者 $j$ 正序导致同一子树被选多次。
- 树上背包读到"未定义"的状态：$j - k$ 超过已合并大小时的 $f_{u,j-k}$ 没有意义，要么限制范围，要么初始化为 $-\infty$。
- 换根时"去掉孩子贡献"处理错误：最大值不能减，要用次大值。
- 支配集类问题漏掉"被父亲覆盖"的状态，或叶子的 $f_{\cdot,1}$ 没设成 $+\infty$。
- 多组数据忘记清空邻接表和 DP 数组。
