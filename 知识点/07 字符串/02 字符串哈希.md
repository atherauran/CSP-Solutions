# 字符串哈希

**组别**：S　**关键词**：多项式哈希、前缀哈希、自然溢出、双哈希、哈希冲突、二分求 LCP、回文

## 1. 是什么 / 解决什么问题

比较两个长度为 $L$ 的字符串是否相等要 $O(L)$。如果要反复比较很多子串（例如在文本里找模式串的所有出现位置），总代价就是 $O(nL)$，太慢。

字符串哈希的想法：把字符串映射成一个整数（哈希值），**比较字符串变成比较整数**，$O(1)$。配合前缀哈希，任意子串的哈希值也能 $O(1)$ 得到。

代价是：不同的字符串可能有相同的哈希值（**冲突**），所以哈希是一种"几乎总是对"的方法。选好参数后冲突概率可以小到忽略不计。

能用哈希的典型问题：

- 子串匹配：模式串在文本里出现了几次；
- 判断两个子串是否相等、是否回文；
- 二分 + 哈希求最长公共前缀（LCP），进而比较两个子串的字典序；
- 统计不同字符串的个数、找最长重复子串等。

## 2. 核心原理

### 2.1 多项式哈希

把字符串看成一个 **$B$ 进制数**，再对 $P$ 取模：

$$h(s_1 s_2 \dots s_L) = \left(s_1 B^{L-1} + s_2 B^{L-2} + \dots + s_L B^0\right) \bmod P$$

其中 $s_i$ 是字符的编码（直接用 ASCII 码即可），$B$ 叫**底数**，$P$ 叫**模数**。

为了看清楚，先不取模，令 $B = 10$，字母编码 $\texttt a = 1, \texttt b = 2, \texttt c = 3$，那么 $h(\texttt{abc}) = 123$，就是把字符串"念"成一个十进制数。只要 $B$ 大于所有字符编码，不同的串一定对应不同的数——取模之后才可能冲突。

对 $B$ 和字符编码的要求：

- **字符编码不能是 0**。如果 $\texttt a = 0$，那么 $\texttt a$、$\texttt{aa}$、$\texttt{aaa}$ 的哈希值都是 0（就像 $0$、$00$、$000$ 是同一个数）。直接用 ASCII 码就没有这个问题。
- **$B$ 要大于字符集大小**，常取 131、13331 这类数。

### 2.2 前缀哈希与子串哈希

记 $H_i$ 为前缀 $s_1 \dots s_i$ 的哈希值。按"$B$ 进制数末尾添一位"的方式递推：

$$H_0 = 0,\quad H_i = H_{i-1} \cdot B + s_i$$

子串 $s_l \dots s_r$ 的哈希值：$H_r$ 是前 $r$ 位组成的数，$H_{l-1}$ 是前 $l-1$ 位组成的数，把 $H_{l-1}$ 左移 $r - l + 1$ 位（乘 $B^{r-l+1}$）后正好和 $H_r$ 的高位对齐，相减就剩下低位：

$$h(l, r) = H_r - H_{l-1} \cdot B^{r-l+1}$$

例：$B = 10$，$s = \texttt{abcab}$（编码 1 2 3 1 2）：

| $i$ | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| $H_i$ | 1 | 12 | 123 | 1231 | 12312 |

$h(3, 5) = H_5 - H_2 \cdot 10^3 = 12312 - 12000 = 312$，正是 $\texttt{cab}$ 的编码。$h(1,2) = 12 = h(4,5)$，说明 $s_{1..2} = s_{4..5} = \texttt{ab}$。

预处理 $H_i$ 和 $B^i$ 之后，每次求子串哈希 $O(1)$。取模时公式里的减法可能得到负数，要加 $P$ 再取模。

### 2.3 取模与自然溢出

$P$ 有两种常见选择：

**取大质数**，如 $10^9 + 7$、$998244353$。哈希值小于 $P < 2^{30}$，两个哈希值相乘小于 $2^{60}$，用 64 位整数不会溢出。取模比较慢，减法要处理负数。

**自然溢出**：哈希数组用 `unsigned long long`（模板里的 `ull`），不写取模，让它溢出。无符号整数溢出的行为是**自动对 $2^{64}$ 取模**，这是 C++ 标准保证的。写起来最短、跑得最快，减法也不用处理负数（无符号减法同样是模 $2^{64}$ 意义下的）。

注意：

- 自然溢出必须用**无符号**类型。模板里的 `int` 是有符号的 `long long`，有符号整数溢出是未定义行为。
- 取模版本中 `h[l - 1] * p[len]` 先取模再和 `h[r]` 相减，最后 `+ P` 再 `% P`。

### 2.4 冲突概率

**单次比较**：设 $P$ 是质数、$B$ 随机，两个长度为 $L$ 的不同字符串哈希值相同，相当于 $B$ 是它们"差多项式"的根。一个不为零的 $L - 1$ 次多项式在模 $P$ 意义下至多 $L - 1$ 个根，所以冲突概率不超过 $\frac{L}{P}$。$P \approx 10^9$、$L = 10^5$ 时约 $10^{-4}$。

**大量比较（生日问题）**：如果有 $k$ 个字符串，问其中有没有两个相同（比如统计不同字符串个数），要比较的是所有 $\frac{k^2}{2}$ 对。即使每对的冲突概率只有 $\frac{1}{P}$，期望冲突次数也是

$$\frac{k^2}{2P}$$

$k = 10^5$、$P \approx 10^9$ 时约为 5——**几乎一定会冲突**。这就是"单模哈希不够用"的主要原因。这个现象叫生日悖论：一个班 23 个人里有两人同一天生日的概率就超过一半，因为要比较的是"对数"而不是人数。

**双哈希**：用两组不同的 $(B, P)$ 各算一次，两个值都相同才认为相等。等价于模数变成 $P_1 P_2 \approx 10^{18}$，上面的期望冲突次数变成 $5 \times 10^{-9}$。代价是常数翻倍。

自然溢出相当于 $P = 2^{64} \approx 1.8 \times 10^{19}$，对随机数据冲突概率极小。

### 2.5 卡哈希

固定的 $(B, P)$ 可以被**专门构造的数据**卡掉：

- **自然溢出**：存在一种著名的构造（Thue–Morse 串，$S_0 = \texttt a$，$S_{k} = S_{k-1} + \overline{S_{k-1}}$，$\overline{\phantom{x}}$ 表示把 a、b 互换），长度约 2000 时，$S_k$ 和 $\overline{S_k}$ 在模 $2^{64}$ 下的哈希值**对任何奇数底数都相同**（偶数底数更糟：$B^{64} \equiv 0$，只要最后 64 个字符相同，哈希值就相同）。所以自然溢出在允许 hack 的比赛中不安全。
- **单模**：知道 $B$ 和 $P$ 后，可以用生日攻击很快找到两个冲突的串。

CSP 的数据是赛前固定的，出题人一般不会针对某种写法造数据，自然溢出通常没问题。比较稳妥的做法：

- 比较次数多（大量串判重）时用双哈希或自然溢出，不要单模 $10^9$ 级；
- 担心被卡时用双模，或在程序开始时随机选底数。

### 2.6 二分 + 哈希求最长公共前缀

两个后缀 $s_x \dots$ 和 $s_y \dots$ 的最长公共前缀（LCP）长度 $k$ 有单调性：长度 $\le k$ 的前缀都相等，长度 $> k$ 的都不相等。所以二分 $k$，每次用哈希 $O(1)$ 判断，单次 $O(\log n)$。

有了 LCP 就能**比较两个子串的字典序**：跳过公共前缀，比较下一个字符；如果某一方已经到头，短的那个更小。用这个比较函数排序，可以 $O(n \log^2 n)$ 求出所有后缀的字典序排名（后缀数组），对 CSP 已经够用。

### 2.7 判断回文与最长回文子串

再对**反串**求一遍哈希：$G_i$ 表示 $s_n s_{n-1} \dots s_i$ 的哈希（从右往左递推 $G_i = G_{i+1} B + s_i$）。$s_l \dots s_r$ 倒过来读的哈希是

$$g(l, r) = G_l - G_{r+1} \cdot B^{r-l+1}$$

$s_{l..r}$ 是回文 $\iff h(l, r) = g(l, r)$，$O(1)$ 判断。

最长回文子串：以位置 $i$ 为中心（奇数长度），如果半径 $k$ 的串是回文，那么半径 $k - 1$ 的也是（两端各去掉一个字符），所以半径可以二分。偶数长度以 $i, i+1$ 之间为中心，同理。总复杂度 $O(n \log n)$。（$O(n)$ 的做法是 Manacher 算法，超出 CSP 常规范围。）

### 2.8 其他用法

- **最长重复子串**：如果长度为 $k$ 的子串有重复出现，长度 $k - 1$ 的也有（取前缀），所以二分长度 $k$，把所有长度为 $k$ 的子串哈希排序后看有没有相同的。$O(n \log^2 n)$。
- **循环同构**：把 $s$ 复制一遍得到 $ss$，$s$ 的所有循环移位就是 $ss$ 中长度为 $n$ 的子串，可以 $O(1)$ 取哈希。
- **动态维护的串**：如果串只在**末尾**增删（栈），可以对每个栈深度存一个哈希值，入栈 $hs_{top} = hs_{top-1} B + c$，出栈直接 $top - 1$，当前串的哈希就是 $hs_{top}$。CSP-S 2023 消消乐的一种做法就是这样（见 3.6）。
- **二维哈希**：先对每一行做哈希（底数 $B_1$），再把每行的哈希值看成一个"字符"按列做哈希（底数 $B_2$），可以 $O(1)$ 比较两个子矩阵。

## 3. 代码模板

### 3.1 子串哈希（自然溢出）：统计出现次数

输入文本 $s$ 和模式串 $t$，输出 $t$ 在 $s$ 中出现的次数（可重叠）。

```cpp
const int N = 1e6 + 5;
const ull B = 131;
int n, m, ans;
ull h[N], p[N], ht;
string s, t;

inline ull get(int l, int r) {
    return h[r] - h[l - 1] * p[r - l + 1];
}

void solve() {
    cin >> s >> t;
    n = s.size(), m = t.size(), s = " " + s, t = " " + t;
    p[0] = 1;
    For(i, 1, n) p[i] = p[i - 1] * B, h[i] = h[i - 1] * B + s[i];
    For(i, 1, m) ht = ht * B + t[i];
    For(i, 1, n - m + 1)
        if (get(i, i + m - 1) == ht) ans++;
    cout << ans;
}
```

### 3.2 子串哈希（取模）

同一个问题的取模写法。模板中 `int` 是 64 位，乘积不会溢出。

```cpp
const int N = 1e6 + 5, P = 1e9 + 7, B = 131;
int n, m, ans, ht;
int h[N], p[N];
string s, t;

inline int get(int l, int r) {
    return (h[r] - h[l - 1] * p[r - l + 1] % P + P) % P;
}

void solve() {
    cin >> s >> t;
    n = s.size(), m = t.size(), s = " " + s, t = " " + t;
    p[0] = 1;
    For(i, 1, n) p[i] = p[i - 1] * B % P, h[i] = (h[i - 1] * B + s[i]) % P;
    For(i, 1, m) ht = (ht * B + t[i]) % P;
    For(i, 1, n - m + 1)
        if (get(i, i + m - 1) == ht) ans++;
    cout << ans;
}
```

### 3.3 双哈希：统计不同字符串个数

$n$ 个字符串，问有多少种不同的。判重要求所有 $\frac{n^2}{2}$ 对都不冲突（生日问题），所以用双模。

```cpp
const int N = 1e4 + 5, M1 = 1e9 + 7, M2 = 998244353, B = 131;
int n;
pii a[N];
string s;

void solve() {
    cin >> n;
    For(i, 1, n) {
        cin >> s;
        int x = 0, y = 0;
        for (char c : s) x = (x * B + c) % M1, y = (y * B + c) % M2;
        a[i] = {x, y};
    }
    sort(a + 1, a + 1 + n);
    cout << unique(a + 1, a + 1 + n) - a - 1;
}
```

### 3.4 二分求 LCP 与后缀排序

`lcp(x, y)` 求后缀 $x$ 与后缀 $y$ 的最长公共前缀，`cmp` 比较两个后缀的字典序，最后输出按字典序排好的后缀起点。

```cpp
const int N = 1e5 + 5;
const ull B = 131;
int n;
int sa[N];
ull h[N], p[N];
string s;

inline ull get(int l, int r) {
    return h[r] - h[l - 1] * p[r - l + 1];
}

inline int lcp(int x, int y) {
    int l = 0, r = n - max(x, y) + 1;
    while (l < r) {
        int mid = (l + r + 1) / 2;
        if (get(x, x + mid - 1) == get(y, y + mid - 1)) l = mid;
        else r = mid - 1;
    }
    return l;
}

inline bool cmp(int x, int y) {
    int k = lcp(x, y);
    if (y + k > n) return false;
    if (x + k > n) return true;
    return s[x + k] < s[y + k];
}

void solve() {
    cin >> s;
    n = s.size(), s = " " + s;
    p[0] = 1;
    For(i, 1, n) p[i] = p[i - 1] * B, h[i] = h[i - 1] * B + s[i];
    For(i, 1, n) sa[i] = i;
    sort(sa + 1, sa + 1 + n, cmp);
    For(i, 1, n) cout << sa[i] << ' ';
}
```

`cmp` 中先判断 $y$ 是否到头：若 $y$ 已经用完，$y$ 是 $x$ 的前缀（或两者相同），$x$ 不比 $y$ 小，返回 `false`。顺序反过来会在 $x = y$ 时返回 `true`，违反 `sort` 对比较函数的要求。

### 3.5 最长回文子串

```cpp
const int N = 1e6 + 5;
const ull B = 131;
int n, ans;
ull h[N], g[N], p[N];
string s;

inline ull get(int l, int r) {
    return h[r] - h[l - 1] * p[r - l + 1];
}

inline ull rget(int l, int r) {
    return g[l] - g[r + 1] * p[r - l + 1];
}

inline bool pal(int l, int r) {
    return get(l, r) == rget(l, r);
}

void solve() {
    cin >> s;
    n = s.size(), s = " " + s;
    p[0] = 1;
    For(i, 1, n) p[i] = p[i - 1] * B, h[i] = h[i - 1] * B + s[i];
    for (int i = n; i >= 1; i--) g[i] = g[i + 1] * B + s[i];
    For(i, 1, n) {
        int l = 0, r = min(i - 1, n - i);
        while (l < r) {
            int mid = (l + r + 1) / 2;
            if (pal(i - mid, i + mid)) l = mid;
            else r = mid - 1;
        }
        ans = max(ans, 2 * l + 1);
        l = 0, r = min(i, n - i);
        while (l < r) {
            int mid = (l + r + 1) / 2;
            if (pal(i - mid + 1, i + mid)) l = mid;
            else r = mid - 1;
        }
        ans = max(ans, 2 * l);
    }
    cout << ans;
}
```

第一段二分奇数长度（以 $i$ 为中心，半径 $l$），第二段二分偶数长度（以 $i, i+1$ 之间为中心，左右各 $l$ 个）。

### 3.6 栈哈希：CSP-S 2023 消消乐

相邻两个相同字符可以消去，问有多少个子串能被消空。从左到右用栈模拟（与栈顶相同就弹出，否则压入），记前缀 $i$ 处理完后的栈为 $st_i$。子串 $s_{l+1..r}$ 能消空 $\iff st_l = st_r$（中间这段把栈从 $st_l$ 变回了原样）。所以对每个前缀的栈求哈希，统计相同哈希值的对数。

```cpp
const int N = 2e6 + 5;
const ull B = 131;
int n, top, ans;
char st[N];
ull hs[N], a[N];
string s;

void solve() {
    cin >> n >> s;
    s = " " + s;
    For(i, 1, n) {
        if (top && st[top] == s[i]) top--;
        else st[++top] = s[i], hs[top] = hs[top - 1] * B + s[i];
        a[i] = hs[top];
    }
    sort(a, a + n + 1);
    for (int i = 0, j = 0; i <= n; i = j) {
        while (j <= n && a[j] == a[i]) j++;
        ans += (j - i) * (j - i - 1) / 2;
    }
    cout << ans;
}
```

$a_0 = 0$ 对应空栈。$hs$ 按栈深度存，弹栈后再压入会覆盖旧值，所以 $hs_{top}$ 永远是当前栈内容的哈希。

## 4. 复杂度

| 操作 | 复杂度 |
| --- | --- |
| 预处理前缀哈希、$B$ 的幂 | $O(n)$ |
| 子串哈希、子串相等、回文判断 | $O(1)$ |
| 模式串匹配（统计出现次数） | $O(n + m)$ |
| 两后缀的 LCP、两子串比较字典序 | $O(\log n)$ |
| 后缀排序 | $O(n \log^2 n)$ |
| 最长回文子串 | $O(n \log n)$ |
| $k$ 个串判重 | $O(\sum L + k \log k)$ |

空间 $O(n)$：前缀哈希和幂各一个数组，回文还需要反串哈希。

## 5. 常见题型与技巧

- **子串相等判断的批量问题**：凡是"两个子串是否相等"要问很多次，就预处理前缀哈希。
- **有单调性就二分**：LCP 长度、回文半径、"存在重复出现的长度为 $k$ 的子串"都有单调性，二分 + 哈希判断。
- **字符串作为键**：把字符串哈希成整数后放进 `map` / `unordered_map` 或排序，比直接用 `string` 作键快得多，也能处理"一组字符串作为一个键"（把每个串的哈希再哈希一次）。
- **和 KMP 的取舍**：单模式串匹配、求循环节，KMP 是确定性的、不会错；需要比较**任意两个子串**、求 LCP、回文时，哈希更灵活。见《KMP》。
- **改一个字符**：$s_i$ 变成 $c$，整串哈希变化量是 $(c - s_i) \cdot B^{n-i}$，可以 $O(1)$ 更新整串哈希。如果还要支持子串查询，就用树状数组或线段树维护（见《树状数组》）。
- **判重时注意生日问题**：单模 $10^9$ 级只适合"少量比较"，大量判重用双哈希或自然溢出。

## 6. 易错点

- 自然溢出用了有符号类型（模板里的 `int`），应为 `ull`。
- 字符编码为 0（如用 `s[i] - 'a'`），导致 $\texttt{a}$、$\texttt{aa}$ 哈希相同。直接用 `s[i]`，或用 `s[i] - 'a' + 1`。
- 取模版本中子串哈希相减得到负数，忘记 `+ P`。
- $B$ 的幂数组只开了 $n$，而模式串更长（或反过来），访问越界。
- 双哈希的两组参数完全相同，等于没加强。
- 二分 LCP 时上界没取 $n - \max(x, y) + 1$，访问越界。
- 比较函数在两个元素相等时返回 `true`，`sort` 可能崩溃。
