# 拓扑排序

**组别**：S　**关键词**：DAG、入度、Kahn 算法、判环、字典序最小拓扑序、DAG 上 DP、关键路径

## 1. 是什么 / 解决什么问题

有一堆任务，某些任务必须在另一些任务之后做（穿袜子要在穿鞋之前，学 DP 要在学递推之后）。能不能把所有任务排成一个序列，使得每条"$u$ 必须在 $v$ 之前"的要求都满足？

把任务当作点、"$u$ 在 $v$ 之前"当作有向边 $u \to v$，问题就变成：给有向图的点排一个顺序，使**每条边都从前面指向后面**。这样的序列叫**拓扑序**，求它的过程叫**拓扑排序**。

```
内衣 → 裤子 → 鞋
袜子 ────────→ 鞋

一个拓扑序：袜子、内衣、裤子、鞋
```

拓扑排序本身很简单，它更重要的作用是：

- **判断有向图有没有环**；
- 给出一个"依赖先于自身"的处理顺序，从而在 **DAG 上做 DP**（最长路、路径计数、各种贡献传递）。

## 2. 核心原理

### 2.1 有拓扑序 ⇔ 无环

- 有环则没有拓扑序：环上的点 $v_1 \to v_2 \to \dots \to v_k \to v_1$ 要求 $v_1$ 在 $v_2$ 前、……、$v_k$ 在 $v_1$ 前，自相矛盾。
- 无环（DAG）则一定有拓扑序：DAG 中一定存在**入度为 0** 的点。否则从任意点出发，沿着入边一直往回走，因为每个点都有入边，可以无限走下去，而点只有 $n$ 个，必然重复，就找到了环。把入度为 0 的点放在最前面，删掉它和它的出边，剩下的图还是 DAG，重复下去即可。

这个证明直接给出了算法。

### 2.2 Kahn 算法（BFS 版）

1. 统计每个点的入度，把所有入度为 0 的点入队；
2. 取出队首 $u$，放进答案序列；把 $u$ 的每条出边 $u \to v$ 删掉，即 $v$ 的入度减 1，若减到 0 就把 $v$ 入队；
3. 队列空时结束。若答案序列中**不足 $n$ 个点**，说明剩下的点都在环上或被环"卡住"，图有环。

手推：边 $1 \to 2$、$1 \to 3$、$2 \to 4$、$3 \to 4$、$4 \to 5$。

| 步骤 | 取出 | 入度变化 | 队列 |
| --- | --- | --- | --- |
| 初始 | | 入度：1:0 2:1 3:1 4:2 5:1 | [1] |
| 1 | 1 | 2→0，3→0 | [2, 3] |
| 2 | 2 | 4→1 | [3] |
| 3 | 3 | 4→0 | [4] |
| 4 | 4 | 5→0 | [5] |
| 5 | 5 | | [] |

拓扑序：1 2 3 4 5。

### 2.3 DFS 版

对每个没访问过的点 DFS，**在一个点的所有出边都处理完、准备回溯时**，把它加入序列。最后把序列**反转**就是拓扑序。

为什么对：对边 $u \to v$，$u$ 回溯时 $v$ 一定已经回溯过了（要么在 $u$ 的 DFS 中访问并回溯，要么之前就已完成）。所以 $v$ 比 $u$ 先加入序列，反转后 $u$ 在 $v$ 前面。

判环用**三色标记**：0 = 未访问，1 = 正在访问（在递归栈中），2 = 已完成。如果沿边走到一个颜色为 1 的点，说明走回了自己的祖先，有环。走到颜色为 2 的点不是环（只是另一条路径已经处理过它）。

Kahn 算法不用递归、判环简单，更常用。DFS 版在已经写了 DFS 的场合（如强连通分量）顺手可以得到。

### 2.4 拓扑序的唯一性与字典序

拓扑序一般不唯一：Kahn 算法中**同时有多个入度为 0 的点**时，先取哪个都行。

- **判断唯一**：如果过程中某一刻队列里有 $\ge 2$ 个点，拓扑序就不唯一。
- **字典序最小的拓扑序**：把队列换成**小根堆**，每次取编号最小的入度为 0 的点。

还有一个容易混淆的要求：**"让 1 尽量靠前；在此前提下让 2 尽量靠前；……"**。这**不是**字典序最小。例：3 个点，只有约束 $3 \to 1$（3 必须在 1 前）。

- 字典序最小：$2, 3, 1$；
- 让 1 尽量靠前：$3, 1, 2$（1 在第 2 位，而前一种在第 3 位）。

正确做法是**反着来**：在**反图**上用**大根堆**求拓扑序（每次取编号最大的），最后把序列**倒过来**输出。

为什么：考虑最后一个位置，能放的点是"没有后继"的点，设其中编号最大的是 $x$。如果某个最优方案最后放的是 $y \ne x$（$y < x$），把 $x$ 挪到最后：$x$ 没有后继，所以仍然合法；$x$ 后面原来的点各前移一位，其中包括 $y$。这样所有比 $x$ 小的数位置都没有变后，并且 $y$ 严格变前了，方案更好，矛盾。所以最后一个位置一定放 $x$，从后往前依次确定即可。

### 2.5 DAG 上的 DP

拓扑序保证了处理 $v$ 之前，所有指向 $v$ 的点都已处理完。于是任何"$v$ 的值由它的前驱决定"的 DP 都可以按拓扑序计算：

- **最长路 / 最短路**（DAG 上可以有负权）：$f_v = \max_{u \to v} (f_u + w)$。
- **路径计数**：$f_v = \sum_{u \to v} f_u$，起点 $f = 1$。
- **关键路径**：每个任务有耗时 $t_v$，必须等所有前置任务完成才能开始。最早完成时间 $f_v = t_v + \max_{u \to v} f_u$（没有前置任务时取 0），整个工程的最短工期是 $\max f_v$。
- **反向传递**：如果 $v$ 的值由它的**后继**决定，就按拓扑序的**逆序**计算。
- **可达点计数**：$n$ 在几万以内时，按逆拓扑序用 `bitset` 求并：$R_u = \{u\} \cup \bigcup_{u \to v} R_v$，复杂度 $O(\frac{nm}{64})$。不能直接把后继的可达点个数相加——不同后继能到达的点会重复。

在 Kahn 算法中可以边出队边转移：$u$ 出队时用 $f_u$ 更新它的所有后继。

DAG 上的 DP 也可以写成**记忆化搜索**，两者等价；记忆化搜索不需要显式求拓扑序，但递归深度可能很大。

## 3. 代码模板

### 3.1 Kahn 算法

输出一个拓扑序，有环输出 `cycle`。

```cpp
const int N = 1e5 + 5;
int n, m;
int deg[N];
vector<int> g[N], ord;

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), deg[v]++;
    }
    queue<int> q;
    For(i, 1, n)
        if (!deg[i]) q.push(i);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ord.pb(u);
        for (int v : g[u])
            if (!--deg[v]) q.push(v);
    }
    if ((int)ord.size() < n) {
        cout << "cycle";
        return;
    }
    for (int u : ord) cout << u << ' ';
}
```

把 `queue<int>` 换成 `priority_queue<int, vector<int>, greater<int>>`（取 `q.top()`）就得到字典序最小的拓扑序。

### 3.2 DFS 求拓扑序 + 三色判环

```cpp
const int N = 1e5 + 5;
int n, m;
int c[N];
bool cyc;
vector<int> g[N], ord;

void dfs(int u) {
    c[u] = 1;
    for (int v : g[u]) {
        if (c[v] == 1) cyc = true;
        else if (!c[v]) dfs(v);
    }
    c[u] = 2, ord.pb(u);
}

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v);
    }
    For(i, 1, n)
        if (!c[i]) dfs(i);
    if (cyc) {
        cout << "cycle";
        return;
    }
    reverse(ord.begin(), ord.end());
    for (int u : ord) cout << u << ' ';
}
```

### 3.3 DAG 上路径计数

食物链计数：边 `a b` 表示 $a \to b$。求从入度为 0 的点（生产者）到出度为 0 的点（最高级消费者）的路径条数，对 $80112002$ 取模。

```cpp
const int N = 5005, P = 80112002;
int n, m, ans;
int in[N], out[N], f[N];
vector<int> g[N];

void solve() {
    cin >> n >> m;
    For(i, 1, m) {
        int a, b;
        cin >> a >> b;
        g[a].pb(b), in[b]++, out[a]++;
    }
    queue<int> q;
    For(i, 1, n)
        if (!in[i]) f[i] = 1, q.push(i);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        if (!out[u]) ans = (ans + f[u]) % P;
        for (int v : g[u]) {
            f[v] = (f[v] + f[u]) % P;
            if (!--in[v]) q.push(v);
        }
    }
    cout << ans;
}
```

$u$ 出队时，它的所有前驱都已出队并把贡献加到了 $f_u$ 上，所以此时 $f_u$ 已是最终值。

### 3.4 反图 + 大根堆："小编号尽量靠前"

多组数据（在 `main` 中打开 `cin >> tests;`）。约束 `x y` 表示 $x$ 必须在 $y$ 之前。要求 1 尽量靠前，其次 2 尽量靠前……无解输出 `Impossible!`。

```cpp
const int N = 1e5 + 5;
int n, m;
int deg[N];
vector<int> g[N], ord;

void solve() {
    cin >> n >> m;
    For(i, 1, n) g[i].clear(), deg[i] = 0;
    ord.clear();
    For(i, 1, m) {
        int x, y;
        cin >> x >> y;
        g[y].pb(x), deg[x]++;
    }
    priority_queue<int> q;
    For(i, 1, n)
        if (!deg[i]) q.push(i);
    while (!q.empty()) {
        int u = q.top();
        q.pop();
        ord.pb(u);
        for (int v : g[u])
            if (!--deg[v]) q.push(v);
    }
    if ((int)ord.size() < n) {
        cout << "Impossible!" << endl;
        return;
    }
    for (int i = n - 1; i >= 0; i--) cout << ord[i] << ' ';
    cout << endl;
}
```

## 4. 复杂度

| 操作 | 时间 |
| --- | --- |
| Kahn / DFS 拓扑排序 | $O(n + m)$ |
| 字典序最小拓扑序（堆） | $O(m + n \log n)$ |
| DAG 上 DP | $O(n + m)$ |
| bitset 求可达点数 | $O(\frac{nm}{64})$ |

## 5. 常见题型与技巧

- **判断依赖关系是否矛盾**：建图后看能否完成拓扑排序。
- **任务调度 / 最短工期**：关键路径，按拓扑序求最早完成时间。
- **DAG 上最长路、路径计数**：边出队边转移。
- **等级 / 分层**：如"若 $a$ 停靠则 $b$ 也必须停靠，级别 $b \ge a$"，要求最少分几级。建边后按拓扑序求最长路，层数就是最长链长度。可以用 BFS 分层：同一批入度为 0 的点是同一层。
- **贡献的传递**：某个量要沿依赖关系从上往下（或从下往上）传递、累加，按拓扑序（或逆序）一次扫描。函数调用关系、计算图、神经网络的信号传递都是这一类。
- **有环怎么办**：先求强连通分量**缩点**，得到 DAG 后再拓扑排序，见《强连通分量与割点割边》。
- **构造类**：给出若干"大小关系"，判断能否确定唯一顺序，或输出一个满足条件的顺序。每加一条约束就判断一次时，要注意"矛盾"和"不唯一"的判定顺序。
- **虚点优化建图**：一组点都要向另一组点连边时（$O(k^2)$ 条），中间加一个虚点，变成 $O(k)$ 条边。

## 6. 易错点

- **用无向图做拓扑排序**：拓扑排序只对有向图有意义。
- **重边导致入度计算错误**：入度按边数统计，删边时也按边数减，两边一致就没问题；但如果题目要求去重，要先去重再建图。
- **忘记判环**：Kahn 算法结束后检查序列长度是否为 $n$。
- **DFS 判环时把"已完成"的点当成环**：只有走到"正在访问"的点才是环。
- **字典序最小与"小编号尽量靠前"混淆**：后者要用反图 + 大根堆 + 倒序。
- **转移时机**：在 Kahn 算法里，要在 $u$ **出队**时用 $f_u$ 去更新后继；不要在入度减到 0 之前就把 $f_v$ 往后传。
- **多组数据**：清空邻接表、入度、答案序列。
- **路径计数取模**：累加时每步取模，答案可能是天文数字。
