# 树的直径、重心与最近公共祖先

**组别**：S　**关键词**：树的直径、树的重心、LCA、倍增、树上距离、树上差分

## 1. 是什么 / 解决什么问题

树是最常考的一类图：$n$ 个点、$n - 1$ 条边、连通、无环，任意两点之间有**唯一**的简单路径。本篇讲树上最基本的三个概念：

- **直径**：树上最长的一条简单路径。回答"树上最远的两个点""从某点出发最远能走多远"。
- **重心**：删掉它之后，剩下的最大连通块最小的点。它是树的"平衡点"，到所有点距离之和最小。
- **最近公共祖先（LCA）**：有根树中两个点的公共祖先里最深的那个。有了它，就能快速求两点间的距离、处理路径上的修改与询问。

## 2. 核心原理

### 2.1 树的基本信息

**存储**：和一般图一样用邻接表，无向边存两次。

**DFS 遍历**：树没有环，所以不需要 `vis` 数组，只要传入父亲 `fa`，不往回走即可。指定一个根后，一次 DFS 可以求出：

- `fa[u]`：父亲；
- `dep[u]`：深度（根为 1）；
- `sz[u]`：子树大小，$sz_u = 1 + \sum sz_v$（$v$ 是儿子）；
- `d[u]`：到根的带权距离。

```
        1            dep: 1:1  2:2  3:2  4:3  5:3  6:3  7:4
      /   \          sz:  1:7  2:4  3:2  4:2  5:1  6:1  7:1
     2     3
    / \     \
   4   5     6
  /
 7
```

很多题直接给出父亲数组，且保证 $fa_i < i$。这时不用 DFS：从 $n$ 到 2 倒序扫一遍就能把儿子的信息累加到父亲（如 $sz_{fa_i} \mathrel{+}= sz_i$），正序扫一遍就能从父亲推到儿子（如 $dep_i = dep_{fa_i} + 1$）。

**递归深度**：一条链的树会让递归深度达到 $n$。$n$ 到 $10^5 \sim 10^6$ 时，若担心爆栈，可以先 BFS 求出 BFS 序和父亲，再按 BFS 序的逆序做"从下往上"的计算。

### 2.2 树的直径

**方法一：两次 DFS**

1. 从任意点 $x$ 出发，找到离它最远的点 $y$；
2. 从 $y$ 出发，找到离它最远的点 $z$；
3. $y$ 到 $z$ 的路径就是一条直径。

关键结论：**从任意点出发，最远的点一定是某条直径的端点**（要求边权非负）。

为什么：设 $(s, t)$ 是一条直径，$y$ 是离 $x$ 最远的点。若 $x \to y$ 的路径与 $s \to t$ 的路径有公共点，设从 $x$ 出发最先碰到的公共点是 $p$。因为 $y$ 最远，$dist(p, y) \ge dist(p, t)$ 且 $\ge dist(p, s)$，于是把直径中 $p$ 到某一端的那一段换成 $p \to y$，长度不减，$y$ 就是某条直径的端点。不相交的情况类似，用一条连接两条路径的边拼接，可以推出比直径更长的路径，矛盾。

这个证明依赖"路径加长不会变短"，**有负权边时两次 DFS 不对**。

**方法二：树形 DP**

以 1 为根，设 $f_u$ 为从 $u$ 出发**往下**走的最长路径长度。任何一条路径都有一个最高点 $u$，它由 $u$ 往下的两条"腿"组成（可以为空）。所以在 $u$ 处枚举儿子 $v$ 时：

$$ans \gets \max(ans,\ f_u + f_v + w),\qquad f_u \gets \max(f_u,\ f_v + w)$$

先更新 $ans$ 再更新 $f_u$：此时 $f_u$ 还是"之前那些儿子方向的最长腿"，和当前儿子 $v$ 拼起来恰好是两条不同方向的腿。

DP 能处理负权边（$f_u$ 初值为 0 表示"这条腿为空"），但只求出长度，要找端点需要额外记录。两次 DFS 则能直接得到端点和路径。

**直径的性质**

- 所有直径的**中点**重合（中点可能在边上）。中点所在的点（或边）叫**树的中心**，它到最远点的距离最小。无权树中这个最小值是直径长度的一半（向上取整）。
- 对任意点 $u$，离 $u$ 最远的点一定是直径的某个端点。所以只要求出直径端点 $s, t$，每个点的最远距离就是 $\max(dist(u, s), dist(u, t))$，两次 DFS 全部求出。

### 2.3 树的重心

对每个点 $u$，删掉 $u$ 后树分成若干块：每个儿子的子树（大小 $sz_v$），和"上面"那一块（大小 $n - sz_u$）。记最大的块大小为

$$mx_u = \max\Big(\max_{v \in son(u)} sz_v,\ n - sz_u\Big)$$

$mx_u$ 最小的点叫**重心**。一次 DFS 求出 $sz$ 后就能算出所有 $mx_u$。

上图中（$n = 7$）：$mx_1 = \max(4, 2) = 4$，$mx_2 = \max(2, 1, 7 - 4) = 3$，$mx_4 = \max(1, 5) = 5$。重心是 2。

**重心的性质**

1. **删掉重心后，每块大小都不超过 $\frac{n}{2}$**。反过来，满足这一点的点一定是重心。

   为什么：设 $c$ 是重心，若某块（与 $c$ 相邻的点 $v$ 所在的块）大小 $> \frac{n}{2}$，把 $c$ 换成 $v$：包含 $c$ 的那一块大小 $< \frac{n}{2}$，$v$ 的其他块都是原来那一块的一部分，严格更小。于是 $mx_v < mx_c$，与 $c$ 是重心矛盾。

2. **重心最多两个，两个时必相邻**，且此时 $n$ 是偶数，删掉它们之间的边，两边各 $\frac{n}{2}$ 个点。
3. **所有点到重心的距离之和最小**（两个重心时两者相同）。

   为什么：从 $u$ 移到相邻的 $v$，$v$ 那一侧的 $sz_v$ 个点距离各减 1，另一侧 $n - sz_v$ 个点距离各加 1，总变化是 $n - 2sz_v$。在重心处所有 $sz_v \le \frac{n}{2}$，往哪边走都不会变小。

4. **加入或删除一个叶子，重心最多移动一条边**。
5. **用一条边连接两棵树，新的重心在原来两个重心之间的路径上**。

重心常用于**点分治**（每次从重心切开，递归深度只有 $O(\log n)$），这超出了 CSP 的常见范围，但"重心让每块不超过一半"这个性质经常单独出现。

### 2.4 最近公共祖先（LCA）

有根树中，$u$ 的**祖先**是从 $u$ 到根路径上的点（包括 $u$ 自己）。$u$ 和 $v$ 的公共祖先中最深的那个就是 $\operatorname{lca}(u, v)$。上图中 $\operatorname{lca}(7, 5) = 2$，$\operatorname{lca}(7, 6) = 1$，$\operatorname{lca}(4, 7) = 4$。

LCA 就是 $u$ 到 $v$ 的路径的"拐点"，路径 = $u \to \operatorname{lca} \to v$。于是

$$dist(u, v) = d_u + d_v - 2\,d_{\operatorname{lca}(u, v)}$$

**朴素做法**：先把较深的点往上跳到和另一个点同一深度，然后两个点同时一步步往上跳，直到相遇。单次 $O(n)$，链状树上太慢。

**倍增**：一步一步跳太慢，就**按 2 的幂跳**。预处理 $f_{u,k}$ 表示 $u$ 往上跳 $2^k$ 步到达的点：

$$f_{u,0} = fa_u,\qquad f_{u,k} = f_{f_{u,k-1},\,k-1}$$

（跳 $2^k$ 步 = 先跳 $2^{k-1}$ 步，再跳 $2^{k-1}$ 步。）跳出根就记为 0，并令 $dep_0 = 0$。

求 $\operatorname{lca}(u, v)$（设 $dep_u \ge dep_v$）：

1. **对齐深度**：把 $dep_u - dep_v$ 写成二进制，$k$ 从大到小，若跳 $2^k$ 步后深度仍 $\ge dep_v$ 就跳。
2. 若此时 $u = v$，答案就是 $v$。
3. **同时上跳**：$k$ 从大到小，若 $f_{u,k} \ne f_{v,k}$ 就两个一起跳。跳完后 $u, v$ 停在 LCA 的**下面一层**，答案是 $f_{u,0}$。

第 3 步为什么只在"不相等"时跳：相等说明跳到了公共祖先，但不一定是**最近**的，可能跳过头了；不相等说明还在 LCA 下面，一定可以跳。这其实是在二分"往上跳多少步恰好在 LCA 之下"。

手推 $\operatorname{lca}(7, 6)$：$dep_7 = 4$，$dep_6 = 3$，7 先上跳 1 步到 4。$k = 1$：$f_{4,1} = 1 = f_{6,1}$，不跳；$k = 0$：$f_{4,0} = 2 \ne 3 = f_{6,0}$，跳到 $u = 2, v = 3$。答案 $f_{2,0} = 1$。

**路径信息**：和 $f_{u,k}$ 一起维护 $mx_{u,k}$ 表示"往上跳 $2^k$ 步经过的边的最大值"：$mx_{u,k} = \max(mx_{u,k-1}, mx_{f_{u,k-1},k-1})$。求 LCA 时每跳一次就把对应的 $mx$ 合并进答案，就得到路径上的最大边。最小值、和也一样。

**其他求 LCA 的方法**（了解即可）：

- 欧拉序 + ST 表：预处理 $O(n \log n)$，单次查询 $O(1)$；
- Tarjan 离线算法：把询问挂在点上，DFS + 并查集，总 $O(n + q)$；
- 树链剖分：预处理 $O(n)$，单次 $O(\log n)$，常数小，还能配合线段树做路径修改。

### 2.5 树上差分

要对很多条路径上的所有点（或边）加一个值，最后问每个点的值。类似序列上的差分，把"路径加"变成几个单点修改，最后**求子树和**还原：点 $u$ 的值 = $u$ 子树中所有差分标记之和。

**点差分**：路径 $u$-$v$ 上每个点加 $x$，设 $l = \operatorname{lca}(u, v)$：

$$c_u \mathrel{+}= x,\quad c_v \mathrel{+}= x,\quad c_l \mathrel{-}= x,\quad c_{fa_l} \mathrel{-}= x$$

检验：$u$ 到 $l$ 之间（不含 $l$）的点，子树里只包含 $c_u$，得到 $x$；$l$ 的子树包含 $c_u, c_v, c_l$，得到 $x + x - x = x$；$fa_l$ 及以上包含全部四个，得到 0；不在路径上的点子树里一个都不含。

**边差分**：把每条边的值记在它下方的端点（儿子）上。路径 $u$-$v$ 上每条边加 $x$：

$$c_u \mathrel{+}= x,\quad c_v \mathrel{+}= x,\quad c_l \mathrel{-}= 2x$$

（$l$ 自己对应的是它上方那条边，不在路径上。）

## 3. 代码模板

以下都是先读 $n$，再读 $n - 1$ 条边。

### 3.1 直径：两次 DFS

```cpp
const int N = 1e5 + 5;
int n, c;
int d[N];
vector<pii> g[N];

void dfs(int u, int fa) {
    for (auto e : g[u]) {
        int v = e.F, w = e.S;
        if (v == fa) continue;
        d[v] = d[u] + w;
        if (d[v] > d[c]) c = v;
        dfs(v, u);
    }
}

void solve() {
    cin >> n;
    Rep(i, 1, n) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].pb({v, w}), g[v].pb({u, w});
    }
    d[1] = 0, c = 1, dfs(1, 0);
    d[c] = 0, dfs(c, 0);
    cout << d[c];
}
```

第一次 DFS 后 $c$ 是直径的一个端点；第二次从 $c$ 出发，结束时 $c$ 变成另一个端点，$d_c$ 就是直径长度。

### 3.2 直径：树形 DP

可以处理负权边，求的是"边权和最大的路径"（允许只含一个点，长度为 0）。

```cpp
const int N = 1e5 + 5;
int n, ans;
int f[N];
vector<pii> g[N];

void dfs(int u, int fa) {
    for (auto e : g[u]) {
        int v = e.F, w = e.S;
        if (v == fa) continue;
        dfs(v, u);
        ans = max(ans, f[u] + f[v] + w);
        f[u] = max(f[u], f[v] + w);
    }
}

void solve() {
    cin >> n;
    Rep(i, 1, n) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].pb({v, w}), g[v].pb({u, w});
    }
    dfs(1, 0);
    cout << ans;
}
```

### 3.3 重心

无权树，求重心（有两个时取编号小的）以及所有点到它的距离之和。

```cpp
const int N = 5e4 + 5;
int n, c, sum;
int sz[N], mx[N];
vector<int> g[N];

void dfs(int u, int fa) {
    sz[u] = 1;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        sz[u] += sz[v], mx[u] = max(mx[u], sz[v]);
    }
    mx[u] = max(mx[u], n - sz[u]);
}

void calc(int u, int fa, int d) {
    sum += d;
    for (int v : g[u])
        if (v != fa) calc(v, u, d + 1);
}

void solve() {
    cin >> n;
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    dfs(1, 0);
    c = 1;
    For(i, 2, n)
        if (mx[i] < mx[c]) c = i;
    calc(c, 0, 0);
    cout << c << ' ' << sum;
}
```

### 3.4 倍增求 LCA

$n$ 个点、$m$ 次询问、根为 $s$，每次询问输出 $\operatorname{lca}(a, b)$。$2^{19} > 5 \times 10^5$，所以 $k$ 取 $0 \sim 19$。

```cpp
const int N = 5e5 + 5;
int n, m, s;
int dep[N], f[N][20];
vector<int> g[N];

void dfs(int u, int fa) {
    dep[u] = dep[fa] + 1, f[u][0] = fa;
    Rep(k, 1, 20) f[u][k] = f[f[u][k - 1]][k - 1];
    for (int v : g[u])
        if (v != fa) dfs(v, u);
}

int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    for (int k = 19; k >= 0; k--)
        if (dep[f[u][k]] >= dep[v]) u = f[u][k];
    if (u == v) return u;
    for (int k = 19; k >= 0; k--)
        if (f[u][k] != f[v][k]) u = f[u][k], v = f[v][k];
    return f[u][0];
}

void solve() {
    cin >> n >> m >> s;
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    dfs(s, 0);
    while (m--) {
        int a, b;
        cin >> a >> b;
        cout << lca(a, b) << endl;
    }
}
```

DFS 中先求出 `f[u][k]` 再递归儿子：`f[u][k]` 依赖的都是 $u$ 的祖先，它们已经算好了。

### 3.5 树上点差分

$k$ 条路径，每条路径上的点都加 1，求最终最大的点值。

```cpp
const int N = 5e4 + 5;
int n, k, ans;
int dep[N], f[N][17], c[N];
vector<int> g[N];

void dfs(int u, int fa) {
    dep[u] = dep[fa] + 1, f[u][0] = fa;
    Rep(j, 1, 17) f[u][j] = f[f[u][j - 1]][j - 1];
    for (int v : g[u])
        if (v != fa) dfs(v, u);
}

int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    for (int j = 16; j >= 0; j--)
        if (dep[f[u][j]] >= dep[v]) u = f[u][j];
    if (u == v) return u;
    for (int j = 16; j >= 0; j--)
        if (f[u][j] != f[v][j]) u = f[u][j], v = f[v][j];
    return f[u][0];
}

void sum(int u, int fa) {
    for (int v : g[u])
        if (v != fa) sum(v, u), c[u] += c[v];
    ans = max(ans, c[u]);
}

void solve() {
    cin >> n >> k;
    Rep(i, 1, n) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    dfs(1, 0);
    while (k--) {
        int u, v;
        cin >> u >> v;
        int l = lca(u, v);
        c[u]++, c[v]++, c[l]--, c[f[l][0]]--;
    }
    sum(1, 0);
    cout << ans;
}
```

$l$ 是根时 $f_{l,0} = 0$，标记打在 0 号点上，不影响任何真实的点。

## 4. 复杂度

| 内容 | 预处理 | 单次询问 |
| --- | --- | --- |
| 直径（两次 DFS / DP） | $O(n)$ | — |
| 重心 | $O(n)$ | — |
| 朴素 LCA | $O(n)$ | $O(n)$ |
| 倍增 LCA | $O(n \log n)$ 时间和空间 | $O(\log n)$ |
| 欧拉序 + ST 表 | $O(n \log n)$ | $O(1)$ |
| 树上差分 | $O(n + k \log n)$ | — |

倍增数组 `f[N][20]` 在 $n = 5 \times 10^5$ 时有 $10^7$ 个 `long long`，约 80MB，注意内存限制；必要时改成 32 位整数。

## 5. 常见题型与技巧

- **树上最远距离**：每个点的最远点是直径端点之一；"选一个点使最远距离最小"就是树的中心。
- **直径上的贪心**：要在树上选一条路径/一段，使其他点到它的距离尽量小，最优的路径往往可以取在直径上。
- **重心相关**：使"所有点到某点距离之和"最小 → 重心；"删掉一个点使最大块最小" → 重心；"每块不超过一半"的分割。
- **每个点作根的信息**：比如每个点到其他所有点的距离之和，用**换根 DP**：先以 1 为根求出答案，再从父亲推到儿子（从 $u$ 换到儿子 $v$，距离和变化 $n - 2sz_v$）。
- **两点距离、路径长度**：$d_u + d_v - 2d_{\operatorname{lca}}$。
- **路径最值**：倍增同时维护最大边/最小边，常与最小（大）生成树结合。
- **路径修改、单点查询**：树上差分 + 子树求和；需要边算边问时，用 DFS 序 + 树状数组。
- **判断点 $x$ 是否在路径 $u$-$v$ 上**：$dist(u, x) + dist(x, v) = dist(u, v)$。
- **路径上的线性 DP 多次询问**：倍增维护"跳 $2^k$ 步"的转移（矩阵），在 LCA 处合并两段。

## 6. 易错点

- **无向边只存一条**，或 DFS 时没跳过父亲导致死循环。
- **有负权边用两次 DFS 求直径**。
- **重心的 $mx$ 漏了"上面那块" $n - sz_u$**。
- **倍增层数不够**：$2^K$ 要大于最大深度。
- **倍增没有处理"跳出根"**：让根的父亲为 0、$dep_0 = 0$，跳到 0 时深度判断自然不会通过。
- **LCA 第二步跳的条件写成 $f_{u,k} = f_{v,k}$ 时跳**，会跳过头。
- **先递归儿子、后算 `f[u][k]`**：儿子的倍增表依赖 $u$ 的，顺序反了就错。
- **点差分忘记减 $fa_l$**，或边差分误用点差分的公式。
- **多组数据**清空倍增数组和邻接表。
- **递归太深爆栈**：链状数据 $10^6$ 个点时改用 BFS 序。
