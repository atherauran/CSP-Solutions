# 栈、队列与链表

**组别**：J　**关键词**：栈、队列、循环队列、双端队列、链表、括号匹配、表达式求值、约瑟夫问题

## 1. 是什么 / 解决什么问题

这三种结构都是"一排元素"，区别在于**允许在哪里插入、在哪里删除**：

| 结构 | 插入位置 | 删除位置 | 口诀 | 典型用途 |
| --- | --- | --- | --- | --- |
| 栈（stack） | 栈顶 | 栈顶 | 后进先出（LIFO） | 括号匹配、表达式求值、模拟递归 |
| 队列（queue） | 队尾 | 队头 | 先进先出（FIFO） | BFS、排队模拟 |
| 双端队列（deque） | 两端 | 两端 | — | 单调队列、0-1 BFS |
| 链表（list） | 任意已知位置 | 任意已知位置 | — | 频繁在中间插入删除 |

数组在中间插入/删除要整体挪动，是 $O(n)$ 的；栈和队列只在两端操作，链表只改指针，所以这些操作都是 $O(1)$。代价是：栈和队列不能随便访问中间元素，链表不能按下标随机访问（要找第 $k$ 个只能从头走）。

## 2. 栈

### 2.1 原理

想象一摞盘子：只能往最上面放，也只能从最上面拿。最后放上去的最先被拿走。

```text
push 1, push 2, push 3, pop, push 4

 |   |    |   |    | 3 |    |   |    | 4 |
 |   |    | 2 |    | 2 |    | 2 |    | 2 |
 | 1 |    | 1 |    | 1 |    | 1 |    | 1 |
 +---+    +---+    +---+    +---+    +---+
```

用数组实现只需要一个栈顶指针 `top`（当前元素个数）：

- 入栈：`st[++top] = x;`
- 出栈：`top--;`
- 取栈顶：`st[top]`；判空：`top == 0`。

STL 的 `stack<int> st;` 提供 `push / pop / top / empty / size`。注意 `pop()` 没有返回值，要先 `top()` 再 `pop()`；对空栈调用 `top()` 或 `pop()` 是未定义行为，通常直接运行错误。

### 2.2 为什么"匹配"类问题要用栈

括号串 `( [ ] ( ) )` 中，每个右括号要和**离它最近的、还没匹配的**左括号配对。"最近的、还没用掉的"正是栈顶：遇到左括号入栈，遇到右括号就看栈顶是不是对应的左括号，是就弹出。扫完后栈必须为空。

手推 `([)]`：

| 字符 | 操作 | 栈 |
| --- | --- | --- |
| `(` | 入栈 | `(` |
| `[` | 入栈 | `( [` |
| `)` | 栈顶是 `[`，不匹配 | 失败 |

```cpp
const int N = 1e6 + 5;
int top;
char st[N];
string s;

void solve() {
    cin >> s;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{')
            st[++top] = c;
        else {
            if (!top || (c == ')' && st[top] != '(') || (c == ']' && st[top] != '[') || (c == '}' && st[top] != '{')) {
                cout << "NO";
                return;
            }
            top--;
        }
    }
    cout << (top ? "NO" : "YES");
}
```

### 2.3 后缀表达式求值

我们平时写的 `(3 + 5) * 2` 是**中缀表达式**，需要括号和优先级。**后缀表达式**（逆波兰式）把运算符写在两个操作数后面：`3 5 + 2 *`，不需要括号，用栈就能直接算：

- 遇到数字：入栈；
- 遇到运算符：弹出两个数（**先弹出的是右操作数**），计算后把结果入栈；
- 最后栈里剩下的一个数就是答案。

下面的代码按 P1449 的格式：每个数后面跟一个 `.`，以 `@` 结束，例如 `3.5.2.-*7.+@` 表示 $3 \times (5 - 2) + 7 = 16$。

```cpp
const int N = 1005;
int top;
int st[N];
string s;

void solve() {
    cin >> s;
    int x = 0;
    for (char c : s) {
        if (c == '@') break;
        if (isdigit(c)) x = x * 10 + c - '0';
        else if (c == '.') st[++top] = x, x = 0;
        else {
            int b = st[top--], a = st[top--];
            if (c == '+') st[++top] = a + b;
            else if (c == '-') st[++top] = a - b;
            else if (c == '*') st[++top] = a * b;
            else st[++top] = a / b;
        }
    }
    cout << st[top];
}
```

**中缀表达式直接求值**用"双栈法"：一个数栈、一个运算符栈。遇到运算符时，先把栈顶**优先级不低于它**的运算符都弹出计算（左结合），再把它压栈；`(` 直接压栈，`)` 一直弹到 `(` 为止。CSP-J 2022 T3 逻辑表达式就是这个框架。

### 2.4 出栈序列

给定入栈顺序 $1, 2, \dots, n$，问某个出栈序列是否可能：用一个真实的栈模拟——按顺序入栈，每入一个就检查栈顶是否等于出栈序列的下一个，相等就一直弹。最后栈空则合法。

```cpp
const int N = 1e5 + 5;
int n, top;
int a[N], b[N], st[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    For(i, 1, n) cin >> b[i];
    int j = 1;
    For(i, 1, n) {
        st[++top] = a[i];
        while (top && st[top] == b[j]) top--, j++;
    }
    cout << (top ? "No" : "Yes");
}
```

初赛常考的结论：$n$ 个元素依次入栈，不同出栈序列的个数是**卡特兰数** $C_n = \dfrac{1}{n+1}\dbinom{2n}{n}$（$1, 1, 2, 5, 14, 42, \dots$）。另一个常考判断：入栈顺序为 $1 \sim n$ 时，出栈序列中**不能出现** $\dots c \dots a \dots b \dots$ 且 $a < b < c$ 的模式（$c$ 出栈时 $a, b$ 都在栈里，$b$ 压在 $a$ 上面，必须先出 $b$）。

## 3. 队列

### 3.1 原理

就像排队买饭：从队尾进，从队头出。用数组实现需要两个指针，`h` 指向队头，`t` 指向队尾：

- 入队：`q[++t] = x;`
- 出队：`h++;`（初始 `h = 1, t = 0`）
- 队头：`q[h]`；判空：`h > t`。

这样的数组队列每个元素只进出一次，数组要开到"总共入队次数"那么大。BFS 中每个点只入队一次，开到点数即可。

STL 的 `queue<int> q;` 提供 `push / pop / front / back / empty / size`。

### 3.2 约瑟夫问题

$n$ 个人围成一圈，从 1 开始报数，报到 $m$ 的人出圈，下一个人重新从 1 报。求出圈顺序。

用队列模拟"转圈"：报 $1 \sim m-1$ 的人从队头移到队尾，报 $m$ 的人出队。每出圈一人要转 $m$ 次，总复杂度 $O(nm)$。

```cpp
int n, m;
queue<int> q;

void solve() {
    cin >> n >> m;
    For(i, 1, n) q.push(i);
    while (!q.empty()) {
        For(i, 1, m - 1) q.push(q.front()), q.pop();
        cout << q.front() << ' ';
        q.pop();
    }
}
```

### 3.3 循环队列

如果元素反复进出（比如上面的约瑟夫问题），普通数组队列的下标会一直往后走，数组要开很大。**循环队列**让下标对容量取模，用完末尾再回到开头。容量为 $N$ 时最多存 $N-1$ 个元素（留一个空位区分"空"和"满"）：

- 空：`h == t`；满：`(t + 1) % N == h`；元素个数：`(t - h + N) % N`。

```cpp
const int N = 105;
int n, m, h, t;
int q[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) q[t] = i, t = (t + 1) % N;
    while (h != t) {
        For(i, 1, m - 1) q[t] = q[h], t = (t + 1) % N, h = (h + 1) % N;
        cout << q[h] << ' ';
        h = (h + 1) % N;
    }
}
```

这里为了取模方便下标从 0 开始。初赛常考循环队列的元素个数公式。

### 3.4 双端队列

`deque<int> dq;` 两端都能进出：`push_front / push_back / pop_front / pop_back / front / back`，还支持下标访问 `dq[i]`。它是单调队列（见本分类"单调栈与单调队列"）和 0-1 BFS 的基础。手写时用数组，把 `h` 和 `t` 都放在数组中间开始，向两边扩展即可。

## 4. 链表

### 4.1 原理

链表中每个元素记录"下一个是谁"（单链表），或者同时记录"上一个是谁"（双向链表）。元素在内存里不必相邻，删除或插入只需改几个指针：

```text
删除 B 之前：  0 <-> A <-> B <-> C <-> 0
删除 B 之后：  0 <-> A <-------> C <-> 0
               r[A] = C, l[C] = A
```

竞赛中**用数组模拟链表**：`l[x]`、`r[x]` 表示元素 $x$ 的左右邻居，下标就是元素编号，这样能 $O(1)$ 定位到任何元素。再加一个哨兵结点 0，让它的右边是表头、左边是表尾，构成一个环，插入删除时就不用特判首尾。

- 在 $x$ 右边插入 $y$：`r[y] = r[x], l[y] = x, l[r[x]] = y, r[x] = y;`（顺序不能乱：先用旧的 `r[x]` 设置好 $y$，最后再改 `r[x]`）
- 删除 $x$：`r[l[x]] = r[x], l[r[x]] = l[x];`
- 遍历：`for (int i = r[0]; i; i = r[i])`

单链表只存 `nxt`，删除 $x$ 需要知道它的前驱，所以一般只在"表头插入、顺序遍历"的场合用（例如图的邻接表"链式前向星"就是若干条单链表）。

### 4.2 例：队列安排

一开始只有 1 号同学。依次把 $2 \sim n$ 号插到某个已在队中的同学 $k$ 的左边（$p=0$）或右边（$p=1$），然后删除 $m$ 个同学（已删除的忽略），输出最终队列。

```cpp
const int N = 1e5 + 5;
int n, m;
int l[N], r[N];
bool del[N];

inline void ins(int x, int y) {
    r[y] = r[x], l[y] = x;
    l[r[x]] = y, r[x] = y;
}

inline void era(int x) {
    r[l[x]] = r[x], l[r[x]] = l[x];
    del[x] = 1;
}

void solve() {
    cin >> n;
    ins(0, 1);
    For(i, 2, n) {
        int k, p;
        cin >> k >> p;
        if (p) ins(k, i);
        else ins(l[k], i);
    }
    cin >> m;
    while (m--) {
        int x;
        cin >> x;
        if (!del[x]) era(x);
    }
    for (int i = r[0]; i; i = r[i]) cout << i << ' ';
}
```

"插到 $k$ 左边"等价于"插到 $k$ 的左邻居的右边"，所以只需要一个插入函数。

## 5. 复杂度

| 操作 | 栈 | 队列 | 双端队列 | 链表 | 数组 |
| --- | --- | --- | --- | --- | --- |
| 两端插入/删除 | $O(1)$ | $O(1)$ | $O(1)$ | $O(1)$ | 尾部 $O(1)$，头部 $O(n)$ |
| 已知位置插入/删除 | — | — | — | $O(1)$ | $O(n)$ |
| 按下标访问 | 只能访问栈顶 | 只能访问两端 | $O(1)$ | $O(n)$ | $O(1)$ |

空间都是 $O(n)$。STL 的 `deque` 常数和内存开销比较大，大数据量时手写数组更稳。

## 6. 常见题型与技巧

- **括号与表达式**：括号匹配、后缀表达式、双栈法求中缀表达式、用栈把后缀表达式建成表达式树（见"树与二叉树"）。
- **用栈代替递归**：递归本身就是系统栈。递归太深（$10^6$ 层的链）可能爆栈时，改成手写栈模拟。
- **队列做 BFS**：最短步数、层序遍历都依赖"先进先出"保证按距离从小到大处理。
- **队列 + 时间窗口**：按时间顺序进入、按时间顺序过期的东西（例如有效期 45 分钟的优惠券），用数组队列加一个只会右移的头指针维护，每个元素只出队一次，总复杂度线性。
- **双队列代替堆**：如果新产生的元素本身就单调（例如合并果子里先排好序、每次合并的结果单调不减），可以用两个队列代替优先队列，做到 $O(n)$。
- **链表模拟删除**：反复"删掉某些元素、再看相邻元素"的模拟题，用双向链表保证每次删除 $O(1)$，跳过已删除的元素也不用花时间。
- **块 = 链表上的一段**：把连续的同类元素合成一块，只记录块的头尾结点，配合链表做合并。
- **倒序处理**：只删不加的问题，有时倒过来变成只加不删更好做（链表、并查集都常用这个技巧）。

## 7. 易错点

- 空栈/空队列取顶：先判空再访问，尤其是右括号多于左括号的情况。
- 后缀表达式中先弹出的是**右**操作数，减法和除法顺序写反会错。
- 数组队列大小要按**总入队次数**开，而不是"同时存在的元素个数"；反复进出的场景用循环队列或 STL。
- 链表插入时修改指针的顺序：先设新结点的 `l/r`，再改邻居，最后改 `r[x]`。顺序写错会把链断掉。
- 链表重复删除同一个元素会把链表弄乱（`l[x]`、`r[x]` 还指着旧邻居）；用 `del` 标记过滤。
- 多组数据时清空 `top`、`h`、`t`、链表指针。STL 容器可以直接重新定义一个空的，或者 `while (!q.empty()) q.pop();`。
