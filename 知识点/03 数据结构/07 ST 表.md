# ST 表

**组别**：S　**关键词**：ST 表、RMQ、区间最值、倍增、可重复贡献、区间 gcd

## 1. 是什么 / 解决什么问题

**RMQ**（Range Maximum/Minimum Query）问题：给定一个**不会被修改**的序列，多次询问区间 $[l, r]$ 的最大值（或最小值）。

- 暴力：每次扫一遍，$O(n)$；$n, q$ 都是 $10^5$ 级别时超时。
- 前缀和行不通：最大值没有"减法"，不能用两个前缀的结果相减。

**ST 表**（Sparse Table，稀疏表）用 $O(n \log n)$ 预处理，之后每次询问 **$O(1)$**。代价是不支持修改。

## 2. 核心原理

### 2.1 预处理：倍增

设 $st_{i,k}$ 为从 $i$ 开始、长度为 $2^k$ 的区间 $[i, i + 2^k - 1]$ 的最大值。

- $k = 0$：$st_{i,0} = a_i$；
- 长度 $2^k$ 的区间可以劈成两个长度 $2^{k-1}$ 的区间：
$$st_{i,k} = \max(st_{i,k-1},\ st_{i + 2^{k-1},\,k-1})$$

按 $k$ 从小到大递推即可。$k$ 最大到 $\lfloor \log_2 n \rfloor$，每层 $O(n)$，总共 $O(n \log n)$。

例：$a = [3, 1, 4, 1, 5, 9, 2, 6]$。

| $i$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| $st_{i,0}$（长 1） | 3 | 1 | 4 | 1 | 5 | 9 | 2 | 6 |
| $st_{i,1}$（长 2） | 3 | 4 | 4 | 5 | 9 | 9 | 6 | |
| $st_{i,2}$（长 4） | 4 | 5 | 9 | 9 | 9 | | | |
| $st_{i,3}$（长 8） | 9 | | | | | | | |

### 2.2 查询：两段覆盖

询问 $[l, r]$，长度 $len = r - l + 1$。取 $k = \lfloor \log_2 len \rfloor$，则 $2^k \le len < 2^{k+1}$，于是两个长度为 $2^k$ 的区间

$$[l,\ l + 2^k - 1] \quad\text{和}\quad [r - 2^k + 1,\ r]$$

一个贴着左端点、一个贴着右端点，**一定能覆盖整个 $[l, r]$**（两段总长 $2^{k+1} > len$），只是中间可能重叠：

```text
l                         r
|=========|               |       左段 [l, l+2^k-1]
|       |=========|       |       右段 [r-2^k+1, r]
         ^^^ 重叠部分
```

答案是 $\max(st_{l,k},\ st_{r-2^k+1,\,k})$。例如询问 $[2, 7]$：$len = 6$，$k = 2$，$\max(st_{2,2}, st_{4,2}) = \max(5, 9) = 9$。

### 2.3 为什么重叠没关系：可重复贡献

重叠部分被算了两次，但 $\max(x, x) = x$，算两次不影响结果。满足 $x \operatorname{op} x = x$ 的运算叫**幂等**（可重复贡献）运算，还需要满足结合律，例如：

- $\max$、$\min$；
- $\gcd$（$\gcd(x, x) = x$）；
- 按位与 `&`、按位或 `|`。

**区间和、区间乘积、区间异或**不满足（重叠部分会被算两次），不能用两段覆盖的方式 $O(1)$ 查询。区间和直接用前缀和就好。

### 2.4 $\log$ 表

查询需要 $\lfloor \log_2 len \rfloor$。预处理 `lg[1] = 0, lg[i] = lg[i / 2] + 1`，或者用 GCC 内置的 `__lg(len)`。不要用 `log2()` 浮点函数，慢且有精度风险。

## 3. 代码模板

```cpp
const int N = 1e5 + 5, LG = 17;
int n, m;
int lg[N], st[N][LG];

inline int ask(int l, int r) {
    int k = lg[r - l + 1];
    return max(st[l][k], st[r - (1 << k) + 1][k]);
}

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> st[i][0];
    For(i, 2, n) lg[i] = lg[i / 2] + 1;
    Rep(k, 1, LG)
        for (int i = 1; i + (1 << k) - 1 <= n; i++)
            st[i][k] = max(st[i][k - 1], st[i + (1 << (k - 1))][k - 1]);
    while (m--) {
        int l, r;
        cin >> l >> r;
        cout << ask(l, r) << endl;
    }
}
```

`LG` 取 $\lfloor \log_2 N \rfloor + 1$：$N = 10^5$ 时 $2^{16} < 10^5 < 2^{17}$，取 17。

**换成别的运算**只需把 `max` 改掉：最小值用 `min`，区间 gcd 用 `__gcd`（每次合并多一个 $O(\log V)$），区间按位或用 `|`。

**要求最值的位置**时，`st` 里存下标，比较时比较对应的值。

## 4. 复杂度

| | ST 表 | 线段树 | 前缀和 |
| --- | --- | --- | --- |
| 预处理 | $O(n \log n)$ | $O(n)$ | $O(n)$ |
| 单次查询 | $O(1)$ | $O(\log n)$ | $O(1)$ |
| 支持修改 | 否 | 是 | 否 |
| 适用运算 | 幂等运算 | 满足结合律即可 | 可减的运算 |
| 空间 | $O(n \log n)$ | $O(n)$ | $O(n)$ |

**空间要算清楚**：$n = 10^6$ 时 $st$ 有 $10^6 \times 20$ 个元素，按 64 位存是 160MB。值在 32 位范围内时改用 `signed`（即 32 位 int）存，空间减半为 80MB。

## 5. 常见题型与技巧

- **直接 RMQ**：多次询问区间最值，查询次数特别多（$10^6$ 以上）时 ST 表的 $O(1)$ 优势明显。
- **多个 ST 表组合**：同一个询问要几种不同的最值（最大、最小、最小的非负数……），分别建表。
- **ST 表 + 双指针 / 二分**：区间最值关于区间端点单调（区间变大，最大值不减、最小值不增），所以"满足 $\max - \min \le d$ 的最长子段"之类可以双指针，每次 $O(1)$ 判断。

例：统计满足 $\max - \min \le d$ 的子段个数。对每个右端点 $r$，合法的左端点是一段 $[l, r]$，$l$ 随 $r$ 单调不减。

```cpp
const int N = 1e5 + 5, LG = 17;
int n, d, ans;
int lg[N], mx[N][LG], mn[N][LG];

inline int ask(int l, int r) {
    int k = lg[r - l + 1];
    return max(mx[l][k], mx[r - (1 << k) + 1][k]) - min(mn[l][k], mn[r - (1 << k) + 1][k]);
}

void solve() {
    cin >> n >> d;
    For(i, 1, n) cin >> mx[i][0], mn[i][0] = mx[i][0];
    For(i, 2, n) lg[i] = lg[i / 2] + 1;
    Rep(k, 1, LG)
        for (int i = 1; i + (1 << k) - 1 <= n; i++) {
            mx[i][k] = max(mx[i][k - 1], mx[i + (1 << (k - 1))][k - 1]);
            mn[i][k] = min(mn[i][k - 1], mn[i + (1 << (k - 1))][k - 1]);
        }
    int l = 1;
    For(r, 1, n) {
        while (ask(l, r) > d) l++;
        ans += r - l + 1;
    }
    cout << ans;
}
```

（这个问题也可以用两个单调队列做到 $O(n)$，ST 表的写法更不容易错。）

- **区间 gcd**：gcd 也是幂等的。"以 $l$ 为左端点，区间 gcd 随 $r$ 增大单调不增，且最多变化 $\log V$ 次"，可以配合二分。
- **LCA**：DFS 序（欧拉序）上两点之间深度最小的点就是 LCA，可以用 ST 表 $O(1)$ 查询（见"树的直径、重心与最近公共祖先"）。
- **ST 表和倍增是同一个思想**：都是"预处理长度为 $2^k$ 的信息，再拼起来"。ST 表能 $O(1)$ 查询是因为允许重叠；不允许重叠时（例如区间和）也能用倍增把区间拆成 $O(\log n)$ 段不重叠的块来查。

## 6. 易错点

- 内层循环边界 `i + (1 << k) - 1 <= n`，否则会越界读到右边的垃圾值。
- 外层循环必须是 $k$（长度），内层是 $i$；写反了会用到还没算好的 $st_{\cdot, k-1}$。
- `lg` 数组从 2 开始递推，`lg[1] = 0`。
- `1 << k` 在 $k$ 较大时注意不要溢出（ST 表里 $k \le 20$ 左右，没问题）。
- 序列会被修改时不能用 ST 表，用线段树或树状数组。
- 不要拿 ST 表的 $O(1)$ 查询去求区间和。
