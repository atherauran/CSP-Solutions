# P5661 CSP-J 2019 T2 公交换乘

## 题意

按时间顺序给出 $n$ 条乘车记录（地铁或公交，票价，时间）。每坐一次地铁得一张优惠券，45 分钟内可免费坐一次票价不超过该地铁票价的公交；能用必用，多张可用时用最早获得的。求总花费。

**标签**：模拟、队列　**难度**：3/10

## 解题思路

### 1. 底层逻辑

按时间扫一遍记录：
- 地铁：付钱，把 (票价, 时间) 放进优惠券队列；
- 公交：在队列里找"未过期、未使用、票价 ≥ 公交价"的最早一张，找到就免费，否则付钱。

核心是"如何快速找到可用的最早券"。

### 2. 隐藏条件

- 记录按时间严格递增，且**同一分钟不会有两条记录**。所以任意时刻有效（45 分钟内）的券最多 45 张。
- 券按获得时间入队，过期也是按时间顺序过期——队头过期了才轮到后面，可以用一个头指针 `h` 单调右移。

### 3. 注意事项

- $n \le 10^5$，如果每次从第一张券开始扫，最坏 $O(n^2)$ 会超时；必须跳过已过期的部分。
- 有效条件是 $t_{bus} - t_{subway} \le 45$（含等于）。
- 用掉的券不能删出队列中间（会打乱结构），打一个 `used` 标记即可。

### 4. 解决方案

数组 `q` 存所有地铁券，`h` 指向最后一张已过期的券。

对每条公交记录：
1. 当 `q[h+1]` 已过期（时间差 > 45）时 `h++`；
2. 从 `h+1` 往后扫到队尾，第一张"未使用且票价够"的券打上标记，本次免费；
3. 若没找到，花费加上票价。

由于有效券最多 45 张，第 2 步每次最多扫 45 张，总复杂度 $O(45n)$。

## 部分分策略 / 错误思路

- 每次从头扫整个券数组：$O(n^2)$，只有 30 分左右。
- 找到第一张**未过期**的券就用，而不检查票价是否够：错误，应跳过票价不够的券继续找。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5;
int n, ans, h;
struct ticket { int p, t; bool used; } q[N];
int tot;

void solve() {
    cin >> n;
    For(i, 1, n) {
        int op, p, t;
        cin >> op >> p >> t;
        if (op == 0) {
            ans += p, q[++tot] = {p, t, false};
            continue;
        }
        while (h < tot && t - q[h + 1].t > 45) h++;
        bool ok = false;
        For(j, h + 1, tot)
            if (!q[j].used && q[j].p >= p) {
                q[j].used = ok = true;
                break;
            }
        if (!ok) ans += p;
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
