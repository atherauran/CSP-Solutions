# P5663 CSP-J 2019 T4 加工零件

## 题意

$n$ 点 $m$ 边无向图。工人 $x$ 生产 $L$ 阶段零件，需要所有邻居生产 $L-1$ 阶段零件；$L=1$ 时邻居需提供原材料。$q$ 次询问：工人 $a$ 生产 $L$ 阶段零件时，1 号是否需要提供原材料。

**标签**：图论、BFS、最短路、奇偶性　**难度**：4/10

## 解题思路

### 1. 底层逻辑

"1 号需要提供原材料"等价于：存在一条从 $a$ 到 $1$、**长度恰好为 $L$** 的路径（可以重复走点和边）。

### 2. 隐藏条件

- 如果存在长度为 $k$ 的路径，那么沿任意一条边来回走一次，就得到长度 $k+2$ 的路径。所以只需知道从 1 到 $a$ 的**奇数长度最短路**和**偶数长度最短路**。
- 判定：$L$ 与最短路同奇偶，且最短路 $\le L$，就是 Yes。
- 前提：路径上至少有一条边可以来回走。只有 $a = 1$ 且 1 号是孤立点时，"长度 0 的路径"无法扩展。

### 3. 注意事项

- $L$ 最大 $10^9$，不能按阶段模拟。
- **特判**：1 号没有任何边时，所有询问都是 No（偶数最短路 $d[1][0]=0$ 会误判 $a=1$、$L$ 为偶数的情况）。
- 边权都为 1，BFS 即可，不需要 Dijkstra。

### 4. 解决方案

拆点 BFS：状态 $(u, k)$ 表示到达 $u$ 时路径长度的奇偶性为 $k$。从 $(1, 0)$ 出发，走一条边奇偶性翻转，求出 $d[u][0/1]$。

询问 $(a, L)$：若 $d[a][L \bmod 2] \le L$ 且 1 号有邻居，输出 Yes，否则 No。

复杂度 $O(n + m + q)$。

## 部分分策略 / 错误思路

- $L \le 1000$ 时可以做 $L$ 轮 BFS 层推（每层标记能到达的点），拿到 60 分左右。
- 只求普通最短路然后判 $d \le L$：忽略了奇偶性，错误。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5;
int n, m, q;
int d[N][2];
vector<int> g[N];

void solve() {
    cin >> n >> m >> q;
    For(i, 1, m) {
        int u, v;
        cin >> u >> v;
        g[u].pb(v), g[v].pb(u);
    }
    mset(d, 0x3f);
    queue<pii> qu;
    d[1][0] = 0, qu.push({1, 0});
    while (!qu.empty()) {
        int u = qu.front().F, k = qu.front().S;
        qu.pop();
        for (int v : g[u])
            if (d[v][k ^ 1] > d[u][k] + 1) {
                d[v][k ^ 1] = d[u][k] + 1;
                qu.push({v, k ^ 1});
            }
    }
    while (q--) {
        int a, l;
        cin >> a >> l;
        bool ok = d[a][l % 2] <= l && !g[1].empty();
        cout << (ok ? "Yes" : "No") << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
