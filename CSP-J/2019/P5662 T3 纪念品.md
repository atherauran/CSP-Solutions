# P5662 CSP-J 2019 T3 纪念品

## 题意

已知 $T$ 天里 $N$ 种纪念品每天的价格，每天可以无限次买卖（当天卖的钱当天可用，当天买的当天也能卖）。初始 $M$ 金币，第 $T$ 天必须全卖掉，求最终最多多少金币。

**标签**：动态规划、完全背包、贪心　**难度**：4/10

## 解题思路

### 1. 底层逻辑

多天持有一件物品的收益可以拆成相邻两天收益之和：第 $i$ 天买、第 $j$ 天卖，等价于"第 $i$ 天买、第 $i+1$ 天卖再买回、……、第 $j$ 天卖"。所以整个问题拆成 $T-1$ 个**独立的一天问题**：今天买、明天卖，求明天能拥有的最多金币。

每个一天问题是一个完全背包：容量是当前金币数 $m$，物品 $j$ 的代价是今天价格 $p_{i,j}$，价值是利润 $p_{i+1,j} - p_{i,j}$，可以无限次选。

### 2. 隐藏条件

- 当天买当天卖不赚不亏，所以"每天开始时手里全是金币"不会损失最优性——这正是拆天的依据。
- 利润 $\le 0$ 的物品不用考虑。
- 题目保证任意时刻金币不超过 $10^4$，背包容量有上界。

### 3. 注意事项

- 背包容量是**当天开始时**的金币数 $m$，每天结束要更新 $m \gets m + dp[m]$。
- 每天的 dp 都要清零重做。
- 复杂度 $O(T \cdot N \cdot M_{max}) = 100 \times 100 \times 10^4 = 10^8$，简单循环可以通过。

### 4. 解决方案

对第 $i = 1 \dots T-1$ 天：
1. `dp` 清零，`dp[k]` 表示花 $k$ 个金币今天买入、明天卖出能赚的最大利润；
2. 对每个 $p_{i+1,j} > p_{i,j}$ 的物品做完全背包：`dp[k] = max(dp[k], dp[k - p[i][j]] + p[i+1][j] - p[i][j])`，$k$ 从小到大；
3. $m \gets m + dp[m]$。

最后输出 $m$。

## 部分分策略 / 错误思路

- 只想着"哪天买哪天卖"直接搜索：状态爆炸。关键在于把持有多天拆成逐天交易。
- 把背包写成 01 背包（$k$ 从大到小）：每种纪念品只能买一个，错误。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 105, M = 1e4 + 5;
int t, n, m;
int p[N][N], dp[M];

void solve() {
    cin >> t >> n >> m;
    For(i, 1, t) For(j, 1, n) cin >> p[i][j];
    Rep(i, 1, t) {
        mset(dp, 0);
        For(j, 1, n)
            if (p[i + 1][j] > p[i][j])
                For(k, p[i][j], m) dp[k] = max(dp[k], dp[k - p[i][j]] + p[i + 1][j] - p[i][j]);
        m += dp[m];
    }
    cout << m;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
