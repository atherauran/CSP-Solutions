# P5660 CSP-J 2019 T1 数字游戏

## 题意

给一个长度为 8 的 01 串，输出其中 `1` 的个数。

**标签**：字符串、模拟　**难度**：1/10

## 解题思路

### 1. 底层逻辑

只有一个子问题：遍历字符串计数。

### 2. 隐藏条件

长度固定为 8，没有空格，直接按字符串读入即可。

### 3. 注意事项

比较的是字符 `'1'`，不是整数 `1`。若按整数读入会丢失前导 0，所以要按字符串读。

### 4. 解决方案

读入字符串，用 `count` 统计 `'1'` 的个数输出。$O(8)$。
