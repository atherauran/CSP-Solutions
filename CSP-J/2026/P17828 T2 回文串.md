# P17828 CSP-J 2026 T2 回文串

## 题意

字符串 $S$ 由 $n$ 段组成，第 $i$ 段是 $a_i$ 个字符 $c_i$。每次可以把一个位置改成任意字母，求把 $S$ 改成回文串的最少修改次数。$n \le 2 \times 10^5$，$a_i \le 10^9$。

**标签**：双指针、字符串、游程编码　**难度**：3/10

## 解题思路

### 1. 底层逻辑

回文要求 $s_i = s_{L+1-i}$，这 $\lfloor L/2 \rfloor$ 对位置互不干扰。每一对如果字符不同，改其中一个就行（代价 1）；相同则代价 0。所以答案就是**不匹配的对数**。

### 2. 隐藏条件

$L$ 可达 $2 \times 10^{14}$，不能展开字符串。但同一段内字符全相同，所以可以**整段整段地配对**：左指针从第 1 段往右走，右指针从第 $n$ 段往左走，每次取两边剩余长度的较小值 $t$，这 $t$ 对位置的左右字符分别都是 $c_l, c_r$，不同则答案加 $t$。

### 3. 注意事项

- 只配对前 $\lfloor L/2 \rfloor$ 对，所以每次的 $t$ 还要和"剩余对数"取 min，否则中间部分会重复计数。
- 左右指针可能指向同一段（从两端各自消耗），此时字符相同，不影响答案。
- $L$ 和答案都要用 64 位整数。

### 4. 解决方案

记 $x, y$ 为左、右当前段的剩余长度。循环直到配满 $\lfloor L/2 \rfloor$ 对：$t = \min(x, y, \text{剩余对数})$，若 $c_l \ne c_r$ 则 $ans \mathrel{+}= t$；$x, y$ 减 $t$，哪边用完就移动哪边的指针。每次至少用完一段，复杂度 $O(n)$。

## 部分分策略 / 错误思路

- $\max a_i$ 较小（$\le 500$）时 $L \le 10^8$，可以展开成字符串直接比较。
- 先合并相邻同字符的段不是必须的，双指针本身就能处理。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2e5 + 5;
int n, ans, len;
int a[N];
char c[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i] >> c[i], len += a[i];
    int half = len / 2, done = 0, l = 1, r = n, x = a[1], y = a[n];
    while (done < half) {
        int t = min({x, y, half - done});
        if (c[l] != c[r]) ans += t;
        done += t, x -= t, y -= t;
        if (!x) l++, x = a[l];
        if (!y) r--, y = a[r];
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
