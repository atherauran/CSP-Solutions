# P17830 CSP-J 2026 T4 纸牌游戏

## 题意

$n \le 5 \times 10^5$ 张牌，点数 $a_i \in [1, m]$。第 $i$ 局依次打出 $a_i, a_{i+1}, \dots, a_n$：桌上没有同点数的牌就放到最右端；有的话，收走那张牌及其右侧所有牌，再把新牌放到最右端。对每种点数 $v$，求 $n$ 局里有多少局结束时桌上留有 $v$。

**标签**：树形结构、子树大小、递推　**难度**：5/10

## 解题思路

### 1. 底层逻辑

关键在于**最左边那张牌永远不会被别的牌收走**（它左边没有牌），只会被同点数的牌"替换"。由此看第 $i$ 局的最终桌面 $f(i)$：

- 若 $a_i$ 之后还会出现，设下一次出现在 $nxt_i$。打出第 $nxt_i$ 张时，最左边的 $a_i$ 连同右边所有牌全被收走，桌面只剩 $[a_{nxt_i}]$——这和第 $nxt_i$ 局此刻的状态完全一样，所以 $f(i) = f(nxt_i)$。
- 若 $a_i$ 是该点数的**最后一次出现**，它会一直待在最左边且不与任何牌交互，右边的牌就是在独立地玩第 $i+1$ 局，所以 $f(i) = \{a_i\} \cup f(i+1)$。

### 2. 隐藏条件

把上面的递推看成一棵树：$i$ 的父亲 $fa_i$ 为 $nxt_i$（非最后一次出现）或 $i+1$（最后一次出现），根是虚点 $n+1$。

$f(i)$ 就是沿 $i$ 往根走时经过的所有"最后一次出现"位置的点数。点数 $v$ 只有一个最后出现位置 $lst_v$，所以 $v \in f(i)$ ⇔ $i$ 在 $lst_v$ 的子树里。

于是答案就是 $lst_v$ 的**子树大小**。

### 3. 注意事项

- $fa_i > i$，所以从小到大扫一遍就能累加子树大小：先 $sz_i \mathrel{+}= 1$，再 $sz_{fa_i} \mathrel{+}= sz_i$。处理到 $i$ 时它的孩子都比它小，已经加完了。
- $fa_n = n+1$，数组要多开一位。
- 每种点数至少出现一次，$lst_v$ 一定存在。

### 4. 解决方案

1. 从右往左扫，用 $pos_v$ 记录点数 $v$ 最近一次（更靠右的）出现位置：若 $v$ 之前出现过，$fa_i = pos_{a_i}$；否则 $i$ 是最后一次出现，记 $lst_{a_i} = i$，$fa_i = i + 1$。
2. 从左往右累加子树大小。
3. 输出 $sz_{lst_v}$。

复杂度 $O(n + m)$。

## 部分分策略 / 错误思路

- $n \le 5000$：每局用栈直接模拟，栈中同点数至多一张，用 `vis` 数组记录是否在栈中即可，总 $O(n^2)$。
- 性质 A（单调不降）：桌面上的牌点数严格递增，每种点数只看最后一次出现，第 $i$ 局留下的是 $a_i \sim a_n$ 中出现过的所有点数，前缀统计即可。
- 试图对每局维护整张桌面再"撤销"：桌面变化量太大，不可行。真正要抓住的是最左边那张牌的特殊地位。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 5e5 + 5;
int n, m;
int a[N], fa[N], sz[N], pos[N], lst[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i];
    for (int i = n; i >= 1; i--) {
        if (lst[a[i]]) fa[i] = pos[a[i]];
        else fa[i] = i + 1, lst[a[i]] = i;
        pos[a[i]] = i;
    }
    For(i, 1, n) sz[i]++, sz[fa[i]] += sz[i];
    For(v, 1, m) cout << sz[lst[v]] << " \n"[v == m];
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
