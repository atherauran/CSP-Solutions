# P17829 CSP-J 2026 T3 按位与

## 题意

从 $n$ 个非负整数中选**恰好** $m$ 个，使它们的按位与最大，输出这个最大值。$n \le 2 \times 10^5$，$a_i < 2^{30}$。

**标签**：贪心、位运算　**难度**：3/10

## 解题思路

### 1. 底层逻辑

按位贪心：二进制下高位的 1 比所有低位加起来都大，所以**从高位到低位**依次尝试让答案这一位为 1。

设已经确定的高位答案为 $ans$，尝试 $cur = ans \mid 2^b$：如果至少有 $m$ 个数满足 $a_i \mathbin{\&} cur = cur$（即 $a_i$ 包含 $cur$ 的所有 1），就能选出 $m$ 个数使与值包含 $cur$，于是 $ans = cur$；否则这一位只能是 0。

### 2. 隐藏条件

- "恰好 $m$ 个"不是问题：只要候选数不少于 $m$ 个，从中任选 $m$ 个，它们的与值都包含 $cur$。多出来的候选不需要全选。
- 最终 $ans$ 就是答案：最后剩下的候选中任选 $m$ 个，与值包含 $ans$；若与值比 $ans$ 多一个 1 位，贪心在那一位时就会成功，矛盾。

### 3. 注意事项

每一位都要用**包含之前所有已确定位**的 $cur$ 去筛，而不是只看第 $b$ 位，否则不同位上满足条件的可能是不同的数。

### 4. 解决方案

$b$ 从 29 到 0，统计 $(a_i \mathbin{\&} cur) = cur$ 的个数，不少于 $m$ 就更新答案。复杂度 $O(30n)$。

## 部分分策略 / 错误思路

- $n \le 20$：枚举所有大小为 $m$ 的子集。
- $m = 1$：输出最大值；$m = n$：输出全部的与。
- $m = 2$、$n \le 2000$：枚举所有数对。
- 错误思路：取最大的 $m$ 个数。如 $\{8, 7, 7\}$、$m = 2$，最大两个的与为 0，而 $7 \mathbin{\&} 7 = 7$。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2e5 + 5;
int n, m, ans;
int a[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) cin >> a[i];
    for (int b = 29; b >= 0; b--) {
        int cur = ans | (1LL << b), cnt = 0;
        For(i, 1, n) cnt += (a[i] & cur) == cur;
        if (cnt >= m) ans = cur;
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);

    while (tests--) solve();
    return 0;
}
