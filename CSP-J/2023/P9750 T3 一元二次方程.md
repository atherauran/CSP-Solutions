# P9750 CSP-J 2023 T3 一元二次方程

## 题意

给定整数系数 $a, b, c$（$a \ne 0$，$|a|,|b|,|c| \le 10^3$），输出 $ax^2 + bx + c = 0$ 的较大实根，按题目规定的最简格式（有理数、`q1+q2*sqrt(r)/...`）输出；无实根输出 `NO`。$T \le 5000$。

**标签**：数学、模拟、最简分数、根式化简　**难度**：4/10

## 解题思路

### 1. 底层逻辑

求根公式：$x = \dfrac{-b \pm \sqrt{\Delta}}{2a}$，$\Delta = b^2 - 4ac$。问题分成三步：
1. 判断 $\Delta < 0$；
2. 把 $\sqrt\Delta$ 化简为 $s\sqrt r$（$r$ 无平方因子）；
3. 按格式输出有理部分和根式部分。

### 2. 隐藏条件

- **先把 $a$ 变成正数**（$a, b, c$ 同时取反，方程不变）。这样较大的根就是取 `+` 号的那个：$x = \dfrac{-b}{2a} + \dfrac{s}{2a}\sqrt r$，并且 $q_2 = \frac{s}{2a} > 0$。
- $r = 1$（$\Delta$ 是完全平方数）或 $\Delta = 0$ 时，根是有理数：$\dfrac{-b + s}{2a}$。
- 否则 $q_1 = \frac{-b}{2a}$，$q_2 = \frac{s}{2a}$，两者分别约分输出。

### 3. 注意事项

- 有理数输出：约分后分母为正，分母为 1 只输出分子；0 输出 `0`。
- $q_1 = 0$（即 $b = 0$）时不输出 $q_1$ 和 `+`。
- $q_2 = p/q$ 约分后：$p = 1$ 时省略 `1*`，$q = 1$ 时省略 `/q`。
- $\Delta \le 5 \times 10^6$，试除到 $\sqrt\Delta$ 提取平方因子即可。
- macOS 的 clang 不支持 `long long` 版 `__gcd`，用 C++17 的 `gcd`。

### 4. 解决方案

对每组：
1. $a < 0$ 时三者取反；求 $\Delta$，小于 0 输出 `NO`；
2. 从 $i = 2$ 开始试除，把 $\Delta$ 中的 $i^2$ 因子提到 $s$ 中，剩下 $r$；
3. $\Delta = 0$ 或 $r = 1$：输出有理数 $\frac{-b + s'}{2a}$（$\Delta = 0$ 时 $s' = 0$）；
4. 否则：$b \ne 0$ 时输出 $\frac{-b}{2a}$ 和 `+`；再把 $\frac{s}{2a}$ 约分为 $\frac pq$，按 `p*` + `sqrt(r)` + `/q` 的规则拼接。

## 部分分策略 / 错误思路

- 性质 C（根都是整数）：直接算出来输出。
- 性质 A（$b = 0$）：没有有理部分。
- 常见错误：$a < 0$ 时没处理，较大根应取 `-` 号；分数没约分；负号放在分母上。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

int t, M;

void print(int p, int q) {
    int g = gcd(abs(p), q);
    p /= g, q /= g;
    cout << p;
    if (q != 1) cout << "/" << q;
}

void solve() {
    cin >> t >> M;
    while (t--) {
        int a, b, c;
        cin >> a >> b >> c;
        if (a < 0) a = -a, b = -b, c = -c;
        int dt = b * b - 4 * a * c;
        if (dt < 0) {
            cout << "NO" << endl;
            continue;
        }
        int s = 1, r = dt;
        for (int i = 2; i * i <= r; i++)
            while (r % (i * i) == 0) r /= i * i, s *= i;
        if (r == 0 || r == 1) {
            print(-b + (r ? s : 0), 2 * a);
            cout << endl;
            continue;
        }
        if (b != 0) print(-b, 2 * a), cout << "+";
        int g = gcd(s, 2 * a), p = s / g, q = 2 * a / g;
        if (p != 1) cout << p << "*";
        cout << "sqrt(" << r << ")";
        if (q != 1) cout << "/" << q;
        cout << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
