# P9749 CSP-J 2023 T2 公路

## 题意

$n$ 个站点排成一线，相邻站距离 $v_i$，站 $i$ 油价 $a_i$，只能加整数升，每升跑 $d$ 公里，油箱无限大。从站 1 空油箱出发到站 $n$，求最小花费。$n \le 10^5$。

**标签**：贪心　**难度**：3/10

## 解题思路

### 1. 底层逻辑

每一段路 $i \to i+1$ 所需的油，应该用**此前经过的站中最便宜**的油（可以提前在那里多加）。

### 2. 隐藏条件

- 由于只能加整数升，可能会多加一点油，多出的油留到后面用。多出来的油都是"当时最便宜的价格"买的，不会比后面的价格更贵，所以用掉它总是不亏。
- 因此可以按段推进：维护当前最低价 $mn$ 和油箱剩余可跑距离 $rem$。不够跑当前段时，在 $mn$ 价格处补 $\lceil (v_i - rem)/d \rceil$ 升。

### 3. 注意事项

- 花费可达 $10^5 \times 10^5 \times 10^5 = 10^{15}$，要用 64 位。
- 补油量是向上取整。

### 4. 解决方案

对 $i = 1 \dots n-1$：$mn = \min(mn, a_i)$；若 $rem < v_i$，补 $k = \lceil (v_i - rem)/d \rceil$ 升，花费 $k \cdot mn$，$rem \mathrel{+}= kd$；然后 $rem \mathrel{-}= v_i$。$O(n)$。

## 部分分策略 / 错误思路

- 性质 A（站 1 最便宜）：全部在站 1 加，$\lceil \sum v / d \rceil \cdot a_1$。
- 性质 B（$v_i$ 是 $d$ 的倍数）：不会有多余的油，直接每段乘最低价。
- 错误：每段单独向上取整而不保留剩余油量，会多花钱。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e5 + 5;
int n, d, ans, rem;
int v[N], a[N];

void solve() {
    cin >> n >> d;
    Rep(i, 1, n) cin >> v[i];
    For(i, 1, n) cin >> a[i];
    int mn = LINF;
    Rep(i, 1, n) {
        mn = min(mn, a[i]);
        if (rem < v[i]) {
            int k = (v[i] - rem + d - 1) / d;
            ans += k * mn, rem += k * d;
        }
        rem -= v[i];
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
