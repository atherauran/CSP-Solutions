# P9751 CSP-J 2023 T4 旅游巴士

## 题意

$n$ 点 $m$ 条单向边，每条边耗时 1，且只能在时刻 $\ge a_i$ 通过。必须在 $k$ 的倍数时刻从 1 号点出发、在 $k$ 的倍数时刻到达 $n$ 号点，中途不能停留。求最早到达时间，无解输出 `-1`。$n \le 10^4$，$m \le 2 \times 10^4$，$k \le 100$。

**标签**：最短路、Dijkstra、分层图（拆点）　**难度**：6/10

## 解题思路

### 1. 底层逻辑

不能停留 → 到达时刻 = 出发时刻 + 路径长度。要求两者都是 $k$ 的倍数 → 路径长度是 $k$ 的倍数。所以状态要记录"当前时刻 $\bmod k$"：**拆点** $(u, j)$。

### 2. 隐藏条件

- 开放时间的限制看似需要"等待"，但不能停留。**等价的做法是把出发时间推迟**：若到达边 $(u, v)$ 时时刻 $t < a$，就把整个行程推迟 $k$ 的若干倍，使 $t \ge a$。推迟 $k$ 的倍数不改变 $\bmod k$ 的状态，也不影响之前走过的边（推迟后时刻更晚，开放条件仍满足）。
- 所以从 $(u, j)$ 在时刻 $t$ 走边 $(u, v, a)$：$t' = t + \lceil (a - t)/k \rceil \cdot k$（若 $t < a$），到达 $(v, (j+1) \bmod k)$ 时刻 $t' + 1$。
- 每个状态的最早到达时刻越早越好（越早越容易满足后续限制，且推迟总是可行），满足 Dijkstra 的单调性。

### 3. 注意事项

- 状态数 $nk = 10^6$，边数 $mk = 2 \times 10^6$，Dijkstra 可以通过。
- 答案是 $dist[n][0]$，不可达输出 `-1`。
- 不能用 BFS：推迟操作使边权不再都是 1。

### 4. 解决方案

从 $(1, 0)$、时刻 0 出发做 Dijkstra；按上面的规则松弛。输出 $dist[n][0]$。复杂度 $O(mk \log(mk))$。

## 部分分策略 / 错误思路

- $a_i = 0$：没有开放限制，分层 BFS 即可。
- $k = 1$：不需要拆点，直接 Dijkstra。
- 二分出发时间 + BFS：也是常见正解思路之一（出发时间越晚越容易满足开放限制，具有单调性），复杂度 $O((n+m)k\log)$。
- 错误：在点上"等待"到开放时刻——题目不允许停留。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e4 + 5, K = 105;
int n, m, k;
int dist[N][K];
bool vis[N][K];
vector<pii> g[N];

void solve() {
    cin >> n >> m >> k;
    For(i, 1, m) {
        int u, v, a;
        cin >> u >> v >> a;
        g[u].pb({v, a});
    }
    mset(dist, 0x3f);
    priority_queue<pii, vector<pii>, greater<pii>> q;
    dist[1][0] = 0;
    q.push({0, 1 * K + 0});
    while (!q.empty()) {
        int d = q.top().F, u = q.top().S / K, j = q.top().S % K;
        q.pop();
        if (vis[u][j]) continue;
        vis[u][j] = true;
        for (auto e : g[u]) {
            int v = e.F, a = e.S, t = d;
            if (t < a) t += (a - t + k - 1) / k * k;
            int nj = (j + 1) % k;
            if (dist[v][nj] > t + 1) dist[v][nj] = t + 1, q.push({t + 1, v * K + nj});
        }
    }
    cout << (dist[n][0] >= LINF ? -1 : dist[n][0]);
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
