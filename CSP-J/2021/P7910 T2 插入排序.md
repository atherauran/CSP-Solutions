# P7910 CSP-J 2021 T2 插入排序

## 题意

长度 $n \le 8000$ 的数组，$Q \le 2 \times 10^5$ 次操作：单点修改（不超过 5000 次），或询问 $a_x$ 在**稳定**排序后的位置。

**标签**：排序、模拟　**难度**：4/10

## 解题思路

### 1. 底层逻辑

题目的插入排序只在 $a_j < a_{j-1}$ 时交换，所以它是**稳定排序**：值相同时按原下标排序。排序后 $a_x$ 的位置就是按 $(a_i, i)$ 二元组排序后的名次。

### 2. 隐藏条件

- 询问次数多（$2 \times 10^5$），修改次数少（5000）→ 让询问 $O(1)$，修改可以 $O(n)$。
- 维护按 $(值, 下标)$ 有序的数组 `b`，以及每个原下标在 `b` 中的位置 `pos`。修改一个值后，数组中只有这一个元素不在正确位置，像插入排序一样向左或向右冒泡即可，$O(n)$。

### 3. 注意事项

- 比较必须带上下标，否则相同值的顺序会错。
- 冒泡时要同步更新被交换元素的 `pos`。
- 修改总代价 $5000 \times 8000 = 4 \times 10^7$，可以接受；每次询问都重新排序则为 $2 \times 10^5 \times n \log n$，会超时。

### 4. 解决方案

1. 初始把 $(a_i, i)$ 排序得到 `b`，记录 `pos`。
2. 询问：直接输出 `pos[x]`。
3. 修改：令 $i = pos_x$，改 `b[i]` 的值；当 `b[i] < b[i-1]` 时与左边交换，当 `b[i+1] < b[i]` 时与右边交换，交换时更新 `pos`。

## 部分分策略 / 错误思路

- 每次询问都按题目模拟插入排序：$O(Qn^2)$，只能过小数据。
- 每次询问排序：约 52 分。
- 每次询问 $O(n)$ 数"比它小的个数 + 相同值中下标不超过它的个数"：$O(Qn) = 1.6 \times 10^9$，大数据超时，但思路正确。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 8005;
int n, q;
int pos[N];
pii b[N];

void solve() {
    cin >> n >> q;
    For(i, 1, n) cin >> b[i].F, b[i].S = i;
    sort(b + 1, b + 1 + n);
    For(i, 1, n) pos[b[i].S] = i;
    while (q--) {
        int op, x;
        cin >> op >> x;
        if (op == 2) {
            cout << pos[x] << endl;
            continue;
        }
        int v, i = pos[x];
        cin >> v;
        b[i].F = v;
        while (i > 1 && b[i] < b[i - 1]) swap(b[i], b[i - 1]), pos[b[i].S] = i, i--;
        while (i < n && b[i + 1] < b[i]) swap(b[i], b[i + 1]), pos[b[i].S] = i, i++;
        pos[x] = i;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
