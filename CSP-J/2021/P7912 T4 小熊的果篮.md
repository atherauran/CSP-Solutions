# P7912 CSP-J 2021 T4 小熊的果篮

## 题意

一排 $n$ 个 0/1 水果，连续相同的为一个"块"。每轮同时取出每个块最左边的水果作为一篮，取完后块可能合并。输出每一篮的编号。$n \le 2 \times 10^5$。

**标签**：链表、模拟　**难度**：5/10

## 解题思路

### 1. 底层逻辑

模拟每一轮：取出所有块的第一个元素、删除这些元素、删除空块、合并相邻同色块。难点在于让每一轮的代价与"块的数量"成正比，而不是与"剩余水果数"成正比。

### 2. 隐藏条件

- 每轮每个块至少被取走一个，所以每轮代价 $O(\text{块数})$ 的总和不超过 $n$。
- 一个块在剩余水果序列中始终是**连续的一段**：用双向链表维护还活着的水果，块就可以只记录**头**和**尾**两个结点。
- 合并只发生在中间的块被取空时，此时两个同色块在块序列中变成相邻。只需新块的尾 = 后一个块的尾，头不变——链表已把中间删掉的水果跳过了。

### 3. 注意事项

- 删除水果时必须真正从链表删除，否则合并后的块会走到已删除的元素上。
- 块的合并要在"本轮的块全部处理完"的同一遍扫描里完成：新块列表中相邻两块同色就合并。
- 输出量大，避免 `endl` 刷新（模板里 `endl` 已定义为 `'\n'`）。

### 4. 解决方案

1. 双向链表 `pre/nxt` 连接 $1 \dots n$；初始按颜色切分成块 `{头, 尾, 颜色}`。
2. 每轮遍历当前块列表：
   - 输出块头 $h$，把 $h$ 从链表删除；
   - 若 $h$ 就是块尾，这个块空了，丢弃；
   - 否则块头变为 `nxt[h]`，放入新列表——若新列表最后一个块同色，直接把它的尾改成本块的尾（合并）。
3. 新列表为空时结束。

总复杂度 $O(n)$。

## 部分分策略 / 错误思路

- 每轮扫描全部剩余水果：$O(n^2)$，70 分。
- 用 `vector::erase` 删除元素：同样是 $O(n^2)$。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2e5 + 5;
int n;
int a[N], pre[N], nxt[N];
struct block { int h, t, c; };
vector<block> bl, nb;

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i], pre[i] = i - 1, nxt[i] = i + 1;
    For(i, 1, n) {
        if (i == 1 || a[i] != a[i - 1]) bl.pb({i, i, a[i]});
        else bl.back().t = i;
    }
    while (!bl.empty()) {
        nb.clear();
        for (auto &b : bl) {
            cout << b.h << " ";
            nxt[pre[b.h]] = nxt[b.h], pre[nxt[b.h]] = pre[b.h];
            if (b.h == b.t) continue;
            b.h = nxt[b.h];
            if (!nb.empty() && nb.back().c == b.c) nb.back().t = b.t;
            else nb.pb(b);
        }
        cout << endl;
        swap(bl, nb);
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
