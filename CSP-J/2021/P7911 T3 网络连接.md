# P7911 CSP-J 2021 T3 网络连接

## 题意

$n \le 1000$ 台机器依次给出类型（Server/Client）和地址串。地址串规范为 `a.b.c.d:e`，$a \sim d \in [0,255]$，$e \in [0, 65535]$，无多余前导 0。服务机地址不合法输出 `ERR`，与已建立的重复输出 `FAIL`，否则 `OK`；客户机不合法 `ERR`，找到对应服务机输出其编号，否则 `FAIL`。

**标签**：字符串、模拟、map　**难度**：4/10

## 解题思路

### 1. 底层逻辑

两部分：
1. **地址串合法性检查**（本题的全部难点）；
2. 用 `map<string, int>` 记录"地址 → 服务机编号"，模拟连接。

### 2. 隐藏条件

合法地址可以按顺序逐段扫描：必须恰好是 5 段数字，前 3 段后面跟 `.`，第 4 段后跟 `:`，第 5 段后面就是串尾。只要顺序扫描并逐个检查分隔符，就能排除所有格式错误（多/少分隔符、分隔符顺序错、空段等）。

### 3. 注意事项

需要排除的情况：
- **空段**：如 `1..2.3:4`、`1.2.3.4:`；
- **前导 0**：段长大于 1 且首位是 `0`；
- **数值越界**：数字可能很长（如 `99999999999`），直接转整数会溢出，先判断长度（$> 5$ 一定非法）再转；
- **分隔符**：位置、种类、数量都必须严格匹配；
- 合法的地址才参与 `map` 比较；同一地址串必然逐字符相同，直接用字符串作为键即可。

### 4. 解决方案

`check(s)`：指针 $i$ 从 0 开始，第 $cnt$ 段：
1. 向后读连续数字到 $j$；若段为空、长度 $> 5$ 或有前导 0，返回非法；
2. 转成整数，前 4 段要求 $\le 255$；
3. 若是第 5 段，要求 $j$ 恰好是串尾且值 $\le 65535$；
4. 否则要求 $s_j$ 是对应的分隔符（前 3 段为 `.`，第 4 段为 `:`），$i = j + 1$ 继续。

扫描完还没到第 5 段就返回非法。主程序按题意查/插 `map` 输出。

## 部分分策略 / 错误思路

- 用 `sscanf(s, "%d.%d.%d.%d:%d")` 解析：需要额外检查"重新输出是否与原串相同"来排除前导 0 和多余字符，且数字过大时有溢出风险，容易漏情况。
- 忘记长度判断，`stoi` 遇到超长数字会抛异常或溢出。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

int n;
map<string, int> mp;

bool check(const string &s) {
    int cnt = 0, i = 0, len = s.size();
    while (i < len) {
        int j = i;
        while (j < len && isdigit(s[j])) j++;
        if (j == i || j - i > 5 || (s[i] == '0' && j - i > 1)) return false;
        int v = stoi(s.substr(i, j - i));
        cnt++;
        if (cnt <= 4 && v > 255) return false;
        if (cnt == 5) return j == len && v <= 65535;
        if (j == len || s[j] != (cnt < 4 ? '.' : ':')) return false;
        i = j + 1;
    }
    return false;
}

void solve() {
    cin >> n;
    For(i, 1, n) {
        string op, ad;
        cin >> op >> ad;
        if (!check(ad)) cout << "ERR" << endl;
        else if (op == "Server") {
            if (mp.count(ad)) cout << "FAIL" << endl;
            else mp[ad] = i, cout << "OK" << endl;
        } else {
            if (mp.count(ad)) cout << mp[ad] << endl;
            else cout << "FAIL" << endl;
        }
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
