# P7909 CSP-J 2021 T1 分糖果

## 题意

在 $[L, R]$ 中选一个整数 $k$，使 $k \bmod n$ 最大，输出这个最大值。$2 \le n \le L \le R \le 10^9$。

**标签**：数学、取模　**难度**：2/10

## 解题思路

### 1. 底层逻辑

"每人拿一块直到不足 $n$ 块"，剩下的就是 $k \bmod n$。问题就是区间内取模的最大值。

### 2. 隐藏条件

$k \bmod n$ 的最大可能值是 $n - 1$，在 $k = qn + n - 1$（即下一个 $n$ 的倍数前一个数）处取到。

- 若 $L$ 和 $R$ 在同一个"长度为 $n$ 的段"里（$\lfloor L/n \rfloor = \lfloor R/n \rfloor$），段内 $k \bmod n$ 随 $k$ 递增，最大值是 $R \bmod n$；
- 否则区间跨过了某个 $n$ 的倍数，它前面那个数就在 $[L, R]$ 中，答案是 $n - 1$。

### 3. 注意事项

$R - L$ 可达 $10^9$，枚举 $k$ 会超时。

### 4. 解决方案

$\lfloor L/n \rfloor = \lfloor R/n \rfloor$ 时输出 $R \bmod n$，否则输出 $n - 1$。$O(1)$。

## 部分分策略 / 错误思路

- 枚举 $k \in [L, R]$：$R - L \le 10^5$ 的点能过。
- 只判断 $R - L \ge n$：漏掉了长度小于 $n$ 但跨过倍数的情况（如 $n=10$，$L=9$，$R=11$）。
