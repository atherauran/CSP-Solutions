# P11229 CSP-J 2024 T3 小木棍

## 题意

用火柴棍拼数字（0~9 分别需要 6,2,5,5,4,5,6,3,7,6 根），恰好用 $n$ 根拼出无前导 0 的最小正整数，无解输出 `-1`。$n \le 10^5$，$T \le 50$。

**标签**：贪心、构造　**难度**：4/10

## 解题思路

### 1. 底层逻辑

比较正整数大小：**位数少的更小**；位数相同时**字典序**比较。所以先确定最少位数，再从高位到低位贪心放尽量小的数字。

### 2. 隐藏条件

- 每个数字用 $2 \sim 7$ 根，所以 $d$ 位数能用掉的根数恰好是区间 $[2d, 7d]$ 里的任意整数（每位可以在 2~7 之间任意调整）。
- 最少位数 $d = \lceil n / 7 \rceil$（$n \ge 2$ 时总能做到）。
- 贪心：第 $p$ 位从小到大试数字 $x$（首位从 1 开始），只要剩下的根数 $n - cost_x$ 能被剩下 $d - p$ 位用完（落在 $[2(d-p), 7(d-p)]$），就选它。

### 3. 注意事项

- $n = 1$ 无解。
- 首位不能是 0。
- 输出可能有 $10^4$ 多位，用字符串拼接。

### 4. 解决方案

$n = 1$ 输出 `-1`；否则 $d = \lceil n/7 \rceil$，逐位按上述规则贪心。复杂度 $O(10 \cdot n/7)$ 每组。

## 部分分策略 / 错误思路

- 也可以打表找规律：答案是"一个短前缀 + 若干个 8"，前缀只由 $n \bmod 7$ 决定（如余 1 时为 `10`，余 3 时为 `200` 等），但小 $n$ 需要单独处理，容易出错；贪心更不容易错。
- 错误贪心：每位直接选"用棍最少的最小数字"（如尽量放 1），会导致位数变多。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

int n;
int cost[10] = {6, 2, 5, 5, 4, 5, 6, 3, 7, 6};

void solve() {
    cin >> n;
    if (n == 1) {
        cout << -1 << endl;
        return;
    }
    int d = (n + 6) / 7;
    string ans;
    For(p, 1, d) For(x, p == 1 ? 1 : 0, 9) {
        int rem = n - cost[x], left = d - p;
        if (rem >= 2 * left && rem <= 7 * left) {
            ans += char('0' + x), n = rem;
            break;
        }
    }
    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
```
