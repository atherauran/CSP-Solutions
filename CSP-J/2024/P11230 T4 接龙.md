# P11230 CSP-J 2024 T4 接龙

## 题意

$n$ 个人各有一个整数序列。每轮一个人从自己序列中选长度 $[2, k]$ 的连续子段：第一轮以 1 开头，之后以上一轮的结尾开头；相邻两轮不能是同一个人。$q$ 次询问：能否恰好 $r$ 轮、最后一轮以 $c$ 结尾。$r \le 100$，$\sum l \le 2 \times 10^5$。

**标签**：动态规划、滑动窗口　**难度**：6/10

## 解题思路

### 1. 底层逻辑

按轮次 DP：记录"第 $r$ 轮可以以元素 $c$ 结尾"的信息，由第 $r - 1$ 轮推到第 $r$ 轮。询问直接查表。

### 2. 隐藏条件

- "相邻两轮不能同一人"的限制：第 $r$ 轮由人 $p$ 从元素 $c$ 开头，需要第 $r-1$ 轮存在**不是 $p$ 的人**以 $c$ 结尾。
- 所以不需要记录所有人，只需记录 $g_{r,c}$：
  - 0：没有人能以 $c$ 结尾；
  - $p$：只有人 $p$ 能；
  - $-1$：至少两个不同的人能（那么任何人都可以接）。
- 对人 $p$ 的序列，位置 $j$ 可以作为开头 ⇔ $g_{r-1, S_j} = -1$ 或 ($> 0$ 且 $\ne p$)。位置 $i$ 可以作为结尾 ⇔ 在 $[i-k+1, i-1]$ 中存在可作为开头的位置。从左往右扫，记录**最近的合法开头** $last$，判断 $i - last < k$ 即可。

### 3. 注意事项

- 第 1 轮的开头条件是元素为 1，任何人都可以。
- 复杂度 $O(100 \sum l)$，$T = 5$ 组共约 $10^8$ 次简单操作。
- $g$ 数组 $101 \times 2\times10^5$，每组数据清空。
- 同一位置先判断"能否作为结尾"，再判断"能否作为开头"，保证子段长度 $\ge 2$。

### 4. 解决方案

对 $r = 1 \dots 100$，对每个人 $p$ 扫描其序列：
1. 若 $i - last < k$，用 $p$ 更新 $g_{r, S_i}$（0 变 $p$；已是别人则变 $-1$）；
2. 若位置 $i$ 满足开头条件，$last = i$。

询问输出 $[g_{r,c} \ne 0]$。

## 部分分策略 / 错误思路

- 只记录"能否以 $c$ 结尾"的布尔值：无法处理"相邻两轮不同人"的限制，会错。
- 记录每个 $(r, c)$ 的所有人集合：空间时间都爆炸；关键观察是"两个以上的人"和"任意多人"等价。
- 对每个开头暴力标记后面 $k - 1$ 个位置：$O(100 \sum l \cdot k)$，超时。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 2e5 + 5, R = 105;
int n, k, q;
int g[R][N];
vector<int> s[N];

inline void upd(int &x, int p) {
    if (x == 0) x = p;
    else if (x != p) x = -1;
}

void solve() {
    cin >> n >> k >> q;
    For(i, 1, n) {
        int l;
        cin >> l;
        s[i].resize(l);
        for (int &x : s[i]) cin >> x;
    }
    Rep(r, 0, R) fill(g[r], g[r] + N, 0);
    For(r, 1, 100) For(p, 1, n) {
        int last = -LINF;
        Rep(i, 0, s[p].size()) {
            int c = s[p][i];
            if (i - last < k) upd(g[r][c], p);
            int pre = r == 1 ? (c == 1 ? -1 : 0) : g[r - 1][c];
            if (pre == -1 || (pre > 0 && pre != p)) last = i;
        }
    }
    while (q--) {
        int r, c;
        cin >> r >> c;
        cout << (g[r][c] != 0) << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
```
