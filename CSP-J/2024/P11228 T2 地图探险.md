# P11228 CSP-J 2024 T2 地图探险

## 题意

$n \times m$ 地图上有障碍，机器人每步：前方是界内空地就前进，否则右转。执行 $k$ 步后，求经过的不同格子数（含起点）。$n, m \le 10^3$，$k \le 10^6$，$T \le 5$ 组。

**标签**：模拟　**难度**：2/10

## 解题思路

### 1. 底层逻辑

直接按规则模拟 $k$ 步，用 `vis` 数组标记经过的格子并计数。

### 2. 隐藏条件

"右转"也算一步操作（位置不变）。$k \le 10^6$，模拟总量 $5 \times 10^6$，完全可行。

### 3. 注意事项

- 多组数据，`vis` 每组要清空。
- 方向数组顺序必须与题目一致：0 东、1 南、2 西、3 北。
- 起点也要计入。

### 4. 解决方案

按 `dx = {0,1,0,-1}`、`dy = {1,0,-1,0}` 模拟；前进到未访问的格子时答案 +1。$O(nm + k)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e3 + 5;
int n, m, k;
int dx[4] = {0, 1, 0, -1}, dy[4] = {1, 0, -1, 0};
char a[N][N];
bool vis[N][N];

void solve() {
    int x, y, d, ans = 1;
    cin >> n >> m >> k >> x >> y >> d;
    For(i, 1, n) For(j, 1, m) cin >> a[i][j], vis[i][j] = false;
    vis[x][y] = true;
    while (k--) {
        int nx = x + dx[d], ny = y + dy[d];
        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m && a[nx][ny] == '.') {
            x = nx, y = ny;
            if (!vis[x][y]) vis[x][y] = true, ans++;
        } else d = (d + 1) % 4;
    }
    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    cin >> tests;
    while (tests--) solve();
    return 0;
}
```
