# P7072 CSP-J 2020 T2 直播获奖

## 题意

依次给出 $n$ 个成绩（$0 \sim 600$），每给出一个，输出当前前 $\max(1, \lfloor p \cdot w\% \rfloor)$ 名的最低分（分数线）。$n \le 10^5$。

**标签**：桶、计数排序、模拟　**难度**：2/10

## 解题思路

### 1. 底层逻辑

每次插入一个数后，求当前所有数中**第 $k$ 大**的值。

### 2. 隐藏条件

成绩值域只有 $0 \sim 600$，可以开桶计数。从 600 往下累加个数，第一次累计 $\ge k$ 时的分数就是第 $k$ 大。

### 3. 注意事项

- 计划人数 $\lfloor p \times w / 100 \rfloor$ 用整数算，**不要用浮点数**（题目也提醒了精度问题）。
- 至少 1 人：取 $\max(1, \cdot)$。
- 每次都排序是 $O(n^2 \log n)$，会超时。

### 4. 解决方案

开桶 `cnt[0..600]`。每读入一个成绩就 `cnt[x]++`，计算 $k = \max(1, \lfloor pw/100 \rfloor)$，从 600 向下累加，累加和首次 $\ge k$ 时输出该分数。复杂度 $O(600n)$。

## 部分分策略 / 错误思路

- 每次插入后排序：只能过 $n \le 2000$ 左右。
- 用插入排序维护有序数组：$O(n^2)$，85 分左右。
- 对顶堆也可以 $O(n \log n)$ 做，但桶更简单。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

int n, w;
int cnt[605];

void solve() {
    cin >> n >> w;
    For(p, 1, n) {
        int x;
        cin >> x;
        cnt[x]++;
        int k = max(1LL, p * w / 100), sum = 0;
        for (int s = 600; s >= 0; s--) {
            sum += cnt[s];
            if (sum >= k) {
                cout << s << " ";
                break;
            }
        }
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);

    // cin >> tests;
    while (tests--) solve();
    return 0;
}
