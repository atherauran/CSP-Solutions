# P7074 CSP-J 2020 T4 方格取数

## 题意

$n \times m$ 方格，从左上走到右下，每步可以向上、向下或向右，不能重复经过格子。求经过格子数值之和的最大值。$n, m \le 1000$，数值可负。

**标签**：动态规划　**难度**：4/10

## 解题思路

### 1. 底层逻辑

因为不能向左走，路径一定是按列推进的：在每一列里先竖着走一段（只能一直向上或一直向下，否则会重复经过），然后向右进入下一列。

所以按列 DP：$dp_{i,j}$ 为走到 $(i,j)$ 的最大和。

### 2. 隐藏条件

- 在同一列内，由于不能重复经过，走过的格子是一段连续区间，且方向唯一（全向下或全向上）。
- 于是到达 $(i, j)$ 只有两种方式：从上方一路走下来，或从下方一路走上来。分别记为 `up[i]`（从上往下）和 `dn[i]`（从下往上）：
  - $up_i = \max(up_{i-1}, dp_{i,j-1}) + a_{i,j}$；
  - $dn_i = \max(dn_{i+1}, dp_{i,j-1}) + a_{i,j}$；
  - $dp_{i,j} = \max(up_i, dn_i)$。

  这里 $dp_{i,j-1}$ 表示"从左边进入这一列的第 $i$ 行"。

### 3. 注意事项

- 第一列只能从 $(1,1)$ 往下走。
- 数值有负数，边界初始化为 $-\infty$；答案可能为负。
- 结果最大约 $10^6 \times 10^4 = 10^{10}$，要用 64 位整数。

### 4. 解决方案

1. 第一列：$dp_{1,1} = a_{1,1}$，$dp_{i,1} = dp_{i-1,1} + a_{i,1}$。
2. 对 $j = 2 \dots m$：从上往下算 `up`，从下往上算 `dn`，取最大值得到 $dp_{\cdot,j}$。
3. 输出 $dp_{n,m}$。

复杂度 $O(nm)$。

## 部分分策略 / 错误思路

- 爆搜（DFS）：只能过 $n, m \le 5$。
- 把状态设为 $dp_{i,j}$ 然后直接从上、下、左三个方向转移：上下方向会互相依赖，转移成环，必须拆成"向上"和"向下"两个方向分别算。
- 用 `int` 存答案：可能溢出。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e3 + 5;
int n, m;
int a[N][N], dp[N][N], up[N], dn[N];

void solve() {
    cin >> n >> m;
    For(i, 1, n) For(j, 1, m) cin >> a[i][j];
    dp[1][1] = a[1][1];
    For(i, 2, n) dp[i][1] = dp[i - 1][1] + a[i][1];
    For(j, 2, m) {
        up[0] = dn[n + 1] = -LINF;
        For(i, 1, n) up[i] = max(up[i - 1], dp[i][j - 1]) + a[i][j];
        for (int i = n; i >= 1; i--) dn[i] = max(dn[i + 1], dp[i][j - 1]) + a[i][j];
        For(i, 1, n) dp[i][j] = max(up[i], dn[i]);
    }
    cout << dp[n][m];
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
