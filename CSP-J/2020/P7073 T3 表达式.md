# P7073 CSP-J 2020 T3 表达式

## 题意

给出一个后缀形式的逻辑表达式（`&`、`|`、`!`），每个变量恰好出现一次。$q$ 次询问：只把某个变量取反时，表达式的值是多少（询问互相独立）。$|s| \le 10^6$，$n, q \le 10^5$。

**标签**：表达式树、栈、树上标记　**难度**：5/10

## 解题思路

### 1. 底层逻辑

1. 用栈把后缀表达式建成**表达式树**，并算出每个结点的原值；
2. 对每个变量判断：它取反时，根的值会不会变？会变就输出原值取反，否则输出原值。

### 2. 隐藏条件

- 每个变量只出现一次 → 变量是树上的叶子，取反只影响它到根这条路径上的结点。
- 一个结点的变化能否传到父亲，只取决于父亲的运算和**兄弟的原值**：
  - `!`：一定传上去；
  - `a & b`：$b = 1$ 时 $a$ 的变化才能传上去（$b = 0$ 时结果恒为 0）；
  - `a | b`：$b = 0$ 时 $a$ 的变化才能传上去（$b = 1$ 时结果恒为 1）。
- 所以"能否影响根"可以从根往下一次性打标记：结点被标记 ⇔ 它的父亲被标记且这条边能传值。

### 3. 注意事项

- 表达式长度到 $10^6$，链状的 `!` 很多时递归可能很深；后缀建树时**孩子编号一定小于父亲**，所以按编号从大到小扫一遍即可完成自顶向下的标记，无需递归。
- 输入用 `getline` 读第一行，再按空格切分。
- 变量下标可能是多位数（`x10`），要完整解析。

### 4. 解决方案

1. 逐个读 token，每个 token 新建结点 $u$：
   - 变量 `xk`：记录 `id[k] = u`，`val[u] = x[k]`；
   - `!`：弹出一个作为孩子，`val[u] = !val[child]`；
   - `&` / `|`：先弹出右孩子，再弹出左孩子，算出 `val[u]`；
   - 把 $u$ 压栈。最后栈顶是根。
2. `flip[root] = 1`，按编号从大到小：若 `flip[u]` 为真，按上面的规则给孩子打标记。
3. 询问变量 $k$：输出 `val[root] ^ flip[id[k]]`。

复杂度 $O(|s| + q)$。

## 部分分策略 / 错误思路

- 每次询问重新求整个表达式的值：$O(q|s|)$，约 50 分。
- 只有 `&` 或只有 `|`：可以直接判断，20 分。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 1e6 + 5;
int n, q, tot;
int val[N], ls[N], rs[N], id[N];
char op[N];
bool flip[N];
stack<int> st;

void solve() {
    string line, t;
    getline(cin, line);
    cin >> n;
    vector<int> x(n + 1);
    For(i, 1, n) cin >> x[i];
    stringstream ss(line);
    while (ss >> t) {
        int u = ++tot;
        if (t[0] == 'x') {
            int k = stoi(t.substr(1));
            id[k] = u, val[u] = x[k], op[u] = 'x';
        } else if (t[0] == '!') {
            ls[u] = st.top(), st.pop();
            op[u] = '!', val[u] = !val[ls[u]];
        } else {
            rs[u] = st.top(), st.pop();
            ls[u] = st.top(), st.pop();
            op[u] = t[0];
            val[u] = t[0] == '&' ? (val[ls[u]] & val[rs[u]]) : (val[ls[u]] | val[rs[u]]);
        }
        st.push(u);
    }
    int root = st.top();
    flip[root] = true;
    for (int u = tot; u >= 1; u--) {
        if (!flip[u]) continue;
        int l = ls[u], r = rs[u];
        if (op[u] == '!') flip[l] = true;
        if (op[u] == '&') flip[l] = val[r], flip[r] = val[l];
        if (op[u] == '|') flip[l] = !val[r], flip[r] = !val[l];
    }
    cin >> q;
    while (q--) {
        int k;
        cin >> k;
        cout << (val[root] ^ flip[id[k]]) << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
