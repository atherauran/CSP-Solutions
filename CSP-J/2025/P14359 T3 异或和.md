# P14359 CSP-J 2025 T3 异或和

## 题意

长度 $n \le 5 \times 10^5$ 的序列，选尽量多的**互不相交**区间，每个区间异或和都等于 $k$。$a_i, k < 2^{20}$。

**标签**：贪心、前缀异或、区间调度　**难度**：4/10

## 解题思路

### 1. 底层逻辑

两步：
1. 用**前缀异或**判断区间：$[l, r]$ 的异或和为 $pre_r \oplus pre_{l-1}$，等于 $k$ ⇔ $pre_{l-1} = pre_r \oplus k$。
2. 选最多不相交区间：经典贪心——**右端点越早越好**。从左往右扫，一旦能以当前位置为右端点凑出一个合法区间（且左端点在上一个选中区间之后），就立刻选它。

### 2. 隐藏条件

贪心正确性：设最优解中第一个区间右端点为 $r^*$，贪心选的第一个右端点 $r \le r^*$，把最优解的第一个区间换成贪心的不会与后面冲突。归纳即可。

实现上：维护"上次切点之后出现过的前缀异或值"集合（包含切点处的前缀值）。扫到 $i$ 时若 $pre_i \oplus k$ 在集合中，答案 +1，并把集合清空、只保留 $pre_i$。

### 3. 注意事项

- 值域 $2^{20}$，用数组 + **时间戳**表示集合，"清空"只需时间戳 +1，避免每次 `memset`。
- 初始集合包含 $pre_0 = 0$。

### 4. 解决方案

`vis[x] == stamp` 表示 $x$ 在当前集合。初始 `vis[0] = stamp`。对每个 $i$：$cur \mathrel{\oplus}= a_i$；若 `vis[cur ^ k] == stamp`，答案 +1、`stamp++`；最后 `vis[cur] = stamp`。复杂度 $O(n)$。

## 部分分策略 / 错误思路

- $O(n^2)$ DP：$f_i = \max(f_{i-1}, \max_{j:\ [j,i] 合法} f_{j-1} + 1)$，$n \le 10^3$ 可过。
- 性质 A/B（$a_i \le 1$）：可以分类讨论 0 和 1 的个数。
- 用 `set`/`map` 维护集合并在切点清空：也能过，但常数较大。
