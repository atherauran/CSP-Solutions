# P14357 CSP-J 2025 T1 拼数

## 题意

字符串 $s$ 中有字母和数字（至少一个 $1 \sim 9$），用其中任意多个数字（每个最多用一次）拼成最大的正整数。$|s| \le 10^6$。

**标签**：贪心、计数　**难度**：1/10

## 解题思路

### 1. 底层逻辑

位数越多越大，所以**所有数字都要用上**；位数固定时，把大的数字放在高位，即按 $9 \to 0$ 降序排列。

### 2. 隐藏条件

保证至少有一个 $1 \sim 9$，降序排列后首位一定非 0，不会出现前导零。

### 3. 注意事项

- 结果最多 $10^6$ 位，只能当字符串输出，不能转成整数。
- 用计数代替排序，$O(|s|)$。

### 4. 解决方案

统计 `0`~`9` 各出现几次，从 9 到 0 依次输出对应个数的字符。

int cnt[10];

void solve() {
    cin >> s;
    for (char c : s)
        if (isdigit(c)) cnt[c - '0']++;
    string ans;
    for (int d = 9; d >= 0; d--) ans += string(cnt[d], '0' + d);
    cout << ans;
}
