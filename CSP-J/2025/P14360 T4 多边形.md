# P14360 CSP-J 2025 T4 多边形

## 题意

$n \le 5000$ 根木棍（长度 $\le 5000$），选出若干根能拼成多边形的条件是：至少 3 根且总长 $>$ 2 倍最长边。求方案数 mod 998244353。

**标签**：计数、0/1 背包、补集转化　**难度**：5/10

## 解题思路

### 1. 底层逻辑

条件"总长 $> 2\max$"等价于"**除最长边外其余边的和 $>$ 最长边**"。所以按最长边分类计数：排序后枚举第 $i$ 根作为最长边（下标最大者），在前 $i-1$ 根中选一个子集，要求子集和 $> a_i$。

### 2. 隐藏条件

- "子集和 $> a_i$"不好直接数，但"子集和 $\le a_i$"只涉及 $\le 5000$ 的和，可以用**背包计数**：$f_s$ = 前面的木棍中和为 $s$ 的子集个数。前 $i-1$ 根共 $2^{i-1}$ 个子集，减去 $\sum_{s \le a_i} f_s$ 即为合法数。
- "至少 3 根"自动满足：空集和 1 根（长度 $\le a_i$）都不满足和 $> a_i$。
- 长度相同的木棍按排序后的下标区分最长边，不会重复计数。

### 3. 注意事项

- 背包只需维护到 5000，更大的和不会被查询，直接截断。
- $2^{i-1}$ 要取模，减法加模数防负。
- 复杂度 $O(n \cdot \max a) = 2.5 \times 10^7$。

### 4. 解决方案

1. 排序，$f_0 = 1$，$pw = 1$（即 $2^0$）。
2. 对 $i = 1 \dots n$：答案加上 $pw - \sum_{s=0}^{a_i} f_s$；然后做 0/1 背包加入 $a_i$（$s$ 从大到小）；$pw \gets 2pw$。

## 部分分策略 / 错误思路

- $n \le 20$：枚举 $2^n$ 个子集直接判断。
- 所有 $a_i = 1$：任选 $\ge 3$ 根都合法，答案 $2^n - 1 - n - \binom n2$。
- 直接数"和 $> a_i$ 的子集"：和可能很大，背包开不下，必须转补集。

#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 5005, P = 998244353;
int n, ans, pw = 1;
int a[N], f[N];

void solve() {
    cin >> n;
    For(i, 1, n) cin >> a[i];
    sort(a + 1, a + 1 + n);
    f[0] = 1;
    For(i, 1, n) {
        int bad = 0;
        For(s, 0, a[i]) bad = (bad + f[s]) % P;
        ans = (ans + pw - bad + P) % P;
        for (int s = N - 1; s >= a[i]; s--) f[s] = (f[s] + f[s - a[i]]) % P;
        pw = pw * 2 % P;
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
