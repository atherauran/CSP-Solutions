# P8816 CSP-J 2022 T4 上升点列

## 题意

平面上 $n \le 500$ 个整点，可以再添加 $k \le 100$ 个任意整点。选出一个序列，相邻两点横坐标 +1 或纵坐标 +1，求最长长度。

**标签**：动态规划、LIS 变形　**难度**：4/10

## 解题思路

### 1. 底层逻辑

序列是一条向右/向上的单位步路径。选定的给定点按 $(x, y)$ 排序后，两个相邻的给定点 $j \to i$ 之间需要补 $d = (x_i - x_j) + (y_i - y_j) - 1$ 个点（要求 $x_j \le x_i, y_j \le y_i$）。这就是一个带"花费"的最长上升子序列。

### 2. 隐藏条件

- 添加的点没有坐标限制，用不完的点总能接在序列的开头（或结尾），每个点长度 +1。所以可以认为 $k$ 个点**全部用完**。
- 设 $dp_{i,c}$ = 以给定点 $i$ 结尾、恰好用了 $c$ 个添加点的最长长度：
  - 初值 $c + 1$（$c$ 个添加点全放在 $i$ 前面）；
  - 转移 $dp_{i,c} = \max_j dp_{j, c-d} + d + 1$。

### 3. 注意事项

- 坐标到 $10^9$，不能按坐标开数组 DP，只能在给定点之间转移。
- 按 $(x, y)$ 排序后，$j < i$ 只需再检查 $y_j \le y_i$。
- 复杂度 $O(n^2 k) = 2.5 \times 10^7$。

### 4. 解决方案

排序后按上述转移计算，答案为 $\max_i dp_{i,k}$。

## 部分分策略 / 错误思路

- $k = 0$：普通的二维偏序 LIS，只能连接相邻点。
- 坐标 $\le 100$：可以在网格上 DP。
- 忘了"剩余添加点可以接在末尾/开头"：答案会偏小。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

const int N = 505, K = 105;
int n, k, ans;
int dp[N][K];
pii p[N];

void solve() {
    cin >> n >> k;
    For(i, 1, n) cin >> p[i].F >> p[i].S;
    sort(p + 1, p + 1 + n);
    For(i, 1, n) For(c, 0, k) {
        dp[i][c] = c + 1;
        Rep(j, 1, i) {
            if (p[j].S > p[i].S) continue;
            int d = p[i].F - p[j].F + p[i].S - p[j].S - 1;
            if (d <= c) dp[i][c] = max(dp[i][c], dp[j][c - d] + d + 1);
        }
        if (c == k) ans = max(ans, dp[i][c]);
    }
    cout << ans;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
