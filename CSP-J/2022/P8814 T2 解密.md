# P8814 CSP-J 2022 T2 解密

## 题意

$k \le 10^5$ 次询问，给定 $n, d, e$，求正整数 $p \le q$ 使 $n = pq$ 且 $ed = (p-1)(q-1) + 1$，无解输出 `NO`。$n \le 10^{18}$，$m = n - ed + 2 \le 10^9$。

**标签**：数学、一元二次方程　**难度**：3/10

## 解题思路

### 1. 底层逻辑

展开第二个式子：$ed = pq - p - q + 2 = n - (p + q) + 2$，所以

$$p + q = n - ed + 2 = m,\qquad pq = n$$

已知两数之和与积，$p, q$ 是方程 $x^2 - mx + n = 0$ 的两根。

### 2. 隐藏条件

$p, q = \dfrac{m \mp \sqrt{\Delta}}{2}$，$\Delta = m^2 - 4n$。有正整数解需要：
- $\Delta \ge 0$ 且是完全平方数；
- $m - \sqrt\Delta$ 为正偶数（此时 $m + \sqrt\Delta$ 也是偶数）。

### 3. 注意事项

- $m \le 10^9$，$m^2 \le 10^{18}$；$4n \le 4 \times 10^{18}$，都在 `long long` 范围内。
- `sqrt` 对 $10^{18}$ 级别的数有精度误差，用 `sqrtl` 后再上下微调，保证 $s = \lfloor\sqrt\Delta\rfloor$。
- 输入顺序是 $n, d, e$，只用到乘积，不影响。

### 4. 解决方案

对每个询问：算 $m$ 和 $\Delta$；$\Delta < 0$ 输出 `NO`；否则求整数平方根 $s$，若 $s^2 \ne \Delta$ 或 $m - s$ 为奇数或 $\le 0$ 输出 `NO`，否则输出 $\frac{m-s}{2}, \frac{m+s}{2}$。$O(k)$。

## 部分分策略 / 错误思路

- 枚举 $p$ 到 $\sqrt n$：只能过 $n \le 10^9$ 的部分。
- 直接 `sqrt(double)` 不修正：大数据可能误判。

#include <bits/stdc++.h>

#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

int k;

void solve() {
    cin >> k;
    while (k--) {
        int n, d, e;
        cin >> n >> d >> e;
        int m = n - e * d + 2, dt = m * m - 4 * n;
        if (dt < 0) {
            cout << "NO" << endl;
            continue;
        }
        int s = sqrtl(dt);
        while (s * s > dt) s--;
        while ((s + 1) * (s + 1) <= dt) s++;
        if (s * s != dt || (m - s) % 2 || m - s <= 0) cout << "NO" << endl;
        else cout << (m - s) / 2 << " " << (m + s) / 2 << endl;
    }
}

    // cin >> tests;
    while (tests--) solve();
    return 0;
}
