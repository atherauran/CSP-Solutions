# P8815 CSP-J 2022 T3 逻辑表达式

## 题意

给定含 `0`、`1`、`&`、`|`、括号的表达式（`&` 优先于 `|`，同级从左到右），按短路规则求值，并统计 `&` 短路与 `|` 短路的次数（被外层短路跳过的部分不计）。$|s| \le 10^6$。

**标签**：表达式求值、栈　**难度**：5/10

## 解题思路

### 1. 底层逻辑

1. 处理优先级和括号：用经典的**双栈法**（操作数栈 + 运算符栈）；
2. 处理短路计数：让每个操作数栈里的元素不只存值，而是存一个**子表达式的结果** $(v, cA, cO)$：值、该子表达式求值过程中的 `&` 短路数和 `|` 短路数。

### 2. 隐藏条件

合并 `a op b` 时：
- `a & b` 且 $a.v = 0$：短路，$b$ 根本不会被计算，所以 $b$ 内部的短路**都不算**：结果为 $(0,\ a.cA + 1,\ a.cO)$；
- `a | b` 且 $a.v = 1$：同理，结果为 $(1,\ a.cA,\ a.cO + 1)$；
- 否则不短路，结果值就是 $b.v$，计数相加。

这样"外层短路内部不计"的规则自然满足。

### 3. 注意事项

- `&` 优先级高于 `|`：遇到 `&` 时只弹出栈顶的 `&`；遇到 `|` 时弹出直到 `(`；遇到 `)` 弹出直到 `(`。同级左结合，所以相同优先级也要先弹。
- $|s| = 10^6$，递归下降解析可能递归很深，双栈法没有这个问题。

### 4. 解决方案

扫描字符：
- 数字：压入 $(c, 0, 0)$；
- `(`：压入运算符栈；
- `)`：不断计算直到栈顶为 `(`，弹出 `(`；
- `&`：当栈顶是 `&` 时计算，然后压入；
- `|`：当栈顶不是 `(` 时计算，然后压入。

最后把剩余运算符算完，输出栈顶的 $v$、$cA$、$cO$。复杂度 $O(|s|)$。

## 部分分策略 / 错误思路

- 没有括号：可以按 `|` 分段，每段是一串 `&`。
- 只统计"每次合并时左值为 0/1"而不丢弃右侧的计数：会把外层短路内部的短路也算上。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
#define pb push_back
#define F first
#define S second
#define For(i, a, b) for (int i = (a); i <= (b); i++)
#define Rep(i, a, b) for (int i = (a); i < (b); i++)
#define mset(arr, x) memset(arr, x, sizeof(arr))
#define dbg(x) cout << #x << " = " << x << endl

#define int long long
typedef long long ll;
typedef unsigned long long ull;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const double EPS = 1e-9;
const int MOD = 1e9 + 7;

struct node { int v, a, o; };
stack<node> num;
stack<char> op;
string s;

inline void calc() {
    node b = num.top();
    num.pop();
    node a = num.top();
    num.pop();
    char c = op.top();
    op.pop();
    if (c == '&') num.push(a.v == 0 ? node{0, a.a + 1, a.o} : node{b.v, a.a + b.a, a.o + b.o});
    else num.push(a.v == 1 ? node{1, a.a, a.o + 1} : node{b.v, a.a + b.a, a.o + b.o});
}

void solve() {
    cin >> s;
    for (char c : s) {
        if (c == '0' || c == '1') num.push({c - '0', 0, 0});
        else if (c == '(') op.push(c);
        else if (c == ')') {
            while (op.top() != '(') calc();
            op.pop();
        } else if (c == '&') {
            while (!op.empty() && op.top() == '&') calc();
            op.push(c);
        } else {
            while (!op.empty() && op.top() != '(') calc();
            op.push(c);
        }
    }
    while (!op.empty()) calc();
    cout << num.top().v << endl << num.top().a << " " << num.top().o;
}

signed main() {
    ios::sync_with_stdio(false), cin.tie(nullptr);
    // freopen("xxx.in", "r", stdin);
    // freopen("xxx.out", "w", stdout);
    int tests = 1;
    // cin >> tests;
    while (tests--) solve();
    return 0;
}
```
