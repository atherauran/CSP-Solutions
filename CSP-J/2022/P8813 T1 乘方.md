# P8813 CSP-J 2022 T1 乘方

## 题意

给定 $a, b \le 10^9$，若 $a^b \le 10^9$ 输出 $a^b$，否则输出 `-1`。

**标签**：模拟、数学　**难度**：2/10

## 解题思路

### 1. 底层逻辑

逐次乘 $a$，一旦超过 $10^9$ 就停止输出 `-1`。

### 2. 隐藏条件

- $a \ge 2$ 时最多乘约 30 次就会超过 $10^9$，所以循环次数很少。
- 唯一的例外是 $a = 1$：结果永远是 1，但循环会跑 $b = 10^9$ 次——要**特判**。

### 3. 注意事项

- 用 64 位整数：$10^9 \times 10^9 = 10^{18}$ 不会溢出 `long long`，每次乘完立刻判断即可。
- 不要用 `pow`：浮点误差可能导致边界判断出错。

### 4. 解决方案

$a = 1$ 输出 1；否则循环 $b$ 次累乘，每次乘后若 $> 10^9$ 输出 `-1` 结束。复杂度 $O(\log_a 10^9)$。

## 部分分策略 / 错误思路

- 忘记特判 $a = 1$：$b$ 很大时超时（洛谷的 Hack 数据专门卡这一点）。
- 用 `int` 累乘：溢出后变成负数或小数，判断失效。
